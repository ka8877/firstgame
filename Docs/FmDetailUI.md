# 판타지마스터즈 디테일 개정

`fm-detail-2026-10-27`은 원작 카드·규칙·음악과 전투 스냅샷을 유지하며 시작·로비·프로필·백필드를 보강한다. 새 실행 결과는 이번 릴리스 검증 문서를 따른다.

## 시작과 로비

시작 화면은 새로 제작한 성채·숲·천구의 파노라마를 사용한다. 이 배경은 원작 클라이언트에서 복원한 그림으로 소개하지 않는다. 원작 인쇄 카드 세 장은 별도 작은 카드 팬으로 배치하며 기존 원작 로그인 타일은 보존한다. 큰 제목·속성·실제 카드/등급/기본 덱 수·시작/이어하기/도감/프로필/음악을 분리하고 버튼은 실제 경로에 연결한다.

로비는 대전실 목록, 도감·덱·프로필의 상단 동선, 우측 로컬 프로필·현재 덱, 아래 규칙·등급·분석과 저장 경로를 제공한다. 원작2005 안내의 대전실과 우측 사용자 정보 구성을 참고하되 가상의 접속자·온라인 방·채팅·SP/XP 경제는 만들지 않는다. 연습방의 승리 표시는 실제 기존 `FC.demo.won.*`에 연결한다.

## 백필드

2005 공식 `interface-game.png`와 공식 안내의 `14. 백필드`는 지형을 전열 아래에 최대10장 배치한다고 설명한다. 2017 실제 플레이 `0090.0s.png`에서도 지형 세 장의 원화가 전열과 손패 사이에 보인다. 출처와 원본 해시는 기존 `Tools/Research/FmFidelity` 기록을 따른다.

단색 지형 표식을 실제 `BattleDisplayState.players[owner].terrain`의 원화 줄로 바꿨다. 내 지형은 전열과 손패 사이, 상대 지형은 상단에 보인다. 지형의 순서·개수·속성과 세부 정보는 현재 실제 카드에서 읽는다. 최대10장의 빈 자리와 배치된 원화를 구분하고 클릭/길게 누르기로 원본 상세를 연다. 작은 화면은 읽을 수 없는 짧은 이름 대신 원화와 속성 기호를 표시하며 상세에서 전체 이름과 수치를 확인한다.

`Terrain drop band`의 부모 드롭 타깃과 자식의 raycast/조상 검색을 유지한다. 새 지형도 손패에서 이 줄로 끌어놓아 실제 Core의 LP/수용량 검사를 거친다. 불법 드롭은 소비하지 않는다. 지형 배치 이벤트는 실제 원본 카드의 화면 복사본이 손패에서 다음 백필드 칸으로 이동한 뒤 해당 스냅샷을 표시한다. 연출은 추가 카드를 생성하거나 RNG를 소비하지 않는다.

## 로컬 프로필

`FC.profile.name`은12자 닉네임, `FC.profile.avatar`는 원작 유닛 카드 ID다. 일곱 원작 카드 아바타 중 선택하고 닉네임을 저장할 수 있다. 아바타는 전투 능력을 부여하지 않는다. 선택은 PlayerPrefs에 저장하며 기존 전투/덱 슬롯과 콘텐츠 버전은 유지한다.

`FC.profile.wins/losses/draws`는 실제 완료 상태가 결과 화면에 도착했을 때만 기록한다. 완료 상태 전체의 `Hash128`으로 `FC.profile.recorded.<hash>`를 저장하므로 같은 결과의 UI 재생성·완료 저장 이어하기가 전적을 중복 집계하지 않는다. 중도 종료를 패배로 꾸미거나 과거 승리 플래그를 총 승수로 추정하지 않는다. 이전부터 존재한 연습방 승리 수는 별도 표시한다.

프로필은 이 브라우저·기기에 저장된 단일 로컬 기록이다. 온라인 계정, 실서비스 랭크, SP·XP·수집 완료율이나 다른 기기 동기화를 주장하지 않는다. 저장 옮기기의 기존 전투 파일에 프로필을 몰래 넣지 않는다.

## 검증 경로

릴리스 담당은 새 실행에서 시작 파노라마/도감 실제 개수, 닉네임·아바타 변경 후 새로고침 복원, 실제 지형 드래그 후 원화·Core 지형 수/소울 일치, 지형 상세와 돌아오기, 완료 결과의 전적 단 한 번 증가를 확인한다. 코인·공방·기존 저장·장면별 원작 음악을 유지한다. 이 문서의 구현 설명은 실행 통과나 미적 사용자 승인 대신 쓰지 않는다.
