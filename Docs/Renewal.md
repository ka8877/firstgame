## 판타지마스터즈

앞선 605종은 원본 자료의 총수가 아니라 당시 지원한 기술 범위로 골라 넣은 전투 카탈로그였다. 이번에는 공개 커뮤니티 DB를 정렬 커서로 마지막 빈 페이지까지 조회했다. 서로 다른 ID 15,350개와 전체 필드를 확보했으며, 원본 클라이언트의 종료일 전체 카탈로그와 같다고 확정하지 않는다. 임시값과 미지원 효과도 포함되므로 원본 자료 도감과 실제 출전 카드를 구분한다.

서비스 후기의 화면은 2017년 원작 영상과 종료 직전 공식 웹 보존 자료를 우선한다. 과거 2005년 매뉴얼, 2017년 영상, 현재 커뮤니티 DB의 정보를 연도와 근거에 맞게 구분한다. 원작 개발 소스·마지막 클라이언트 전체 복구라고 소개하지 않는다.

손패와 전열의 카드가 직접 플레이하는 대상이다. 전체 인쇄의 원래 비율을 유지하고 AP/DP/HP, 코인 앞뒤와 변화량을 카드에 붙인다. 실제 Core 판정과 중간 상태를 재생하며 UI가 다시 코인을 굴리지 않는다. 공개 카드 이미지는 필요한 화면에서 불러오는 방식으로 확장하고, 확보한 원본과 배포용 변환의 출처·해시를 기록한다. 현재 소스의 출전 카드는2,571종(기존605종과 신규1,966종), 기본 덱은27개다. 유니크23·레전드4·시크릿15·스페셜27종이 실제 전투 지원 대상이다. 전체 원본 DB15,350개가 모두 출전 가능하다는 뜻은 아니다. 원본 그림의 확보·누락 및 실제 빌드 검증은 데이터·릴리스 기록에서 별도로 확인한다.

장면 음악 전환은 같은 길이의 페이드 곡선으로 정돈하고 효과음은 클릭·카드 배치·코인·공격·피해에 맞춰 구분한다. 실제 음악 출력과 효과음 확인은 이번 실행 증거를 따른다. 원작 음원의 발췌 편집을 전체 OST 복구로 바꾸어 소개하지 않는다.

## 예수님의 길

새 그림 오프닝은 탄생, 성경에 기록된 어린 시절, 열두 살의 예루살렘 방문을 소개한다. 첫 플레이의 나이를 명확히 표시하며 기록되지 않은 성장기를 사실로 창작하지 않는다. 이어지는 걷기와 NPC 대화에서 말씀을 획득하고, 도감에서 획득한 구절을 다시 읽는다. 성경 인용과 학습을 위한 극화 대화·해설은 구분한다.

기존 탄생과 성전 본문의 순서·저장을 보존하면서 새 대화와 여덟 학습 지점을 확장한다. 읽기·탐색 약10분 이상의 초반 여정을 목표로 구성하며 강제 대기시간을 추가하지 않는다. 빠르게 넘기면 더 짧게 진행할 수 있고, 분량 추정과 실제 실행 시간은 구분한다. 전체 생애는 후속 범위다.

주인공은 발을 딛는 구간과 발을 내딛는 구간에 따라 무릎·발목을 움직이고 상체·팔·머리·옷자락을 함께 다듬는다. 기존 숲의 2D 조명과 깊이는 유지한다. 튜닉·샌들·물주머니·등잔·수첩·안내도는 새 원화와 설명을 가진 학습용 소지품이다. 등잔은 장착과 실제 손의 불빛·저장에 연결한다. 실제 성경에 나열된 소유품이라는 뜻은 아니다.

새 탄생 그림과 소지품 원화의 출처·해시는 `Tools/Art/GospelRenewal`에 있다. Unity 공식 Lost Crypt 자산의 출처·라이선스는 기존 [2D 참고 자료](GospelLuminousReferences.md)를 보존한다.
