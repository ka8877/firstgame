# 첫 플레이 안내

두 게임은 각각 실행하는 싱글 플레이 개발판입니다. 카드 원화는 승인 전 후보이며 인물·공간·효과음에는 임시 에셋이 포함돼 있습니다. 빌드 및 플랫폼 검증의 최신 상태는 [검증 기록](Validation.md)을 참고하세요.

## Windows와 Web 실행

| 게임 | Windows ZIP의 실행 파일 | Web ZIP의 시작 파일 |
|---|---|---|
| 별빛의 서약 | `FantasyCards-Windows/FantasyCards.exe` | `FantasyCards-Web/index.html` |
| 새벽의 길 | `PathOfDawn-Windows/PathOfDawn.exe` | `PathOfDawn-Web/index.html` |

**Windows:** 해당 ZIP을 폴더째 압축 해제한 뒤 실행 파일을 여세요. `.exe`와 같은 위치의 DLL·데이터·런타임 폴더를 함께 두어야 합니다. ZIP 안에서 실행하거나 `.exe`만 다른 곳으로 옮기면 필요한 파일을 찾지 못합니다.

**Web:** 압축 해제한 폴더 전체를 HTTP/HTTPS 서버에서 제공해야 합니다. `index.html`을 더블클릭하는 `file://` 실행은 지원하지 않습니다. Python이 설치돼 있다면 `index.html`이 있는 폴더의 터미널에서 다음 명령을 실행할 수 있습니다.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

브라우저 주소창에 `http://127.0.0.1:8000`을 입력하고 로딩이 끝나면 게임 영역을 클릭하세요. 서버 터미널은 플레이하는 동안 열어 두고, 종료할 때 `Ctrl+C`를 누릅니다. 두 게임을 동시에 제공하려면 두 번째 서버에 다른 포트를 지정하세요. 브라우저 저장은 서버 주소와 포트에 따라 분리되므로 이어하기를 확인할 때는 같은 주소를 사용하세요.

## 별빛의 서약: 첫 결투

첫 체험은 기본 덱으로 시작하면 아래 순서를 그대로 따라갈 수 있습니다. 덱을 수정했다면 손패와 사용 가능한 카드는 달라집니다.

1. 타이틀의 **새로운 결투**를 누르고 짧은 도입 연출이 끝날 때까지 기다립니다.
2. 아래 손패의 **새벽의 정원**을 선택하고 왼쪽 **지형 전개**를 누릅니다. 내 지형에 카드 이름이 나타나고 여명 자원이 1 증가합니다. 지형은 턴마다 한 장 전개할 수 있고, 이후에도 전장에 남아 내 턴 시작에 자원을 생산합니다.
3. 손패의 **별길의 정찰자**를 선택한 뒤 아래쪽 아군의 빈 **전장** 칸을 누릅니다. 여명 1을 지불해 유닛이 남습니다. 소환한 턴에는 공격하거나 가로막을 수 없으므로 첫 턴은 **턴 종료**로 넘기세요.
4. 상대 행동이 끝나 내 턴이 되면 지형·유닛을 추가하거나 마법·장비를 사용합니다. 비용의 속성도 맞아야 합니다. 마법/장비를 선택하면 설명에 맞는 아군 또는 적 유닛 칸을 누르세요. **확대 보기**에서 상세 효과를 확인할 수 있습니다.
5. 준비를 마쳤으면 **공격 단계** → 준비된 아군 유닛 → 위쪽 적 유닛 또는 **달의 수호자 생명** 표시를 순서대로 누릅니다. AI가 가로막을지 판단한 뒤 전투를 처리합니다. 공격 단계에 들어가면 그 턴의 카드 사용은 끝납니다.
6. 상대가 공격하면 **방어 대응**에서 준비된 아군 유닛을 선택해 가로막거나 **가로막지 않기**를 누릅니다. 공격에 참여한 유닛은 행동을 마치므로, 상대 턴의 방어에 남겨 둘 유닛도 생각해 보세요.
7. 코인은 전투 때 자동으로 결정됩니다. 연출과 오른쪽 **전투 기록**에서 앞/뒷면·공격력·피해·반격을 확인하세요. 효과 재생 중에는 입력이 잠깁니다. 공격을 마치면 **공격 종료 · 턴 넘기기**를 누릅니다.
8. 승리·패배 또는 무승부 화면에서 **같은 결투 재도전**으로 새 전투를 시작하거나 **덱을 다듬기**로 구성을 바꿉니다. 같은 덱의 재도전은 같은 시작 조건을 사용합니다.

**덱 편집:** 타이틀의 **덱 구성 · 24장**에서 카드별 `-/+`를 누릅니다. 저장 조건은 총 24장, 지형 4장 이상, 유닛 6장 이상, 같은 카드 최대 4장입니다. **덱 저장**으로 다음 결투에 적용하고, **기본 덱 복원** 후 **덱 저장**으로 초기 구성을 되돌릴 수 있습니다. **카드 도감**에서는 16종의 상세 내용을 볼 수 있습니다.

**저장·복귀:** 유효한 행동 뒤 자동 저장됩니다. 상단 **저장** → **타이틀** → **이어하기**로 같은 전투에 복귀할 수 있습니다. **새로운 결투**는 현재 전투 저장을 교체하므로 보관할 전투가 있다면 먼저 아래 방식으로 내보내세요.

저장에 실패하면 오류를 표시하고 현재 전투 화면에 머뭅니다. 저장 공간이나 접근 문제를 해결한 뒤 **저장**을 다시 눌러 성공을 확인하세요. 저장하지 못한 최신 진행은 프로그램을 닫으면 보존되지 않습니다.

## 새벽의 길: 첫 대화와 두 번의 선택

1. **새 게임**을 누릅니다. 기존 저장이 있으면 안내 후 **새 여정 시작**을 선택합니다. 기존 파일은 보존되며 이 기기의 이어하기 대상은 새 여정으로 바뀝니다.
2. 도입 조망이 끝나면 **다음 대사 [E]**와 **계속 [E]**를 클릭하거나 `E`를 눌러 도입 대사를 읽습니다. 대화창을 닫으면 이동할 수 있습니다.
3. `WASD`/방향키로 걷고 마우스 오른쪽 버튼을 누른 채 드래그해 시점을 바꿉니다. 처음에는 앞쪽 호숫가의 예수님에게 다가갑니다. 화면 아래 **[E] 예수님과 미리암에게 말 걸기**가 보이면 `E`를 누릅니다. 다른 조사 안내가 보인다면 인물에게 더 가까이 이동하세요.
4. 대사를 읽고 **선택하기 [E]**까지 진행한 뒤 원하는 선택문을 클릭합니다. 선택 뒤의 대사도 끝까지 읽으세요.
5. 화면 위 목표가 **왼쪽 석조 방에서 미리암과 이야기하세요.**로 바뀝니다. 석조 방의 열린 문으로 들어가 **[E] 미리암과 바구니에 관해 이야기하기**가 보일 때 `E`를 누릅니다. 대사 뒤 두 번째 선택을 하고 결과 대사까지 읽으면 발견한 길 화면이 나옵니다.
6. **기억을 품고 과거로** 또는 이동 중 `M`/상단 **기억 / 회귀 [M]**에서 방문한 선택 직전으로 돌아갈 수 있습니다. 세계·소지품·관계는 되돌아가고 발견한 길·단서·누적 선택 기록은 남습니다. 도입이나 대화 중에는 이동 입력이 제한됩니다.

상단 **저장**, `Esc`의 **저장하고 타이틀로**, 타이틀의 **이어하기**로 여정을 보관하고 복귀합니다. 선택과 회귀 시에도 자동 저장됩니다. 설정에서는 한국어 자막 크기와 전체 음량을 조절할 수 있습니다. 시계·호숫가 바구니·돌벽의 등불 자리는 가까이 가서 `E`로 조사합니다.

현재 이어하기는 세계·위치·선택·기억을 복원하지만 대사는 해당 묶음의 처음부터 다시 표시하며, 도입 대사를 이미 닫았어도 다시 나올 수 있습니다. 정확히 읽던 문장으로 복귀하는 기능은 후속 보완 대상입니다.

처음부터 세 번째 선택이 보이지 않는 것은 정상입니다. 나눔과 쉼터의 두 기억이 있어야 열립니다. 첫 선택도 바꾸고 싶으면 **첫 선택 전 · 호숫가로 회귀**를 사용하세요. 새 게임으로 시작하면 같은 여정의 기억을 이어받지 않습니다.

## 저장 텍스트를 다른 기기로 옮기기

게임별 저장은 서로 호환되지 않습니다. 동일 게임의 호환되는 버전에서 내보낸 **전체 JSON 텍스트**를 옮기세요. 일부 항목만 복사하거나 내용을 수정하면 검증에 실패합니다.

| 게임 | 보내는 기기 | 받는 기기 |
|---|---|---|
| 별빛의 서약 | 전투 **저장** → **타이틀** → **저장 내보내기 / 가져오기** → **내보내기** | 같은 화면의 입력칸에 붙여넣기 → **검증 후 가져오기** → **돌아가기** → **이어하기** |
| 새벽의 길 | **설정 [Esc]** 또는 타이틀 **설정 · 저장 가져오기** → **저장 내보내기** | 같은 설정 화면의 입력칸에 붙여넣기 → **JSON 가져오기**; 성공하면 가져온 여정으로 바로 이어집니다. |

입력칸을 클릭해 `Ctrl+A`, `Ctrl+C`로 전체를 복사한 뒤 텍스트 파일 등으로 옮기고, 받는 기기에서 `Ctrl+V`로 붙여넣으세요. 자동 클립보드 복사가 되지 않아도 표시된 텍스트를 직접 선택할 수 있습니다. 카드의 내보내기는 **전투 저장**만 옮기며 별도 덱 편집 설정은 포함하지 않습니다. 서사 내보내기는 현재 여정의 기억·체크포인트를 포함하며 자막 크기·음량 설정은 별개입니다.

카드 가져오기는 현재 전투 저장을 교체합니다. 서사 가져오기는 별도 슬롯을 만든 뒤 이어하기 대상을 전환합니다. 손상되거나 호환되지 않는 저장은 오류를 표시하고 기존 저장을 보존합니다. 브라우저 데이터를 지우기 전에는 외부 텍스트로 내보내 보관하세요.

## 확인된 범위와 플레이할 때 확인할 항목

**확인된 것:** 실제 Unity에서 카드 18/18·서사 10/10 테스트 통과. 카드의 지형 사용·저장·새 씬 이어하기와 승패 저장 복귀·재도전, 서사의 이동/상호작용·나눔/쉼터·회귀·이어하기를 검사했습니다. 저장 실패 시 최신 진행 보존과 재시도도 검사했습니다. 두 게임의 Windows·Web 빌드 4개가 성공했고 네이티브 1080p 캡처를 남겼습니다. 실제 브라우저에서 카드 지형 사용과 서사 W 이동, 저장·페이지 새로고침·이어하기, 720p·1080p 화면도 검사했습니다. 세 서사 경로는 규칙 테스트로 검사했습니다. 최신 Web 빌드·브라우저 결과는 [검증 기록](Validation.md)을 기준으로 합니다.

**직접 확인할 것:** Windows에서 실제 실행, 마우스로 카드 전투 전체 완료, 석조 방까지 전체 걷기/충돌 경로, 세 번째 서사 결과 화면, 음향·글자 크기·화면 비율, 브라우저 프로그램 전체 종료·재시작 뒤 이어하기, Web↔Windows 저장 이동, 실제 기기의 로딩 시간·프레임률입니다. Unity 자동 UI 검증은 버튼 콜백을 사용하고, Web 검사는 실제 포인터·키 입력을 사용합니다. 확인한 일부 흐름이 모든 조작의 통과를 뜻하지는 않습니다. 오류를 보고할 때는 게임/플랫폼, 누른 버튼 순서, 표시된 오류, 재현 화면을 함께 남겨 주세요.
