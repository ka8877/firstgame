# 첫 플레이 안내

두 게임은 각각 실행하는 싱글플레이 개발판입니다. 이번 안내는 판타지마스터즈의 새 타이틀·연습 대기실과, 탄생부터 시작하는 예수님의 길 첫 구간을 기준으로 합니다. 새 버전의 공개 주소 반영 여부와 실제 확인 범위는 [검증 기록](Validation.md)을 따릅니다.

**[브라우저에서 바로 플레이](https://ka8877.github.io/firstgame/)** — 이 주소를 테스터에게 공유하세요. 기존 탭은 업데이트 뒤 새로고침하세요. 모바일은 가로 화면을 권장합니다.

## Windows와 Web 실행

| 게임 | Windows ZIP의 실행 파일 | Web ZIP의 시작 파일 |
|---|---|---|
| 판타지마스터즈 리마스터 체험판 | `FantasyCards-Windows/FantasyCards.exe` | `FantasyCards-Web/index.html` |
| 말씀을 따라 예수님의 길 | `PathOfDawn-Windows/PathOfDawn.exe` | `PathOfDawn-Web/index.html` |

Windows ZIP은 폴더째 압축 해제한 뒤 실행 파일을 여세요. 같은 위치의 DLL·데이터·런타임 폴더도 필요합니다. `.exe`만 다른 곳으로 옮기거나 ZIP 안에서 실행하지 마세요.

Web ZIP은 전체 폴더를 HTTP/HTTPS 서버에서 제공해야 합니다. `index.html`을 더블클릭하는 방식은 지원하지 않습니다. Python이 있으면 `index.html`이 있는 폴더의 터미널에서 아래 명령을 실행하고 `http://127.0.0.1:8000`을 여세요.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

서버 터미널은 플레이하는 동안 열어 두고 종료할 때 `Ctrl+C`를 누릅니다. 저장은 주소와 포트에 따라 분리되므로 이어하기는 같은 주소로 접속하세요. 휴대폰에서 세로 안내가 나오면 기기를 가로로 돌리세요. 실제 휴대폰·Safari의 동작과 성능은 기기별 확인이 필요합니다.

## 판타지마스터즈: 연습방에서 첫 대전 시작하기

이번 단계는 옛 판타지마스터즈의 방 목록·금속 장식·전장 구성을 바탕으로 싱글플레이 진입을 다시 만든 체험판입니다. 타이틀과 로비의 **프로필**에서 닉네임과 원작 카드 아바타를 선택해 저장할 수 있습니다. 연습전 전적은 기록 시작 이후의 실제 완료 결과이며 이 브라우저·기기에 저장됩니다. 로비의 방은 컴퓨터 상대와 진행하는 연습전입니다. 현재 온라인 매칭은 제공하지 않습니다.

1. 타이틀에서 **게임 시작**을 누릅니다.
2. **Room · 연습실**에서 원하는 연습방을 고릅니다. **숲과 빛의 첫 대전 / 물과 암흑의 대전 / 불과 금속의 대전** 세 상대를 선택할 수 있습니다.
3. 대전실에서 **덱 선택**을 누르고 50장 기본 덱 다섯 종 중 하나를 고릅니다. 처음에는 **숲과 빛 · 생명의 전열**, 새 등급과 소각을 보려면 다음 페이지의 **강화 체험**을 선택해 보세요. 편집해 저장한 덱은 **내 편집 덱**을 선택합니다.
4. **대전실로** 돌아와 **START**를 누릅니다. 시작 손패 6장을 확인한 뒤 원하면 **전체 손패 교체**로 여섯 장을 모두 다시 뽑고, **이대로 시작**을 누릅니다.
5. 손패의 지형을 아래 지형·소울 띠로 끌어놓거나, 선택 후 오른쪽 **지형 전개**를 누릅니다. LP를 사용해 지형을 내면 색 소울과 총소울을 얻습니다. 전개한 지형은 전열과 손패 사이 **백필드**에 원작 그림으로 표시되며 눌러서 상세를 볼 수 있습니다. 보유 LP와 비용을 확인하세요.
6. 사용할 수 있는 유닛을 고르면 아군 빈 전열에 **여기에 배치**가 나타납니다. 그 칸을 누르거나 카드를 빛나는 칸으로 끌어놓으면 소환합니다. 색 소울과 총소울이 모두 충분해야 하며 유닛·예약 마법은 다섯 전열을 함께 사용합니다.
7. 마법은 설명에 따라 대상 유닛을 선택하거나 **마법 예약**을 누릅니다. 대상 없는 마법을 빈 아군 전열에 끌어놓으면 그 칸에 예약합니다. 아이템은 조건에 맞는 아군 유닛에게 장착합니다. 공격 준비 전용·방어 준비 전용 여부를 상세에서 확인하세요.
8. 배치를 마치면 오른쪽 아래 **준비 완료**를 누릅니다. 공격측 준비와 방어측 준비를 거쳐 전열 순서대로 자동 공방합니다. 수비가 없을 때 공격 유닛의 레벨만큼 상대 덱을 파괴하며, 상대 덱을 소진시키는 것이 목표입니다.
9. 다음 턴에는 손패가 여섯 장까지 채워집니다. 카드를 사용하기 전에는 **손패 셔플**로 손패 전체를 한 번 다시 섞을 수 있습니다. 시작 손패 교체를 사용했다면 첫 준비의 셔플도 사용한 것으로 처리합니다.
10. **기록 / 메뉴**에서 전투 기록·소각장/상태·음악·저장·대기실 복귀를 선택합니다. 결과 화면의 **다음 결투** 또는 **다시 도전**으로 다른 대전을 시작할 수 있습니다.

전투는 실제 코인 앞뒤와 능력치, 공격·반격, 방어·피해, 카드 파괴와 덱 소각을 순서대로 보여줍니다. 재생 중 `×1/×2/×4`와 **끝까지**는 연출 속도만 바꾸며 코인이나 결과를 바꾸지 않습니다. 준비 단계에서는 손패를 오른쪽 **소각** 칸으로 끌어놓아 버릴 수 있습니다. 업그레이드 등급의 손패 소각은 카드 설명대로 총소울을 1 얻습니다.

오른쪽 패널에서 색 소울·LP·총소울·공수 단계·서로의 남은 덱을 확인하세요. AP는 공격, DP는 방어, HP는 유닛 생명이며 코인 결과에 따라 값이 달라집니다. 유닛 유지비도 필요하므로 지형과 유닛의 균형을 맞추세요.

PC에서는 카드·전열·버튼에 마우스를 올려 설명을 봅니다. 모바일은 카드를 길게 누르거나 **카드 상세**를 누릅니다. 가려진 손패는 가로로 밀어 보세요. **원본 카드**는 원작 인쇄 이미지를 표시하며, 실제 적용 수치는 능력 설명을 확인하세요. 인쇄판과 DB 수치는 시기에 따라 다를 수 있습니다.

**도감과 덱 편집:** 로비의 **카드 도감 / 덱 편집**을 엽니다. 250종을 속성·종류·비용·등급·랭크·장착 능력으로 찾고, 편집에서 카드별 `-/+`로 수량을 바꿉니다. 목록과 큰 카드 보기를 전환할 수 있습니다. 총 50장과 지형·속성 생산·카드별 한도 조건을 맞추고 **덱 저장**을 누르세요. **덱 분석**에서 비용·소울/유지비·등급/랭크 분포를 확인합니다. 진행 중인 전투의 덱은 이후 편집으로 바뀌지 않습니다.

이번에는 7속성과 프리·커먼·언커먼·레어·스페셜·업그레이드·유니크·이벤트·레전드의 실제 카드가 포함됩니다. 등급 사전은 원작 12등급과 현재 수록 수를 구분합니다. 미수록 등급과 모든 특수기술을 구현한 것으로 표시하지 않습니다. [이번 개정](DetailRemaster.md)과 [기존 규칙 범위](FantasyMastersClassic.md)를 참고하세요.

## 예수님의 길: 탄생에서 성전의 소년까지

예수님을 주인공으로 복음서 기록을 따라가는 첫 학습 구간입니다. 현재는 탄생의 말씀 세 페이지와 열두 살 예수님의 성전 방문을 플레이합니다.

1. **새 여정**을 누릅니다. 탄생 장면에서 누가복음 2장의 말씀을 읽고 **다음 구절**로 넘깁니다. 세 번째 페이지의 **성전으로**를 누르면 소년 예수님으로 이동을 시작합니다.
2. 빛나는 표식을 향해 걸어갑니다. 현재 목표와 남은 거리가 화면 위에 표시됩니다. 가까이 가면 **읽기 · E**를 누르거나 `E`를 눌러 말씀을 엽니다.
3. **성전 문 → 선생들 → 부모 → 나사렛으로 돌아가는 문** 순서로 네 목표를 따라갑니다. 각 본문을 읽고 **말씀을 따라 걷기**를 누르면 다음 목표가 열립니다. 긴 본문은 위아래로 스크롤할 수 있습니다.
4. 마지막 본문 뒤 **나사렛으로** 화면이 나오면 첫 여정을 마친 것입니다. **성경 기록**에서 읽은 구절을 다시 살펴보세요.

| 조작 | PC | 모바일 가로 화면 |
|---|---|---|
| 이동 | WASD / 방향키 | 왼쪽 이동 패드 |
| 달리기 | Shift | 현재는 이동 패드로 걷기 |
| 시점 회전 | 마우스 오른쪽 버튼을 누른 채 드래그 | 오른쪽 빈 공간 드래그 |
| 카메라 거리 | 마우스 휠 / 화면 +·- | 화면 +·- / 설정 슬라이더 |
| 인물 상태 | I / 상태 버튼 | 상태 버튼 |
| 말씀 읽기 | 가까이서 E 또는 **읽기 · E** | 가까이서 **읽기 · E** |
| 설정 | Esc 또는 **설정** | **설정** |

걷기·달리기·정지는 실제 3D 인물의 자세로 연결됩니다. 성전 마당과 인물 모습은 말씀을 읽기 위한 장면 구성입니다. 화면 아래에는 현재 구절이 계속 표시되고 **성경 기록**에서 읽은 본문 전체와 문맥 안내를 다시 볼 수 있습니다. 본문은 **성경전서 개역한글판 · 대한성서공회**이며 문맥 요약과 구분합니다.

**장 선택**은 전체 일생의 26개 구간을 보여 줍니다. 탄생과 성전 방문 뒤의 장에는 **준비 중**이 표시됩니다. 세례·공생애·수난·부활·승천은 앞으로 이어 만들 구간이며 현재 완성된 장면으로 열리지 않습니다. 현재 첫 여정은 말씀을 따라 진행하며 전투나 가상 결말 선택은 후속 개발 범위입니다.

## 배경 음악과 음량

카드게임은 타이틀·대기실·덱·전투용 내장 창작 연주곡을 사용합니다. 로딩 화면의 **게임 시작**이나 첫 클릭·터치로 시작하며, **음악 설정**과 하단 버튼으로 음량·음소거를 조절합니다. 외부 임베드·광고 플레이어는 일반 플레이에서 사용하지 않습니다. Web과 Windows 모두 연주곡을 파일로 포함하며 원작 OST로 표시하지 않습니다.

예수님의 길은 첫 클릭·터치·키 입력 후 배경 음악이 시작합니다. **설정**에서 **음악 켜기/끄기**, **음량 슬라이더**를 사용하세요. 이전 이야기의 창작 대사 음성은 새 성경 구절에 들어 있지 않으며 본문은 화면에서 읽습니다. 음악 설정은 현재 기기·브라우저에 보관됩니다.

## 저장과 다른 기기에서 플레이

두 게임의 진행은 현재 기기·브라우저에 저장됩니다. 같은 URL을 집과 회사에서 열어도 진행이 자동으로 공유되지는 않습니다. 브라우저 데이터를 지우거나 다른 주소·포트·시크릿 창을 사용하면 기존 진행을 찾지 못할 수 있습니다.

**카드게임:** 유효한 행동 뒤 자동 저장되며 **기록 / 메뉴 → 저장**으로 직접 보관할 수 있습니다. 타이틀이나 대기실의 **이어하기**로 복귀합니다. 새 `START`는 진행 중인 전투 저장을 교체하므로 보관할 전투가 있다면 먼저 내보내세요.

1. 현재 기기의 대기실에서 **저장 옮기기 → 내보내기**를 누릅니다.
2. 표시된 내용을 전부 복사해 텍스트 파일로 보관하거나 다른 기기로 옮깁니다.
3. 다른 기기에서 같은 게임의 **저장 옮기기**를 열고 붙여넣은 뒤 **검증 후 가져오기**를 누릅니다. 이 기기의 전투 저장을 교체하므로 기존 진행이 필요하면 먼저 내보내세요.
4. 완료 안내 뒤 타이틀의 **이어하기**를 누릅니다. 형식이나 버전이 맞지 않는 저장은 오류를 표시합니다.

**예수님의 길:** 화면 위 **저장**을 누르고, **설정 → 처음 화면 → 이어하기**로 현재 목표·읽은 말씀·인물 위치를 이어갈 수 있습니다. 구절을 읽는 중의 진행도 저장합니다. **새 여정**은 이전 여정을 남기고 새 진행을 시작하며 이어하기 대상은 새 여정으로 바뀝니다. 현재는 게임 안에서 다른 기기로 내보내는 기능을 제공하지 않으므로 같은 기기·브라우저에서 이어가세요. 이전 관찰자 이야기의 저장은 새 성경 여정과 별도로 보존됩니다.

저장 실패 안내가 나오면 창을 닫기 전에 공간·접근 문제를 해결하고 **저장**을 다시 눌러 성공 여부를 확인하세요. 저장하지 못한 최신 진행은 종료하면 사라질 수 있습니다.

## 리마스터 추가 조작

카드 도감은 161종을 검색·정렬·필터링합니다. 검색은 이름과 능력 설명에 적용되며, **내 덱**으로 포함한 카드만 볼 수 있습니다. 기존50장 기본 덱4종은 유지했습니다.

예수님의 길에서는 **Shift 달리기**, **Space 점프**, **E 대화**를 사용합니다. 모바일은 이동 패드와 시점 드래그, **달리기 ON/OFF**, **점프**, **대화** 버튼을 사용합니다. 대화에서는 초상화와 발화자를 확인하고 **다음 대화**로 한 턴씩 읽습니다. 성경 직접 인용과 학습 안내를 구분하며 관련 개역한글 본문을 아래에서 스크롤해 볼 수 있습니다. 대화 중간의 저장도 같은 턴에서 이어집니다.

뜰 남서쪽 금색 원은 선택적인 자유 연습 구역입니다. 그 안에서 **F / 동작 연습**을 누르면 팔을 뻗는 동작을 합니다. 현재 NPC 피해나 전투·가상 분기는 포함하지 않습니다.
