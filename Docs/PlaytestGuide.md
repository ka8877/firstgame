두 게임은 각각 실행하는 싱글플레이 개발판입니다. 현재 소스 개정은 `fm-chronicle-2026-10-29` / `gospel-chronicle-2026-10-29`입니다. 카드와 UI 범위는 [후기 전투 표시 안내](FmChronicleUI.md), 예수님 게임은 아래 최신 여정 안내를 따릅니다. 실제 빌드·공개 여부는 [이번 개정 안내](Chronicle.md)와 [검증 기록](ChronicleValidation.md)에서 구분합니다.

**[브라우저에서 바로 플레이](https://ka8877.github.io/firstgame/)** — 이 주소를 테스터에게 공유하세요. 기존 탭은 업데이트 뒤 새로고침하세요. 모바일은 가로 화면을 권장합니다.

## Windows와 Web 실행

이번 Chronicle 클라우드 결과물은 **Web**입니다. 아래 Windows 실행 방법은 이전 Windows ZIP 또는 같은 소스로 직접 빌드한 경우의 안내입니다. 이전 Polish Windows ZIP을 새 Chronicle 버전으로 사용하지 마세요.

| 게임 | Windows ZIP의 실행 파일 | Web ZIP의 시작 파일 |
|---|---|---|
| 판타지마스터즈 리마스터 체험판 | `FantasyCards-Windows/FantasyCards.exe` | `FantasyCards-Web/index.html` |
| 말씀을 따라 예수님의 길 | `PathOfDawn-Windows/PathOfDawn.exe` | `PathOfDawn-Web/index.html` |

Windows ZIP은 폴더째 압축 해제한 뒤 실행 파일을 여세요. 같은 위치의 DLL·데이터·런타임 폴더도 필요합니다. `.exe`만 다른 곳으로 옮기거나 ZIP 안에서 실행하지 마세요.

Web ZIP은 전체 폴더를 HTTP/HTTPS 서버에서 제공해야 합니다. `index.html`을 더블클릭하는 방식은 지원하지 않습니다. Python이 있으면 `index.html`이 있는 폴더의 터미널에서 아래 명령을 실행하고 `http://127.0.0.1:8000`을 여세요.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

서버 터미널은 플레이하는 동안 열어 두고 종료할 때 `Ctrl+C`를 누릅니다. 저장은 주소와 포트에 따라 분리되므로 이어하기는 같은 주소로 접속하세요. 휴대폰에서 세로 안내가 나오면 기기를 가로로 돌리세요. 실제 휴대폰·Safari의 동작과 성능은 기기별 확인이 필요합니다.

## 판타지마스터즈: 연습방에서 첫 대전 시작하기

이번 단계는 2017년 판마1 플레이 영상의 파란 전장·카드·코인 표시와 후기 공식 홈페이지 원화를 참고해 다듬은 싱글플레이 체험판입니다. 타이틀·로비는 원작 그림으로 새로 구성했으며, 마지막 클라이언트 화면 전체를 회수한 것은 아닙니다. 로비 오른쪽 **프로필**에서 닉네임과 원작 카드 아바타를 선택해 저장할 수 있습니다. 연습전 전적은 기록 시작 이후의 실제 완료 결과이며 이 브라우저·기기에 저장됩니다. 로비의 방은 컴퓨터 상대와 진행하는 연습전입니다. 현재 온라인 매칭은 제공하지 않습니다.

1. 타이틀에서 **게임 시작**을 누릅니다.
2. **ROOM · 연습**에서 원하는 연습방을 고릅니다. **숲의 첫 결투 / 심연의 시험 / 강철의 관문** 세 AI 상대를 선택할 수 있습니다.
3. 대전실에서 **덱 선택**을 누르고 화면에 표시된 50장 기본 덱 중 하나를 고릅니다. 기본 덱 수와 속성 구성은 실제 현재 목록을 따릅니다. 단일/듀얼과 속성 필터로 찾고 페이지를 넘겨 선택하세요. 기존 **숲과 빛 · 생명의 전열**과 **강화 체험** 덱도 유지합니다. 편집해 저장한 덱은 **내 편집 덱**을 선택합니다.
4. **대전실로** 돌아와 **START · 대전 시작**을 누릅니다. 시작 손패 6장을 확인한 뒤 원하면 **전체 손패 교체**로 여섯 장을 모두 다시 뽑고, **이대로 시작**을 누릅니다.
5. 손패의 지형을 아래 지형·소울 띠로 끌어놓거나, 선택 후 오른쪽 **지형 전개**를 누릅니다. LP를 사용해 지형을 내면 색 소울과 총소울을 얻습니다. 전개한 지형은 전열과 손패 사이 **백필드**에 원작 그림으로 표시되며 두 번 누르거나 길게 눌러 상세를 볼 수 있습니다. 보유 LP와 비용을 확인하세요.
6. 사용할 수 있는 유닛을 고르면 아군 빈 전열에 **여기에 배치**가 나타납니다. 그 칸을 누르거나 카드를 빛나는 칸으로 끌어놓으면 소환합니다. 색 소울과 총소울이 모두 충분해야 하며 유닛·예약 마법은 다섯 전열을 함께 사용합니다.
7. 마법은 설명에 따라 대상 유닛을 선택하거나 **마법 예약**을 누릅니다. 대상 없는 마법을 빈 아군 전열에 끌어놓으면 그 칸에 예약합니다. 아이템은 조건에 맞는 아군 유닛에게 장착합니다. 공격 준비 전용·방어 준비 전용 여부를 상세에서 확인하세요.
8. 배치를 마치면 오른쪽 아래 **준비 완료**를 누릅니다. 공격측 준비와 방어측 준비를 거쳐 전열 순서대로 자동 공방합니다. 수비가 없을 때 공격 유닛의 레벨만큼 상대 덱을 파괴하며, 상대 덱을 소진시키는 것이 목표입니다.
9. 다음 턴에는 손패가 여섯 장까지 채워집니다. 카드를 사용하기 전에는 **손패 셔플**로 손패 전체를 한 번 다시 섞을 수 있습니다. 시작 손패 교체를 사용했다면 첫 준비의 셔플도 사용한 것으로 처리합니다.
10. **기록 / 메뉴**에서 전투 기록·소각장/상태·소리 설정·저장·대기실 복귀를 선택합니다. 결과 화면의 **다음 결투** 또는 **다시 도전**으로 다른 대전을 시작할 수 있습니다.

전투는 실제 코인 앞뒤와 능력치, 공격·반격, 방어·피해, 카드 파괴와 덱 소각을 순서대로 보여줍니다. 카드의 원래 AP·DP·HP 숫자 자리에는 `5`처럼 현재 수치를 표시하고, 사각 코인 결과 창과 전투 안내에는 `AP 3→5 (+2)`처럼 이전 값과 변화량을 표시합니다. 이후 피해는 해당 카드의 실제 현재 HP에 반영됩니다. 재생 중 `×1/×2/×4`와 **끝까지**는 연출 속도만 바꾸며 코인이나 결과를 바꾸지 않습니다. 준비 단계에서는 손패를 오른쪽 **소각** 칸으로 끌어놓아 버릴 수 있습니다. 업그레이드 등급의 손패 소각은 카드 설명대로 총소울을 1 얻습니다.

오른쪽 패널에서 색 소울·LP·총소울·공수 단계·서로의 남은 덱을 확인하세요. AP는 공격, DP는 방어, HP는 유닛 생명이며 코인 결과에 따라 값이 달라집니다. 유닛 유지비도 필요하므로 지형과 유닛의 균형을 맞추세요.

손패와 전열에서 **카드 자체를 선택하고 배치**합니다. 같은 원본 인쇄 이미지를 원래 비율로 사용하면서, 원래 이름·비용·기술 설명을 가리지 않고 현재 AP/DP/HP만 오른쪽 아래 원래 숫자 자리에서 갱신합니다. 도감·상세·**크게 보기**에서는 동적 표시 없는 원본 전체를 볼 수 있습니다. 한 번 누르면 카드를 선택하고, 같은 카드를 두 번 빠르게 누르면 상세를 엽니다. PC에서는 마우스를 올려 도움말을 봅니다. 모바일은 길게 누르거나 **카드 상세**를 눌러도 됩니다. Esc는 상세에서 전장으로 돌아오며, 전장에서는 선택 해제 후 메뉴를 엽니다. 가려진 손패는 가로로 밀어 보세요. 원본 인쇄판과 현재 DB 수치는 시기에 따라 다를 수 있습니다.

**출전 카드와 덱 편집:** 타이틀의 **출전 카드**, 로비의 **덱 편집**, 또는 상위 등급 화면의 **출전 카드 도감**을 엽니다. 속성·종류·비용·등급·랭크·장착 능력으로 찾고, 편집에서 카드별 `-/+`로 수량을 바꿉니다. 처음에는 큰 카드가 표시되며 **목록 보기**로 전환할 수 있습니다. 총 50장과 지형·속성 생산·카드별 한도 조건을 맞추고 **덱 저장**을 누르세요. **덱 분석**에서 비용·소울/유지비·등급/랭크 분포를 확인합니다. 진행 중인 전투의 덱은 이후 편집으로 바뀌지 않습니다.

**전체 원본 도감:** 타이틀의 **전체 원본 도감** 또는 로비의 **전체 원본**을 엽니다. 이름·원작 번호·능력을 입력하고 **검색**을 누르세요. **등급 · 전체**는 현재 수록된 모든 등급의 실제 카드 수와 선택 화면을 열고, **속성 · 전체**는 속성을 순서대로 바꿉니다. **이전 / 다음**으로 넘기고 **검색 초기화**로 필터를 풉니다. 카드 그림은 필요한 페이지부터 불러오므로 처음에는 잠깐 카드 뒷면이 보일 수 있습니다. 상세의 **출전 지원** 카드에는 **덱에서 보기**가 있으며, 그 외 카드는 원문과 현재 미지원 사유를 보여줍니다. 원본 도감 수록 수와 실제 전투 지원 수는 서로 다른 값입니다.

**상위 등급:** 로비의 **상위 등급**을 열면 스페셜·유니크·레전드·시크릿의 대표 출전 카드와 실제 개수를 봅니다. 등급 버튼은 출전 도감의 해당 등급으로 이동합니다. **전체 원본 도감**에서는 에픽·이카젠 등 다른 수록 등급도 찾을 수 있습니다. 기본 덱 화면에서는 상위 카드를 포함한 연습 덱을 고르거나 덱 편집으로 직접 구성하세요. 최신 수록·지원 범위는 [이번 개정 안내](Chronicle.md)를 따릅니다.

**시나리오:** 로비의 **SCENARIO**는 소울의 기초 → 파도의 시험 → 강철의 관문 → 유산의 수호자로 이어지는4과제입니다. 첫 과제를 고르고 설명·목표를 확인한 뒤 **추천 덱으로 시작** 또는 **선택한 덱으로 시작**을 누르세요. 실제 승리로 다음 과제가 열리며 완료한 과제는 다시 할 수 있습니다. 원작 카드·규칙으로 새로 구성한 학습 경로이며 원작 캠페인 전체를 복구한 것은 아닙니다. **MULTI**는 추후 제공할 방·초대·매칭의 준비 화면입니다. 현재 온라인 대전과 가상 접속자·채팅은 제공하지 않습니다.


전투 오른쪽 **상대 정보**에서 **대전 데스크**를 엽니다. 실제 AI 상대와 공개된 덱·손패·소각장 개수를 확인하고, **전투 기록**에서 지난 코인·피해 결과를 스크롤해 읽습니다. **연습 메모**는 나에게 남기는 개인 기록이며 다른 사람에게 전송되지 않습니다. 입력 후 **기록** 또는 Enter로 남기고 **전장으로** 복귀하세요. 메모는 새 결투·새로고침 때 초기화됩니다.


공방 중에는 위쪽 상대와 아래쪽 내 카드 옆에 각각 **5칸 코인 결과 창**이 나타납니다. 금색 앞면과 원작 그림의 역면, 실제 확률, 슬롯별 능력 아이콘, AP/DP/HP 변화량을 확인하세요. 공방 중 하단은 내 지형 원본 띠로 바뀌며 다음 준비에 손패가 돌아옵니다. 왼쪽 위에는 실제 전투 사건이 짧게 표시됩니다.

## 예수님의 길: 이야기를 따라 성경 채우기

1. **새 여정 시작**을 누릅니다. 탄생과 아기 때의11개 그림 장면에서 **다음 말씀**으로 기록을 읽습니다. 한 장면의 대화를 마쳐야 성경의 해당 면이 열립니다.
2. **성전의 소년 · 유월절의 길**이 나오면 **이야기 속으로**를 누릅니다. 이제 열두 살 예수님으로 움직입니다. 화면의 화살표와 현재 목표를 따라 요셉·마리아·성전 길잡이·선생들을 만나세요.
3. NPC 가까이에서 `E` 또는 **대화**를 누르고 대화를 끝까지 읽습니다. 출발 준비부터 성전의 만남·부모와의 대화·나사렛 귀향까지7개 목표가 순서대로 이어집니다.
4. 다음 장 **요단강 · 공생애의 문턱**에서는 삼십세쯤의 성인 인물로 바뀝니다. 새 강가에서 세례 요한을 만나고 세례와 공생애 시작의5개 목표를 따라갑니다.
5. 이번 구간을 마치면19개 말씀을 성경에서 다시 읽을 수 있습니다. 이후의 사역·십자가·부활·승천은 이번 플레이 구간에 포함되지 않습니다.

**성경은 펼친 책입니다.** 탐색 중 `M` 또는 화면의 **성경**을 누르세요. 미발견 면은 제목·출처·본문·그림이 감춰져 있습니다. 해당 이야기의 마지막 대화를 마치면 정확한 본문과 그림이 채워지고 그 면을 바로 펼칠 수 있습니다. **이전 면 / 다음 면**으로 넘기고 본문을 위아래로 읽습니다. 책을 열거나 넘기는 일로 말씀을 얻지는 않습니다. **여정으로**를 누르면 직전의 이동 또는 열린 대화로 돌아갑니다.

**여정 기록**은 별도입니다. 탐색 중 `J` 또는 오른쪽 기록 아이콘을 누르면 지금 가야 할 곳과 지나온 만남을 봅니다. 대화 중에는 오른쪽 위 **성경 / 메뉴**를 사용하세요. 직접 인용·본문 요약·게임용 극화 대화는 화면에서 구분합니다.

| 조작 | PC | 모바일 가로 화면 |
|---|---|---|

## 배경 음악과 음량

카드게임 BGM은 SOUND-I 원작 로그인·로비·덱의 무음성 발췌와 SID-Sound 원작 전투곡을 포함합니다. 발췌를 전체 원곡 복구라고 표시하지 않습니다. 곡의 역할이 바뀌면 새 곡은 처음부터 페이드로 시작하고, 같은 화면의 버튼·설정 변경으로는 재시작하지 않습니다. 브라우저는 첫 클릭·터치 등 사용자 입력 후 소리를 낼 수 있습니다. 타이틀의 **소리 설정** 또는 로비의 **음악 / 효과음**에서 배경 음악과 효과음의 켜기/끄기·음량을 따로 조절합니다. UI 클릭·카드 선택/드래그·셔플·전개·코인·공격·방어·마법·파괴의 별도 효과음이 있으며, 이는 새로 제작한 리마스터 효과음입니다. 원작 녹음을 회수한 효과음이라고 표시하지 않습니다. 외부 임베드·광고 플레이어는 일반 플레이에서 사용하지 않습니다.

예수님의 길은 첫 클릭·터치·키 입력 후 배경 음악이 시작합니다. **설정**에서 **음악 켜기/끄기**, **음량 슬라이더**를 사용하세요. 이전 이야기의 창작 대사 음성은 새 성경 구절에 들어 있지 않으며 본문은 화면에서 읽습니다. 음악 설정은 현재 기기·브라우저에 보관됩니다.

## 저장과 다른 기기에서 플레이

두 게임의 진행은 현재 기기·브라우저에 저장됩니다. 같은 URL을 집과 회사에서 열어도 진행이 자동으로 공유되지는 않습니다. 브라우저 데이터를 지우거나 다른 주소·포트·시크릿 창을 사용하면 기존 진행을 찾지 못할 수 있습니다.

**카드게임:** 유효한 행동 뒤 자동 저장되며 **기록 / 메뉴 → 저장**으로 직접 보관할 수 있습니다. 타이틀이나 대기실의 **이어하기**로 복귀합니다. 새 `START`는 진행 중인 전투 저장을 교체하므로 보관할 전투가 있다면 먼저 내보내세요.

1. 현재 기기의 대기실에서 **프로필 → 저장 옮기기 → 내보내기**를 누릅니다.
2. 표시된 내용을 전부 복사해 텍스트 파일로 보관하거나 다른 기기로 옮깁니다.
3. 다른 기기에서 같은 게임의 **프로필 → 저장 옮기기**를 열고 붙여넣은 뒤 **검증 후 가져오기**를 누릅니다. 이 기기의 전투 저장을 교체하므로 기존 진행이 필요하면 먼저 내보내세요.
4. 완료 안내 뒤 타이틀의 **이어하기**를 누릅니다. 형식이나 버전이 맞지 않는 저장은 오류를 표시합니다.

**예수님의 길:** 등잔 장착/보관도 현재 여정에 함께 저장됩니다. **Esc / 메뉴 → 현재 여정 저장**을 누르고, 같은 메뉴의 **처음 화면**으로 돌아간 뒤 타이틀의 **이어하기**로 현재 목표·읽은 말씀·인물 위치를 이어갈 수 있습니다. 구절을 읽는 중의 진행도 저장합니다. **새 여정**은 이전 여정을 남기고 새 진행을 시작하며 이어하기 대상은 새 여정으로 바뀝니다. 현재는 게임 안에서 다른 기기로 내보내는 기능을 제공하지 않으므로 같은 기기·브라우저에서 이어가세요. 이전 관찰자 이야기의 저장은 새 성경 여정과 별도로 보존됩니다.

저장 실패 안내가 나오면 창을 닫기 전에 공간·접근 문제를 해결하고 **저장**을 다시 눌러 성공 여부를 확인하세요. 저장하지 못한 최신 진행은 종료하면 사라질 수 있습니다.
