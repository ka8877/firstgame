# 첫 플레이 안내

두 게임은 각각 실행하는 싱글 플레이 개발판입니다. 이 안내는 카드 40종·네 리더·네 기본 덱·세 결투와, 서사의 일러스트 2.5D 호숫가·석조 방, 전신 인물·보행과 초반 한국어 음성 20줄을 포함한 소스 기준입니다. 새 빌드와 공개 URL에 반영되었는지, 실제 조작·음악·음성을 어디까지 확인했는지는 [검증 기록](Validation.md)을 따릅니다. 이전 공개판의 테스트 통과를 새 개정의 검증으로 간주하지 않습니다.

**[브라우저에서 바로 플레이](https://ka8877.github.io/firstgame/)** — 테스터에게 이 주소를 공유하세요. 아래 ZIP 실행 방법은 내려받은 파일을 따로 사용할 때의 안내입니다.

## Windows와 Web 실행

| 게임 | Windows ZIP의 실행 파일 | Web ZIP의 시작 파일 |
|---|---|---|
| 별빛의 서약 | `FantasyCards-Windows/FantasyCards.exe` | `FantasyCards-Web/index.html` |
| 새벽의 길 | `PathOfDawn-Windows/PathOfDawn.exe` | `PathOfDawn-Web/index.html` |

**Windows:** 해당 ZIP을 폴더째 압축 해제한 뒤 실행 파일을 여세요. `.exe`와 같은 위치의 DLL·데이터·런타임 폴더를 함께 두어야 합니다. ZIP 안에서 실행하거나 `.exe`만 다른 곳으로 옮기면 필요한 파일을 찾지 못합니다.

**Web:** 압축 해제한 폴더 전체를 HTTP/HTTPS 서버에서 제공해야 합니다. `index.html`을 더블클릭하는 `file://` 실행은 지원하지 않습니다. Python이 설치돼 있다면 `index.html`이 있는 폴더의 터미널에서 다음 명령을 실행할 수 있습니다.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

브라우저 주소창에 `http://127.0.0.1:8000`을 입력하고 로딩이 끝나면 게임 영역을 클릭하세요. 서버 터미널은 플레이하는 동안 열어 두고, 종료할 때 `Ctrl+C`를 누릅니다. 두 게임을 동시에 제공하려면 두 번째 서버에 다른 포트를 지정하세요. 브라우저 저장은 서버 주소와 포트에 따라 분리되므로 이어하기를 확인할 때는 같은 주소를 사용하세요.

**휴대폰:** 가로 화면에서 플레이하세요. 세로 화면의 안내에서 전체화면 시작을 선택할 수 있으며, 브라우저가 회전 잠금을 지원하지 않으면 기기를 직접 돌리면 됩니다. 카드게임은 화면을 터치해서 조작합니다. 새벽의 길은 왼쪽 패드로 이동하고 오른쪽 빈 공간을 드래그해 그림 장면을 조금씩 둘러봅니다. 대화·조사, 기억/회귀, 저장, 설정은 화면 버튼으로 사용할 수 있습니다. 실제 휴대폰 성능 및 Safari 호환성은 기기별 테스트가 필요합니다.

## 배경 음악과 음량

두 게임은 서로 다른 오리지널 관현악 BGM을 반복 재생합니다. 별빛의 서약은 현악·호른·하프·타악이 있는 웅장한 판타지 분위기, 새벽의 길은 목관·피아노·하프·현악 중심의 따뜻하고 서정적인 분위기입니다. 음악은 타이틀·플레이·설정 화면을 오갈 때 이어집니다.

**브라우저에서는 로딩 뒤 게임 화면을 한 번 클릭하거나 탭하세요.** 첫 입력 전에는 브라우저의 자동재생 제한으로 음악이 나오지 않을 수 있습니다. Windows 플레이어는 타이틀에서 재생을 시작하도록 구성했습니다. 실제 플랫폼별 재생 확인 여부는 검증 기록을 따릅니다.

| 게임 | 음악 조작 |
|---|---|
| 별빛의 서약 | 타이틀 또는 전투 화면의 **음악** → **음악 켜기/끄기**, **음량 − / 음량 +** → **돌아가기** |
| 새벽의 길 | 타이틀의 **설정 · 저장 가져오기** 또는 플레이 중 **설정 [Esc]** → **배경 음악 켜기/끄기**, **대사 음성 켜기/끄기**. **전체 음량**의 **줄이기/높이기**는 음악·대사 음성·효과음에 적용됩니다. |

음악 설정은 현재 기기·브라우저에 저장되며 게임 진행 저장 내보내기에는 포함되지 않습니다. 음악을 껐다 켜도 곡이 매번 처음부터 시작하지 않습니다. 소리가 없으면 게임 안의 음소거·음량과 브라우저 탭·기기의 음량을 확인하세요. 음악 제작·출처는 [Audio.md](Audio.md)에 기록합니다.

새벽의 길은 도입 9줄과 첫 호숫가 선택 전 11줄에 한국어 AI 음성을 제공합니다. 음성이 있는 대화에는 **대사 음성**과 **다시 듣기**가 표시됩니다. 읽는 도중 **다음 대사 [E]**를 누르면 이전 음성이 멈추고 다음 문장으로 진행합니다. 음성 종료를 기다릴 필요는 없습니다. 음성을 꺼도 자막·선택을 그대로 사용할 수 있고, 다시 켠 뒤 듣고 싶은 문장은 **다시 듣기**를 누릅니다. 한 명의 일반 한국어 MeloTTS 음성이며 인물별 배우 연기나 실존 인물의 목소리 복제는 아닙니다. 전체 대사가 더빙된 것은 아닙니다. 제작·문장 일치 범위는 [Voice.md](Voice.md)를 참고하세요.

## 별빛의 서약: 리더를 고르고 세 결투에 도전하기

처음에는 리리아와 **꽃바람의 숲**을 선택하면 지형·소환·공격과 방어를 익히기 좋습니다. 새 결투마다 실제로 덱을 섞으므로 특정 카드가 항상 같은 순서로 나오지는 않습니다.

1. 타이틀의 **새로운 결투** → 리리아·카엘·세린·노아 중 한 명 → **기본 덱 선택**으로 진행합니다. 리더와 덱은 자유롭게 조합할 수 있습니다.
2. **꽃바람의 숲 / 백화 기사단 / 달호수의 노래 / 별술사의 서고** 중 덱을 고릅니다. 모두 24장이며 빠른 전개·방어/장비·제거/회복·뽑기/코인이라는 전략이 다릅니다. 저장한 편집 덱은 **내 편집 덱 사용**으로 선택합니다.
3. 세 결투 중 상대를 선택하고 **덱을 섞고 시작**을 누릅니다. 셔플 뒤 시작 손패 다섯 장을 보고 바꿀 카드를 선택하거나 **이대로 시작**을 누릅니다. 교체는 한 번만 할 수 있으니 지형과 낮은 비용 유닛을 남기는 편이 좋습니다.
4. 아래 손패의 지형을 선택하고 **지형 전개**를 누릅니다. 넓은 화면에서는 왼쪽, 작은 가로 화면에서는 손패 위 조작 행에 있습니다. 내 지형에 카드 이름이 나타나고 해당 속성 자원을 얻습니다. 지형은 턴마다 한 장 전개하며 이후 내 턴 시작에도 자원을 생산합니다.
5. 자원으로 낼 수 있는 유닛을 선택하고 아래쪽 아군의 빈 **전장** 칸을 누릅니다. 비용의 속성과 수가 모두 맞아야 합니다. 소환한 턴에는 공격하거나 가로막을 수 없습니다. 마법/장비는 설명에 맞는 아군·적 유닛을 선택하거나, 대상이 필요 없는 효과는 사용 버튼을 누릅니다.
6. 왼쪽 아래 내 리더 초상 → 기술 내용을 읽고 **리더 기술 사용**을 누릅니다. 준비 단계에 속성 자원 2를 지불하며 내 턴에 한 번입니다. 카엘은 아군 유닛, 세린은 회복할 피해, 노아는 뽑을 카드와 손패 여유가 필요합니다. 쓸 수 없는 이유는 상세 화면에 표시됩니다.
7. 준비를 마쳤으면 **공격 단계** → 준비된 아군 유닛 → 위쪽 적 유닛 또는 상대 리더 생명 표시를 순서대로 누릅니다. AI가 가로막을지 판단한 뒤 전투를 처리합니다. 공격 단계에 들어가면 그 턴의 카드와 리더 기술 사용은 끝납니다.
8. 상대가 공격하면 **방어 대응**에서 준비된 아군 유닛을 선택해 가로막거나 **가로막지 않기**를 누릅니다. 공격에 참여한 유닛은 행동을 마치므로 상대 턴에 방어할 동료도 남겨 두세요.
9. 코인은 전투 때 자동으로 결정됩니다. 연출과 **전투 기록**에서 앞/뒷면·공격력·피해·반격을 확인하세요. 효과 재생 중에는 입력이 잠깁니다. 공격을 마치면 **공격 종료 · 턴 넘기기**를 누릅니다.
10. 결과에서 **다음 결투** 또는 **다시 도전**으로 상대 선택에 돌아가거나 **덱을 다듬기**를 누릅니다. 새로 시작하는 결투는 다시 섞습니다. 세 상대를 골라 반복해서 플레이할 수 있습니다.

**설명 읽기:** PC에서는 카드·전장·자원·단계·리더 기술과 버튼에 마우스를 올려 보세요. 모바일은 카드를 선택한 뒤 **확대 보기**, 또는 카드를 길게 눌러 상세를 확인합니다. 손패가 여섯 장 이상이면 가로로 밀어 다른 카드도 선택할 수 있습니다.

**덱 편집:** 타이틀의 **덱 구성 · 24장**에서 카드별 `-/+`를 누릅니다. 저장 조건은 총 24장, 지형 4장 이상, 유닛 6장 이상, 같은 카드 최대 4장과 필요한 속성의 자원 생산입니다. **덱 저장** 후 새 결투에서 **내 편집 덱 사용**을 선택합니다. **기본 덱 복원**은 현재 선택한 기본 덱을 편집 목록에 넣습니다. **카드 도감**과 덱 편집은 40종을 네 장씩 10페이지로 표시합니다. **이전/다음**으로 넘기고 카드를 누르면 큰 원화와 상세 내용을 볼 수 있습니다. 진행 중 전투를 이어 해도 나중에 편집·저장한 덱은 바뀌지 않습니다.

**저장·복귀:** 유효한 행동 뒤 자동 저장됩니다. 상단 **저장** → **타이틀** → **이어하기**로 같은 전투에 복귀할 수 있습니다. **새로운 결투**는 현재 전투 저장을 교체하므로 보관할 전투가 있다면 먼저 아래 방식으로 내보내세요.

저장에 실패하면 오류를 표시하고 현재 전투 화면에 머뭅니다. 저장 공간이나 접근 문제를 해결한 뒤 **저장**을 다시 눌러 성공을 확인하세요. 저장하지 못한 최신 진행은 프로그램을 닫으면 보존되지 않습니다.

## 새벽의 길: 첫 대화와 두 번의 선택

1. **새 게임**을 누릅니다. 기존 저장이 있으면 안내 후 **새 여정 시작**을 선택합니다. 기존 파일은 보존되며 이 기기의 이어하기 대상은 새 여정으로 바뀝니다.
2. 도입 조망이 끝나면 **다음 대사 [E]**와 **계속 [E]**를 클릭하거나 `E`를 눌러 도입 대사를 읽고 듣습니다. 음성이 있는 문장은 **다시 듣기**로 반복할 수 있습니다. 대화창을 닫으면 이동할 수 있습니다.
3. `WASD`/방향키로 화면 기준 방향으로 걷습니다. 마우스 오른쪽 버튼을 누른 채 드래그하면 그림 장면이 조금 움직입니다. 이동하면 앞뒤 방향에 맞는 걷기 그림, 멈추면 정지 자세로 전환합니다. 처음에는 앞쪽 호숫가의 예수님에게 다가갑니다. 화면 아래 **[E] 예수님과 미리암에게 말 걸기**가 보이면 `E`를 누릅니다. 다른 조사 안내가 보인다면 인물에게 더 가까이 이동하세요.
4. 대사를 읽고 **선택하기 [E]**까지 진행한 뒤 원하는 선택문을 클릭합니다. 선택 뒤의 대사도 끝까지 읽으세요.
5. 첫 선택 뒤 이야기가 석조 방으로 이어지고 배경도 방으로 바뀝니다. 미리암 곁으로 이동해 **[E] 미리암과 바구니에 관해 이야기하기**가 보일 때 `E`를 누릅니다. 대사 뒤 두 번째 선택을 하고 결과 대사까지 읽으면 발견한 길 화면이 나옵니다.
6. **기억을 품고 과거로** 또는 이동 중 `M`/상단 **기억 / 회귀 [M]**에서 방문한 선택 직전으로 돌아갈 수 있습니다. 세계·소지품·관계는 되돌아가고 발견한 길·단서·누적 선택 기록은 남습니다. 도입이나 대화 중에는 이동 입력이 제한됩니다.

상단 **저장**, `Esc`의 **저장하고 타이틀로**, 타이틀의 **이어하기**로 여정을 보관하고 복귀합니다. 선택과 회귀 시에도 자동 저장됩니다. 설정에서는 한국어 자막 크기·전체 음량·배경 음악·대사 음성 켜기/끄기를 조절합니다. 회귀하거나 다른 대사로 이동하면 이전 음성은 중단됩니다. 시계·호숫가 바구니·돌벽의 등불 자리는 가까이 가서 `E`로 조사합니다.

현재 이어하기는 세계·위치·선택·기억을 복원하지만 대사는 해당 묶음의 처음부터 다시 표시하며, 도입 대사를 이미 닫았어도 다시 나올 수 있습니다. 정확히 읽던 문장으로 복귀하는 기능은 후속 보완 대상입니다.

같은 여정에서 회귀와 기억 조건까지 확인하려면 다음 순서가 짧습니다.

1. **빵과 물을 나른다 → 나눌 준비를 한다**로 ‘나눔의 목격자’를 발견합니다.
2. 결과의 **기억을 품고 과거로** → **두 번째 선택 전 · 석조 방으로 회귀**를 누르고, 대사를 읽은 뒤 **쉼터로 준비한다**를 선택해 ‘문턱의 등불’을 발견합니다.
3. 다시 **두 번째 선택 전 · 석조 방으로 회귀**합니다. 이번에는 **두 길의 기억으로, 먼저 서로의 사정을 연결한다.**라는 세 번째 선택이 나타납니다. 이를 고르면 ‘이어진 발걸음’에 도달합니다.

처음부터 세 번째 선택이 보이지 않는 것은 정상입니다. 나눔과 쉼터의 두 기억이 있어야 열립니다. 첫 선택도 바꾸고 싶으면 **첫 선택 전 · 호숫가로 회귀**를 사용하세요. 새 게임으로 시작하면 같은 여정의 기억을 이어받지 않습니다.

‘나눔의 목격자’는 마가복음 6:30–44·요한복음 6:1–13의 사건으로 이어지는 창작 연결 장면이며, 나머지 두 길은 가상 루트입니다. 여행자·미리암·대사·회귀는 창작입니다.

</details>

## 저장 텍스트를 다른 기기로 옮기기

게임별 저장은 서로 호환되지 않습니다. 동일 게임의 호환되는 버전에서 내보낸 **전체 JSON 텍스트**를 옮기세요. 일부 항목만 복사하거나 내용을 수정하면 검증에 실패합니다.

| 게임 | 보내는 기기 | 받는 기기 |
|---|---|---|
| 별빛의 서약 | 전투 **저장** → **타이틀** → **저장 내보내기 / 가져오기** → **내보내기** | 같은 화면의 입력칸에 붙여넣기 → **검증 후 가져오기** → **돌아가기** → **이어하기** |
| 새벽의 길 | **설정 [Esc]** 또는 타이틀 **설정 · 저장 가져오기** → **저장 내보내기** | 같은 설정 화면의 입력칸에 붙여넣기 → **JSON 가져오기**; 성공하면 가져온 여정으로 바로 이어집니다. |

입력칸을 클릭해 `Ctrl+A`, `Ctrl+C`로 전체를 복사한 뒤 텍스트 파일 등으로 옮기고, 받는 기기에서 `Ctrl+V`로 붙여넣으세요. 자동 클립보드 복사가 되지 않아도 표시된 텍스트를 직접 선택할 수 있습니다. 카드의 내보내기는 **전투 저장**만 옮기며 별도 덱 편집 설정은 포함하지 않습니다. 서사 내보내기는 현재 여정의 기억·체크포인트를 포함하며 자막 크기·음량 설정은 별개입니다.

카드 가져오기는 현재 전투 저장을 교체합니다. 서사 가져오기는 별도 슬롯을 만든 뒤 이어하기 대상을 전환합니다. 손상되거나 호환되지 않는 저장은 오류를 표시하고 기존 저장을 보존합니다. 브라우저 데이터를 지우기 전에는 외부 텍스트로 내보내 보관하세요.

이번 카드 확장판은 새 저장 슬롯을 사용합니다. 이전 16종 카드판의 전투·편집 덱 파일은 남겨 두지만 이전 전투를 새 규칙으로 이어 할 수는 없습니다. 새 리더와 덱을 선택해 시작하고, 기기 간 이동은 같은 확장판에서 내보낸 저장을 사용하세요.

## 확인된 범위와 플레이할 때 확인할 항목

**실제 확인 범위:** 새 카드 선택·손패 교체·기술·설명, 서사 그림 장면·전신 인물·보행·20줄 음성의 native·브라우저·공개 URL 검증 상태는 [검증 기록](Validation.md)을 확인하세요. 이 안내의 기능 설명만으로 검사 완료를 뜻하지 않습니다. 이전판 근거는 [보존 기록](ValidationHistory/2026-10-23-art-edition.md)에 보존합니다. Chromium 화면·터치 에뮬레이션은 실제 휴대폰 검증과 구분합니다.

**직접 확인할 것:** Windows에서 실제 실행, 네 리더와 덱의 사용감·세 결투의 난이도·설명 읽기, 마우스로 카드 전투 전체 완료, 호숫가·석조 방의 이동/상호작용 경로와 그림 전환, 세 번째 서사 결과 화면, 음성의 발음·음량과 보행의 자연스러움, 글자 크기·화면 비율, 브라우저 전체 종료·재시작 뒤 이어하기, Web↔Windows 저장 이동, 실제 기기의 로딩 시간·프레임률입니다. Unity 자동 UI 검증은 버튼 콜백을 사용하고 Web 검사는 실제 포인터·키 입력을 사용합니다. 확인한 일부 흐름이 모든 조작의 통과를 뜻하지는 않습니다. 오류를 보고할 때는 게임/플랫폼, 누른 버튼 순서, 표시된 오류, 재현 화면을 함께 남겨 주세요.
