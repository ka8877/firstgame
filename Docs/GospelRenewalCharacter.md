# 예수님의 길 — 인물·첫 그림 개정

현재 개정은 `gospel-renewal-2026-10-29`다. 이전 공식 Lost Crypt 배경·2D 조명·캐릭터 원화는 보존하고, 관절과 발 접지에서 드러난 부자연스러운 동작을 수정한다. 첫 여정의 인물은 누가복음 2장의 열두 살 예수님이다.

## 인물과 보행

종아리 그림에 함께 붙어 있던 신발을 원본 아틀라스의 별도 UV 사각형으로 읽는다. 원본 PNG와 GUID, 픽셀을 바꾸지 않고 발목에 독립적인 샌들 관절을 추가했다. 무릎이 굽어도 발은 지면 방향을 유지하며, 발뒤꿈치 착지·지지·발을 앞으로 옮기는 세 구간을 사용한다.

두 다리는 목표 발목 위치를 향하는 2본 역운동학으로 움직인다. 화면의 시간만으로 다리를 흔들지 않고 컨트롤러의 측정 속도로 보폭을 진행한다. 지지 중인 발은 이동량만큼 뒤로 흘러가며, 발을 옮길 때만 작은 호를 그린다. 골반 높이를 다리 길이 안에서 계산해 무릎이 뒤집히거나 다리가 늘어나지 않도록 했다. 컨트롤러가 측정한 지면 법선은 발 높이에만 반영하며 캐릭터 그림이 물리 위치를 바꾸지 않는다.

걷기는 초당 2.2, 달리기는 4.2월드 단위다. 점프·가속·감속·입력 버퍼와 접지 유예는 실제 Rigidbody2D 동작을 사용한다. 상체·머리·팔꿈치의 각도에는 연속 보간을 적용하고 머리는 상체 기울기를 일부 상쇄한다. 머리카락과 두른 천의 진폭을 줄이고, 긴 튜닉과 머리 폭을 정리했다. 손의 등잔과 정확한 노멀맵·Sprite 쿠키 조명 계약은 유지한다.

## 전경에서 인물 가림 방지

실제 NativeDraft01 원본에서 왼쪽 전경 나무와 낮은 수풀이 점프 중 인물과 다리를 가리는 것을 확인했다. 7개 전경 스프라이트만 플레이어의 보간된 실제 위치·키 주변에서 부드럽게 투명해지도록 수정했다. 나무·수풀의 원본, 시차 이동, 정렬 순서와 조명은 유지하고, 플레이어가 지나가면 원래 농도로 돌아온다. 확대·점프 중에도 카메라 중심 대신 인물 위치를 따른다. 수정 후 실제 화면 검토는 새 Native 기록에 구분한다.

## 첫 그림

`Art/GospelRenewal/Opening/temple-journey`는 이번에 새로 만든 가로 삽화다. 마리아·요셉과 길을 걷는 열두 살 예수님, 올리브 나무와 멀리 보이는 예루살렘을 그렸다. 인물은 오른쪽에, 제목을 읽을 공간은 왼쪽에 둔다. 글자나 UI를 원화에 굽지 않았다. 성전과 길은 학습 게임의 미술적 표현이며 실제 유적의 측량 복원은 아니다.

생성 원본은 보존하고 PNG 바이트를 그대로 프로젝트에 복사했다. 경로·크기·SHA-256은 `Tools/Art/GospelRenewal/Opening/temple-journey.json`, 기존 인물 원본과 새 UV 창은 `Tools/Art/GospelRenewal/Character/manifest.json`에 기록한다. 기존 NPC의 새 만남 배치와 실제 대화·말씀 도감은 여정 앱이 소유한다.

## 검증 범위

원화 직접 확인, 소스 사각형 범위와 원본 해시, 공백 검사를 수행했다. 실제 Unity·브라우저에서 걷기·달리기·양방향·점프·착지·등잔을 확인하는 일은 단일 릴리스 실행 담당의 새 Renewal 기록으로 남긴다. 이 문서의 원화와 코드 검토를 엔진 화면 또는 실제 기기 성능 검증으로 대신하지 않는다.
