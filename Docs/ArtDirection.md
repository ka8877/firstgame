# 아트 방향과 현재 상태

## 2026-10-23 사용자 플레이 피드백 반영

사용자가 이전 원화의 서양 반실사 얼굴과 각진 캐릭터·카드·배경을 원하지 않으며, 더 만화적인 인물과 자연스러운 이동을 요청했다. 이번 방향은 **분명한 선화·셀 채색의 서브컬처 판타지**다. 원신은 부드러운 실루엣·간결한 얼굴·색과 환경의 통일감을, 섀도우버스와 아리사는 만화적인 인물 중심 카드 표현을 참고한다. 기존 게임의 캐릭터·얼굴·의상·프레임·음악을 복제하지 않는다. 이전 그림에 필터만 입히는 작업으로 대체하지 않는다.

기존 원화와 첫 셀 셰이딩 개정은 승인된 최종 아트가 아니다. 이전 실행 결과는 [첫 아트 개정 기록](ValidationHistory/2026-10-23-art-edition.md)에 보존한다. 최신 실제 결과는 [검증 기록](Validation.md), 이미지 출처와 슬롯은 [일러스트](Illustration.md), BGM은 [음악](Audio.md), 초반 음성은 [음성](Voice.md)을 따른다. 이 문서의 구현 설명만으로 새 빌드나 공개판의 검증이 완료된 것으로 해석하지 않는다.

## 별빛의 서약 — 화려한 천공 판타지

- 성인 남녀의 매력적인 만화 캐릭터. 큰 눈과 간결한 코·턱, 또렷한 선화, 넓고 정돈된 셀 명암, 선명한 머리카락 덩어리로 표현한다. 실사 피부 질감·사진 같은 얼굴·서양 반실사 유화 묘사는 사용하지 않는다. 숲의 궁수 리리아·태양 기사 카엘·물결 마녀 세린·별의 기록자 노아는 이 프로젝트의 독자적 리더다.
- 40종 카드에 2×2 아틀라스 10장과 네 리더의 독립 초상을 연결한다. 숲·기사단·호수·별술사라는 기본 덱 네 가지의 색과 역할을 인물·지형·장비에서 읽을 수 있도록 한다. 리더 선택부터 전투의 기술 상세까지 같은 초상을 유지한다.
- 남색·라벤더·상아색·청록·금빛을 사용한다. 구름 위 건축과 꽃, 별빛이 있는 아름다운 전장 배경을 원화로 제공한다.
- 카드·도감·덱·전장·버튼을 하나의 둥근 형태와 가는 장식 테두리로 연결한다. 원화도 실제 둥근 영역으로 마스킹하며, 그림자와 얇은 안쪽 선으로 구분한다. 단순한 사각형 색판의 반복을 줄인다.
- 셔플 연출과 시작 손패 교체로 결투의 도입을 보여 준다. 카드·자원·단계·기술에 마우스 설명을 붙이고 모바일은 상세 보기·길게 누르기로 같은 정보를 제공한다. 화려한 장식이 비용·공격·생명·현재 단계나 사용 불가 사유를 가리지 않도록 한다.
- 일러스트에는 글자나 수치를 생성하지 않는다. 카드 이름·비용·공격·생명은 기존 정의에서 읽는 별도 UI다. 모바일 693×390에서도 모든 중요 글리프와 터치 면적을 확인한다.
- 음악은 선율·현악·브라스·하프·타악이 있는 웅장한 오리지널 판타지 곡이다. 반복 재생에 적합한 길이와 전개, 음량·음소거 조작을 제공한다.

## 새벽의 길 — 따뜻하고 청량한 애니메이션 모험

- 귀여운 블록 캐릭터와 사실적인 얼굴을 섞지 않고, 일러스트와 3D 모두 따뜻한 애니메이션 모험의 인상으로 맞춘다. 인물은 성인 비율과 고유한 복장·색을 유지한다.
- 예수님은 짙은 갈색 머리·짧은 수염·크림색 옷·붉은 겉옷, 미리암은 청록색 옷·크림색 머릿수건, 여행자는 남청색 옷과 가방을 유지한다. 역사적 외모의 단정이나 승인된 초상이라는 주장은 하지 않는다.
- 얼굴·눈·목·어깨·팔·옷자락·머리카락의 실루엣을 실제 메시로 다듬는다. 매끄러운 노멀만으로 각진 외곽선을 숨겼다고 판단하지 않는다. 셰이더의 명암 전환·림·외곽선도 조형과 함께 검수한다.
- 세 인물의 14본 Generic 리그에 무릎·발을 포함한다. Idle/Walk를 `Speed` BlendTree로 연결하고, 걷기의 발 디딤·무릎 굽힘·팔과 몸통의 움직임을 실제 이동 속도와 맞춘다. 제자리 Walk와 컨트롤러 이동의 결합이며 얼굴 연기·립싱크·발 IK가 모두 완성된 것으로 표현하지 않는다.
- 둥근 돌, 풍성한 나무, 꽃과 잔디, 청량한 물빛과 회화풍 하늘로 공간을 통일한다. `galilee-painted-sky` 원화와 하늘/물 셰이더·조명·카메라를 함께 조정해 과도하게 딱딱한 3D 인상을 줄인다. 기존 충돌체·문·NPC와 상호작용 위치를 보존하고, 시각 자산이 길과 카메라를 막지 않는지 확인한다.
- 대화 패널·초상·버튼도 둥근 형태와 부드러운 색을 사용한다. 자막 대비와 모바일 조이스틱·시점·대화 조작을 유지한다.
- 음악은 하프·목관·피아노·현악을 중심으로 따뜻하고 서정적으로 구성한다. 대사를 방해하지 않는 음량과 자연스러운 반복을 우선한다.
- 도입 9줄·첫 호숫가 11줄은 일반 한국어 MeloTTS 음성으로 읽는다. 실존 인물의 목소리를 복제하지 않으며 한 음성을 인물별 배우 연기라고 소개하지 않는다. 기존 Ink 문장과 정확히 맞는 클립만 재생하고 음량·음소거·다시 듣기를 제공한다.

## 제작과 검수 기준

1. 새 원화는 이미지 생성 도구로 제작한 독자적 에셋이며, 원본·프롬프트·해시·투명도·슬롯을 기록한다. 사용자 승인 전에는 승인 완료라고 쓰지 않는다.
2. 3D는 `Tools/Art/ToonDawn.md`의 생성 경로를 사용한다. 기존 `generate_proxies.py` 단독 실행으로 구형 모델을 덮어쓰지 않는다. FBX GUID·리그·발 기준 원점과 단일 스킨드 몸체를 유지한다.
3. Blender 렌더로 형태를 먼저 검수한 뒤 실제 Unity·Web 화면에서 재질·실루엣·배경·UI를 확인한다. Blender 미리보기를 플레이 화면 증거로 쓰지 않는다.
4. BGM은 출처와 샘플 라이선스를 기록하고, 클리핑·루프 경계·재생·음소거·볼륨·웹 첫 사용자 입력 후 재생을 확인한다. 기존의 효과음이나 파형 비프를 음악의 대체품으로 제공하지 않는다.
5. 카드 확장판은 기존 안정 ID를 보존하되 내부 schema 2/`starlight-0.2.0`과 별도 전투·덱 슬롯을 사용한다. 구 저장을 조용히 바꾸거나 삭제하지 않는다. 서사 진행·회귀 스키마는 유지한다. 화면 열기·호버·셔플 연출·음성 재생이 게임 규칙 RNG를 소비하지 않는지 확인한다.
6. 음성 파일의 문장 일치·클리핑·누락 검사, 실제 Unity/브라우저에서의 재생·중단·음량 검사, 사람의 발음·연기 청취를 구분한다. Blender 보행 미리보기나 음원 분석만으로 실제 게임의 자연스러움을 통과했다고 보고하지 않는다.

현재 제작 상태와 측정치는 각 자산 매니페스트 및 검증 기록이 기준이다. 화면 개선과 기능 테스트 통과를 상용 게임 수준의 최종 품질 달성으로 표현하지 않는다.
