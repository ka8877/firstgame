# 아트 방향과 현재 상태

요청에 언급된 **승인 원화, 기존 ZIP, 웹 시제품은 현재 작업 공간에서 제공되지 않았다.** 따라서 승인된 인상이나 색감을 재현했다는 주장은 하지 않는다. 아래는 첫 플레이를 구현하기 위한 제안과 교체 가능한 임시 자산 기준이다. 사용자 승인 또는 실제 게임 화면 검수가 완료된 최종 아트가 아니다.

## 별빛의 서약

- 오리지널 판타지: 한밤의 청색 돌, 오래된 금색 문양, 차가운 별빛, 절제된 청록색. 기존 게임의 카드 그림·로고·프레임을 복제하지 않는다.
- 카드의 원화 영역과 프레임·이름·비용·공격·체력·설명을 분리한다. 생성 원화에는 글자나 수치를 넣지 않는다. 상세 보기와 손패에서 같은 콘텐츠 정의를 읽는다.
- 2.5D 전장: 낮은 원형 돌 단, 금빛 나침반 문양, 외곽 결정 기둥. 카드와 클릭 가능한 슬롯의 대비를 우선한다. 조형물은 규칙이나 유효 배치 위치를 결정하지 않는다.
- 기본 팔레트: Midnight Slate `#17213B`, Moonlit Slate `#304063`, Antique Gold `#9C6B2B`, Starlight Cyan `#3DA3DB`. 이는 sRGB 표시용 근삿값이며 실제 URP 조명에서 다시 조정한다.
- 카드 일러스트 생성·연결·잘라 쓰기 방식은 `Docs/Illustration.md`를 따른다. 이미지 생성 결과도 검수 전 후보로 구분한다.

## 새벽의 길

- 최종 목표는 따뜻한 빛의 회화풍 반실사다. 현재 Blender 프록시는 단순한 면, 저밀도 천, 분리된 머리카락과 경직된 스킨을 가진 **동선·카메라 검증용 임시 모델**이다.
- 갈릴리 호수에서 영감 받은 작은 석조 쉼터, 올리브나무, 낚싯배, 그물, 갈대, 토기. 공간은 창작한 연결 장면이며 고고학적으로 검증된 재현을 표방하지 않는다.
- 예수님: 무염색 린넨과 흙빛 적색 겉옷, 따뜻한 올리브 피부, 짙은 갈색 머리. 이 임시 인상은 승인된 초상이나 역사적 외모의 단정이 아니다.
- 여행자: 린넨과 청회색 천, 작은 가방. 미리암: 청회색 천과 밝은 머릿수건. 얼굴과 천 주름, 손, 발, 머리카락은 최종 제작 시 교체한다.
- 기본 팔레트: Warm Stone `#947552`, Sunlit Linen `#D9C294`, Galilee Teal `#1F636E`, Earth Red `#873D2B`, Olive `#475C30`. 대화 자막 뒤에는 충분히 어두운 패널을 사용한다.
- 한 캐릭터와 한 공간부터 원화→턴어라운드→토폴로지→UV/재질→리깅→대기/걷기/말하기→Unity 조명 순서로 마무리한다. 현재 Generic 리그의 `BasicIdle`은 교체를 전제로 한 4초 호흡·고개 움직임이다.

## 글꼴, 재질, 조명, 접근성

- 한국어 자막과 규칙 설명을 실제 포함한 한글 글꼴 및 TMP 폰트 자산으로 제공한다. 작은 UI에서 장식 글꼴을 쓰지 않는다. 글꼴의 실제 포함 여부와 라이선스는 `AssetRegister.md`의 글꼴 항목과 검증 기록으로 확인한다.
- 소스 Blender 재질은 이름과 기본색을 명시적으로 유지한다. FBX가 Unity에서 자동으로 URP 재질을 만드는 것을 가정하지 않는다. Unity 에디터 생성 경로에서 URP/Lit 재질을 연결하고 스킨드 메시도 확인한다.
- 임시 자산에는 이미지 텍스처·UV·노멀맵·LOD가 없다. 웹 체험판 크기를 줄이는 장점은 있지만 최종 품질의 증거가 아니다.
- 광원은 따뜻한 주광과 차가운 환경광을 기본으로 한다. PC/웹 품질을 나누고, 실제 측정 전 프레임 속도나 로딩 시간을 보장하지 않는다.
- Unity 네이티브 가져오기로 확인한 환경 좌표는 `AssetRegister.md`를 따른다. 환경 FBX만 Y축 180° 정규화하며 석조 공간/충돌체/상호작용을 (x=−4,z=−3) 기준으로 맞춘다. Blender 렌더 좌표를 Unity 좌표와 동일하다고 가정하지 않는다.
- 갈릴리의 물은 현재 불투명 청록 재질이다. 수면 셰이더, 투명도와 반사, 그림자 접촉, 물가 전환은 후속 단계에서 추가한다.

## 교체 승인 기준

1. 실제 Unity 1080p 화면에서 손패, 선택지, 한국어 줄바꿈을 검수한다.
2. 플레이 카메라와 대화 카메라에서 얼굴, 시선, 천, 손, 관절을 검수한다.
3. 기존 프리팹의 논리 컴포넌트와 안정 ID를 보존하고 시각 자식만 교체한다.
4. 저작권·출처·수정 내역과 사용자 승인 상태를 자산 장부에 남긴다.
5. Windows 및 웹의 실측 결과를 남긴 뒤 해당 플랫폼에서 완료로 표시한다.

`Tools/Art/Previews`의 이미지는 **Blender 소스 렌더**다. Unity 실제 플레이 화면 또는 Windows/웹 빌드 실행 증거로 사용하지 않는다.

네이티브 Unity 플레이 씬의 실제 1920×1080 렌더는 `Artifacts/Screenshots/FantasyCards`와 `Artifacts/Screenshots/PathOfDawn`에서 확인한다. UI를 포함한 URP 오프스크린 캡처 방식과 검증 한계는 `Docs/UnitySmokeTests.md`를 따른다. 현재 카드 일러스트 연결과 한글 표시를 육안 검수했으며, 서사 캐릭터는 이 화면에서도 임시 프록시로 구분한다. 성능 달성의 증거로 사용하지 않는다.

## 실제 화면 검수 후속 작업

서사 캡처 `PathOfDawn/06-returned-title.png`에서는 타이틀로 돌아온 뒤에도 직전 대화의 가까운 카메라 구도가 남아 인물과 석조 벽이 크게 보인다. 타이틀 복귀용 카메라 구도를 정리한다. `07-continuing-state.png`에서는 대화 패널이 화면 아래 조작 안내 일부를 덮으므로, 대화 중 안내를 숨기거나 패널과 겹치지 않게 배치한다. 주요 제목·대사·버튼은 읽히지만 이 두 항목은 화면 연출과 배치의 후속 개선으로 남긴다.

이 육안 검수 항목은 `Docs/Validation.md`의 기능 테스트 통과와 별개다. 기능 통과를 최종 아트 승인으로 간주하지 않으며, 개선 후 같은 장면을 다시 촬영해 확인한다.
