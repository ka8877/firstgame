# 판마 상위 등급 확장 — fm-polish-2026-10-29

이 개정은 기존 플레이 가능 카드 2,571장에 **원본 상위 등급 유닛 75장**을 추가한다. 공개 DB에서 확인한 전체 15,350장의 원본 인쇄 그림은 그대로 유지한다. 전체 도감이 전부 전투 지원 카드라는 뜻은 아니다.

| 등급 | 이전 플레이 가능 | 이번 추가 | 현재 플레이 가능 |
|---|---:|---:|---:|
| 레어 | 21 | 28 | 49 |
| 스페셜 | 27 | 37 | 64 |
| 유니크 | 23 | 4 | 27 |
| 시크릿 | 15 | 6 | 21 |
| 레전드 | 4 | 0 | 4 |
| 전체 | 2,571 | 75 | 2,646 |

추가된 유니크는 **스파클러, 카오스마스터, 머메프린스, 리크리에이터**다. 신규 카드의 ID·이름·등급 전체 목록은 [검증 목록](../Tools/Data/Polish/verification.json)의 `newCards`, 원문과 구현 근거는 [명시적 허용 목록](../Tools/Data/Polish/premium-admissions.json)에 있다. 기존 2,571장의 전체 데이터 행과 기존 27개 기본 덱, 저장 schema3 및 콘텐츠 버전은 보존했다.

## 구현한 동작

- 원본 공격 기술: 강한은폐, 시간차공격, 멀티어택, 약탈공격, 공격이용, 분기공격, 솔버스트, 솔카운터, 연합공격, 음파·초음파, 숲의연합, 강한방어이용, 가치감정, 방어지원, 연환공격, 화염공격, 무기제압, 컨슘, 투척공격.
- 방어 기술: 실제로 나온 앞면 개수만큼 피해를 줄이는 코인디펜스, 상대 레벨 조건을 검사하는 기선제압, 빈 전열 수를 계산하는 프레셔. 공격·방어 기술이 함께 인쇄된 카드에는 양쪽을 모두 적용한다.
- 유니크: 소환 비용에 맞춘 다음 소울 코스트의 소울 환급, 실제 처치한 카드의 소환 소울 회수, 자신을 파괴한 낮은 레벨 유닛 복사, 소각장 최상단 아이템 재장착.
- 시크릿: 소각장 위쪽 유닛 최대 두 장을 손패 빈칸으로 이동한다. 새 카드를 생성하거나 기존 인스턴스를 복제하지 않는다.
- 부가 능력: 2차 강화 8장의 실제 소울 생산, 3차 강화 11장의 만능 장비 조건과 자기 레벨 **미만** 아이템 무료 장착. 코인예측도 실제 판정된 코인이 모두 뒷면일 때만 적용한다.

새 기술은 추가 피해와 AP 자체를 구분하고, 공격·반격에서 같은 규칙을 사용한다. 피해 이후 발동하는 효과를 앞당기지 않고, 이미 죽은 유닛을 HP=1 효과로 되살리지 않는다. 실제 코인 이벤트를 읽으므로 기술 표시를 위해 RNG를 추가 소비하지 않는다. 데스미로잉은 직접 공격뿐 아니라 크로스카운트·코인플레임의 실제 사망 원인도 추적한다. 자기 코인 감소로 죽은 경우에는 파괴자를 만들어 내지 않는다.

## 근거와 해석 범위

원본 수치·비용·코인·그림·ID는 기존 [전체 공개 DB 스냅샷](../Tools/Data/Renewal/complete-observations.json)을 사용한다. 기술 순서와 추가 피해 구분은 2017년 공식 도움말에서 연결된 [2016년 공식 기술 설명](../Tools/Research/FmRenewal/faq736-text.txt)을 참고했다. 소울 생산은 같은 시기의 [전투 설명](../Tools/Research/FmRenewal/faq734-text.txt)을 따른다. 이 자료만으로 서비스 종료 당시의 모든 패치를 복구했다고 주장하지 않는다.

공격이용은 공식 설명에 따라 AP 영구 증가가 아닌 추가 공격 피해로 처리한다. 솔버스트는 공식 설명에 있는 남은 무소울 소각도 수행한다. 원문 전체는 보존하고 이 차이는 공격 허용 목록의 `lateManualNote`에 기록한다. 소울퓨리는 DB의 AP/HP 증가와 공식 설명의 AP/DP 증가가 직접 충돌해 이번에 추가하지 않았다. 상태·오라·히어로·고정 기호를 구현하지 않은 카드의 설명을 삭제해서 전투 카드로 만들지 않았다.

리크리에이터의 원문은 장비 조건 면제를 명시하지 않는다. 따라서 일반 장비 조건과 현재 두 슬롯 한도를 적용하며, 실제 소각장 맨 위 아이템이 부적합하면 그 아래의 유리한 아이템을 임의로 골라 주지 않는다. 영혼의사슬은 현재 엔진의 파괴→소각장 이동→사망 기술 순서에 따라 방금 소각된 본인도 회수 대상이 될 수 있다. 이 두 경계 동작은 원 클라이언트 영상으로 독립 확인한 사항과 구분한다.

## 데이터·저장 검증

[기존 행 기준선](../Tools/Data/Polish/compatibility-baseline-2571.json)으로 이전 2,571장의 행 해시를 모두 검사한다. 신규 75장은 관측 원본의 전체 필드와 설명이 일치하고 그림 파일이 존재하는지 검사한다. 전체 도감 15,350개의 17개 필드는 생성기와 별도로 원본에서 투영해 검증한다. IL2CPP의 거대한 단일 초기화 함수를 다시 만들지 않도록 기존 최대128행·120개 `NoInlining` 함수 구조를 유지한다. 이전 분할 검증 기록은 `Tools/Data/Polish/before-archive-initialization-*.json`에 남겼다.

다음 턴 속성 소울 배열은 schema3의 선택 필드다. 구형 Unity JSON에서 누락되어 `null`이면 0으로 읽으며, 복사할 때 배열을 공유하지 않는다. 새 생성 카드는 원본 기술·원본 인스턴스·소유자·허용된 결과를 검증하는 출처 기록이 필요하다.

재현 명령:

```sh
python3 Tools/Data/Polish/build-admissions.py
python3 Tools/Data/Renewal/build-catalog.py
python3 Tools/Data/ClassicCards/generate-catalog.py
python3 Tools/Data/Polish/verify-premium-expansion.py
python3 Tools/Data/ClassicCards/verify-remaster.py
python3 Tools/Data/Renewal/verify-media.py
```

독립 데이터·이전 행/원본 아트·생성 재현 검사는 통과했다. 전투·저장 회귀 테스트와 실제 Unity·브라우저·배포 실행 결과는 실행 담당자가 `Artifacts/Validation/Polish`에 새로 기록한다. 이 문서의 데이터 검증을 실행 완료로 대신하지 않는다.
