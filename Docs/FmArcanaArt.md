# 판타지마스터즈 — 아르카나 타이틀 원화

개정은 `fm-arcana-2026-10-27`이다. 사용자의 현대적인 판타지·서브컬처 분위기 요청에 따라 타이틀과 로비의 전경 인물 원화를 새로 제작했다.

`Art/FmArcana/hero-duo`는 은발의 성인 엘프 궁수·마도사와 남색 머리의 성인 기사·마도사 두 명을 담은 투명 PNG다. 정교한 의상 장식과 보석색 계열의 셀 채색을 사용하며 기존 성채·숲 파노라마 위에 합성하도록 제작했다. 둘은 이 프로젝트의 새 가상 인물이며 기존 게임의 특정 캐릭터나 원작 판마에서 회수한 인물이라고 소개하지 않는다.

원본 PNG, 실제 생성 프롬프트, 픽셀·파일 해시는 `Tools/Art/FmArcana`에 있다. 런타임 PNG는 RGBA 픽셀이 같은 무손실 압축이며, 투명 배경은 이미지 생성 도구가 직접 만들었다. 기존 판마 원본 카드 그림과 출처는 그대로 보존하며 새 일러스트로 교체하지 않는다. 원작 전체 클라이언트 복구나 사용자 미적 승인이라는 주장은 하지 않는다.

전경은 가로 구도의 두 인물이므로 타이틀·버튼과 겹치지 않게 오른쪽에 배치하고 종횡비를 유지한다. 두 얼굴이 잘리거나 불투명 배경 직사각형이 생기지 않는지 실제 Unity·웹 화면에서 별도로 확인한다. 이 문서의 자산 생성·픽셀 검사는 실제 게임 UI 검증이나 실물 기기 성능 검사를 대신하지 않는다.
