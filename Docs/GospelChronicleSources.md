## 첫 장: 열두 살의 유월절 여정

탄생은 이전 사건을 보여주는 짧은 서문으로 둘 수 있다. 직접 조작하는 첫 장은 누가복음 2:41–52의 같은 여정을 따라간다. 탄생 시점의 목자·시므온·안나를 열두 살의 예수님 앞에 차례로 배치하는 기억 여행은 이 장의 실제 시간·공간으로 사용하지 않는다.

| 순서 | 이동·만남 | 근거와 표현 범위 | 말씀 발견 |
|---|---|---|---|
| 1 | 나사렛 집과 출발 준비 | 2:39–40의 나사렛·성장은 배경 요약, 2:41–42가 해마다의 유월절과 열두 살의 방문을 밝힌다. 집 구조·물품 준비·일상 인사는 장면 구성이다. | 2:41–42 |
| 2 | 가족과 순례길, 예루살렘 도착 | 부모와 함께 올라간다는 기록에 맞춰 걷는다. 이동 거리·길의 정확한 모습·대화 내용은 확정된 기록이라고 하지 않는다. | 앞서 찾은 구절을 다시 읽고 다음 장면 진행 |
| 3 | 절기를 마친 예루살렘 | 2:43은 예수님이 머무셨고 부모가 알지 못했다고 기록한다. 부모를 고의로 속였다는 동기나 부모가 버렸다는 해석을 추가하지 않는다. | 2:43–45 |
| 4 | 성전 선생들 가운데 | 부모가 찾으며 돌아온 2:44–45는 별도 서술 장면으로 연결한다. 예수님이 다른 장소의 부모 대화를 직접 들은 것처럼 만들지 않는다. 2:46–47의 듣기·묻기를 행동으로 보여 준다. | 2:46–47 |
| 5 | 마리아·요셉과 다시 만남 | 2:48의 마리아 말과 2:49의 예수님 말만 직접 대사로 인용할 수 있다. 2:50은 부모가 깨닫지 못했다고 기록하므로 즉시 이해했다는 결말로 바꾸지 않는다. | 2:48–50 |
| 6 | 부모와 나사렛으로 돌아감 | 2:51–52의 귀환·순종·성장을 읽는다. 귀환까지가 첫 장의 완료 조건이다. | 2:51–52 |

선생들이 구체적으로 무엇을 물었고 예수님이 어떤 답을 하셨는지는 이 본문에 기록되지 않았다. 창작한 문장을 예수님의 성경 발언으로 표시하지 않는다. 자연스러운 NPC 인사·이동 안내는 사용할 수 있지만 `장면을 위한 대화`로 구분한다. 해설자가 전하는 내용은 `본문 요약`, 그대로 가져온 절이나 발언은 `성경 직접 인용`으로 나눈다. 기록된 직접 대사에서도 화자가 말하지 않은 서술 꼬리말을 대사로 섞지 않는다.

## 다음 장: 요단강의 세례

첫 장을 마친 뒤 시간 전환을 명시하고 성인 예수님으로 바꾼다. 누가복음 3:23은 다음과 같다.

> 예수께서 가르치심을 시작할 때에 삼십세쯤 되시니라 사람들의 아는대로는 요셉의 아들이니 요셉의 이상은 헬리요

나이 표시는 **공생애 시작 · 삼십 세쯤**으로 할 수 있다. “정확히 서른 번째 생일에 세례를 받았다”거나 소년기 이후의 매년 행적을 안다고 말하지 않는다. 세례를 통해 처음 ‘예수’ 또는 ‘하나님의 아들’이 되었다는 설명도 본문에 덧붙이지 않는다.

마태복음 3:13–17의 순서로 짧은 첫 성인 장을 구성할 수 있다: 갈릴리에서 요단강에 이르심 → 요한의 말 → 예수님의 대답 → 세례와 물에서 올라오심 → 하늘의 소리. 요한과의 직접 대사는 각각 3:14와 3:15에 실제로 기록되어 있다. 강변의 길·NPC 배치·물의 깊이·몸짓은 시각 구성이다. 예수님이 세례받으실 때 요셉·마리아가 현장에 있었다고 이 본문을 근거로 배치하지 않는다.

누가복음 3:21–22는 예수님이 기도하셨다는 서술과 하늘의 소리를 함께 전한다. 같은 사건의 병행 본문으로 별도 페이지에 제시하며 서로 다른 문장을 하나의 정확한 인용처럼 합치지 않는다.

- 마태복음 3:17: “이는 내 사랑하는 아들이요 내 기뻐하는 자라”
- 누가복음 3:22: “너는 내 사랑하는 아들이라 내가 너를 기뻐하노라”

각각의 인용은 해당 장절을 유지한다. 누가복음의 나이 기록을 마태복음 본문의 문장인 것처럼 붙이지 않는다. 사복음서를 하나의 완전히 확정된 세부 연대기로 합쳤다고 주장하지 않는다.

## 말씀 도감과 기존 API 점검

말씀은 실제 장면·대화를 끝냈을 때 발견하고 도감의 해당 빈 페이지를 채우는 진행 보상이다. 장소·구절 발견 순서와 중복 획득 방지는 Core가 소유하고, UI는 발견 여부를 읽는다. 아직 발견하지 않은 본문은 초기 목록이나 반복 NPC 주제에서 미리 표시하지 않도록 한다. 본문을 바꾸거나 잘라서 빈칸으로 저장하는 대신 원문 데이터와 공개 상태를 분리한다.

검토 당시 기존 `GospelReading.SourceUrl`은 모든 구절에 누가복음 2장 URL을 반환한다. 새 성인 본문은 절별 출처 URL을 가져야 한다. 기존 `GospelStudyCatalog`의 여덟 기억 대화와 `GospelNpcCatalog`의 반복 주제는 새 선형 시간 진행·발견 도감과 분리해 이식해야 한다. 기존 저장의 식별자를 조용히 다른 사건으로 재사용하지 않는다. 기존 `IsVerbatim` 구분은 유지하되, 창작 NPC 대화를 `본문 요약`과 혼동하지 않도록 장면 대화 라벨도 고려한다.
