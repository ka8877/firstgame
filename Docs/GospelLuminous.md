# 예수님의 길 — 빛의 뜰 2D 개편

현재 개정은 `gospel-luminous-2026-10-28`이다. 사용자가 제공한 Ori와 Unity Lost Crypt 화면을 기준으로 2D 횡스크롤의 화면 구성·빛·깊이와 간결한 UI를 우선한다. 첫 시작은 바로 둘러볼 수 있는 새 장면으로 연결하고, 말씀 읽기와 기록은 기존 Gospel Core를 사용한다. 기존 카드게임은 변경하지 않는다.

## 그림과 실제 렌더링

공식 Lost Crypt 샘플의 개별 나무·풀·꽃·바위·하늘 원본 29개를 사용한다. 전체 그림 한 장으로 공간을 대신하지 않고 여러 시차 계층에 배치하며, 실제 지면 충돌과 Unity URP 2D 조명·노멀맵·Bloom을 연결한다. 성전 아치와 예수님·교사·마리아·요셉 그림은 이 프로젝트에서 새로 제작했다. 배경은 성경 학습을 위한 미술적 공간이며 실제 성전의 측량 복원은 아니다.

소년 예수님의 머리·팔·팔꿈치·허벅지·무릎·머리카락을 별도 관절로 움직이고, 튜닉과 두른 천은 격자 메시로 변형한다. 위치는 Rigidbody2D와 실제 CapsuleCollider2D가 소유하며, 그림은 측정한 속도·접지·방향에 반응한다. NPC는 구분되는 세 인물 원화의 조용한 배치이며 주인공과 같은 관절 애니메이션을 제공한다고 표시하지 않는다.

원본 샘플의 고정 커밋·파일 해시·Unity Companion License와 사용 범위는 [참고 자료](GospelLuminousReferences.md), [캐릭터](GospelLuminousCharacter.md), [UI](GospelLuminousUI.md)에 기록한다. Ori의 상용 클라이언트나 소스를 복구한 결과로 소개하지 않는다.

## 조작과 화면

- A/D 또는 좌우 방향키: 이동. Shift: 달리기. Space: 점프. E: 말씀/현재 만남.
- 마우스 휠: 2D 카메라 확대·축소. I: 인물. B: 가방. M: 말씀 기록. Esc: 메뉴/복귀.
- 터치는 별도 좌우 누르기·달리기 토글·점프·대화 버튼을 사용한다.
- 가방의 토기 등잔은 실제 손의 작은 등잔과 2D 조명을 켜고 장착 상태를 저장한다. 소지품은 학습용 게임 설정이다.

화면 위에는 현재 길과 읽은 말씀 수, 아래에는 작은 성경 인용을 둔다. 상태/소지품/기록/본문은 메뉴에서 펼치며 배경이 주인 화면을 유지한다. 가상의 체력·화폐·전투 능력치는 표시하지 않는다.

## 말씀과 이전 저장

새 여정 시작 즉시 공간을 둘러볼 수 있다. 말씀 버튼/E로 탄생의 세 본문을 읽은 뒤 성전의 네 목표를 순서대로 진행한다. 단순 이동·본문 미리보기·메뉴 열기는 읽은 말씀을 추가하지 않는다. 직접 인용과 학습용 해설은 구분한다. 현재 실제 성경 범위는 탄생 도입과 누가복음 2장 성전 방문이며 이후 생애는 이 개편의 구현 범위가 아니다.

`gospel-journey`/schema1/`gospel-0.1.0`과 기존 슬롯을 유지한다. 선택 필드 `presentationSpace`가 없는 예전 3D 저장은 읽은 말씀·현재 대화·장착을 그대로 복원하고 해당 목표의 새 2D 진입 위치로 연결한다. 새 저장은 `luminous-side-v1`과 실제 2D 위치를 기록한다. 알 수 없는 좌표 공간은 현재 여정을 바꾸지 않고 거부한다. 예전 3D 원본 좌표를 새 2D 위치로 오해하지 않으며 읽기만으로 원본 파일을 갱신하지 않는다. 현재 앱의 명시적 저장·자동 저장은 새 좌표 공간을 기록한다.

## 실행 근거

새 저장 호환성 세 건을 포함한 순수 규칙/저장 검사 145개를 실제 실행해 통과했다. Unity 렌더링·조작·새 빌드·공개 URL 검증은 별도의 [이번 실행 기록](GospelLuminousValidation.md)을 따른다. 원화 원본이나 코드 검토를 실제 엔진 화면·성능·사용자 미적 승인으로 대신하지 않는다.
