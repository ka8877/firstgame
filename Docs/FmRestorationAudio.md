# 판타지마스터즈 효과음 개정

현재 개정은 `fm-restoration-2026-10-27`이다. 기존 원작 BGM의 파일·출처·장면 전환 방식은 유지하고, 효과음은 이 프로젝트에서 새로 제작한 짧은 소리 25종을 사용한다. 원작 클라이언트나 원본 효과음을 역공학으로 회수한 것으로 소개하지 않는다.

## 소리와 실제 입력

| 행동 | 소리 |
|---|---|
| 마우스 올림·키보드 선택, 버튼 클릭, 확인, 취소, 불가능한 사용 | 짧은 목재·금속 클릭과 서로 다른 알림 |
| 카드 선택·끌기·취소, 새 손패·손패 교체 | 종이 마찰, 집기·뽑기, 연속 셔플 |
| 지형 전개·유닛 배치·장비 부착 | 낮은 석재 울림, 등장, 금속 걸쇠 |
| 마법 공개·회복 | 상승하는 마법 잔향·별도의 회복 화음 |
| 코인·공격·반격·피해·방어 | 금속 동전, 날아가는 칼날, 타격, 금속 방패 |
| 손패/덱 소각·유닛 파괴·준비 단계·결과 | 타는 종이, 흩어지는 파편, 단계 알림, 승리·패배 짧은 구절 |
| 명시적 저장 버튼 | 저장 알림; 자동 저장 때에는 반복 재생하지 않음 |

전투 소리는 실제 `BattleEvent`가 화면에 재생될 때 한 번 발생한다. 공격은 동작 시작과 실제 타격 시점의 소리를 분리한다. 카드 사용을 실패하면 오류음만 더하고 규칙·RNG·진행 상태를 바꾸지 않는다. 연출 건너뛰기는 생략한 소리까지 한꺼번에 재생하지 않는다. 결과창 재생성 때 승리음을 반복하지 않는다. 미리 예약한 마법은 종이 소리만 내고 실제 공개할 때 마법 소리가 난다.

## 출력과 설정

`FmBattleAudio`와 `FmSfxHost`는 화면 UI가 지워져도 살아 있는 12개의 2D 음성 풀을 사용한다. 이전 `.24` 소스 음량과 합성 효과음의 낮은 진폭을 여러 번 곱하던 구조를 없애고 별도의 효과음 음량을 적용한다. 기본값은 82%이며 `FC.effects.volume`과 `FC.effects.muted`에 저장한다. BGM의 기존 설정·재생 위치·브라우저 음악 브리지에는 영향을 주지 않는다.

소리 설정에서 효과음을 켜고 끄거나 음량을 바꾸고 `전투 효과 듣기`로 확인할 수 있다. 음악 설정은 같은 화면의 별도 버튼으로 연다. 음소거·0%는 이미 재생 중인 효과음도 즉시 멈추며, 다시 켰을 때 지난 효과음을 뒤늦게 재생하지 않는다. UI 재생성·해상도 변경 자체로 소리가 나지 않는다. 터치 입력에는 마우스 올림 소리를 추가하지 않는다. 동일한 짧은 이벤트의 우발적 중복만 12–95ms 동안 제한하며 서로 다른 공격·타격은 정상적으로 겹친다. 모든 소리는 음성·외부 서버·추가 다운로드 없이 Unity 리소스에 포함된다.

## 제작과 검증 범위

`Tools/Audio/Restoration/render-sfx.py`는 고정 시드로 필터한 잡음·비정수 배음·타격·종이 마찰·음높이 변화와 짧은 좌우 반사를 만든다. PCM16/44.1kHz/stereo WAV 25개는 총 2,617,996바이트다. 출력별 SHA-256·길이·RMS·DC·peak는 `sfx-manifest.json`, 출처는 `SOURCE-NOTICE.txt`에 있다. 모든 파일에서 유한한 샘플, peak 0.62 이하, 클리핑 0, 처음·끝 0, DC 절댓값 0.001 미만, RMS 0.012 초과를 실제 파형으로 확인했다. 이 분석은 사람의 청취 평가나 게임 출력 검증을 대신하지 않는다.

최신 실제 Unity/Web 검증은 `RestorationValidation.md`의 해당 결과를 따른다. 검증용 읽기 전용 관찰은 `FmBattleAudio.LastCue`, `PlayedCount`, `History`, `FmSfxHost.LoadedCueCount`, `ActiveVoiceCount`다. 관찰 기록은 재생을 요청한 시각·음량·클립을 남기며, 실제 출력 PCM과 구분한다. 브라우저에서는 첫 입력 후 Unity 오디오가 허용되며 BGM을 끈 상태에서 클릭·셔플·배치·코인·타격을 따로 검사해야 한다.
