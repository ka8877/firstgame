# 인물·가방·안내도

현재 개정 `gospel-toon-2026-10-27`은 I(인물), B(가방), M(안내도)와 HUD 버튼으로 같은 네 탭 화면을 연다. 인물 화면은 현재 성전 구간의 나이·의복·목표·본문·실제 읽기를 완료한 구간 수를 표시한다. 전투/성장 수치를 구현된 기능처럼 꾸미지 않는다.

소지품 여섯 개는 학습용 게임 설정이다. 성경에 이 물품의 소유가 기록되어 있다는 주장이 아니다. 튜닉·샌들은 현재 외형, 물주머니는 설명 가능한 소품이며 소모 효과를 표시하지 않는다. 수첩은 실제 말씀 기록을, 안내도는 현재 플레이어·실제 NPC·현재 말씀 장소의 위치를 연다. 원본 벡터 아이콘은 해상도 독립 UI로 직접 그린다.

토기 등잔은 실제 3D 모델과 따뜻한 점광원을 켜고 끌 수 있다. `GospelSave.equippedUtility`는 기존 schema1의 선택 필드이며, 값이 없는 예전 저장은 등잔 보관 상태로 열린다. 장착을 변경해도 성경 본문·대화 위치·읽은 말씀은 바뀌지 않는다. 알 수 없는 도구 ID는 저장 오류로 거부하고 원본을 보존한다. 같은 기존 여정 슬롯에 저장된다.

안내도는 현재 게임 공간 x/z 좌표를 직접 투영한다. 성전 고고학적 실측도는 아니다. 실제 이동 조작과 말씀의 진행은 기존 모터·Core가 소유한다. 메뉴에서는 이동 입력을 멈추고, 닫으면 기존 목표로 돌아간다.

검증 결과는 새 `Artifacts/Validation/Restoration`의 실제 실행 기록에 따로 기록한다. Core 검사는 이전 schema1 열기, 장착 저장 왕복, 본문 진행 불변, 알 수 없는 도구 거부를 다룬다.
