# 판마1 후기 자료를 적용한 카드 중심 UI

개정 `fm-renewal-2026-10-29`. 사용자가 카드와 능력치가 따로 보이는 문제와 2005년 중심 화면을 지적해, 직접 확인한 2017년 플레이 영상과 후기 공식 홈페이지 미술을 기준으로 표시 방식을 바꾼다. 원작의 마지막 클라이언트 전체를 회수했다거나 모든 시기의 화면/규칙이 같다고 주장하지 않는다.

## 실제 참고 자료

- `Tools/Research/FmFidelity/VideoFrames/Gameplay2017/0090.0s.png`와 `118.00s.png`를 원본 크기로 직접 확인했다. 2017-07-02 실제 판마1 플레이는 파란 연무 배경, 로마 숫자 I–V의 다섯 칸 전열, 카드 아래 부분에 통합된 능력치, 위쪽 가로 코인 패널과 우측 상태·덱·소울 레일을 보여준다. 기존 2005년 녹색 대리석을 유일한 후기 화면으로 사용하지 않는다.
- `Tools/Research/FmRenewal/late-bg-host.bin` 원본 2000×610 JPEG를 직접 확인했다. 2017-12-16 공식 홈페이지가 참조한 실제 후기 배경이며, 해당 이미지의 보존본은 2015-11-05다. `late-bg-host.json`에 출처를 보존한다. 클라이언트 로그인 스크린샷으로 소개하지 않는다.
- 위 JPEG를 `Resources/Art/FmRenewal/late-official.jpg`에 바이트 변경 없이 복사했다. 새 타이틀·로비의 UI는 이 원작 인물 배경 위에 다시 구성한다. 원본 픽셀이나 날짜를 바꾸지 않으며, UI에서만 원본 윗부분을 종횡비 보존하여 배치한다. `ui-art-use.json`에 해시와 UI용 UV 범위를 기록한다.

## 카드가 전장의 조작 대상

손패·전열·중앙 대결 카드는 같은 원본 인쇄 이미지 전체를 종횡비 그대로 사용한다. 전투 중에는 **그 카드 안**에 현재 이름·AP·DP·HP와 실제 코인 결과를 겹쳐 표시한다. 카드 밖 우측 능력치 판넬과 별도 이름줄을 없앴다. 작은 화면에서도 카드를 왼쪽 절반으로 축소하지 않는다. 손패는 현재 비용과 기본 코인 산식을 카드 아래에 표시하며, 상세/원본 보기에는 동적 표시 없이 원본 전체를 보여준다. 덱 편집의 첫 화면도 큰 카드 보기다.

동전 판정 이벤트는 Core가 넘긴 `hasStatTransition`과 `before/afterAttack/Defense/Health`만 읽는다. 카드의 값은 `5 +2`처럼 현재 수치와 부호 있는 변화량을 한 줄에 표시하고, 중앙 전투 안내는 `AP 3→5 (+2)`처럼 이전 수치까지 함께 표시한다. UI는 코인을 다시 던지거나 RNG를 소비하지 않는다. 코인 미리보기는 그 판정에만 적용해, 다음 피해 이벤트에서 이전 HP가 계속 남지 않게 한다. 공격/반격/소각/효과 재생과 실제 중간 스냅샷을 유지한다.

현재 화면의 배치 좌표는 손패 y0.012–0.277, 아군 지형0.285–0.358, 아군 전열0.365–0.615, 안내0.618–0.656, 적 전열0.660–0.910, 적 지형0.919–0.995다. 전열의 카드 표면이 실제 클릭·끌어놓기와 긴 누르기/마우스 안내에 연결된다. 각 효과의 출발·도착 좌표와 대결 카드 위치도 함께 변경했다.

## 전체 원본 도감과 이미지 로딩

전체 원본 도감은 고정 30장/5등급 필터를 제거하고 현재 데이터 전체를 사용한다. 이름·원작 번호·기술 본문 검색, 속성 필터, 실제 모든 등급의 수와 필터, 페이지 이동을 제공한다. 출전 지원 카드는 상세에서 덱 편집으로 연결하고, 그 외 카드는 원문과 미지원 사유를 보여준다. 도감 숫자를 출전 가능 카드 수로 소개하지 않는다.

대규모 원본은 `StreamingAssets/Cards/<ID>.jpg`를 필요할 때 읽는다. `FmStreamingCardArt`는 Web와 Windows의 로컬 경로를 처리하며 동시에 최대3개 요청, 사용하지 않는 이미지96개 캐시를 유지한다. 이미 닫힌 페이지의 대기 요청은 시작 전에 건너뛰고, 실패한 요청은 30–300초 간격으로 재시도한다. 같은 RawImage에 다른 카드를 연결하면 이전 요청의 소비자를 해제한다. 현재 화면에 붙은 텍스처를 지우지 않고, 닫힌 화면의 참조를 정리한 뒤 오래된 텍스처부터 비운다. UI를 재생성하지 않고 같은 카드의 RawImage에 결과를 넣는다. 기존605종의 Resources 원본/메타데이터는 변경하지 않는다. 전송용 JPEG와 원본 WebP의 차이·다운로드 범위는 카드 데이터 담당의 근거를 따른다.

## 검증 상태

이는 현재 구현 계약이다. 소스 공백 검사는 통과했으나 Unity·브라우저·공개 URL의 실제 실행 결과는 `Artifacts/Validation/Renewal` 및 릴리스 담당의 새 보고서를 따른다. 원본 자료 직접 확인을 게임 실행 통과나 사용자의 미적 승인으로 대신하지 않는다.
