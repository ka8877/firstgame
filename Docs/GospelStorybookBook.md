# 이야기가 한 면씩 남는 성경

`gospel-storybook-2026-11-02`의 `GospelStorybookUi`는 이전 목록형 성경/본문 병렬 대화 화면을 대신한다. 게임이 시작하면 탄생을 앞둔 길·구유·목자들의 밤·아기 때 성전 방문을 원화와 짧은 대화로 따라간다. 실제 조종은 기록이 남은 열두 살 시점부터다. 직접 인용·기록의 요약·게임용 극화 대사는 대화 옆에 구분한다. 기록되지 않은 성장기를 실제 사건으로 채우지 않는다.

사건의 마지막 대화를 마치면 Core가 해당 본문을 한 번 지급하고 App이 먼저 저장한다. 책의 새 면에 기록되는 연출은 이미 획득한 말씀을 보여 주며, 본문을 별도로 읽어야 다음 사건으로 넘어가는 조건은 없다. 대화 중 성경을 열거나 전체 새로고침/이어하기를 해도 발견 상태와 기존 대화 위치를 유지한다. 기존 23개 목표·19개 본문의 ID·직접 인용·옛 저장은 보존한다. 이후 사역·십자가·부활·승천은 이번 실행 범위에 포함하지 않는다.

성경은 새로 그린 가죽 표지·종이 단면·책등·두 장의 펼쳐진 면 위에 실제 텍스트를 조판한다. 한 면에 한 본문, 한 펼침에 두 본문이다. 첫 사건 이전에는 두 면이 모두 비어 있으며, 사건을 마치면 완료 순서대로 본문을 채운다. 미발견 면에는 미래 제목·구절·본문·삽화를 생성하지 않는다. 긴 본문은 각 면 안에서 독립적으로 스크롤한다. 이전/다음 면·최근 말씀으로 찾아가며, 별도의 목록 도감을 정독하는 방식이 아니다.

새 원화는 오리지널 생성물이며 이미지 원본·알파·해시를 `Tools/Art/GospelStorybook/sources.json`에 보존한다. 그림 속 의복·풍경·조명·공간은 사건의 미술적 표현이며 고고학적으로 복원된 사진이 아니다. 장면 atlas는 UI에서 각 사분면의 UV만 선택하고 원본 픽셀은 바꾸지 않는다. 책 역시 그려진 빈 면 위에 게임 UI가 정확한 본문을 표시한다. 미발견 내용을 원화에 미리 써 넣지 않았다.

PC와 작은 터치 화면의 실제 가독성·입력·본문 미노출·발견/저장 연결은 새 Reprise 검증 근거를 따른다. 소스 작성이나 원화 생성 자체를 실행 검증으로 소개하지 않는다.
