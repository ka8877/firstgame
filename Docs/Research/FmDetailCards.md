# 판타지마스터즈 세부 보완 — 카드·백필드 근거

개정 `fm-detail-2026-10-27`. 확인일2026-10-27, 사용자 표시 시각 기준 Asia/Seoul.

## 추가 카드 72종

카탈로그는 **250종: 지형28·유닛180·마법15·아이템27**이다. 기존178종의 전체 선택 레코드·WebP·PNG·Unity GUID는 `Tools/Data/Detail/compatibility-baseline-178.json`과 대조해 보존했다. 콘텐츠 버전 `fm-classic-0.1.0`과 schema3, 기존 다섯50장 기본 덱의 카드 순서·ID는 바꾸지 않았다.

공개 팬 DB의 완전한 문서 필드를 읽은 `Tools/Data/Detail/category-*-observations.json`에서72종을 선정했다. 정상 공개 Firestore 요청의 필터·응답200·바이트·SHA-256을 보존했다. 유닛 후보 조회는2000개 제한 표본이며 원작 전체 DB나 전체 클라이언트 복구가 아니다. 선택한72개 전체 레코드는 `selected-records.json`, 재현 도구는 `fetch-observations.py`와 `apply-selection.py`다.

- 지형14종: 7속성마다2종을 추가했다. 켈타인의새벽·번제단·추억의장소·숨겨진길·천사의타락지·거인의침략지·왕궁입구와 땅끝의요새·폭염신전·세상의끝·침엽수림·숨겨진대장간·의문의지저·성소의나무다. 모두 실제LP1, 해당 속성 소울1+총소울1 생산을 보존한다.
- 유닛44종: 각7속성마다 레벨1–6을 한 종씩 추가하고, 물의 레벨7넵튠과 암흑의 레벨8스컬둠터틀을 추가했다. 섀도우위치·불꽃의마녀·머메소서리어·미라클엘프·페어리퀸·워마스터·빛의무녀 등이다. AP/DP/HP·색/총소울·유지비·코인식·장착 능력·개별 덱 제한을 원본 필드에서 생성한다. 신규 유닛44종은 실제 N랭크다.
- 아이템14종: 7속성마다2종이다. 다크로브·검은거미줄·루비목걸이·불꽃방패·얼음조각상·아이스플라워·숲요정방패·엘프의장난감·마법사반지·핼버드·수호의목걸이·모래향로·헤일로·제압의길이다. 증가/감소 부호와 장착 능력 제한을 보존한다.

모든 신규 카드는 `TextExtra`가 비어 있다. 유닛은 실제 두 기술 필드와 AP/DP/HP 연산 종류가 모두 기본형이고, `TextBase`도 비어 있다. 장비는 순수 가감 수치와 대괄호 안의 설명문만 있으며, 지형은 LP1과 설명문만 있다. 기술 필드가 없다는 이유만으로 `TextExtra`의 추가 능력을 삭제한 카드를 넣지 않았다. 새 전투 능력 구현은 필요하지 않았다.

실제 수록 등급은 **9종**이다. 프리116·커먼62·언커먼42·레어1·스페셜11·업그레이드3·유니크1·이벤트13·레전드1이다. 새 레전드 [제압의길](https://fmlunatic.com/card/15120941678)은 원본 인쇄 카드에 `LEGEND`, `+2 / 0 / +2`가 보인다. 실제 비용은 무소울1, 레벨1, 덱 제한1이며 부가 기술은 없다. 이카젠·시크릿·에픽은 여전히 미수록이다. 신규72종의 개별 덱 제한은4장69종·2장2종·1장1종이며 등급별 일괄 제한을 발명하지 않았다.

원작 카드 원화는 `Tools/Art/ClassicCards/Originals`의 실제 WebP와 Unity PNG에 보존한다. 기존 파이프라인으로 컨테이너만 무손실 변환하며, 크기·RGBA 픽셀·해시를 대조한다. 새 그림을 원작 원화로 대체하지 않았다. 직접 확인한 대표 인쇄 원본과 DB 전체 필드/픽셀 검증을 구분한다.

## 원작의 지형 표시와 로비

사용자가 기억한 지형의 별도 표시는 원작 자료에서 확인됐다. [2005년 공식 인터페이스 안내](https://web.archive.org/web/20050807002655id_/http://www.fantasymasters.co.kr:80/Guide/Manual/tutorial2_1.asp)의14번은 “백필드: 지형카드를 내려놓는 자리입니다. 최대10장까지 내려놓을 수 있습니다.”라고 설명한다. 보존 본문은 `Tools/Research/FmFidelity/official-interface-guide.json`이다.

직접 본 원본 `Assets/Resources/Art/Revival/interface-game.png`는 프론트필드 아래, 손패 위에 원화와 이름이 있는 지형 카드를 보여준다. [2017년 실제 플레이](https://m.blog.naver.com/orderandchaos030/221042522552)의 원본90초 프레임 `Tools/Research/FmFidelity/VideoFrames/Gameplay2017/0090.0s.png`에서도 같은 위치에 지형 세 장의 원화·이름·LP1이 보인다. 단순 소울 점만으로 표시하던 현재판의 누락을 판단할 근거다. 두 자료의 화면 전체를 현재 게임 배경으로 붙이는 방식은 사용하지 않는다.

같은 공식 안내의 로비6–8번은 계급 아이콘과 레벨, 아이디, 승패·SP·경험치를 설명한다. 직접 본 `Assets/Resources/Art/Revival/interface-lobby.png`에는 방/대기/채팅 탭, 방 목록, 접속자 목록, 오른쪽 프로필 열과 아래 튜토리얼·리플레이·덱 편집이 있다. 단일 연습판의 프로필은 실제 로컬 진행과 기록을 연결해야 하며 가짜 온라인 접속자·유료 재화·서비스 계정을 꾸미지 않는다.

## 검증 범위

`python3 Tools/Data/ClassicCards/verify-remaster.py`에서250종 선택·원본 미디어·생성기 재현과 기존96/161/178종 보존을 확인했다. 새 카탈로그로 Core108개를 실행해 통과했다. Unity의 새 CardAsset72종 생성·전체250종 의미 검증, 실제 백필드/로비 조작과 웹 배포는 릴리스 담당의 이번 개정 실행 보고서에 따로 기록한다. 소스 검증을 Unity 실행이나 미적 승인으로 대신하지 않는다.
