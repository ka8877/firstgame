# 판타지마스터즈 전투·등급 보완 근거

개정 `fm-fidelity-2026-10-27`. 이번 작업은 판타지마스터즈 한 게임에 집중한다. 원작 카드 DB의 실제 분류·수치와 확인된 전투 절차를 유지하면서 화면과 입력·전투 재생을 보완한다. 원작 클라이언트 전체 소스 복구나 전체 카드 기술 구현을 뜻하지 않는다.

## 실제 카드와 등급

현재 **178종: 지형14·유닛136·마법15·아이템13**이다. 이전161종의 원본 JSON 행·WebP·PNG·Unity GUID는 그대로 보존했다. [161종 호환 기준](../../Tools/Data/FmFidelity/compatibility-baseline-161.json)과 [추가 감사](../../Tools/Data/FmFidelity/import-verification.json)에 개별 해시와 비교 결과가 있다. 기존 네 기본 덱의 카드 순서·ID도 유지한다.

새17종은 [실제 조회한 전체 공개 DB 레코드](../../Tools/Data/FmFidelity/selected-records.json)를 기준으로 선정했다. 후보 필드 몇 개만 보고 수록하지 않고 `TextBase`·`TextExtra`·장착 능력·요구 소울·각 AP/DP/HP 코인·랭크·개별 `DeckLimit`까지 확인했다. 별도 기술이 없는 `Skill1/2=1` 카드도 `TextExtra`에 다른 기능이 있으면 그대로 바닐라 카드로 만들지 않았다. 인쇄 원본17장도 직접 검토했으며, WebP→PNG는 픽셀과 크기를 바꾸지 않는 컨테이너 변환이다.

추가 구성은 업그레이드3종(다크핸드·님블피라냐·스톤스캘럽), 유니크1종(킹핀사이클롭), 이벤트13종이다. **모두 실제 개별 DeckLimit이2**이며 이를 그대로 적용했다. 등급 전체를 무조건 같은 장수로 제한하는 새 규칙은 만들지 않았다. 현재 실제 수록 등급은 프리·커먼·언커먼·레어·스페셜·업그레이드·유니크·이벤트의8종이다.

공개 DB 분류의12등급과 N/C/B/A/S 랭크는 서로 다른 개념이다. `CardDefinition.rank`와 `CardCatalog.RankName()`을 별도로 두었다. 현재136개 유닛은 모두 실제 N랭크이며, C/B/A/S 카드의 지원이 검증됐다고 표시하지 않는다. 레전드·이카젠·시크릿·에픽은 별도 기술을 누락하지 않고 정확히 재현할 대표를 확정하지 못해 실제 수록 수0으로 표시한다. 등급을 바꾸거나 지원하지 않는 기술을 지워12개 칸을 채우지 않는다.

## 실제 추가된 카드 기능

- **1차 강화 손패 소각:** [카오스브링거의 공개 상세](https://fmlunatic.com/card/4071421211)에 “1차 강화 카드는 핸드에서 소각장으로 버릴 경우 사용가능한 무소울1을 생성”한다고 명시돼 있다. 이 공통 특징을2004년의 세1차 강화 카드에 적용한다. 색 소울은 증가시키지 않고 사용 가능한 총소울만1 증가시킨다. 자원 상한을 넘는 부분은 받지 않는다. 2차·3차 강화의 다른 특징을 이 카드에 섞지 않는다.
- **킹핀사이클롭:** [해당 카드 자체의 상세](https://fmlunatic.com/card/5112322069)는 만능 장착과 “자기 레벨 미만의 아이템을 장착할 때 소울을 지불하지 않는다”를 명시한다. 원본 `UnitType=1`의 만능 장착을 보존하고, 낮은 레벨 아이템만 색·총소울 지불을 면제한다. 기존 장착 가능 검사와 체험판의 유닛당 아이템2장 상한은 유지한다.
- **별도 마법 예약 칸:** 기존 `Play`는 빈 첫 칸에 마법을 예고한다. 새 `CanPlayInSlot/PlayInSlot(player,id,reservationLane,targetLane,out reason)`은 마법을 예고할 빈 칸과 효과 대상 칸을 분리한다. 유닛은 `reservationLane`, 아이템은 `targetLane`을 사용한다. 원래 API와 저장 형식은 유지한다.

손패 소각은 `CanDiscardHand/DiscardHand`로 실제 손패를 소각장에 옮긴다. 자신의 준비 중이고 시작 손패가 확정된 때만 허용한다. [2005 공식 오프라인 가이드](https://web.archive.org/web/20051101013311id_/http://www.fantasymasters.co.kr:80/Guide/Manual/tutorial6.asp)는 준비 완료 전에 카드를 소각할 수 있다고 설명한다. 직접 재조회한 문장·해시는 [근거 파일](../../Tools/Research/FmFidelity/hand-discard-official-evidence.json)에 있다. 이번 구현은 손패에 한정하며 필드 유닛·장착 아이템·지형의 임의 소각 전체를 지원한다고 주장하지 않는다.

소각은 카드 배치와 구분해 `playedThisPreparation`을 바꾸지 않는다. 따라서 그 전에 카드를 배치하지 않았다면 기존 손패 셔플은 여전히 가능하다. 이는 새 동작과 기존 `play` 이벤트 기반 저장 검증을 일관되게 유지하기 위한 **이번 구현의 선택 정책**이다. 해당 세부 조합까지 공식 문장에서 확인했다고 표시하지 않는다. 소각·장착 검사는 RNG를 소비하지 않는다.

## 전투를 순서대로 보여 주는 계약

기본 공방·소울·코인 결과 산식은 이번 개정에서 바꾸지 않았다. 기존 전투는 Core에서 즉시 결과를 계산했으나, 화면이 개별 단계를 표시할 구조화 정보가 부족했다. 새 `BattleEvent`는 기존 `kind/text/actor/amount`를 보존하고 아래 선택적 정보를 추가한다.

| 필드 | 의미 |
|---|---|
| `hasPresentationData` | 새 메타데이터가 있는 이벤트. 이전schema3 저장에는 없어도 된다. |
| `source/targetInstanceId`, `source/targetDefinitionId` | 실제 행동 카드와 받는 카드의 안정 ID |
| `source/targetPlayer`, `source/targetLane` | 실제 소유자와 칸. 없는 값은−1 |
| `coinIndex`, `coinHeads` | 이번에 판정한 코인의1부터 시작하는 순번과 실제 앞면 여부 |
| `attack/defense/health` | 이벤트 시점 행동 유닛의 AP/DP/남은HP |
| `targetHealth` | 해당 사건 적용 직후 받는 유닛의 남은HP |
| `stat`, `amount` | 마법 대상의 실제 변경 능력치와 부호 있는 변화량, 또는 실제 피해량 |

`BeginPlaybackCapture()`에서 수집을 켜고 `EndPlaybackCapture()`로 끄면서 프레임 목록을 받는다. 각 프레임은 이벤트의 복사와 그 직후 두 플레이어의 깊은 복사, 턴·공격자·단계·승패를 갖는다. 생성·저장 로드 시에는 수집이 꺼져 있다. 이 임시 목록은 `BattleState`와 저장·RNG에 들어가지 않는다.

이벤트 순서는 실제 카드 사용, 마법 공개→대상별 효과→효과 완료, 개별 코인→최종 수치, 공격→살아남은 수비의 반격→파괴→실제 덱 소각→소울 회복·유지비→공수 교대다. 한 장씩 소각된 카드도 정확한 소각장 상태를 가진다. 기존 `damage` 요약 로그는 호환을 위해 남아 있으므로 화면에서 같은 타격을 중복 재생하지 않는다. 상대 손패와 예고 마법의 메타데이터가 있다고 뒷면을 미리 공개해서는 안 된다.

## 체험 덱과 검증

기존4덱 뒤에 다섯 번째 `fidelity` **강화 체험·암흑과 대지**를 추가했다. 지형16·유닛24·마법6·아이템4의50장이며, 새 업그레이드·유니크·이벤트 카드를 포함한다. 이는 이번 체험판의 선별 덱이며 당시 공식 기본 덱을 복구했다고 소개하지 않는다.

새 Core 검사는 연출 수집 유무의 동일 RNG·결과, 중간 프레임의 공격/반격/파괴 순서와 깊은 복사, 실제 소각 카드 보존, 마법 공개 전후 HP, 예약 칸 분리, 기존schema3의 선택적 이벤트 메타, 새 카드별2장 한도, 다섯 번째 덱, 업그레이드의 무소울만 생성, 킹핀 무료 장착과 장착 상한을 검사한다. 최종 Core·Unity·브라우저 실행 결과는 릴리스 검증 문서에 기록한다. 소스나 이미지 감사 통과만으로 플레이·실물 기기·원작 전체 기술 재현을 검증했다고 표시하지 않는다.
