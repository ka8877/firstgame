# Restage: 실제 화면·규칙·재사용 가능한 Unity 자료

2026-11-02의 `fm-restage-2026-11-02` / `gospel-canopy-2026-11-02` 조사다. 아래의 **새 HTTP 조회**, **보존 자료 재검토**, **설치된 공식 샘플 확인**을 구분한다. 조사 담당은 게임 실행·Unity·테스트·빌드·Git·배포를 하지 않았다. 실제 구현·실행 결과는 해당 담당의 Restage 기록을 따른다.

새 응답·선택 이미지·참조용 코드·SHA-256 목록은 `Tools/Research/Restage/evidence-manifest.json`에 있다. 외부 코드는 실행하지 않고 `.txt`로 보존했다. 원작 마지막 클라이언트나 상용 Ori 소스를 확보했다는 뜻은 아니다.

## 실제 공개 Unity 자료와 현재 프로젝트에 맞는 샘플

### 공식 Lost Crypt: 새로 읽은 작은 소스와 보존 자산

공식 [Unity-Technologies/mobileQA-LostCrypt-AutoPlay-Deterministic](https://github.com/Unity-Technologies/mobileQA-LostCrypt-AutoPlay-Deterministic), 고정 커밋 `96015220e0f35b18b3ad390d38f97ddcc38bb514`의 트리와 선택 파일 여덟 개를 새로 받았다. 원래 전체 샘플/666 LFS 파일의 확보 기록과 이 프로젝트에서 보존하는 환경 그림29개는 [Luminous 출처](../GospelLuminousReferences.md)·`Tools/Art/GospelLuminous/Reference/manifest.json`·`World/manifest.json`을 따른다. 그 전체 원본을 이번에 다시 다운로드했다고 주장하지 않는다.

- `ParallaxLayer.cs`: 시작 카메라 위치와 현재 위치 차이에 계수를 곱해 오브젝트 위치를 옮기는 799바이트 실제 코드다. 기본은 X만 움직이며 다른 분기는 전체 벡터를 움직인다. 현재 XZ 투영·3D 카메라에서는 이동축·부모 공간을 맞춰 적용해야 한다.
- `LightColorController.cs`: 자식의 색 설정기들을 0–1 시간 값으로 갱신하는 실제 코드다. 현재 포워드 3D 광원에 쓰려면 setter 계약을 맞춰야 한다.
- `MaterialVectorSetter.cs`: 지정한 재질 속성에 자신의 월드 위치를 넣는 작은 실제 코드다. 식생 상호작용 중심점을 전달하는 방법으로 참고할 수 있지만, 이것만으로 식생이 휘지는 않는다.
- `LightIntensityController.cs`: **이 QA 변형에서는 `Random.Range`가 주석이고 최소/최대의 중간값으로 보간**한다. 그대로 복사하면 지속적인 불규칙 불빛 효과를 얻지 못한다.
- `ShaderGraph_Vegetation_Wind_Lit.shadergraph`: 원화·mask·normal 텍스처와 Wind Direction/Scale/Strength/Speed, Y Position 영향 마스크가 있다. 원본 기본값은 Strength0.01, Speed0.4, Y-mask4다. 노이즈·시간·위치 노드를 실제 확인했다.
- `ShaderGraph_Water_Unlit.shadergraph`: Water Color, Caustic Color/Scale/Brightness, Wave Strength, Edge Strength, Ripple Scale, Render Texture/Brightness, Refraction Strength가 있다. 2D 샘플의 렌더 텍스처 의존성을 무시하고 현재 3D 강에 바로 붙일 수 있다고 소개하지 않는다.

원본은 Unity2019.3.12f1·URP7.3.1이다. 현재 Unity6000.3/URP17.3과 차이가 있어 구식 Shader Graph/API의 실행 호환을 확인했다고 주장하지 않는다. 공식 상품 설명의 재사용 허용 문장과 **Unity Companion License1.4** 전문은 기존 출처 manifest와 이번 참조 폴더에 보존한다. Unity로 만든 콘텐츠와 함께 사용하는 조건이며, 상당한 복사 부분에는 해당 라이선스·Unity Technologies 출처·별도 제삼자 고지를 유지한다. 공개 GitHub 저장소라는 이유만으로 퍼블릭 도메인/MIT라고 표시하지 않는다.

### 현재 설치된 URP17.3의 완전한 공식 샘플

현재 `Games/PathOfDawn/Packages/manifest.json`의 URP는17.3.0이다. 실제 해당 패키지의 `Library/PackageCache/com.unity.render-pipelines.universal@5495a1eecd3c/Samples~/URPPackageSamples`에서 아래 완전한 파일을 읽었다. 캐시는 수정하지 않았다. 재사용 시 필요한 자산·GUID 의존성을 정식 import하고 현재 장면에서 검증할 책임은 구현/실행 담당에게 있다.

| --- | --- |
| `RendererFeatures/TrailEffect` | 실제 scene·TrailMap render texture·Sand/TrailMap Shader Graph가 있다. `DepthHistory_Renderer.asset`는 `KeepFrame`·`DrawObjects`를 연결하고 `_FrameCopyTex`를 보존한다. 그래프에는 `FadeFactor`가 있다. XZ 바닥의 이동 흔적·발자국을 다룰 때 읽을 수 있는 완성된 출처다. 현재 게임에 이 기능이 통합됐다는 주장은 하지 않는다. |

패키지 `LICENSE.md`는 Unity Technologies 저작권과 Unity-dependent project에 대한 Unity Companion License를 지정한다. 실제 로컬 샘플의 경로·크기·SHA를 manifest에 기록했다. 원격 `6000.3/staging`의 그래프/scene 일부는 **130바이트 Git LFS 포인터**였으며 자료 자체로 취급하지 않는다. 완전한 로컬 파일과 포인터를 구분했다. BoatAttack README도 소규모 조회했으나 오래된 실험적 샘플이고 라이선스 파일 요청은404여서 이번 통합 대상으로 권하지 않았다.
