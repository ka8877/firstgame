# 판마 전투·카드 목록 재검토

이번 검토는 새로 최종 클라이언트를 회수한 조사가 아니라 저장소에 바이트·URL·날짜가 보존된 공개 자료를 다시 읽은 것이다. 지난 영상·웹 문서가 지금 새로 다운로드되었다고 표시하지 않는다. 가장 후기의 날짜가 확실한 실제 플레이 근거와 사용자 첨부의 구분은 [Chronicle 자료 기록](FmChronicleSources.md)을 따른다.

- 공식 사이트의 기보존 FAQ `Tools/Research/FmRenewal/faq734-text.txt` 메뉴에는 `스페셜상점`과 `앨범`이 있다. 본문은 특정 카드를 모두 모으면 스페셜 카드를 획득할 수 있다고 설명한다. 이는 앨범과 조합 보상의 존재 근거다. 현재 리마스터의 별도 상위 등급 카드 감상 목록과 동일한 기능이었다는 증거는 아니다.
- [GG게임의 2006-04-02 사용자 가이드](https://www.ggemguide.com/guides/online/964/?dpage=129), 보존본 `Tools/Research/Quest/fm-beginner-964-text.txt`는 스페셜·유니크와 앨범·카드 조합 상점을 설명한다. 사용자 작성의 옛 가이드이며 종료 직전 서버의 정확한 획득표·가격·앨범 항목을 확정하지 않는다. 가이드의 부정확한 소울/LP 표현을 최신 규칙처럼 재사용하지 않는다.
- 공식 셔플 매뉴얼은 미사용 손패 6장 전체를 덱에 넣고 섞은 뒤 다시 받는다고 설명한다. 상충하는 사용자 글보다 이 문장을 우선한다. 원문·날짜·보존 경로는 [Quest 조사](QuestReferences.md)에 있다.
- 2017-12-29 실제 혼자 플레이한 영상은 위·아래 전열, 별도 양측 코인 판정 창, 인쇄 카드 오른쪽 아래의 AP/DP/HP와 소울·지형 구성을 보여 준다. `Tools/Research/FmChronicle/VideoFrames/Live2017December/0056.0s.png`를 원본 기준으로 삼는다. 2018 회고 업로드의 촬영일을 2018년 최종 패치라고 단정하지 않는다.

현재 원작 그림 15,350종과 출전 가능 2,646종은 다르다. 원본 전체는 한 카드 목록에서 검색·필터로 접근할 수 있도록 정리하고, 출전 지원되지 않은 기술을 지운 채 플레이 가능으로 표시하지 않는다. 원작의 앨범 수집 보상표를 확보하지 않은 상태에서 현재의 검색형 도감을 원작 앨범 완전 복원이라고 부르지 않는다. 새 전투 규칙은 [실제 Core 대조 기록](../FmRepriseBattle.md), 시각 변경은 [화면 기록](../FmRepriseUI.md)을 따른다.

기존 판마 BGM은 공개 원곡 발췌·녹음과 편집 범위가 기록된 현재 파일을 보존한다. 새 효과음은 별도 제작물이다. 예수님의 길에서 Ori의 빛·색·숲 분위기를 참고해도 Ori의 음악·음성·그래픽·소스를 회수했다는 뜻은 아니다.
