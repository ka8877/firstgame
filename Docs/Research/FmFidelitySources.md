# 판타지마스터즈 원작 동작·파일 근거 보강

확인일: 2026-10-27 UTC. 이번 작업은 판타지마스터즈만 원작의 규칙과 정보 구조에 맞춰 리마스터하기 위한 조사다. 실제 읽은 공식 안내·원본 실행 파일의 정적 문자열·팬 DB를 구분한다. 이 문서는 제품 구현이나 원작 전체 복구 완료 보고가 아니다.

## 원작 화면과 공방 정보

[2005년 공식 인터페이스 안내](https://web.archive.org/web/20050807002655id_/http://www.fantasymasters.co.kr:80/Guide/Manual/tutorial2_1.asp)를 다시 직접 읽었다. HTTP200, 원문 바이트·SHA와 디코딩한 본문은 `Tools/Research/FmFidelity/official-interface-guide.json`에 있다. 기존 공식 화면 세 장도 원본 크기로 직접 확인했다. 이미지의 실제 보존본은 2006년이며 URL·픽셀 보존 기록은 `Tools/Research/FmRevival/official-ui-manifest.json`을 따른다.

| 화면 요소 | 공식 안내에서 확인한 의미 | 구현에 주는 기준 |
|---|---|---|
| 녹색 대리석 전장 | 두 줄의 5칸 프론트필드, 아래 6장 손패, 우측 소울·상태 | 다른 TCG의 리더 HP 전장으로 바꾸어 원작이라고 소개하지 않는다. |
| 우측 칼/방패와 숫자 | 공방 역할과 턴수 | 역할·턴수·준비 완료와 실제 상태를 연결한다. |
| 우측 세 동전과 FLIP/SP | 상대 준비 중 SP를 얻는 **별도 미니게임** | 이 화면을 전투 코인 판정창으로 오인하지 않는다. |
| 양측 상태 | 핸드, 덱, LP, 소각장 | 양측의 실제 카드·자원 수를 구분한다. |
| 소각장 | 파괴 유닛·아이템, 사용한 마법이 쌓이는 곳 | 단순 장식이나 숫자만이 아니라 실제 소각 카드와 연결할 근거가 있다. |
| 게임방 | 덱 선택과 준비, 위닝룰·셔플·카드 장수 옵션 | 당시 안내는 Deck/Life, 셔플4/6/무제한/없음, 40/50/60장을 설명한다. 실제 지원하지 않는 옵션을 활성 기능처럼 표시하지 않는다. |

공식 안내의 마법카드 설명은 우클릭으로 상세 효과·조건을 보며, 상대에게는 전투 전까지 뒷면으로 보인다고 설명한다. 전열의 은폐 마법과 상세 정보는 별도 계약이다.

## 준비 중 소각의 공식 근거

[2005년 공식 오프라인 규칙](https://web.archive.org/web/20051101013311id_/http://www.fantasymasters.co.kr:80/Guide/Manual/tutorial6.asp) 11번 다음 문장을 직접 확인했다.

> 준비완료 전에 어느 시점이라도 카드를 소각 (무덤에 버리는일)을 할수 있습니다. (소울을 사용한 지형은 소각불가)

조회 HTTP200과 원문 SHA는 `hand-discard-official-evidence.json`에 있다. 이 문장 자체는 손패만을 별도로 지정하지 않는다. 팬 DB의 강화 유닛 설명에 있는 “핸드에서 소각장으로 버릴 경우”와 함께 손패 소각 구현의 근거로 쓴다. 원작2003 실행 파일에도 “소울을 사용한 지형은 소각할 수 없습니다.”라는 한국어 문자열이 존재한다. **오프라인 규칙과 특정 온라인 버전의 모든 예외가 동일하다고 확장하지 않는다.**

## 공개 원본 실행 파일의 정적 조사

Wayback에 보존된 두 공개 파일을 정상 HTTP로 받아 **실행하지 않고** PE 섹션·리소스·문자열만 읽었다. 바이너리는 `/tmp/fm-fidelity-original`에 두었고 게임·저장소 배포 자산으로 도입하지 않았다. 정확한 최종 URL·크기·SHA·검사 범위는 `archived-launcher-inspection.json`에 있다.

| 공개 보존 파일 | 실제 받은 크기 | 확인한 사실 |
|---|---:|---|
| [2002 game.exe](https://web.archive.org/web/20021128130556id_/http://www.fantasymasters.co.kr:80/AutoPatch/game.exe) | 151,552바이트 | `fmgame.ini`, `fmsound.ini`, `graphics.ini`, `SvrList.dat` 이름 |
| [2003 fmtest.exe](https://web.archive.org/web/20031028155420id_/http://www.fantasymasters.co.kr:80/autopatch/fmtest.exe) | 1,151,031바이트 | 장면별 BGM, 여러 공격 효과음 파일명, 외부 리소스 경로, 소각·덱 제한·단축키 문구 |

`fmtest.exe`에서 확인한 실제 BGM 파일명은 `bgm-login.mp3`, `bgm-lobby.mp3`, `bgm-deck.mp3`, `bgm-ready.mp3`, `bgm-battle.mp3`, `bgm-result.mp3`다. 실제 효과음 이름에는 `coin.wav`, `flip.wav`, `roomenter.wav`, `pop.wav`, `whip.wav`, `spell.wav`, `bom1.wav`~`bom4.wav`, `fr1.wav`~`fr2.wav`, `fi1.wav`~`fi3.wav` 등이 있다. 파일명만으로 각 카드·공격과 효과음의 정확한 연결이나 음색을 확정하지 않는다.

외부 경로는 `resource/sound`, `resource/data`, `resource/data/card1`~`card4`다. PE 리소스는 BMP/TXT/아이콘/단축키 정보뿐이며 음원 리소스를 찾지 못했다. 파일의 단일 `RIFF` 표식은 WAV를 검사하는 기계어의 상수여서 실제 WAV 파일이 아니다. 그러므로 이 실행 파일에서 원작 효과음이 추출되었다고 소개할 수 없다.

원본 TXT에는 `F1: 화면별 인터페이스 설명`, `F2: 스크린샷 캡처`, `F3: 옵션창` 안내가 있다. 소스 코드·완전한 리소스 묶음·동작하는 원작 서버를 확보한 것은 아니다.

구체적인 `AutoPatch/resource/sound/coin.wav`, `spell.wav` CDX 조회는 HTTP200 빈 목록이었다. 알려진 데이터 디렉터리 두 곳의 제한된 prefix 조회는 HTTP503으로 끝났다. 이 실패는 `concrete-resource-index.json`에 남겼으며 어디에도 파일이 없다는 결론으로 쓰지 않는다. 음악 파일의 추가 확인은 음악 담당의 `FmFidelityMusic` 조사 기록과 연결한다.

## 등급·랭크 추가 수록 후보

공개 FM Lunatic Firestore의 `livecardlist`를 RareType6~12별로 읽었다. 로그인·비공개 서비스·외부 데이터 변경은 사용하지 않았다. 쿼리와 응답 크기·SHA는 `grade-*-candidates.json`, 재현 도구는 `find-grade-candidates.py`다. 이벤트는 조회 한도1000에 도달했으므로 전체 이벤트 목록이 아니다.

“기술 두 필드가 없음 + 정적 수치”는 **수록 승인 기준으로 불충분**하다. 별도 `TextExtra`에 강화 공통 효과·소환 상태·섀도우 능력이 들어 있다. 예를 들어 실제 fullrecord 재조회에서 다음을 확인했다.

- 업그레이드 카오스브링거: 손패에서 소각하면 사용 가능한 무소울1을 생성한다.
- 유니크 킹핀사이클롭: 만능 장비와 자기 레벨 미만 아이템의 소울 비용 면제가 있다.
- 레전드 천상의군주: 별도 섀도우오라·쉬프트와 전용 장비가 있다.
- 시크릿 요정여왕: 소환 시 프리퍼레이션 상태와 후속 공격기술이 있다.

`verified-grade-representatives.json`에 정확한 이름·ID·원본 인쇄 이미지 URL·전체 DB 필드를 보존했다. 후보 중 실제 지원할 효과를 구현한 카드만 제품에 추가하며, 설명이나 기술을 무시해 바닐라 카드로 바꾸지 않는다. `TextExtra=invalid`인 랭크 변형도 원본 인쇄 카드 확인 없이 기술이 없다고 단정하지 않는다. 등급과 랭크는 별개 필드이며 빈 랭크 수를 채우려고 임의 변형을 만들지 않는다.

## 영상 조사와 한계

YouTube 직접 요청은 HTTP403으로 막혀 우회하지 않았다. Google·DuckDuckGo는 자동화 확인 화면, 일부 일반 검색은 관련성이 낮은 결과를 주었다. 정상 공개 Naver 검색과 서비스 시기 블로그 링크는 조사 파일에 구분했다. 판마2·팬마·다른 게임의 영상을 판마1 원작 전투 영상으로 취급하지 않는다.

서비스 시기 공개 Naver 블로그 두 곳에서 판마1 영상을 찾았고, 해당 공개 페이지가 제공하는 정상 플레이어 API의 HTTP200 응답으로 원본 영상을 읽었다. 공개 플레이어 키·서명된 임시 미디어 URL은 연구 파일에서 제외했다. 원본 영상은 `/tmp`에만 두고 게임 자산으로 도입하지 않았다. 전체 파일 SHA와 실제 디코딩 프레임의 SHA는 각각의 provenance JSON에 있다.

| 영상 | 원 게시일·확인 범위 | 원본·근거 |
|---|---|---|
| [2009 판타지마스터즈 홍보동영상](https://m.blog.naver.com/sonsy84in/40064066618) | 2009-03-18, 58.96초, 640×480, 약5.7MB. 원작 로고·UI·일러스트를 광고용 편집으로 보여준다. | `promo-video-provenance.json`, `VideoFrames/Promo2009` |
| [크룩스덱 실제 온라인 플레이](https://m.blog.naver.com/orderandchaos030/221042522552) | 2017-07-02, 934.669초, 360×270, 약52.6MB. 게시자가 원작에 접속해 실제 게임 중 촬영했다고 설명하며, 동영상에서 판마1의 공방·필드·손패·상태를 확인했다. | `gameplay-video-provenance.json`, `VideoFrames/Gameplay2017` |

2017 영상의117~123초를0.25초 간격으로 원본 해상도 PNG로 디코딩했고, 아래 핵심 프레임을 직접 확인했다. 프레임 추출은 자르기·리사이즈·합성 없이 수행했다. 시각 표는 영상 내 해당 시점의 관찰이며, 엔진 내부 이벤트 시각을 계측한 결과가 아니다.

| 영상 시점 | 실제 보이는 연출 |
|---|---|
| 0~1초 | 두 플레이어의 세로 인물 초상과 중앙 VS 도입 |
| 20초 | 전장 중앙의 `No Battle` 표시 |
| 117.00~119.50초 | 중앙 윗부분 가로 테두리 패널에서 금색 동전 앞면/옆면이 회전한다. 코인·수치와 Auto 조작을 전투 장면 위에 보여준다. |
| 120.00초 | 아래쪽 표적 카드 위로 주황·노랑 대각선 불꽃 타격이 겹친다. |
| 120.50초 | 표적 카드 위에 적색 피해 정보가 보인다. |
| 121.00초 | 파괴될 카드가 검붉게 번쩍이며 흰 십자광·주황 화염이 겹친다. |
| 121.50초 | 카드가 사라지고 주황 불티가 흩어진다. |
| 122.50~123.00초 | 다음 카드 위로 파란 겹원과 별 모양의 마법진이 나타난다. |

따라서 전투의 코인 판정 패널, 대각선 타격, 적색 피해 정보, 파괴 불티, 파란 마법진은 실제 원작 영상에서 확인한 표현이다. 원작 효과음 파일 자체나 모든 카드·기술의 VFX를 확보한 것은 아니다. 영상의 코인창에 보이는 `Coin90%`는 해당 사용자·동전·옵션의 적용 조건을 확인하지 못했으므로, 이를 원작 기본 코인 확률90%라는 규칙으로 해석하지 않는다.

공식2005 안내, 원본2003 실행 파일, 실제2017 영상은 서로 다른 시기다. 2017 영상은 파란 배경을 사용하고2005 설명 화면은 녹색 대리석이므로 둘을 원작의 유일한 고정 스킨이라고 설명하지 않는다. 새 VFX를 제작하는 리마스터는 이 자료의 정보 구조와 해결 순서를 근거로 삼되, 추출한 원작 스프라이트·효과음과 동일한 원본이라고 소개하지 않는다.

신규 후보17장의 인쇄 원본 PNG도 각각 직접 확인했다. 이미지 SHA·이름·관찰은 `card-print-review.json`에 있으며 DB의 기본 수치·소울·코인과 일치하고 인쇄 본문에서 누락한 추가 전투 기술을 발견하지 못했다. 이는 실제 엔진 기능 통과와 별도인 인쇄 원본 대조 검수다.
