확인일: **2026-10-26, Asia/Seoul**. 실제 HTTP 응답과 공개 JSON을 읽었다. 검색 결과의 문장만으로 카드 수치나 원작 소스 공개를 확정하지 않았다. 사용자는 개인 감상을 위한 재현을 설명한 뒤 URL 접근도 다시 요청했다. 이 문서는 **재현판의 조사 자료**이며, 사용자의 배포 요청과 별개로 권리자의 재배포 허락을 증명하는 문서는 아니다.

## DB 확인 방법과 근거 파일

공개 웹 클라이언트가 사용하는 Firestore REST 읽기 API에서 `livecardlist` 카드와 `liveappsetting/enumtable` 정의를 조회했다. 로그인·토큰·비공개 서비스·접근 제어 우회는 사용하지 않았다. `runQuery`와 `batchGet`은 읽기 작업이며 외부 데이터를 변경하지 않았다.

- `Artifacts/Validation/FmExpansion/Research/database/verified-card-samples.json`: 7속성별 유닛 네 장과 지형 한 장, **35개**의 개별 페이지·정확한 수치·소울 해석·비교 자료.
- 같은 폴더 `card-<ID>.json`: 위 35개의 실제 DB 필드와 생성/갱신 시각.
- `original-candidates.json`: 체험판 선택용 **237개 후보**를 원작 팬 DB에서 재조회했다. **지형 14, 유닛 139, 마법 49, 아이템 35**이며 최종 게임 수록 수와 다르다. 모든 항목에 `pageUrl`, `imageUrl`, `fields`, `fanmaLocator`를 기록했다.
- `fmdb-settings.json`: 속성·등급·종류·코인·능력치 기호를 해석한 공개 enum 원문.
- `public-image-check.json`: 지형/유닛/마법 세 이미지 URL의 실제 HEAD 200, `image/webp` 응답. 픽셀 검수와 최종 수록 이미지 검증은 미디어 담당 기록을 따른다.
- `github-fantasy-masters.json`: 공개 저장소 메타데이터·루트 목록·README 실패 결과.

원본 이미지 주소는 `https://storage.googleapis.com/fmdb-bcb70.appspot.com/cardlist/<종류>/large/<KIND÷1000 두 자리>/<L/U/M/I><KIND 다섯 자리>L.webp`다. 예를 들어 [좀비 원본 카드](https://storage.googleapis.com/fmdb-bcb70.appspot.com/cardlist/unit/large/00/U00004L.webp). 최초 조사에서 `/00/` 하위 디렉토리를 빠뜨려 404가 나왔으며 공개 클라이언트의 경로 구성 함수를 다시 읽어 수정했다. 그 실패는 `public-image-check-before-directory-fix.json`에 보존했다. 현재 후보 JSON은 수정된 경로다.

## 데이터 계약

| 필드 | 확인한 뜻 |
|---|---|
| `Category` | 1 지형, 2 유닛, 3 마법, 4 아이템, 5 인챈트. 초반 체험판 후보에는 앞의 네 종류만 수집했다. |
| `SoulType` | 1 암흑, 2 불, 3 물, 4 숲, 5 금속, 6 대지, 7 빛. |
| `LV` | 카드 레벨. 원작 소울 비용과 구분하는 별도 필드다. |
| `RequireSoul` | 네 자리 단위의 유형 코드 두 자리 + 개수 두 자리. `11/21/31/41/51/61/71`은 각각 위 7 유소울, `81`은 무소울. 예: `11028101`은 암흑 2 + 무소울 1. 복합 소울 코드도 별도로 있으므로 일반 코드를 모든 카드에 가정하면 안 된다. |
| `ATK/DEF/HP` | 각각 AP/DP/HP 원본 수치. `ATKStatType/DEFStatType/HPStatType`에 별도 기호가 있으면 단순 정수와 의미가 다르다. |
| `*Coin`, `*CoinCount`, `*CoinType` | AP/DP/HP마다 문자열, 코인 개수, 연산 코드가 별도로 있다. `CoinType` 1 없음, 2 더하기, 3 빼기, 4 곱하기, 5 대입. `C4`와 `2C1`을 같게 처리하면 안 된다. 공통 코인열 여부와 전투 처리 순서는 DB만으로 확정하지 않고 규칙 조사와 대조한다. |
| `*StatType` | 1 기호 없음, 11 ★ 고정, 12 ▲, 13 ▼, 31 +, 32 −, 33 = 등이 있다. 아이템 `ATK=6/ATKStatType=33`은 AP +6이 아니라 AP =6이다. |
| `Skill1/Skill2` | DB enum의 특수기술 키. 1은 기술 없음. 기술 없는 유닛도 수치 기호·코인 연산을 별도로 확인해야 한다. |
| `RankType` | 같은 이름의 랭크 변형을 구별하는 별도 필드. `RareType` 등급과 혼동하지 않는다. |

DB의 `RareType`은 **프리, 커먼, 언커먼, 레어, 스페셜, 업그레이드, 유니크, 이벤트, 레전드, 이카젠, 시크릿, 에픽**을 정의한다. 이 순서를 단순 전투력 순위로 간주하지 않는다. 팬마의 등급 정수와 FM LUNATIC 정수는 같은 표가 아니므로 문자열 이름으로 비교한다.

## 단순 구현과 원작 값의 차이를 막기 위한 선택 기준

- 유닛은 `Skill1=1`, `Skill2=1`, 정적인 `*StatType=1`을 먼저 골라 실제 기본 수치와 코인을 재현할 수 있다. 후보에 각 속성당 기술 없는 유닛이 18–21개 있어 저레벨부터 상위 레벨까지 선택할 여지가 있다.
- 순수 가감 아이템 예는 **오닉스(+1/+1/+2), 아이스큐브(−1/0/+3), 늑대이빨(+4/0/0), 허수아비(−1/−1/+3), 거북이등껍질(−1/+2/0), 거인의곤봉(+4/−1/0), 거인의팔찌(+1/+1/0), 롱소드(+5/−1/0), 병사투구(−1/+2/0), 블레스트아머(−1/+4/−1), 아이언실드(−1/+3/0), 골렘의심장(0/0/+3)**다. 괄호는 AP/DP/HP 변화다.
- 본소드·악마의뿔은 AP를 **대입**하는 값이고 스컬실드·바이블에는 **고정** 기호가 있다. 단순 강화 카드로 바꿔 놓고 원작과 같다고 표시하면 안 된다.
- 초기 마법도 복합 효과가 많다. **아이스실드**는 아군 하나 DP +2, **낙석**은 적 전체 유닛에 물리 피해 2, **파이어볼**은 적 필드 1–3 유닛의 HP −2, **홀리레인**은 아군 전체 HP +1과 적 전체 HP −1로 읽힌다. 물리 피해의 DP 적용과 HP 직접 감소를 구분해야 한다. 그 외 조건·위치·카드 파괴·소울 예약이 있는 마법은 해당 기능을 구현하거나 수록 대상에서 제외한다.
- 최종 제안은 `selection-proposal.json`의 **96종(지형14·유닛56·마법14·아이템12)**이다. 기존 237개 후보에 추가 원작 마법 6종을재조회해 14개 마법의 지원 범위를 명시했으며, 장황한 스토리·flavor는 선정 JSON에서 제외했다. 실제 지원 효과는 코어 담당이 확정한 카탈로그를 기준으로 한다. 여기의 237개 후보 전체를 자동으로 수록하거나 설명만 있고 효과가 다른 카드로 만들지 않는다.

## 권리와 불확실성

DB·팬 사이트의 공개 접근과 이미지 표시를 확인했지만, 게임 원화·원작 자료·팬 프로그램에 대한 포괄적인 재배포 라이선스를 찾은 것은 아니다. 저장소가 공개되어 있다는 사실만으로 오픈소스나 원작 공식 소스라고 부르지 않는다. 원작 프로그램·음원·팬 프로젝트 구현 코드를 도입하지 않았다. 원작 카드 이미지 수록과 URL 접근 범위는 최신 사용자 요청 및 루트 배포 기록을 따른다.

## 96종 최종 제안 추가 확인

`selection-proposal.json`은 기능 매핑까지 포함한 코어 검토용 선택안이다. 등급 분포는 프리67·커먼12·언커먼11·레어1·스페셜5, 레벨 분포는 0/1/2/3/4/5/6/7 각각14/23/18/10/9/7/9/6이다. 각속성은지형2개·정적유닛8개·마법2개를포함한다. 금속 유닛은 확인한 정적 후보 범위에서레벨7조건을만족하는카드를찾지못해레벨1–6을사용하며전체카탈로그는레벨7까지있다.

마법의공격/방어제약을보존한다. `TurnType`1은공격/방어공용,2는공격전용,3은방어전용이다. 14개마법은모두`DurationType=1`, `Duration=1`이다. 소울비용과이시간제약을구현에서임의로없애면안된다. `요새방어`는팬마현재API의레벨2와원작팬DB의레벨1이다르며선정안은후자의실조회값1을사용했다.

선정한14지형은모두`RequireLP=1`, 각속성유소울1+무소울1을뜻하는`EarnSoulList`를가지며`MuSoul=1`도별도로기록되어있다. **두필드를합쳐무소울2개를생성해서는안된다.** 장비와유닛의`UnitType`은만능/야수/장비/마법및복합능력마스크에대응하며원작장비호환제약검사에사용한다.

`selection-audit.json`에서는 선정 96종의 모든 보존 필드가 원본 조회값과 같은지, 정적 유닛·0–5코인·기본 지형 소울·순수 가감 장비·마법 공방/기간·flavor 제외를 검사했다. 실행 중 게임 효과 통과를 대신하지 않는다.
