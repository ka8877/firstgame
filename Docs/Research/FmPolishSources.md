# 판마 상호작용 자료 재검토

이번 검토는 이전에 바이트·출처를 보존한 공식 자료를 다시 읽은 것이다. 새 클라이언트나 새 원본 영상을 확보한 것으로 소개하지 않는다. 서비스 후기 자료와 낮은 해상도 영상의 한계는 [Renewal 조사](FmRenewalSources.md)를 따른다.

- `Tools/Research/FmRenewal/tutorial2_1.html`의 공식 전체 대기실 설명은 대기자 우클릭으로 상세 정보를 보고, 방 목록 우클릭으로 참가자를 확인하며, 공개 채팅·입력창·승패/SP/경험치·리플레이·덱 편집기로 이동하는 구성을 명시한다. 이 매뉴얼의 구형 배치를 종료 직전 화면 전체의 증거로 사용하지 않는다.
- `Tools/Research/FmRenewal/faq737-text.txt`의 공식 섀도우 능력 설명은 **카드 우측 위 섀도우 표시를 더블클릭**, 또는 **Ctrl+마우스 클릭**으로 능력을 사용한다고 명시한다. 따라서 리마스터의 더블클릭 상세 보기는 새 편의 조작이며 모든 원작 더블클릭을 복원한 동작이 아니다. 구현되지 않은 섀도우 기술을 눌러 사용한 것처럼 표시하지 않는다.
- 보존한 2017년 플레이 영상의 직접 확인 범위는 청색 필드·I–V 두 전열·지형 열·우측 세로 정보 영역·상단 코인 판정 창·표적 카드 위의 적색 피해와 불꽃이다. 화면 모션은 실제 Core 사건과 중간 스냅샷을 따라야 하며 UI가 다시 판정하지 않는다.

현재 싱글 플레이의 상대 정보는 실제 AI·공개 필드·남은 덱·소각 수를 보여준다. 연습 메모는 사용자가 자신에게 남기는 내용이며 가상 온라인 이용자의 채팅으로 소개하지 않는다. 멀티플레이 원작 채팅 전체를 구현했다고 표시하지 않는다.
