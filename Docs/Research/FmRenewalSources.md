# 서비스 후기 판마1 자료 대조

2026-10-29 작업에서 직접 조회하거나 원본을 확인한 자료다. 최신 방향은 판마1의 서비스 후기이며, 판마2나 출시 초기 화면을 마지막 판의 증거로 쓰지 않는다. 공개된 마지막 클라이언트 전체를 확보했거나 모든 최종 패치를 확인했다고 주장하지 않는다.

## 후기에 실제 쓰인 공식 미술

[공식 홈페이지의 2017-12-16 보존본](https://web.archive.org/web/20171216010139id_/http://www.fantasymasters.co.kr/)을 HTTP 200으로 받았다. 본문은 `/FM_Image/FM_Image/nfm/Main/bg_main_00_new.jpg`를 배경으로 지정한다. 동일한 이미지 경로의 원 이미지 서버 보존본 [2015-11-05 JPEG](https://web.archive.org/web/20151105133243id_/http://211.233.57.195/FM_image/nfm/Main/bg_main_00_new.jpg)도 HTTP 200으로 받아 직접 확인했다.

원본은 **2000×610**이며, 어두운 청색 기둥 사이에 왼쪽 백발 남성·오른쪽 흑발 여성을 둔 구도다. 원본 파일 SHA-256은 `c6eaed1de689d79088566a7a761b6f436166cc9625f5e2738fdf3b61a890e0b6`이고 `Tools/Research/FmRenewal/late-bg-host.bin`에 JPEG 바이트 그대로 보존한다. 홈페이지는 이미지 프록시 경로를 사용하고 원 서버의 파일 경로는 같은 `nfm/Main/bg_main_00_new.jpg`다.

이는 **2017년 공식 웹사이트가 참조한 원작 미술**이다. 별개의 클라이언트 로그인 화면 전체나 종료 직전 마지막 패치의 타이틀이라는 증거는 아니다. 리마스터에서 이 원본과 새 버튼·타이포그래피를 조합한 화면은 새 배치로 구분한다. 더 작은 초기 웹 인물을 임의로 확대해 최신판 원본이라고 부르지 않는다.

## 2017 플레이 영상

[2017-07-02 크룩스 덱 플레이 글](https://m.blog.naver.com/orderandchaos030/221042522552)을 다시 HTTP 200으로 조회하고 게시 시각을 확인했다. 이전 작업에서 확보한 원본 영상의 SHA·해상도·다운로드 근거는 `Tools/Research/FmFidelity/gameplay-video-provenance.json`에 있다. 이번에는 보존한 **118.50초·120.50초·900초 원본 PNG**를 직접 열어 다음을 확인했다.

- 배경은 청색 연기와 어두운 청색 필드다. 두 전열의 I–V 칸, 위쪽 지형 카드 열, 오른쪽 세로 정보·조작 영역을 갖는다.
- 필드에 놓인 카드 자체에 이름·그림·하단 공방체 수치가 들어 있다. 카드 밖의 분리된 수치 목록을 주된 전투 대상으로 쓰는 구도가 아니다.
- 전투 코인은 필드 중앙 위의 가로 테두리 창에서 돌고, 카드 정보와 판정이 함께 보인다. 오른쪽의 대기용 코인 미니게임과 구분한다.
- 적색 피해 수치와 불꽃은 표적 카드에 직접 겹쳐 나타난다.

360×270 녹화여서 작은 문자 판독에는 한계가 있다. 특히 `Coin90%`를 게임 기본 확률로 해석하지 않는다. 이번 검토는 명시한 원본 프레임 검토이며 영상을 새로 완주했거나 모든 전투 규칙을 영상에서 역산한 결과가 아니다.

## 후기 공식 규칙 안내

2017 홈페이지의 게임 가이드 링크인 [FAQ 1059의 2017-07-15 보존본](https://web.archive.org/web/20170715151258id_/http://www.fantasymasters.co.kr/HelpDesk/FAQ_View.asp?FaqNo=1059)에서 공식 매뉴얼·자료실 링크를 찾았다. 연결된 FAQ 12개를 2016-09-11 보존본으로 확보했다. 실제 최종 리다이렉트 URL·원 응답 크기·SHA와 UTF-8로 디코딩한 본문은 `Tools/Research/FmRenewal/faq*.json`, `faq*-text.txt`에 있다. 보존 시각은 문서가 처음 쓰인 시각이나 마지막 규칙 패치 시각과 같지 않다.

## 확보하지 못한 자료

[공식 다운로드의 2017-11-29 보존본](https://web.archive.org/web/20171129125309id_/http://www.fantasymasters.co.kr/download/download.asp)은 정상적으로 읽었다. 여기서 실제 후기 배포 URL인 `http://sf01-iu4452.ktics.co.kr/download/FantasyMasters.exe`와 `.zip`을 확인했다. 해당 파일의 정상 Wayback 요청과 공식 Manual.zip 요청은 HTTP 404였다. 이는 이 경로의 확보 실패이며 모든 인터넷에 파일이 없다는 증거가 아니다.

이전 Guide/Manual 경로에 2017 시각을 요청해도 실제로는 2007 또는 2013 보존본으로 이동했다. 그 결과를 2017 공식 규칙으로 표시하지 않는다. 최신 시점 단어를 넣은 일반 검색은 무관한 결과가 많았으며 `search-*.json`에 구분했다. 인증·비공개 서버·유출 개발 소스는 이용하지 않았다.

원작 BGM은 현재 확보한 제작자 공개 발췌/녹음의 한계를 유지한다. 이번에는 장면 전환의 음량 저하를 수정하고, 별도의 새 효과음을 추가했다. [오디오 구현과 검증 범위](../FmRenewalAudio.md)를 따른다.

## 전체 공개 카드 목록의 출시일 범위

현재 공개 DB에서 끝 페이지까지 확보한 **15,350개 레코드**를 읽기 전용으로 대조했다. 모든 `ReleaseDate`가 원본 카드 ID 앞의 날짜와 일치했고 불일치는 0개였다. 같은 이름이면서 출시일이 다른 카드 묶음은 590개이며, 랭크 변형들은 대체로 같은 출시 묶음의 날짜를 공유한다. 최대 출시일은 **2016-12-15**다. Firestore의 생성·갱신 시각은 2023년으로, 커뮤니티 DB의 등록·수정 시각이며 원작 게임의 출시·패치 시각을 뜻하지 않는다.

최신 카드 `16121533861 선물쟁탈전`의 원문에는 **2016-12-22 버그 수정 예정**이라는 별도 설명이 남아 있다. 따라서 2016-12-15 출시일만으로 최종 밸런스 패치나 종료 직전 전체 카드 목록을 확인했다고 할 수 없다. 2017 공식 홈페이지에는 1월·3월 공지가 남아 있고 신규 카드 영역은 주석 처리되어 있지만, 이것만으로 신규 카드 업데이트가 중단되었다고 확정하지 않는다. 추가 공식 공지·카드 상점·공개 DB 프런트엔드 조회는 당시 관리형 프록시의 HTTP 503 연결 오류로 실패했다. 이전에 성공한 홈페이지 URL도 같은 오류였으므로 자료 자체가 없다는 근거로 쓰지 않는다. 이번 추가 조회에서 2017년 이후 카드 자료를 확보하지 못했다. 수치·예시·실패 URL과 시각은 `Tools/Research/FmRenewal/latest-card-audit.json`에 보존한다.
