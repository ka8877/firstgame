# 원본 인쇄 카드와 클래식 대기실

`fm-restoration-2026-10-27`은 사용자의 요청에 따라 이전 Arcana의 재조립 카드 틀을 기본 표시에서 제거한다. 공개 원작 DB에서 확보한 카드 이미지의 프레임·이름·그림·인쇄 수치·규칙 영역을 한 장 전체로 표시한다. 소스 PNG·GUID·픽셀은 변경하지 않는다.

## 카드 표시

- `FmArcanaCards.ArcanaCardFace`의 각 면은 원본 텍스처의 실제 가로/세로 비율로 `AspectRatioFitter.FitInParent`를 적용한 `RawImage`다. UV는 정확히 `(0,0,1,1)`, 색은 흰색이다. 원본의 원화 부분만 잘라 확대하거나 카드 이름·소울·등급·능력치를 새 틀 위에 재배치하지 않는다.
- 손패, 시작 손패, 도감, 편집 덱, 상세, 전열, 전투 확대, 타이틀 대표 카드, 드래그 복사본에 같은 면을 사용한다. 전장 지형의 넓은 환경 타일과 프로필 아바타는 별도 배경/초상 표현이다. 카드를 확인하면 전체 인쇄 원본을 볼 수 있다.
- 등급별 원작 프레임 색과 장식은 원본 이미지에 포함된 그대로다. UI의 새 등급 팔레트는 카드 밖의 검색·설명 글자에만 사용한다. 선택 테두리는 원본 밖의 2픽셀 선이며 원본 위에 등급 배지·장식·가림판을 덧씌우지 않는다.
- 인쇄된 값과 실제 플레이 중 바뀌는 값은 서로 다르다. 전열 밖의 AP/DP/HP 패널은 실제 Core 값을 읽고, 상세 오른쪽은 현재 DB의 정확한 코인식·비용·기술을 읽을 수 있도록 별도로 제공한다. 작은 손패 인쇄를 읽기 어렵다면 마우스 도움말·우클릭/길게 누르기 상세·원본 크게 보기를 사용한다. 원본보다 높은 해상도를 복구했다고 주장하지 않는다.
- `FmArcanaCardSurface`의 `DefinitionId`, `Grade`, `SourceAspect`, `UsesFullPrint`와 읽기 전용 `RenderedAspect`로 실제 생성된 면과 소스 비율을 검사할 수 있다.

## 로비와 대전 준비실

직접 확인한 근거는 [원작 인터페이스 조사](Research/FmRevivalSources.md)의 `Tools/Research/FmRevival/interface_lobby.gif`와 `interface_gameroom.gif`다. 공식 2005 안내의 설명 화면은 571×445픽셀이며 주황색 안내 번호·옛 접속자·채팅이 포함되어 있다. 그 스크린샷을 게임 전체 배경으로 확대하지 않았다.

새 로비는 원작에서 확인한 왼쪽 Room 탭/방 목록, 아래 공지·기록, 오른쪽 Fantasy Masters 표제·보라색 구체·프로필·전적, 하단 덱·카드 이동을 실제 상태로 다시 구성한다. 갈색 가죽과 검은 바탕, 금속선과 좌우 대칭 조각 장식은 `FmRestorationFrame`이 해상도에 맞게 직접 그린다. 타이틀의 오리지널 인물 일러스트는 이전판을 유지하며 원작 타이틀 그림이라고 표시하지 않는다.

- `ROOM · 연습`: 기존 세 AI 상대만 보여준다. 입장하면 실제 선택된 플레이어 덱/상대 덱과 룰을 확인하는 대전 준비실을 거친다.
- `SCENARIO · 시나리오`: Core의 `FmScenarioCatalog.Stages` 네 실전 학습 과제다. 원작 카드와 규칙을 활용해 새로 구성한 순차 학습이며 원작 시나리오 전체를 회수한 것이 아니다. 처음부터 모든 과제를 완료했다고 표시하지 않는다. 앞 단계에서 실제로 승리하면 다음 단계가 열린다. 추천 덱/현재 선택한 덱으로 시작할 수 있다.
- `MULTI · 멀티플레이`: 추후 제공할 영역을 별도 탭으로 구분한다. 가상의 온라인 사람·채팅·방·접속자·매칭 성공을 만들지 않는다. 현재 가능한 연습실 진입을 제공한다.
- 프로필과 공지의 카드/덱 수·전적은 현재 카탈로그와 이 기기 저장을 읽는다. 기본 덱 선택과 덱 편집·저장·이어하기는 기존 슬롯과 호환된다.

시나리오 저장은 기존 배틀 schema를 유지한다. 고유 encounter ID와 상대 덱·리더 일치를 Core가 확인해 저장/이어하기 후에도 원래 과제를 인식한다. `FC.scenario.won.<stageId>`는 해당 과제의 완전 종료·실제 플레이어 승리 때만 기록한다. 연습전 승리나 다른 방으로는 시나리오를 완료할 수 없다.

## 상위 등급

타이틀/로비의 상위 등급 진입점은 유니크·레전드·시크릿의 실제 출전 카드와 각 등급의 수를 먼저 보여준다. 여기에서 플레이 도감의 실제 등급 필터로 이동하고 카드 설명·덱 편집을 사용할 수 있다. 새 고급 기본 덱도 일반 기본 덱 목록에 나타난다.

별도 원본 도감은 `OriginalCardArchive.All`의 30장(유니크 7, 레전드 7, 시크릿 7, 에픽 7, 이카젠 2)을 실제 원작 전체 인쇄와 함께 보여준다. 이 30장은 기술 전체를 지원하지 않는 감상용이며, 화면·상세에 감상 전용과 덱에 넣을 수 없는 이유를 표시한다. 원문 기술을 지우고 정상 출전 카드인 것처럼 추가하지 않는다. 실제 출전하는 상위 등급과 감상 전용 원본의 데이터·개수를 섞지 않는다. 카드의 원작 소스·재배포 허가를 회수했다고 주장하지 않는다.

## 검증 범위

위 내용은 구현 계약이다. 새 빌드의 실제 입력·원본 화면·카드 UV/비율·등급 검색·시나리오 저장/승리/해금·음악과 효과음 출력 결과는 `RestorationValidation.md`에 기록한다. 이전 Arcana 통과와 Blender/정적 소스만으로 새 실행 화면이 통과했다고 보고하지 않는다.
