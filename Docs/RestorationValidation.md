# 원본 카드·효과음·카툰 인물 개정 검증

현재 배포한 개정은 `fm-restoration-2026-10-27` / `gospel-toon-2026-10-27`이며 릴리스 프로필은 `restoration`이다. 이전 Arcana 통과 기록은 새 배포 근거로 대신하지 않는다.

새 결과는 `Artifacts/Validation/Restoration`에 남긴다. 이전 결과·실패 시도·교정 전 원본도 보존하며 최종 근거와 구분한다.

전체 규칙·저장 테스트 142개, 최종 소스에 묶인 Unity Editor PlayMode 카드 게임 9개와 Gospel 8개가 모두 통과했다. 두 게임의 Windows·Web 빌드 네 개도 오류 없이 성공했다. 원본 카드 605종의 전체 정의·원화 참조·GUID·인쇄 전체 사각형과 원본 텍스처 606개를 대조했다. 두 게임의 데스크톱·모바일 Web 검증을 완료했고, 실제 공개 HTTPS 파일 대조와 별도 공개 실행 검증도 아래 범위로 기록했다.

카드 게임 PlayMode 검증은 합법적인 AI 행동 108개로 첫 시나리오의 실제 승리·다음 과제 잠금 해제를 확인했다. 결과를 직접 설정하거나 승리 기록을 주입하지 않았다. 프로필의 저장 옮기기는 실제 내보내기·가져오기와 잘못된 코드 거부·원래 진행 보존을 확인했다. Gospel은 여섯 소지품 아이콘의 실제 메시 렌더링, 손 관절을 따라가는 등잔·실제 조명, 저장·새로 불러오기·장착 해제, 이동에 따른 안내도 위치를 확인했다.

카드 게임 데스크톱 Web은 실제 입력 검사 101개와 원본 화면 26개를 확인했다. 첫 무작위 손패의 카드 종류를 보고 일반 드래그로 지형·유닛을 배치했으며 초기 미전개·툴팁 화면도 보존했다. 브라우저 자동 입력기의 한글 IME 조합은 확인하지 못했으므로 시크릿 카드 검색은 실제 지원되는 숫자 원본 ID `15052733622`로 다시 입력했다. 잘못된 첫 검색 화면을 통과로 바꾸지 않았다. BGM을 끈 상태의 짧은 효과음 출력과 별도 효과음 음소거 상태의 실제 버튼 입력·무출력을 각각 디지털 PCM 원본으로 남겼다.

Gospel 첫 데스크톱 Web 시도는 상태창이 실제로 열린 뒤 검증 도구의 캔버스 위치 조회 기본 30초 제한에 걸렸다. 게임 예외·HTTP 실패는 없었으며 원본 23파일을 `Trials/GospelDesktop-query-timeout`에 해시 대조 후 보존했다. 도구가 지정한 300초를 위치 조회에도 사용하게 고쳤고 동일 빌드의 새 실행과 구분한다.

그 다음 데스크톱 시도는 실제 검사 35개와 원본 게이트 10개를 확인한 뒤, 리뷰 추가 입력의 `shift` 오타 때문에 달리기 교정 명령에서 끝났다. Playwright의 올바른 키 이름은 `Shift`이며 제품 오류로 분류하지 않았다. 실패한 원본 44파일과 상태는 그대로 고정했다. 동일 빌드를 새 정상 세션에서 시작해 남은 달리기·NPC/말씀·저장/전체 새로고침 복원·우물과 복원 뒤 PCM을 확인하는 별도 후속 실행을 진행했다. 두 실제 세션을 정확한 런타임·원본·실행 하네스·PCM 해시로 묶는 검증이며 하나의 중단 없는 데스크톱 통과로 소개하지 않는다. 새 입력 도구는 캔버스 노드·URL·실제 화면 크기·가시성을 확인한 DOM 사각형을 사용하고, 잘못된 리뷰 키 이름은 전송 전에 거부한다.

이 후속 실행은 실제 검사 30개·새 원본 8개와 복원 뒤 PCM을 통과했다. 좁은 두 세션 검증은 실패 원본을 그대로 유지하면서 합계 65검사·18승인 원본·PCM5창과 동일 런타임/소스를 대조했다. 새 달리기는 열린 바닥의 정상 Shift+A 입력으로 확인했고, NPC 근접 대화·해설과 아래 본문·실제 등잔 장착·저장/전체 새로고침 복원·속이 빈 석조 우물을 실제 원본으로 확인했다. 일시 저장 알림이 사라진 정지 화면에서는 알림이 보였다고 주장하지 않으며 저장 전후 실제 비교로 지속성을 확인했다.

카드 게임 모바일 가로 화면(844×390, 실제 캔버스616×346)은 119검사·26승인 원본을 통과했다. 정상 턴·셔플 뒤 실제 퓨리울프를 전열02에 배치했고, 지형3장·LP1·숲1/총0·AP3/DP0/HP4가 전체 새로고침과 잘못된 저장 가져오기 거부 뒤에도 유지됐다. 초기 제스처·작은 그림의 카드명 오인 등 19교정 원본은 미승인 상태로 보존했다. 작은 시나리오 목록에는 과제 이름/잠금이 보이고, 추천덱/목표는 정상으로 연 첫 단계 상세 원본에서 확인했다. 목록의 보이지 않는 둘째 줄을 읽었다고 주장하지 않는다. 실제 터치 효과음은 63개 짧은 PCM 관측과 최대RMS0.198892를 기록했고, 별도 음소거 중 새 버튼 입력의 출력은0이었다.

새 실행은 게임별 소스 입력 SHA로 묶는다. `.asmdef`, `.hlsl`, `.cginc`, 재질·FBX·그림·메타와 실제 Editor가 읽는 외부 재질 명세도 포함한다. 자동 생성 Boot/CardAsset 원시 직렬화와 TMP Korean/Display의 동적 atlas/kerning 캐시는 예외이며, 생성기·원본 OTF·원화·안정 GUID를 묶고 CardAsset 의미와 실제 렌더링을 별도로 검사한다. TMP 캐시는 시도별 전후 바이트 기록을 보존한다.

Gospel의 현재 실제 구간은 탄생 도입과 누가복음 2장 성전 방문이다. 소지품·등잔·안내도는 학습용 게임 설정이며 성경의 추가 증언으로 소개하지 않는다. 원작 카드 중 기술이 아직 없는 30종은 감상 전용 도감으로 분리하고 실제 출전 605종과 혼동하지 않는다. 멀티플레이는 준비 화면이며 실제 온라인 사용자나 매칭을 꾸미지 않는다.

검증은 소프트웨어 Chromium과 모바일 입력 에뮬레이션이다. 실제 휴대폰·Safari·Windows 하드웨어 성능이나 사람의 스피커 청취와 구분한다. 소스 또는 상용 게임 전체를 복구한 결과나 사용자 미적 승인을 뜻하지 않는다.

공개 카드 실행의 `lobby/battle/deck.ogg` GET 세 건은 `ERR_ABORTED`로 기록됐다. 원본 상태를 통과로 바꾸거나 일반 예외를 추가하지 않았다. 별도 `verify-restoration-fm-public-ranges.py`는 정확한 실패 보고서·요청3건·실행 하네스·원본 승인·현재 빌드/공개 파일·4음원 전체 디코딩과 같은 세션의 타이틀/로비 독립 PCM을 재검증한다. 세 취소는 첫 수동 관측보다64–85ms 앞서므로 취소 전 요소 상태나 정확한 사용자 입력 이전 시점은 확인하지 못했다. 이후 실제 브라우저 loadeddata/ready 상태는 기록됐지만 `HTMLMediaElement.error`와 media error 이벤트는 수집하지 않았으므로 부재를 추정하지 않는다. 공개 실행의 전투/덱 음악은 사용하지 않은 디코딩된 프리로드이며 실제 청취/재생을 검증했다고 주장하지 않는다. 해당 역할의 선택·출력은 같은 바이트의 로컬 전체 브라우저 실행에서 별도로 확인했다.

최초 공개 포털 브라우저 시도는 제한된 실행 범위의 기존 프록시 CA/NSS 접근 차이로 인증서 오류를 보고했다. 이미 등록된 공식 CA의 정상 NSS 접근으로 재실행해 TLS 검증을 유지한 채 통과했다. HOME·프록시·인증서를 바꾸거나 인증서 오류 무시 옵션을 사용하지 않았으며 실패 원본도 보존했다.

공개 두 게임 검사는 실제 URL의 바이트·기본 실행·정상 입력·PCM에 한정한다. 저장/전체 새로고침·등잔·전장 복원은 같은 최종 빌드의 로컬 전체 데스크톱/모바일 실행에서 확인했다. 소스와 최종 문서는 main에 기록하고, 네 플레이어 ZIP·Unity 소스 ZIP·검증 근거 ZIP은 현재 파일 집합/바이트/CRC/LFS 포인터/인증 경로 검사 뒤 제공한다.
