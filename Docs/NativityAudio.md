# 탄생 오프닝 음악과 핵심 대사 음성

현재 개정은 `gospel-nativity-2026-11-02`다. 오프닝은 이야기의 호흡을 우선한다. 실제 `IsPrologue` 장면 동안 UI·대화 진입·말씀 획득·페이지 신호음을 억제한다. 새로 발견한 본문은 Core에서 정상 기록되고 화면의 작은 알림으로만 소개한다. 이후 탐험의 이동·상호작용 소리는 기존 경로를 유지한다.

탄생 장에는 새 독자 작곡 `The Quiet of Bethlehem`을 사용한다. 느린 플루트, 현악, 첼로와 성긴 하프만 배치하며 종·획득 효과음·타악기·기존 캐럴 녹음을 쓰지 않는다. 고대 유대 음악의 역사적 복원이 아니라 탄생 이야기를 위한 현대적 배경음이다. 기존 세 장의 음악과 원본은 삭제하지 않는다. 제작 스크립트·악보·MIDI·실제 해시는 `Tools/Audio/Nativity`에 있고 기존 FluidR3 GM MIT 표기를 유지한다.

핵심 대사 28개는 캐시된 MeloTTS 한국어 모델의 **일반 한국어 AI 내레이터 한 명**으로 제작한다. 탄생 오프닝 23개에는 첫 화면의 해설도 포함하며, 이후 열두 살 성전의 마리아·예수님과 세례 때 요한·예수님·하늘의 소리 5개도 정확한 기존 본문에서 선택한다. 특정 실존 인물을 모사하거나 피치 변조를 서로 다른 배우로 소개하지 않는다. 화면의 화자 표시는 이야기의 인물이며 음성은 같은 내레이터가 읽는다. 원문과 대사를 표시하는 본문은 동일하고, 문구를 넘기면 이전 녹음이 멈춘다. 음성은 실제 사용자 입력 이후 시작하며 전체 음량·음소거와 별도 음성 켜기 설정을 따른다.

`GospelNativityVoice.PlayForTurn(stableKey, turn)`은 안정적인 사건/대사 키·정확한 화자·본문이 manifest와 모두 일치할 때만 녹음을 요청한다. 비동기 로드 중 장면이 바뀌면 요청 세대가 무효화되어 늦게 준비된 이전 음성이 재생되지 않는다. 하나의 AudioSource만 사용하며 장면·책·메뉴·새 여정·앱 중단에서는 Stop 경로를 사용한다. 실제 재생 중에만 배경 음악/환경음을 낮추고 종료 시 서서히 복귀한다. 대사 재생은 이야기 진행·본문 해금·저장·난수를 소유하지 않는다.

현재 제작 입력 `Tools/Voice/Nativity/dialogue-lines.json`은 기존 22개 항목에 승인된 6개를 추가한 **28개 병합본**이다. 원래 22개 입력 파일의 바이트 보존본은 `Artifacts/Validation/Nativity/AudioVoice/Source/Tools/Voice/Nativity/dialogue-lines.json`에 있다. 기존 22개 항목의 문구·화자·키와 실제 녹음은 그대로이며, 현재 입력 파일 전체 바이트가 이전 22개 파일과 같다는 뜻은 아니다. 실제 녹음/manifest/입력 해시는 `production.json`에 기록한다. 32 kHz mono Vorbis의 새 핵심 음성은 전체 4 MB 안으로 제한한다. 원래 Ink의 20개 음성과 그 제작 근거는 이전 경로에 보존하며 새 대사의 음성이라고 재사용하지 않는다. 독립 한국어 ASR·신호·정확한 문구 검사와 실제 Unity/브라우저 재생 검증은 따로 수행한다. 실행 전에는 새 음성 통과나 사람의 자연스러움 검수를 완료했다고 표시하지 않는다.

이번 제작의 첫 22개 문구는 실제 생성과 독립 ASR을 먼저 마쳤으며, 확정된 원본과 결과를 `Artifacts/Validation/Nativity/AudioVoice/Base22`에 바이트 그대로 보존했다. 승인된 추가 6개를 제작할 때 `--reuse-existing`은 이 22개 문구·화자·키·클립 SHA가 모두 같음을 확인하고 새 6개만 합성한다. `--reuse-base22-asr`은 현재 28개 전부의 문구/해시/디코딩 신호를 새로 검사하지만, ASR 추론 자체는 새 6개만 수행한다. 동일한 22개 클립의 이전 ASR 시각·보고서·생산자 및 검사 소스를 명시적으로 연결하며 이를 새 추론이라고 표시하지 않는다. 이 재사용은 새 게임 실행이나 현재 Core의 28개 문구 일치 검사를 대신하지 않는다.

실제 28개 제작·신호 검사는 `AudioVoice/Additional6/closure.json`에서 입력 변화 없이 완료됐다. 녹음은 합계 287.894초·1,975,891바이트이며 가중 문자 오류율은 0.07905다. 현재 manifest SHA는 `a6458e8a4fe16803d6a848fcfe6a37dc61725d13b8a57817dbde44106a3be6c4`, 제작 보고서는 `635008782a6a364b79f0b607a27c43cc8a37545d42a21eafa41e85af0f19d869`다. 새 탄생 음악은 실제 84.706초·1,071,765바이트이며 디코딩 RMS −25.95 dBFS·peak −11.87 dBFS·loop endpoint jump 0.0008875를 확인했다. 이것은 파일/명료도 검증이며 사람의 발음·연기 검수나 게임 재생 통과를 뜻하지 않는다. 게임 실행 여부는 현재 Nativity Native·브라우저 근거를 따른다.

공개 브라우저의 실제 음성 시작은 `GOSPEL_NATIVITY_NARRATION actual-start` 관측으로 따로 확인한다. 이는 수락한 현재 대사의 실제 AudioSource가 재생 중이고 source.time과 source.volume이 모두 양수일 때 한 번만 기록한다. 키·클립·문구 해시·길이·실제 재생 위치만 남기며 대사 본문이나 개인 정보는 로그에 넣지 않는다. Stop은 실제 재생/로드 중인 이전 키와 중지 사유를 남긴다. 혼합 PCM의 소리만으로 음성 시작을 추정하거나 로그만으로 사람의 청취를 승인하지 않는다.

Native01은 소스 OGG의 32 kHz를 실제 Unity AudioClip 주파수로 가정한 fixture에서 실패했다. 이 고정 Unity/Native 대상에서는 imported AudioClip 44.1 kHz, DSP output 48 kHz가 관측됐다. ProjectSetup에 별도 오디오 리샘플 정책이 있다고 단정하지 않는다. 보완 fixture는 각 정확한 원본 OGG SHA·32 kHz mono 제작 정보와 실제 AudioImporter의 Preserve/override 설정을 함께 기록한다. Native 주파수는 지원되는 32/44.1/48 kHz 범위에서 소스보다 낮지 않아야 하며, `samples/frequency`와 clip.length가 해당 원본 녹음 길이의 ±0.15초 이내여야 한다. 실제 pitch1·양수 재생 시계·정확한 28개 문구/클립·취소·음소거·duck 검사는 유지한다. 소스 녹음·제작자·ASR은 바꾸지 않았고 실패 원본은 보존한다.
