# 판타지마스터즈 클래식 규칙 체험판

개정: `fm-classic-2026-10-26`. 사용자가 옛 판타지마스터즈를 개인적으로 즐기고 회사 PC에서도 URL로 테스트하기를 요청해, 원작 공개 카드 DB와 공식 가이드 보존본을 바탕으로 구현한다. 기존 별빛의 서약 40종 판은 Git 이력과 `Artifacts/PreviousBuilds/2026-10-26-before-classic`에 보존한다. 새벽의 길의 `fluid-dawn-2026-10-24` 플레이어는 유지한다. 실제 완료·검증 결과는 [Validation.md](Validation.md)에 별도로 기록한다.

## 자료의 기준

- [공식 가이드와 규칙 조사](Research/FantasyMastersRulesSources.md): 2005년 공식 온라인/오프라인 가이드와 2008년 카드 표기 가이드, 확인되지 않은 예외를 구분한다.
- [카드 DB와 팬 프로젝트 조사](Research/FantasyMastersDatabaseSources.md): FM Lunatic에서 직접 조회한 원작 카드 숫자·등급·원본 이미지 경로를 사용한다. 팬마의 수정 수치를 원작 수치로 대신하지 않는다.
- [카드 이미지](ClassicCardArt.md): 공개 원본 카드의 이미지와 출처를 보존하며, Unity 입력에 필요한 파일 형식만 변환한다. UI에서는 원화 영역을 읽고 상세에서 원본 카드 전체를 볼 수 있게 한다.
- [음악](ClassicAudio.md): 별도의 오리지널 오케스트라 루프를 사용한다. 원작 녹음이나 선율을 그대로 복제한 음악으로 소개하지 않는다.

원작 소스를 복구하거나 공식 서비스를 재개한 프로젝트가 아니다. 서비스 종료·개인 이용·비상업성을 원작 자료의 권리 소멸 또는 재배포 허가로 설명하지 않는다. 사용자 요청에 따라 공개 테스트 URL에 배포하며, 자료의 출처와 확인되지 않은 재사용 조건을 함께 남긴다.

## 구현 계약

원작 DB 96종(지형14·유닛56·마법14·아이템12)에 암흑·불·물·숲·금속·대지·빛 7속성과 실제 카드 등급·레벨·소울·AP/DP/HP·코인식을 반영한다. 등급과 랭크를 구분하고 희귀도를 단일 전투력 순서로 취급하지 않는다. 카드별 예외 기술은 원문 기능과 실제 지원 범위를 대조해 선정한다.

기본 룰은 50장 덱, 6장 손패, 전열5칸, 지형10장, 매턴 LP1, 공격 준비→방어 준비→배치 순서 전투→소울 유지비→공수 교대다. 마법도 전열을 사용하고 배틀에서 공개한다. 공격 유닛이 선타를 가하고 살아남은 수비 유닛이 반격한다. 막을 전열이 없으면 공격 유닛 레벨만큼 덱을 소각한다. 덱 모드를 기본으로 하며 이전판의 리더 생명18을 원작 수치처럼 표시하지 않는다.

소환은 해당 색 소울과 총소울을 함께 소비하며, 카드에 표기된 무속성 부분은 유지비다. 예를 들어 색4+무3의 레벨7 카드는 소환 때 색4·총7, 유닛인 경우 이후 유지비3을 요구한다. 아이템에는 유지비를 부과하지 않는다. LP와 색 소울·총소울·유지비는 UI에서 구분한다. 새 준비 때 손패가6장까지 보충되므로 지형 없이 막히지 않도록, 원작의 셔플 옵션 중 각 준비에서 카드 사용 전 전체 손패를 한 번 다시 섞는 구성을 사용한다. 시작 손패의 일부만 교체하는 이전 멀리건은 사용하지 않는다.

기존 네 리더 초상은 선택 가능한 아바타로 유지한다. 이전판의 능동 리더 기술은 클래식 룰에서 사용하지 않는다. 50장 기본 덱과 초반 상대3전, 덱 편집, 속성/종류/비용/등급 필터, 원본 카드 상세, 저장·이어하기를 제공하는 범위로 작업한다.

선정 카드의 실제 등급은 Free67·Common12·Uncommon11·Rare1·Special5의 다섯 가지이며 레벨0~7을 포함한다. 유닛56종의 랭크는 모두 N이다. 복잡한 고유 기술이 없는 원작 유닛을 골랐으며 선정한 마법14종과 아이템12종의 수치 효과를 구현한다. 원작 전체 카드와 특수 예외의 복구는 범위에 포함하지 않는다.

코인식 Cn은 0~n개의 앞면 수로 계산한다. AP·DP·HP가 공통 코인열의 앞 n개를 읽는 방식과 유닛당 아이템2장 상한은 이번 구현의 선택이며, 공식 자료로 확정한 원작 규칙으로 소개하지 않는다. 셔플은 원작의 여러 옵션 중 준비별 사용 제한만 두는 구성을 선택했다.

## 저장·검증

새 콘텐츠는 `fm-classic-0.1.0`, 내부 schema3이며 새 전투/덱 슬롯을 사용한다. 이전 저장을 조용히 새 규칙으로 해석하지 않고 원본을 보존한다. 카드 정의는 `CardCatalog`와 전체 필드를 복사한 `CardAsset.classicDefinition`이 일치해야 한다. 원본 이미지와 코인 연산·소울·등급·출처가 모두 제작 데이터 검증 대상이다.

코어의 실제 공방·자원·셔플·카드 보존·저장 결정론, Unity의 실제 UI·원작 이미지·도감·저장 실패 보호, PC/모바일 크기 Chromium의 실제 포인터/터치·음악·새로고침/이어하기를 구분해 검사한다. 공개 배포 후 실제 파일 SHA와 URL 조작을 확인한다. 단순 빌드 성공이나 원본 이미지 검사만으로 전체 플레이·실물 기기 성능·원작의 모든 카드 예외를 재현했다고 주장하지 않는다.
