## 화면과 오디오

원본 PNG를 직접 보며 얼굴·의상·배경·대화창과 이동 장면을 검토했다. 이는 개발 시각 검수이며 사용자의 최종 아트 승인이나 원신 수준의 3D 제작을 뜻하지 않는다. 걷기는 앞/뒤 각4포즈의 그림 애니메이션이고 자유 회전 3D 카메라는 제한된 풍경 이동으로 바뀌었다.

기존 BGM과 초반 한국어 합성음성20줄은 유지한다. 브라우저에서는 첫 입력, 음소거/해제, 음량, reload 후 음악과 대사 재생/재시작/다음 대사 중단/자연 종료를 실제 출력 신호로 검사했다. 물리 스피커 청취나 발음·연기 승인을 대신하지 않는다.

처음 native 검사는 비활성 오브젝트 조회와 캡처 카메라의 UI 레이어 처리로 실패했다. 원본 실패를 보존하고 테스트를 고쳤다. 이후 통과했으나 원본 화면에서 글자와 장면 전환이 아직 갱신되지 않은 캡처를 발견해, 실제 캔버스 갱신과 전환 안정화 후 다시 캡처했다. Web에서 발견한 도입 HUD 잔여 표시·근접 이름표의 얼굴 가림을 고치고, 멈춘 여행자의 뒷모습을 위한 별도 양발 접지 원화를 추가했다. 첫 PC 진단의 마지막 캐시304 분류 검사는 복귀 검사 이름 계약 불일치로 실패했으며 원본을 보존하고 이름 계약을 바로잡았다. 화면 검토를 단순 테스트 통과와 구분한다.
