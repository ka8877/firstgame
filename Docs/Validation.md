## 카드와 서사

리더 → 기본 덱 → 상대 → 셔플 → 첫 손패 교체 → 전투의 실제 UI를 검사한다. 새 내부 전투 스키마는 2, 콘텐츠는 `starlight-0.2.0`이다. 공용 저장 봉투는 유지하고 새 슬롯을 사용하여 구판 원본을 보존한다. 판타지 마스터즈의 지형/유닛/마법/장비 및 코인 공방을 참고했지만 현재는 두 속성·24장 덱의 독자적 체험판이다. 섀도우버스는 리더와 원화 방향의 참고이며 캐릭터·그림·룰 전체를 복제한 게임이 아니다.

인게임 이동은 실제 변위 기반 애니메이션과 무릎·발 본을 사용한다. Idle 4초/Walk 0.9초를 별도 클립으로 가져오고 root motion을 끈다. Blender 계약 및 원본은 `Tools/Art/ToonDawn.md`, 실제 Unity 캡처는 `Artifacts/Screenshots/PathOfDawn`에 있다. 이는 개발 모델 개선이며 원신급 완성품·사용자 아트 승인으로 표현하지 않는다.

실제 검수에서 보행 중 튜닉 관통과 그림 배경을 가리던 단순 원경, 이전 전투를 이어할 때 최신 편집 덱을 덮어쓰던 문제를 수정했다. 첫 카드 native 실패는 초상을 atlas로 판정한 검사와 이어진 테스트 러너 재개 문제였으며, 아트 종류를 분리하고 직접 데이터 어셈블리 참조를 연결한 뒤 전체 26건이 통과했다. 브라우저의 첫 음악 관측은 타이머 지연으로 표본이 부족해 실패했으며 표본·신호 기준을 유지한 채 관측 시간을 늘렸다. 새벽의 길 PC에서는 밝은 모래에 이동 안내가 묻혀 어두운 받침을 추가하고 native와 두 플레이어를 다시 만들었다. 카드 리더·상대 선택 이름에는 대비를 높이는 어두운 받침을 추가했으며, 새벽의 길 native 보행 검사는 소프트웨어 GPU 부하를 고려해 실제 이동·각도 임계값을 유지하면서 허용 시간을 벽시계 기준 8초로 늘렸다. 실패 원본과 해결 기록은 `Artifacts/ValidationHistory`, `Artifacts/Validation/ExpandedDemo/iteration-notes.json`에 보존한다.

## 음성·음악

로컬 MeloTTS의 일반 한국어 목소리로 도입 9줄과 첫 호숫가 대화 11줄을 제작했다. 특정 배우·실존인 음성을 복제하지 않았다. Ogg 1,543,350 bytes, 디코딩 합계 168.231초이며 독립 ASR의 문자 오류율은 4.073%다. 이는 청취·연기 품질 승인을 의미하지 않는다. 대사 원문과 해시, 클리핑·파형·독립 ASR 근거는 [Voice.md](Voice.md), `Tools/Voice/verification.json`에 있다. 배포에 `ThirdParty/Voice-NOTICE.txt`를 포함한다.

두 기존 반복 BGM과 음악 설정을 유지한다. 브라우저의 첫 입력 전후·음소거·해제·음량 감소/복원·reload 이어하기의 일곱 구간에서 실제 출력 PCM을 검사한다. 대사에는 별도 다시 듣기·음성 켜기/끄기가 있고 재생 중 음악이 낮아진다. 음성 브라우저 검증의 세부 범위는 각 보고서와 [VisualValidation.md](VisualValidation.md)에 기록한다. 물리 스피커 청취는 하지 않았다.

## 범위와 한계

Unity 6000.3.26f1, Blender 4.3.2, .NET 8.0.426과 기존 유효 Personal 라이선스를 사용했다. 소프트웨어 GPU Mesa/SwiftShader 검사이며 실제 PC·휴대폰 성능 측정은 아니다. 모바일은 Chromium 터치 에뮬레이션이다. 실제 Windows 실행·Android/iPhone·Safari, 물리 음향 청취, 동시 멀티터치, 전체 전투의 포인터 완료, 전체 충돌 경로, 브라우저 프로세스 종료 후 복귀, Web↔Windows 저장 이동은 별도 실기 범위다. 표정·입모양·천/머리카락·LOD 및 성우 연기는 후속 제작 범위다.

외부 core와 native에는 중복 규칙이 있어 고유 기능 수로 합산하지 않는다. 산출물은 플레이어 ZIP 네 개, 소스 ZIP, 검증 근거 ZIP, `Deliverables.sha256`이다.
