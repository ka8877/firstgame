# 판마 리마스터: 카드 가독성·준비 조작·실제 사건 연출

현재 소스 개정은 `fm-reprise-2026-11-02`다. 실행 결과는 새 `Artifacts/Validation/Reprise`와 배포 검증 기록을 따른다. 과거 Quest의 통과를 현재 화면 검증으로 대신하지 않는다.

카드 원본15350종·출전2646종·기본 연습덱27개, 실제 소유 덱·SP·봉인된 구매 결과와 기존 저장 슬롯을 보존한다. 저해상도 원본을 실제 HD 원화로 복구했다고 표시하지 않는다. 카드 그림 파일을 재채색·확대 덮어쓰기하지 않는다.

## 원작과 바뀐 표시

기존 동적 수치는 인쇄 카드의 밝은 종이/금색 띠를 샘플링한 바탕 위에 밝은 숫자를 얹어 일부 판형에서 구별하기 어려웠다. AP/DP/HP 원래 숫자 열에 **불투명한 짙은 바탕과 흰색 굵은 숫자**를 사용한다. 실제 증가/감소 중에는 밝은 녹색/주황색으로 표시하며 코인 결과창의 정확한 이전→이후 수치와 증감도 유지한다. 이름·등급·그림·기술·원래 능력 아이콘은 덮지 않는다. 손패와 출전 카드 앨범의 유닛 기본값에도 같은 규칙을 적용한다. 원본 상세 확대는 동적 덮개 없는 인쇄 원본을 보존한다. 밝은 종이 `리틀엔젤`과 금색 `라바서커`를 실제 Unity에서 따로 검증하도록 고정한다.

모든 카드 수치와 상태는 Core의 유닛과 실제 사건 전환값에서 읽는다. 화면 이펙트는 Unity/global/Core 난수를 소비하지 않고 UI가 결과를 다시 계산하지 않는다.

## 준비 중 전열 배치

`Tools/Research/FmRenewal/faq734-text.txt`의 공식 후기 FAQ에는 공격/방어 준비 중 필드 카드를 마우스로 드래그해 순서를 바꿀 수 있다고 명시돼 있다. 새 Core의 실제 `MoveFieldCard`/`DiscardField`를 화면에 연결한다.

- 아군 유닛 또는 자신의 예고 마법을 다른 아군 전열로 드래그하면 빈 칸으로 이동하거나 이미 있는 카드와 교환한다. 카드를 한 번 선택한 다음 다른 아군 칸을 눌러도 같은 실제 API를 호출한다.
- 준비 중 아군 유닛/예약 마법을 오른쪽 소각장으로 드래그하거나, 선택 후 `선택 카드 소각`을 눌러 실제로 소각한다. 유닛의 장비도 함께 소각되며 비용은 반환되지 않는다. 장착 장비 하나만 고르는 별도 화면은 이번 범위가 아니다.
- 사용한 지형인지 추적할 수 없는 기존 저장 구조에서 지형 소각을 임의 허용하지 않는다. 기존 손패 소각과 업그레이드 손패 총소울 보상은 유지한다.
- 상대 카드, 상대 준비, 시작 손패 미확정, 전투 연출 잠금 중에는 조작할 수 없다. 두 번 누르기/길게 누르기 상세, Esc 해제, 손패 셔플과 저장/이어하기는 유지한다.

필드 이동·교환·소각은 실제 Core 사건과 저장에 남는다. 이동 표현은 카드의 원래 전열 마스크 밖 별도 공개 복사본으로 그려 옆 칸으로 갈 때 잘려 없어지지 않게 한다. 상대의 숨은 예약 마법은 공개되기 전 얼굴을 표시하지 않는다.

## 소환과 전투

2017년12월 실제 판마1의 위/아래 전열과 양측 사각5칸 코인 창, 실제 현재 수치·확률·앞뒤 결과, 원본 카드 전체 비율은 유지한다. 근거는 [후기 원작 조사](Research/FmChronicleSources.md)와 보존 원본 프레임이다. 이 개정은 독자 클라이언트 소스를 회수한 것이 아니라 원작 규칙에 연결된 새 화면 연출이다.

유닛 소환은 실제 사용된 인쇄 카드가 손패 쪽에서 자기 전열로 이동하고, 속성색 발광 고리·상승 입자·착지 효과음을 동기화한다. 공격에는 준비→접근→0.42시점 타격→짧은 정지→복귀가 있으며, 실제0피해는 방패, 양수 피해는 겹친 빛/파편과 정확한 피해 숫자로 나타난다. 큰 피해의 표시와 `PlayImpact(actualDamage)` 소리도 실제 값에 연결한다. 파괴/필드 소각은 불꽃·파편과 소각장 이동을 사용한다. 청색 필드의 미세한 안개와 명암도 원작 계열 색을 유지하며 개선했다.

1·2·4배속/끝까지는 표현 시간만 바꾼다. 공격이 끝난 상태를 미리 그리지 않고 기존 transient 스냅샷 순서를 유지한다. 새 효과가 전투 판정·저장·보상·무작위 상태를 소유하지 않는다.

## 하나의 카드 앨범

보존한 원작 공식 메뉴에 `앨범`은 있지만, 이번 조사에서 독립된 **상위 등급 도감**을 원작 기능으로 확인한 근거는 없다. 리마스터에서 추가했던 별도 상위 등급 허브를 없애고 타이틀·싱글 대기실·자유 연습에서 **하나의 카드 앨범**으로 들어간다. 레어/스페셜/유니크는 같은 앨범의 등급 필터다. 원작의 앨범 수집 보상과 완전히 동일한 UI/서버 기능을 복구했다고 표시하지 않는다.

전체15350 원본을 검색·속성7종·실제 원본 종류5종(지형/유닛/마법/아이템/인챈트)·등급·실제 출전 지원 여부로 찾는다. 이름/기술/원작번호 검색, 번호 역순/이름/레벨 정렬, 처음 조건으로 초기화, 이전/다음/마지막 이동을 제공한다. 일반 PC는 기본12개를 표시하며, 작은 화면은 기본4개 원본을 크게 표시한다. 명시적으로 `앨범 보기`를 선택하면 작은 화면도6개를 보며 이름·등급은 한 줄로 합쳐 좁은 하단에서 잘리지 않게 한다. 사용자가 고른 보기 방식은 다음 검색과 크기 변경에서도 유지한다. 원본 상세에서는 기술과 전투 지원 범위를 확인하고, 실제 지원 카드만 기존 자유 연습 덱 편집으로 이동할 수 있다. 미지원 카드 그림을 출전 가능인 것처럼 판매하거나 덱에 넣지 않는다.

실제 소유 카드와 전체 원본 앨범은 구분한다. 현재 싱글 대기실에서는 프로필 이름을 눌러 기존 프로필로 들어가며, 새 카드 앨범 입구를 추가하느라 프로필 기능을 제거하지 않는다.

## 새 실행 담당 확인

`FantasyCards.SmokeTests.RepriseSmokeTests`는 실제 밝은/금색 인쇄 카드의 AP/DP/HP 값·불투명 대비·실제 TMP 글자 기하를1280×720/616×346에서 검사한다. 전열 조작은 실제 드래그 이벤트/선택 콜백과 Core를 거쳐 이동·교환·소각·RNG 보존·저장 복귀를 확인한다. 소환·타격·소각은 실제 Core 사건 재생 중 현재 효과를 캡처한다. 앨범은 전체15350·유니크 필터·실지원2646·큰 카드·원본 상세를 확인한다.

이 결정론적 Native 입력 fixture를 일반 플레이의 자연 드로우/실제 브라우저 포인터/물리 휴대폰 증거와 혼동하지 않는다. 실행·웹 포인터/터치·공개 URL 검증과 실제 원본 화면 검토는 별도로 기록한다.
