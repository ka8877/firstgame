# 새벽의 길 · 일러스트 2.5D 제작 계약

개정 ID는 `painted-dawn-2026-10-24`다. 사용자는 얼굴·인물·배경을 크게 개선하고, 3D로 충분한 품질을 내기 어렵다면 더 적합한 표현 방법을 사용해 달라고 요청했다. 이에 새벽의 길의 현재 인게임 표현을 **회화풍 장면과 전신 만화 인물이 함께 움직이는 2.5D**로 바꾼다. 카드게임의 원화·규칙·덱·리더는 이번 개정 범위에 포함하지 않는다.

이 문서는 소스와 자산의 제작 계약이다. 최신 Unity 테스트·Windows/Web 빌드·실제 브라우저·공개 배포 결과는 [Validation.md](Validation.md), 실제 화면 검수는 [VisualValidation.md](VisualValidation.md)를 따른다. 전환 직전의 [검증 기록](ValidationHistory/2026-10-24-before-painted-dawn.md)과 [시각 검수](ValidationHistory/2026-10-24-before-painted-dawn-visual.md)는 이력으로 보존한다. 새 그림 생성이나 이전 공개판의 통과 결과를 새 런타임의 검증으로 대신하지 않는다.

## 화면과 조작

- 호숫가는 햇빛이 드는 석조 집, 꽃과 올리브나무, 청록색 호수와 먼 마을을 한 장면으로 그린다. 석조 방은 따뜻한 아치·들보·직물·등잔·호수 전망을 사용한다. 화면 아래의 넓은 바닥은 인물 이동과 발 위치를 읽기 위한 공간이다. 하늘만 교체하는 방식이 아니다.
- 예수님은 따뜻한 성인 얼굴과 짙은 물결 머리·짧은 수염·상아색 옷·붉은 겉옷, 미리암은 청록색 옷·크림색 머릿수건, 여행자는 남청색 옷·크림색 망토·가방을 사용한다. 기존 게임의 인물이나 의상을 복제하지 않으며 역사적 외모를 확정하는 자료로 소개하지 않는다.
- `DawnIllustratedStage`가 배경과 투명 전신 원화를 uGUI에 배치한다. 발 위치·원근 크기·앞뒤 그리기 순서·접지 그림자를 실제 월드 위치에서 계산한다. 대화에서는 화자의 얼굴을 크게 보이도록 인물 구도를 전환하고 기존 자막·선택 UI를 위에 표시한다. 도입 조망 중에는 HUD를 숨기고, 탐색에서 상호작용 안내가 나타나는 거리에서는 NPC 이름 표식을 숨겨 인물과 겹치지 않게 한다.
- 이동은 화면 기준이다. `W`/위 방향은 화면 안쪽, `A`/`D`는 좌우이며 모바일 왼쪽 패드도 같은 방향을 사용한다. 오른쪽 마우스 드래그·모바일 오른쪽 드래그는 제한된 장면 이동과 층별 시차를 만든다. 고정된 그림 장면을 한 바퀴 도는 카메라 회전은 제공하지 않는다.
- 여행자의 걷기는 앞·뒤 방향 각각 네 자세, 총 여덟 장면의 atlas다. 실제 이동 거리로 프레임을 진행하고 멈추면 앞쪽은 전신 대기 그림, 뒤쪽은 양발을 바닥에 둔 별도 `traveler-back.png`를 표시한다. 뒤쪽 보행 프레임을 정지 자세로 대체하지 않는다. 저장 복원·회귀의 위치 변경을 보행으로 처리하지 않는다. 이는 짧은 그림 걷기 루프이며 모션 캡처·뼈대 보간·얼굴 연기나 립싱크의 완료를 뜻하지 않는다.

## 그림과 가져오기

필수 PNG 일곱 개는 `Games/PathOfDawn/Assets/Resources/Art/Painted`에 `.meta`와 함께 둔다. 실제 등장인물은 예수님·미리암·여행자 세 명이다.

| 파일 | 원본 크기 | 용도 |
|---|---|---|
| `shore.png` | 1672×941 RGB | 인물 없는 갈릴리 호숫가 전체 장면 |
| `room.png` | 1672×941 RGB | 인물 없는 석조 방 전체 장면 |
| `jesus.png` | 1024×1536 RGBA | 예수님 전신·대화 구도 |
| `miriam.png` | 1024×1536 RGBA | 미리암 전신·대화 구도 |
| `traveler.png` | 1024×1536 RGBA | 여행자 전신·대화 구도 |
| `traveler-back.png` | 1024×1536 RGBA | 양발을 바닥에 둔 여행자 뒷모습 정지 원화 |
| `traveler-walk.png` | 1448×1086 RGBA | 4열×2행, 각 362×543의 보행 atlas |

위쪽 행은 앞쪽 사선 네 자세, 아래쪽 행은 뒤쪽 사선 네 자세다. Unity UV는 아래쪽 원점을 사용하므로 앞쪽 행의 Y는 `.5`, 뒤쪽 행은 `0`이다. `ProjectSetup`은 투명 경계와 발 기준점을 측정해 전신 영역 4개·보행 프레임 8개의 `layout.json`을 만들고, 런타임은 이 UV를 사용한다. PNG를 잘라 별도 프레임으로 저장하거나 픽셀을 재합성하지 않는다.

생성 도구는 `OpenAI image_gen.imagegen`이며 결과 PNG의 원본 바이트를 그대로 사용한다. 도구가 정확한 모델 버전·seed를 제공하지 않았으므로 같은 픽셀의 재생성을 보장하지 않는다. 프롬프트·참조·원본 경로·크기·SHA-256·파일 검수는 [배경 생성 기록](../Tools/Art/Painted/backgrounds-generation.json)과 [인물 생성 기록](../Tools/Art/Painted/characters-generation.json)에 있다. 배경은 새 묘사로 생성했고 인물은 이 프로젝트의 기존 초상을 참고해 새 전신 그림을 제작했다.

가져오기 설정은 Default, sRGB, mipmap 끄기, 원본 NPOT 크기, Clamp, Bilinear, 최대 4096, 무압축이다. 인물과 보행 atlas의 입력 알파를 보존하고 Read/Write는 끈다. 이전 플랫폼별 축소·압축 설정이 새 얼굴에 적용되지 않게 한다. 그림의 원본 변경과 `.meta`/UV 설정 변경은 구분하며, 원본을 바꾸면 생성 기록의 해시도 갱신한다.

## 게임 상태와 보존 범위

실제 이동은 기존 `CharacterController`와 충돌·이동 범위가 처리한다. 인물 Transform과 상호작용 거리, Ink 진행, 두 번의 선택·세 결과, 체크포인트·회귀·저장 형식은 게임 상태가 소유한다. 표현 레이어는 이를 읽기만 하며 위치·진행·보상·규칙 RNG를 별도로 변경하지 않는다. 장면 전환은 저장된 `pointId`에 맞춰 호숫가/석조 방 그림을 선택한다. 결말에서는 저장된 쉼터 여부를 함께 읽어 쉼터는 방, 목격자·연결은 호숫가로 표시하며 회귀와 이어하기에도 같은 원칙을 적용한다.

오리지널 BGM, 초반 일반 한국어 AI 음성 20줄, 자막 크기·음량 설정, 음성 중단·다시 듣기, 웹의 첫 사용자 입력 정책을 유지한다. 실행 중 이미지·음악·음성 생성 API를 요구하지 않는다.

이전 절차적 3D 환경·인물은 현재 인게임에 렌더링하지 않는다. 기존 런타임 프리팹은 GUID를 유지한 채 `Assets/Art/Archive/LegacyModels`로 옮기고 Boot의 네 모델 필드는 비운다. `Assets/Art/Generated`의 FBX와 `Tools/Art/ToonDawn.md`·원본·제작 기록은 보존된 3D 이력이다. 이전 14본 Idle/Walk·셀 셰이더·회화풍 하늘 검수는 해당 과거 개정의 증거이며 현재 그림 장면의 검증이 아니다. 기존 타이틀과 초상은 UI 자산으로 보존한다.

## 검수 기준과 남은 품질 작업

원본 그림 검수와 Unity 합성 화면 검수는 별개다. 실제 화면에서 탐색·대화·장면 전환·저장 복원·회귀 각각의 인물 크기와 발 접지, 투명 경계, 걷기 프레임의 잘림과 크기 변화, 앞뒤 방향, 배경 없는 순간, HUD·자막·터치 패드의 가림을 확인한다. PC 16:9와 작은 모바일 가로 화면에서 같은 핵심 정보를 읽을 수 있어야 한다. 자동 상태 검사는 최종 화면의 미적 품질이나 실제 휴대폰 성능을 보증하지 않는다.

후속 품질 범위는 표정·손짓·보행 자세의 연결, 장면별 가림과 깊이감, 대화 연기·립싱크, 음성의 사람 청취, 실제 Windows/휴대폰의 로딩·메모리·프레임률이다. 현재 자산은 개발용 창작 결과이며 사용자 최종 스타일 승인이나 상용 대작과 같은 제작 범위를 달성했다고 표시하지 않는다.
