# 판타지마스터즈 화면 개편 — 2026-10-26

사용자의 이번 요청은 원작 게임성과 카드 자료를 유지하면서 화면 디자인은 현대적으로 다시 만드는 것이다. 이전 클라이언트의 목재색 표·금색 판·반복되는 장식 모서리를 재현하는 방향에서 벗어난다.

- 시작 화면은 새로 제작한 숲·성채·두 인물의 오리지널 일러스트를 화면 가득 사용한다. 왼쪽의 어두운 그라데이션 위에 한국어 제목과 주 동작인 게임 시작을 배치한다. 이 그림은 원작 카드 일러스트나 회수한 원작 클라이언트 자료로 소개하지 않는다.
- 본문은 Pretendard Regular, 제목과 조작 문구는 Pretendard SemiBold를 사용한다. Fonts/Korean과 Fonts/Display의 생성·라이선스 계약은 글꼴 제작 기록을 따른다.
- 배경은 짙은 남색, 선택·주 동작은 샴페인색, 보조 정보는 청록색으로 통일한다. 패널과 카드는 둥근 모서리·얇은 경계·짧은 호버 및 화면 전환을 사용한다. 장식선은 각 표면의 조용한 한 줄만 유지한다.
- 대기실은 실제 컴퓨터 대전 세 개를 카드 그림과 함께 보여준다. 가상의 온라인 접속자·방·매칭은 만들지 않는다. 덱 선택·카드 검색·필터·정렬·카드별 수량 제한은 기존 실제 동작을 유지한다.
- 카드 원본 픽셀과 안정 ID·수치·등급·규칙·50장 덱은 유지한다. 큰 카드의 그림 창은 확대하고 작은 모바일 카드의 이름·비용·AP/DP/HP는 실제 픽셀 높이를 확보한 줄을 유지한다. 선택 상태와 등급은 테두리와 표시 색으로 보조한다.
- 배경 음악은 외부 재생 서비스의 안내·광고 음성이 끼어들지 않도록 로컬 연주곡으로 전환한다. 음악 설정은 새 배경 음악을 원작 SOUND-I 음원으로 소개하지 않는다. 제작 및 재생 계약은 오디오 개편 기록을 따른다.

구현 코드만으로 미적 사용자 승인이나 실제 장치 검증을 뜻하지 않는다. 최종 실행 화면·모바일 줄바꿈·입력·저장·재접속·음량 동작은 현재 빌드에서 확인해야 한다.
