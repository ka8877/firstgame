# 현재 두 게임 개선 회차

기존 C1 카드 능력 비트·등급 안내 개선을 보존하면서 최신 사용자 피드백을 반영한다. 게임을 초기화하거나 기존 저장을 덮어쓰지 않는다.

- 판타지마스터즈: 후기 FAQ에 근거한3종 공격 기술과 대표3장, 비활성 멀티플레이 표시, 기존 모든 원본/카드/경제/저장 유지.
- 예수님의 길: 설명용 메타대사를 장면 속 대화로 정리, 직접 기록된 재회 대사와 음성 원문 보존, 출처는 내부에 유지.
- 그래픽: 별도 새 원본32프레임 소년/성인과4인 NPC, 기존 원본/GUID 보존, 실제 발 위치와6단계 보행 계약 유지. 새 종이·제본 원화와 한국어 명조 조판을 사용한다.
- 배경: 기존 허가 자산으로 성전 실루엣·열린 포치·아치·동선 시야·접지와 구도를 개선한다.
- 검증: 현재 Core309개, 카드 Native8개, Gospel 기존16+책/대화3+구도2의21개, 새 Web·PC/터치·저장2재접속·음성/PCM·현재 원본·전체SHA/985MB·공개 확인을 분리해 기록한다.

이번 소스가 수정됐다는 사실은 공개 배포 완료를 뜻하지 않는다. 이전 G2 공개판을 새 검증이 끝날 때까지 유지한다. 원작 완전 재현이나 전체 성경·일대기가 완성됐다고 표시하지 않는다.
