# 예수님의 길 · Chronicle 인물과 연속 관절

현재 개정은 `gospel-chronicle-2026-10-29`다. 세계 원경·토양·조명은 승인된 Radiance 판을 유지하고 인물의 팔·손·무릎·발목 표현을 바꾼다.

## 진단과 변경

기존 소년 팔은 별도의 윗소매와 소매가 이미 포함된 팔 그림을 함께 렌더해 팔꿈치에 옷이 겹쳤다. 또 손과 등잔이 전완의 회전을 그대로 물려받았고, 팔 흔들림이 발 접촉의 위상과 어긋났다. 이전 머리/몸통/원화를 보존하면서 이 조립 방식을 교체한다.

소년은 기존1254×1254 Radiance 그림을 사용한다. 새 소년 원화는 생성하지 않았다. 소매와 전체 팔이 연결된 셀5/7만 사용하고 별도 셀4/6은 렌더하지 않는다. 팔 하나를 실제 연속 격자 메시로 만들고 팔꿈치 주변 가중치를 부드럽게 섞는다. 다리는 로브 안쪽에 기존 종아리·샌들 연속 그림을 사용하며, 뼈의 길이 방향만 보정하여 굵기와 신발 비율을 보존한다. 무릎·발목은 같은 가중 표면의 일부다. 한 장의 아이보리 로브가 허리와 다리 위를 덮어 여러 치마나 이중 소매를 겹치지 않는다.

성인 장은 새 원본 `Art/GospelChronicle/Actors/jesus-adult.png`의 완전히 옷을 입은 한 인물을 사용한다. 1024×1536 원본 픽셀은 수정하지 않고 머리·몸통·전완을 포함한 전체 팔·다리·로브의 UV 창과 실제 그림상의 어깨/팔꿈치/손목/발목 위치를 측정한다. 붉은 겉옷·수염·어깨 길이 머리는 게임의 예수님 도상이며 실존 외모의 확정 복원으로 소개하지 않는다. 성인은 이야기상 약서른 살 세례 장에서 사용한다.

## 실제 제어 계약

`SetAdult(bool)`는 같은 플레이어와 컨트롤러의 위치·속도·진행을 유지하며 소유한 렌더링만 교체한다. 장착한 등잔도 유지한다. `IsAdult`, `UsesContinuousLimbRig`, `UsesOriginalChildAtlas`, `UsesChroniclePainting`, `ContinuousLimbCount`는 실제 로드된 리그를 확인하는 검사 계약이다. 소년/성인 모두 연속 팔·다리 표면4개를 사용하며, 소년은 기존 원본·성인은 새 전신 원본을 구분한다.

`GospelCharacterKinematics`는 실제 실행과 테스트에서 공유하는 Unity 독립 기하 코드다. 두 뼈 길이를 지키며 닿지 않는 목표를 제한하고, 같은 표면의 가중치를 합쳐 팔꿈치/무릎 경계를 잇는다. 이동 속도에서 발 접촉 주기를 계산하며 팔은 발과 반대로 흔든다. 등잔은 손목 위치를 따르지만 전완이 회전해도 불꽃이 수직을 유지한다. 발 접촉 그림자는 실제 지면에 남고, 좌우 방향 전환은 같은 리그 전체를 뒤집는다.

## 원본 실행 화면 체크

실행 담당자는 새 지문에서 다음 실제 입력과 원본을 확인한다. 소스에 수치가 있다는 것만으로 렌더를 통과 처리하지 않는다.

- 소년 정지 근접: 어깨·소매가 한 번만 보이고 손이 몸통에서 떨어지거나 겹친 손으로 보이지 않는지.
- 소년 좌/우 걷기 각3위상: 팔꿈치·무릎 방향, 반대 팔 흔들림, 발의 접촉과 들어 올림.
- 소년 달리기·점프·착지: 전완이 꺾이거나 길어지는지, 소매/로브의 틈, 발목 방향.
- 소년 등잔 장착 정지/걷기/방향 전환: 손목과 등잔 연결, 수직 불꽃, 저장 후 장착 유지.
- 성인 장 진입과 저장 복귀: 실제 성인 원본·수염·붉은 겉옷, 소년으로 돌아오지 않는지.
- 성인 근접·좌/우 걷기·달리기·점프·등잔: 같은 관절 연속성과 한 번만 보이는 팔다리.

정지 원본은 지속 애니메이션 품질이나 실제 휴대폰 성능을 확정하지 않는다. 기존 승인된 배경과 이번 인물 원본은 새 네이티브/웹 결과에서 함께 확인한다.

## 첫 실제 렌더에서 바로잡은 성인 팔

Native01의 성인 등잔 포즈에서 전완 위 검은 가로 막대가 보였다. 원본 전신의 직사각형 팔 창이 손 옆의 망토/배경 어두운 부분도 포함해, 팔이 회전할 때 그 부분까지 가로로 따라온 것이 원인이다. 원본을 재색칠하거나 픽셀을 지우지 않고 실제 팔을 따르는 행별 UV 외곽으로 메시를 제한한다. 성인 팔꿈치 가중 구간은 더 넓게 섞고 등잔을 잡은 손목은 자연스럽게 낮춘다. 소년 포즈와 배경은 이 수정에서 바꾸지 않는다. 최종 승인은 새 Native02 원본에서 막대 제거·팔꿈치 곡선·맨손 보행과 등잔 포즈를 확인한 뒤 기록한다.
