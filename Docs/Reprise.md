# 선명한 카드와 이야기가 남는 성경

현재 소스 개정은 `fm-reprise-2026-11-02` / `gospel-storybook-2026-11-02`다. 실제 실행·배포 상태는 [새 검증 기록](RepriseValidation.md)을 따른다. [기존 웹 주소](https://ka8877.github.io/firstgame/)를 유지한다.

카드는 밝은 인쇄와 금색 프레임에서도 AP/DP/HP를 읽도록 원래 숫자 위치에 불투명한 짙은 판·굵은 밝은 숫자를 표시한다. 원본 인쇄 전체·비율·일러스트는 보존한다. 준비 중 아군 유닛/예고 마법을 드래그하여 이동·교환하고, 소각장으로 보내 버릴 수 있다. 비용은 돌려받지 않으며 유닛 장비도 함께 소각된다. 지형별 소울 사용을 추적하지 못하므로 지형 소각은 지원하지 않는다. 규칙 근거와 범위는 [전투 보완](FmRepriseBattle.md)에 있다.

소환 카드가 손패에서 전열로 이동하고, 공격/반격·명중/방어·피해·파괴가 실제 Core 이벤트 순서에 맞춰 재생된다. 불빛·충격·파편·서로 다른 소리가 판정을 따라가며 연출용 난수로 전투를 다시 굴리지 않는다. 기존 배속·건너뛰기·원작 코인/수치 표시와 저장을 유지한다. [화면 안내](FmRepriseUI.md)에서 실제 구현을 확인한다.

별도 상위 등급 도감은 기존 제작 과정에서 추가한 화면이며 원작 기능으로 확인되지 않아 진입점을 제거했다. 타이틀과 로비의 **카드 앨범**으로 15,350개 원본을 한곳에서 찾는다. 등급·속성·종류·검색·큰 카드·출전 지원 필터를 사용한다. 실제 전투 지원 카드는 기존2,646종이며 모든 원본이 플레이 가능하다는 뜻은 아니다. 무료 기본 덱·보유 수량·SP 보상/구매와27개 자유 연습 덱을 보존한다. 멀티·GP 결제는 계속 준비 중이다.

예수님의 길은 목록식 본문 진행을 사건과 인물 대화로 바꾼다. 탄생·아기 때·성장의 기록을 그림 장면으로 따라간 뒤 열두 살과 성인 시점의 실제 필드에서 사람들을 만난다. 사건을 마치면 정확한 본문을 한 번 획득하고 먼저 저장한 뒤 성경책에 기록한다. 본문을 별도로 읽어야 진행하는 조건은 없다. [스토리와 저장](GospelStorybook.md)·[펼친 성경책](GospelStorybookBook.md)을 참고한다.

첫 성경은 두 면이 비어 있으며 완료한 사건의 본문이 한 면씩 채워진다. 미래 제목·본문·그림은 미발견 상태에서 노출하지 않는다. 기존23목표·19본문과 이전 저장을 보존한다. 현재 이야기는 요단강의 세례와 공생애 시작까지이며 전 생애가 완성된 것은 아니다.

기존 자유 X/Z 필드·방향별 인물·NPC/충돌은 유지하면서 식생·빛줄기·그림자·수면·카메라와 짧은 탐험 대시를 보강한다. Ori의 분위기와 탐험 반응을 참고한 자체 구현이다. [시각 범위](GospelStorybookVisual.md)·[음악과 효과음](RepriseAudio.md)에 실제 변경과 제작 출처를 기록한다. 이전 원작 음악과 모든 원본·고유 ZIP·검증 기록은 보존한다.
