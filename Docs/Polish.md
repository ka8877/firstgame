# 판마 디테일과 빛의 숲 개정

현재 소스 개정은 `fm-polish-2026-10-29`와 `gospel-radiance-2026-10-29`다. 실제 실행·빌드·공개 반영 여부는 [이번 검증](PolishValidation.md)을 따른다. 이전 Renewal의 결과는 제작 이력이며 새 화면의 실행 증거를 대신하지 않는다.

## 카드게임

이번 확장은 일반 카드 수보다 희귀·스페셜·유니크의 실제 기술 지원을 우선한다. 원본 그림과 설명은 이미 전체 도감에 있었고, 기존 미지원 이유는 복합 능력의 판정·저장·중간 연출이었다. 새 카드는 원본 수치와 모든 기술을 함께 지원하는 경우에만 전투 카탈로그에 추가한다. 기존 2,571종과 저장 ID·원본 인쇄 비율은 보존한다. 현재 소스는 75종을 추가한 2,646종이며 희귀21→49, 스페셜27→64, 유니크23→27, 시크릿15→21종이다. 레전드는 기존4종을 유지한다. 새 유니크는 스파클러·카오스마스터·머메프린스·리크리에이터이며, 정확한 ID/원본 기술과 제외 이유는 [카드 근거](FmPolishCards.md)에 기록한다.

대기실의 `상위 등급`에서 스페셜·유니크·레전드·시크릿을 보고, 오른쪽 위 `레어 · 49종`으로 희귀 등급 카드 목록을 바로 열 수 있다. 이 버튼은 실제 카탈로그 수를 읽고 출전 카드의 등급 필터를 설정한다.

대전 데스크는 현재 AI 상대와 공개된 전장·손패 수·덱·소각장 정보를 표시한다. 전투 기록은 실제 Core 사건에서 나오고 연습 메모는 이 실행에서 작성하는 개인 메모다. 온라인 이용자나 채팅 응답을 꾸미지 않는다. 원작의 실제 상대 정보와 채팅 영역을 참고한 싱글 연습용 구성이며 멀티플레이는 후속 범위다.

손패·전장 카드는 한 번 눌러 선택하고 두 번 누르거나 길게 눌러 원본 상세를 본다. Esc는 현재 상세·대전 데스크에서 전장으로 돌아가고, 선택 상태에서는 선택을 풀며, 기본 전장에서는 메뉴를 연다. 원작의 더블클릭으로 특수능력을 사용하는 조작과 이번 상세 보기 편의를 혼동하지 않는다.

공방 재생은 실제 Core 사건과 중간 수치를 사용한다. 카드 진입·공격 준비·타격·피격·회복·소각 이동을 보강하며, 화면 연출이 RNG나 전투 결과를 만들지 않는다. 음악 역할 전환은 기존 원작 공개 음원의 확인된 발췌·원곡 구분을 유지하고, 클릭·카드 선택·전투 효과음의 음량과 방향감을 다듬는다.

## 예수님의 길

새 원화는 유기적인 큰 나무와 폭포·청록색 안개·빛의 층을 가진 오리지널 숲이다. 원경 그림, 실제 지형, 전경 식생, 안개, 빛줄기를 나눠 깊이와 움직임을 만든다. 새 인물 부품 원화는 소년 얼굴·상체·천·팔·다리·샌들을 분리해 관절 보행에 사용한다. 원본 PNG를 수정하지 않고 런타임의 측정한 영역과 리그로 조립한다.

Ori and the Will of the Wisps는 빛·색·공간의 깊이와 움직임의 참고다. 상용 게임의 소스·자산을 확보했다거나 같은 완성도를 달성했다고 소개하지 않는다. 숲은 학습 게임의 시각적 구성으로 역사적 공간의 실측 재현은 아니다. 원화의 원본·해시·사용 경로는 `Tools/Art/GospelRadiance/manifest.json`과 출처 안내에 기록한다.

`풍경 보기 · H`로 화면 안내를 잠시 숨겨 인물과 숲을 볼 수 있다. 같은 위치의 `게임으로 · H` 또는 H 키로 안내를 복원한다. 터치에서도 복귀 버튼은 남아 있으며 메뉴나 대화를 열면 일반 화면으로 돌아간다. 말씀 15항목, 정확한 성경 인용, 탄생 도입과 열두 살 시점, 소지품과 기존 저장은 유지한다.

새 실행 근거는 `Artifacts/Validation/Polish`에 보존한다. 기계적 화면 검사와 실제 원본 검토, 빌드 성공과 실물 기기 성능, 오디오 출력 측정과 사람의 청취를 구분한다.
