# 장면과 행동에 맞춘 소리

`fm-reprise-2026-11-02` / `gospel-storybook-2026-11-02`의 새 소리는 [제작 명세](../Tools/Audio/Reprise/manifest.json)와 [출처·라이선스](../Tools/Audio/Reprise/SOURCE-NOTICE.txt)를 따른다. 파일 분석과 실제 Unity·브라우저 출력은 구분하며, 현재 실행 결과는 Reprise 릴리스 검증 기록을 따른다. 사람의 청취 평가를 대신하지 않는다.

판마는 원 제작자가 공개한 기존 로그인·로비·덱·전투 곡과 반복 편집 바이트를 보존한다. 기존 0.55초 등전력 전환과 장면이 실제 바뀔 때 0초부터 재생하는 정책도 유지한다. 짧은 포트폴리오 발췌를 전체 원곡 복구로 표시하지 않는다. 관련 근거는 [이전 반복 경계 기록](FmRenewalAudio.md)에 있다.

전투 효과음은 소환·지형·장착·마법·회복·공격·반격·피격·큰 피격·방어·파괴·소각의 12개를 새로 제작했다. 종이 마찰과 상승음 뒤의 저음 착지, 스윙과 별도 타격, 금속 방어, 파괴의 짧은 균열과 잔향을 구분한다. 공격·반격은 타격보다 낮게 배치해 실제 명중 순간이 들리게 했다. `PlayImpact`는 Core가 이미 결정한 피해가 0이면 방어, 1–5면 일반 피격, 6 이상이면 큰 피격을 고른다. 이는 소리만 바꾸며 피해를 다시 계산하지 않는다. 기존 코인 앞뒤·능력치 변화·카드 선택 등 20개 큐와 기존 원본 파일은 보존해 총 32개 큐를 로드한다.

예수님의 길은 한 곡을 전 구간에서 반복하는 대신 탄생·성전·요단강의 세 편곡을 사용한다. 같은 새 선율을 바탕으로 탄생에는 절제된 비브라폰·하프, 성전에는 목관·피아노·현악, 요단강에는 플루트와 흐르는 하프를 배치한다. 길이는 각각 약 53.33초·48초·50.53초다. 실제 챕터 변경 때 1.15초 등전력 전환을 사용하고, 새 곡이 준비될 때까지 이전 곡을 유지한다. 같은 챕터의 UI를 다시 그릴 때는 재시작하지 않는다. 18초의 작은 바람·물·먼 새소리 환경층은 음악보다 낮게 유지한다. 이는 성경의 실제 환경음을 복원했다는 뜻이 아닌 제작된 배경음이다.

발걸음은 실제 지면 접촉 중 이동한 거리에 연결한다. 가만히 서 있거나 메뉴를 여는 동안에는 새 발소리를 내지 않으며, 위치 이동·챕터 변경을 걸음으로 계산하지 않는다. 점프·착지·대시·책장·인물 대화·새 말씀 기록·UI는 서로 다른 짧은 소리다. 대시는 실제 물리 시작 순번을 관측해 한 번 재생하므로 한 프레임 안에 짧은 대시가 끝나도 소리가 빠지지 않고, 대기 중인 버튼 요청을 먼저 울리지 않는다. 첫 장면의 초기 지면 정착을 점프 착지로 재생하지 않는다. 발소리의 음색 변화는 고정 순번을 써 게임 난수에 영향을 주지 않는다.

새 `GospelStorybookAudio`는 기존 `GOSPEL.music` 음량·음소거 설정을 계승한다. Web에서는 실제 사용자 입력 뒤 시작하며 설정·모달 재생성은 브라우저 권한을 만들어내지 않는다. 운영체제 일시 정지 때 현재 위치를 보존해 재생을 멈춘다. 현재 인터페이스는 하나의 음량·음소거로 음악·환경·효과음을 함께 조절하며 별도 효과음 슬라이더가 구현된 것처럼 표시하지 않는다. 기존 Shared `BgmPlayer`와 기존 음원은 수정하지 않는다.

새 26개 파일은 총 5,548,553바이트다. 세 악보의 MIDI·명시적 음표 JSON과 생성 코드를 함께 보존한다. 기존 MIT FluidR3 악기 라이브러리로 연주하고, 효과음·환경층은 기록된 고정 시드의 오프라인 합성으로 만든다. 원본 음원·무단 음성·상용 Ori 자산을 추출한 것으로 소개하지 않는다. 제작 시 유한 PCM·DC·클리핑·길이·끝점과 디코드 음악을 검사했으며 실제 출력 검증은 릴리스 담당의 현재 실행에 바인딩한다.
