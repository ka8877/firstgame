# 원작 전투 수치와 새 타이틀·상점, 회화형 탐험 필드

현재 소스는 `fm-restage-2026-11-02` / `gospel-canopy-2026-11-02`, 릴리스 프로필 `restage`다. [현재 검증·배포 상태](RestageValidation.md)를 따른다. 기존 [웹 주소](https://ka8877.github.io/firstgame/)를 유지하며 이전 Reprise 실행은 보존한 이력이다.

판마는 코인·아이템·피해의 실제 판정과 카드 내부 공격/방어/체력 숫자를 같은 시점에 연결한다. 원래 인쇄 카드 전체, 종횡비, 원래 숫자 위치와 어두운 수치 판을 유지한다. 타격·장착·코인 결과의 각 프레임을 실제 Core 후속 스냅샷으로 표시하며 화면이 RNG나 전투 판정을 다시 만들지 않는다. 독립 원작 근거와 구현 범위는 [규칙 보완](FmRestageRules.md)에 기록한다.

사용하지 않은 지형 소각을 추가한다. 사용한 소울의 지형별 출처를 선택적인 schema3 필드로 기록하며, 출처를 모르는 예전 저장은 실제 다음 소울 회복 전까지 안전하게 제한한다. 원작 매뉴얼의 소각 금지 조건과 현재의 결정적인 지형별 지불 배분 정책은 구분한다. 2,646개 출전 카드·15,350개 원본·27개 연습덱·기존 저장/소유/재화는 보존한다. 칠성보검 같은 미지원 고정 능력치/복합 기술 카드를 단순 덧셈으로 바꿔 출전 가능하다고 표시하지 않는다.

새 타이틀은 전용 오리지널 판타지 원화와 읽기 쉬운 제목·시작 메뉴를 사용한다. 상점19상품의 봉투/뒷면은 실제 상품 ID별 별자리·보석·검·책·속성 기호와 포장 구조를 구분한다. 원작 후기 상품의 뒷면을 복구했다고 소개하지 않는다. 봉인 팩과 다시 열기, 중복을 포함한5장 개별 획득, 실제 소유 수량과 SP가 연결된다. 대결은 상대/내 전열을 문구·위치·적색/청록으로 구분한다. [화면 계약](FmRestageUI.md), [후기 원작 조사](Research/RestageSources.md)를 따른다. 구매 가격/확률/보상은 기존 싱글판 구성이며 실제 원작 서버 표를 회수한 것은 아니다.

예수님의 길은 사용자 Ori 사진의 실제 빛·명암·유기적 지형·작은 HUD를 참고해 평평한 초록 면과 직선 띠 길 대신 회화형 지면·휘어진 길·마모된 석재·다층 숲·옥빛 강을 사용한다. 기존 공식 Lost Crypt의 실제 원본 나무/수풀/암석을 현재 3D XZ 필드에 맞춰 배치하고 묶어서 그린다. 원래 우물과 성전의 충돌·이동 목표 및 finite Cedar 수정은 유지한다. [환경과 실제 샘플 활용](GospelCanopyWorld.md)에 출처·범위를 기록한다.

새 소년/성인 인물은 원본32프레임을 보존한 방향별6단계 보행·별도 공중 자세·정지 안정화·실제 손 위치의 등잔을 사용한다. 완벽한 반대 발 접촉이나 실제 사람 비율의 모션 캡처로 소개하지 않는다. [측정·인물 계약](GospelCanopyCharacter.md)을 따른다. 기존12프레임/NPC 원본, 저장과23사건/19본문의 발견형 성경책은 보존한다. UI는 작은 신원/목표 띠와 실제 기록 수치를 남기고 중복 막대를 없앴다. 둥근 무광 패널·한글 중심 제목·Pretendard SemiBold·짧은 전환으로 장면을 덜 가린다. [UI 안내](GospelCanopyUI.md)를 참고한다.

새 원화의 원본·SHA·참조는 `Tools/Art/Restage/manifest.json`, 인물의 실제 alpha/영역/손 위치는 `Tools/Art/GospelCanopy/actors-manifest.json`에 있다. PNG 픽셀을 편집하거나 기존 원본/GUID를 덮어쓰지 않는다. 이 개정은 새 게임 두 편의 Web 검증·기존 Pages 게시를 대상으로 하며, 이전 Windows/ZIP은 이전 판의 이력이다. 원작 전체 클라이언트·서버 또는 Ori와 같은 상용 그래픽/게임플레이 완성을 주장하지 않는다.
