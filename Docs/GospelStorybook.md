# 사건을 따라 채워지는 성경책

현재 개정은 `gospel-storybook-2026-11-02`다. 기존의 **23개 사건·19개 본문**과 모든 말씀 ID, 정확한 개역한글 본문, 저장 schema1/`gospel-0.1.0`을 보존한다. 새 실행 결과는 `Artifacts/Validation/Reprise`에 따로 기록하며, 과거 Quest 실행 통과를 이번 화면·소리·이야기의 통과로 대신하지 않는다.

시작은 성경 본문 목록이 아니라 탄생을 따라가는 이야기 장면이다. 호적을 위한 여행, 탄생, 목자들의 밤과 방문, 이름, 아기 때 성전 방문, 시므온과 안나, 나사렛의 성장으로 이어진다. 이야기는 성경이 자세히 기록하지 않은 어린 시절을 새로운 사건으로 채우지 않는다. 탄생 도입의 아기 예수님을 조종하게 하지 않고, 도입 뒤 열두 살 예수님으로 성전 여정을 걷는다. 이후 성인 예수님으로 요단강의 세례까지 이어진다. 이후 사역·십자가·부활·승천은 아직 구현된 장으로 소개하지 않는다.

`GospelStorybookCatalog`는 각 사건의 장소·시간·원화 키·장면 지시와 짧은 대화를 제공한다. 기존 `GospelChronicleQuest.Dialogue`의 수와 저장된 대화 인덱스 범위를 바꾸지 않는 별도 표현 계층이다. 기존 대화 도중의 저장도 같은 사건·같은 인덱스에서 열린다. 원래 대화·본문은 제작 이력과 이전 실행을 위해 남긴다.

인물의 발언은 다음과 같이 구분한다. 성경에 남은 천사·목자·시므온·마리아·예수님·요한의 말은 검증된 해당 절에서 정확히 추출한다. 예수님의 새로운 대사를 창작하지 않는다. 기록을 연결하는 짧은 설명은 이야기로, 이동을 안내하는 요셉·마리아·길잡이의 게임용 발언은 극화 대화로 표시한다. 소리와 그림은 예술적 표현이며 실제 당시 공간이나 음향을 복원한 자료가 아니다. 정확한 성경 본문 전체는 사건을 완료해 획득한 뒤 성경책에서 읽는다.

말씀 획득은 `GospelChronicle.AdvanceStory(out acquired)`가 소유한다. 이동 구간에서는 실제 목적지 가까이 가서 현재 NPC에게 말을 걸어야 한다. 해당 사건의 마지막 대화를 마치면 말씀 한 편을 획득하고 저장하며, 별도의 본문 읽기 완료 버튼은 없다. 본문이 없는 길 안내 사건은 다음 목표로 진행하지만 말씀을 지급하지 않는다. 획득 연출은 이미 저장 가능한 결과를 보여 주므로 책을 열거나 닫아 중복 획득할 수 없다. 교체된 대화 버튼을 두 번 눌러도 기존 콜백은 자신의 한 차례만 진행하며, 새 게임·다른 저장으로 옮긴 뒤의 오래된 콜백은 새 여정을 변경하지 않는다.

성경책은 실제 두 면을 펼친 형태다. 새 여정의 각 면은 제목·구절·참조·원문이 모두 비어 있고, 이야기를 지나온 면만 본문이 새겨진다. 아직 획득하지 않은 미래의 제목과 구절을 목록처럼 보여 주지 않는다. 책을 펼쳐 보는 행동은 진행·획득 상태·대화 위치를 바꾸지 않는다. 기존 완료한 저장의 말씀을 지우거나 새 시작으로 강제하지 않는다. 이전 옆보기 저장은 원래 슬롯을 보존한 채 필드 좌표 공간으로 복사하며, 현행 필드 저장은 실제 X/Y/Z와 방향으로 복원한다.

배경 음악과 환경음은 탄생·열두 살 성전·요단강의 장면 역할에 맞춘 새 오리지널 편곡이다. 발소리는 실제 지면 접촉과 이동 거리, 착지는 실제 접지 전환을 따른다. 책 넘김·대화·말씀 획득 효과음은 표현만 담당하며 말씀이나 저장 상태를 조작하지 않는다. 기존 음량·음소거 설정과 브라우저 첫 입력 제한을 보존한다.

자동 검증 소스는 `GospelStorybookTests`의 실제 인용 경계, 기존 대화 인덱스 복귀, 사건 완료 획득, 미래 내용 비노출, 전체 23/19 순서와 중복 방지를 검사한다. 새 Unity `RepriseSmokeTests`는 빈 양면 책→첫 사건 완료→한 면만 기록/다음 면 빈 상태→실제 필드 이동/NPC→대화 중 저장과 복귀→전체 여정·기존 원본 슬롯 보존을 실제 UI 콜백과 카메라 캡처로 확인한다. 포인터·터치 입력과 공개 URL은 별도 브라우저 실행의 범위이며, 테스트 소스가 존재한다는 이유로 통과했다고 표현하지 않는다.
