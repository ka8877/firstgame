# 클래식 카드 이미지

이번 개정은 사용자가 원한 판타지마스터즈의 카드 이름·수치·등급·그림을 확인하기 위한 체험판이다. 원작 자료는 [FM Lunatic 팬 카드 DB](https://fmlunatic.com/)의 공개 카드 페이지와 해당 페이지에서 실제로 표시하는 이미지 URL을 사용한다. 게임은 준비된 로컬 이미지를 읽으며 실행 중 외부 DB나 이미지 서버를 호출하지 않는다.

`fm-remaster-2026-10-26`의 정면 카드는 161종이다. 기존 96종과 GUID를 보존하고 65종의 실제 원작 카드를 추가했다. 선정 조건·추가 효과·저장과 기본 덱의 호환 검사는 [CardRemaster.md](CardRemaster.md)를 따른다.

원본 그림은 제3자의 원작 카드 이미지다. 새로 생성한 그림 또는 재배포 허가가 확인된 자료라고 표시하지 않는다. 공개 접근 가능 여부, 비상업 목적, 과거 서비스 종료는 권리의 소멸이나 이용 허락을 뜻하지 않는다. 사용자 요청에 따른 사용 범위와 게시 여부는 프로젝트의 최신 배포 기록을 따른다.

## 파일과 표시

- 원본 응답: `Tools/Art/ClassicCards/Originals/fm_<DB ID>.webp`.
- Unity 입력: `Games/FantasyCards/Assets/Resources/Art/ClassicCards/fm_<DB ID>.png`.
- 런타임 리소스: `Art/ClassicCards/fm_<DB ID>`의 `Texture2D`.
- 원본 카드 전체: `Rect(0, 0, 1, 1)`.
- 새 UI의 그림 부분: `Rect(.13, .36, .805, .56)`. 좌표는 Unity의 아래쪽 기준 UV다. 실제 PNG를 잘라 저장하지 않는다.
- 덱과 셔플용 구 카드 뒷면: 사이트의 공개 `img/card_back_old_large.webp`를 같은 방법으로 보존하고, `Art/ClassicCards/Decor/card-back`에서 전체 UV로 읽는다. 정면 카드 수에 포함하지 않는다.

원본 WebP가 Unity의 직접 가져오기 대상이 아니므로, Pillow로 디코딩한 이미지를 무손실 PNG 컨테이너에 저장한다. 전후 RGBA 픽셀 바이트·해상도의 완전 일치를 검사한다. 색 보정, 확대, 보간, 크롭, 글자나 로고 제거, 새 그림 생성은 하지 않는다. 원본의 작은 크기와 압축 흔적은 그대로 남으며, 새 UI의 글자·등급·능력치 표시는 별도 요소다. 카드에 인쇄된 값과 팬 DB의 현재 값은 버전 차이가 있을 수 있으므로 원본 카드 보기와 현재 규칙 설명을 구분한다.

메타데이터는 무압축·mipmap 없음·bilinear·clamp로 구성한다. 작은 원본이 웹 품질 설정으로 더 줄어들지 않도록 mipmap 한도 영향을 끈다. 최종 Unity 가져오기와 실제 작은 카드의 가독성은 루트의 실행 검증 대상이다.

## 출처와 검증

`Tools/Art/ClassicCards/manifest.json`은 선택한 카드 ID, 이름, 공개 카드 페이지, 실제 이미지 URL, 조회 시각, 원본/PNG SHA-256, 크기, 디코드 픽셀 SHA-256을 기록한다. `media-selection.json`은 확인한 후보 자료와 최종 선택 파일의 해시를 연결한다. 출처 카드의 로고·문자·기존 프레임은 원본 전체 보기에서 보존한다.

```sh
python3 Tools/Art/ClassicCards/prepare-media.py
python3 Tools/Art/ClassicCards/verify-media.py
```

처음 선정할 때만 `--selection <확정된 ID 목록> --candidates <DB 후보 JSON>`을 지정한다. 이후에는 커밋된 `media-selection.json`만으로 같은 선택의 파일 경로를 복원할 수 있다. 이미 보존된 원본이 있으면 네트워크 재조회 없이 원본을 사용한다.

다운로드는 공개 사이트가 실제로 사용한 `cardlist/<종류>/large/<천 단위 폴더>/<종류 접두사><다섯 자리 KIND>L.webp` 경로를 사용한다. 예를 들어 `U00001`의 경로에는 `large/00/`이 포함된다. 이미지 서버 응답을 직접 확인하며, 데이터에 적힌 URL만으로 다운로드 성공을 주장하지 않는다.

직접 연 원본 표본은 지형 묘지, 유닛 다크배트·좀비, 마법 해골던지기·비행정탑승, 장비 본소드, 스페셜 유닛 타락천사다. 284×404 또는 285×405의 공통 카드 프레임과 그림 영역을 확인했다. 이 표본 검수는 모든 카드의 고유 효과 구현, 전체 원본의 미적 승인 또는 게임 안의 렌더링 검증을 대신하지 않는다. 최종 파일별 동일 픽셀 검사는 `verification.json`, 실제 플레이 결과는 프로젝트의 최신 검증 기록을 따른다.
