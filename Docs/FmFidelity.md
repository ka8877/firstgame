# 판타지마스터즈 원작 충실성 개정

개정은 `fm-fidelity-2026-10-27`이다. 이번 작업은 카드게임에 집중한다. 예수님의 길의 소스·플레이어·공개 파일은 이전 배포 그대로 보존한다. 사용자의 목표는 판타지마스터즈의 게임 흐름과 음악·카드 정보를 되살리고 화면과 조작을 정돈하는 그래픽 리마스터다.

## 현재 구현 방향

기존판은 전투를 즉시 계산한 최종 화면 위에 제한된 텍스트 효과만 띄웠다. 개정판은 실제 규칙 엔진의 구조화 이벤트와 일시적인 중간 상태를 받아 카드 배치, 마법 공개, 코인, 공격과 반격, 피해, 파괴, 덱 소각, 유지비를 순서대로 표시한다. 재생 속도나 연출 건너뛰기가 규칙·코인·최종 상태를 바꾸지 않는다. 상대 손패의 내용은 화면에서 공개하지 않는다.

등급과 랭크를 구분하고 도감·손패·전장·원본 상세에 실제 정보를 표시한다. 기존 원작 카드의 ID·수치·원화를 유지하며, 추가 카드는 원작 DB의 수치·기술·원화까지 확인한다. 지원하지 않는 기술을 무시해 등급 종류만 채우지 않는다. 도감의 미수록 등급은 미수록이라고 표시한다.

현재178종은 프리·커먼·언커먼·레어·스페셜·업그레이드·유니크·이벤트의8등급이다. 신규17종의 개별2장 제한, 업그레이드 손패 소각의 총소울+1과 킹핀사이클롭의 실제 무료 장착 조건을 연결한다. 기존50장4덱은 그대로 두고 새카드를 사용할 강화 체험 덱을5번째로 추가했다. 레전드·이카젠·시크릿·에픽은 아직 수록하지 않았으며 기존 선정 카드의 랭크는N이다.

손패는 클릭 외에 끌어놓기로 사용할 수 있다. 지형은 지형·소울 띠, 유닛과 장비는 합법적인 아군 전열, 대상 마법은 적법한 대상에 놓는다. 대상 없는 예약 마법은 놓은 빈 전열을 실제 예약 위치로 사용한다. 손패에서 소각장으로 놓는 조작도 별도 Core 검사와 카드 보존을 따른다. 드래그 중 합법적인 위치가 빛나고 불법 위치나 취소는 카드를 사용하지 않는다. 모바일 가로 스와이프는 손패 스크롤로 남긴다.

음악은 장면 이름과 실제 공개 음원의 출처를 확인한다. SOUND-I의 공개 포트폴리오 데모에는 반복되는 안내 음성이 들어 있어 그대로 루프 재생하지 않는다. 원본과 실제 사용 발췌·편집을 구분하며, 확인된 원작 전투곡과 장면별 발췌를 창작곡이나 원곡 전체 복구로 잘못 표시하지 않는다.
