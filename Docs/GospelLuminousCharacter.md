# Luminous 인물과 실제 이동

현재 개정은 `gospel-luminous-2026-10-28`이다. 첫 실행 구간은 열두 살 예수님의 성전 방문이며, 새 원화도 소년 인물이다. 이전 3D 모델·골격·원본은 보존하고 새 화면에서 렌더링하지 않는다. 다른 상용 게임의 인물이나 원본 코드를 추출한 결과로 소개하지 않는다.

`Art/GospelLuminous/Actors/jesus-parts`는 이 작업에서 새로 생성한 RGBA 원화다. 얼굴/머리, 상의, 치맛자락, 머리카락, 팔/팔꿈치, 다리/무릎, 푸른 천, 등잔과 주머니를 분리했다. 원본 픽셀을 후처리하지 않고 실제 알파 실루엣의 사각형만 측정하여 Unity가 각각 읽는다. 낮은 알파 아래의 RGB 값이 이미지 뷰어에서 붉거나 노랗게 보일 수 있지만, 실제 알파 혼합의 품질은 Unity 실행에서 별도로 확인한다. 파일·생성 원본·SHA-256은 `Tools/Art/GospelLuminous/Actors/manifest.json`에 기록한다.

주인공은 하나의 완성 그림을 미는 방식이 아니다. 어깨/팔꿈치·엉덩이/무릎·목과 머리카락을 각각 움직이고, 두 천 부분은 각각 77개 정점의 실제 메시를 변형한다. 걷기/달리기/점프/낙하 상태는 측정한 이동 속도와 접지에서 선택한다. 작은 호흡과 머리 움직임은 시각 효과이며 진행 상태나 RNG를 소유하지 않는다. 등잔 장착은 팔꿈치 아래 실제 손 소켓의 등잔 원화와 `Light2D`에 연결한다.

천 메시의 재질은 일반 `MeshRenderer`에 맞춘 `FirstGame/Luminous Cloth 2D Lit`다. URP의 공식 Mesh2D 패스 계약을 바탕으로 양면·알파 혼합·깊이 기록 없음과 좌우 반전에 맞는 접선 처리를 사용한다. SpriteRenderer 전용 색/반전 전역값을 천에 사용하지 않는다. 스프라이트와 메시의 원화·흰색 광원 마스크·평면 노멀은 명시적으로 바인딩한다. 셰이더 출처·변경과 Unity Companion License 전문은 Actors의 안내에 포함한다.

`npcs`에는 별도로 생성한 교사·마리아·요셉 세 인물을 넣었다. 얼굴·연령·옷·실루엣이 서로 다르며, 주인공 얼굴을 복제하거나 색만 바꾼 인물이 아니다. 이 NPC 원화는 조용히 서 있는 전신 그림이며 주인공과 같은 관절 보행을 지원한다고 주장하지 않는다.

`GospelLuminousController`가 `Rigidbody2D`와 캡슐 충돌체로 실제 이동을 소유한다. 좌우 가속·감속, 공중 제어, 점프 입력 버퍼와 짧은 접지 유예를 사용한다. 키보드는 A/D·좌우 방향키, Shift, Space, E이며 UI는 터치 입력을 같은 컨트롤러에 전달한다. `Enabled`의 같은 값 재설정은 속도를 바꾸지 않는다. 명시적 새 여정/실제 저장 이어하기의 `SetPose`만 위치와 속도를 초기화한다.

생성 원화 검토와 소스 검토는 실제 Unity/Web 동작 검증이나 사용자의 미적 승인을 대신하지 않는다. 최신 실행 결과는 릴리스 담당의 Luminous 검증 기록을 따른다.
