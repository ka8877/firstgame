# 판타지마스터즈 재구성 · 첫 단계

화면 개정은 `fm-revival-2026-10-26`이다. 사용자는 기존 창작 아바타와 별빛의 서약 표현을 교체하고, 옛 판타지마스터즈의 시작부터 대전까지를 싱글플레이로 재구성하도록 요청했다. 이번 단계는 원작 공개 자료에 근거한 타이틀·대기실·대전실·덱 선택·전장 인터페이스를 실제 조작 흐름으로 연결한다. 규칙 콘텐츠와 저장 형식은 `fm-classic-0.1.0`을 유지한다.

## 이번에 바꾼 흐름

`게임 시작` → Room 연습 대기실 → 세 AI 연습방 중 하나 선택 → 대전실 → 덱 선택 → `START` → 6장 시작 손패 → 지형·유닛·마법을 준비하는 자동 공방이다. 4개의 50장 기본 덱, 편집 덱, 96종 원작 카드 도감, 셔플, 상세 보기, 저장·이어하기와 저장 내보내기/가져오기를 사용한다. 방 목록은 실제 로컬 AI 대전 진입점이며 접속자 수·다른 이용자·채팅을 꾸며서 표시하지 않는다.

기존 리리아·카엘·세린·노아 선택 화면과 창작 초상은 현재 시작/전장 흐름에서 사용하지 않는다. 기존 저장에 들어 있는 `leaderId`와 기본 덱 추천 ID는 저장 호환을 위해 유지하지만, 전장의 플레이어·컴퓨터와 덱 구성으로 표시한다. 원작에 없는 리더 능동 기술을 추가하지 않는다.

공식 2005년 인터페이스 안내의 방 목록/우측 세로 패널/대전실/전장 구성을 참고했다. 갈색 바탕, 금속 테두리, 좁은 우측 소울·LP·덱 패널, 중앙 5열×2 전열, 하단 6장 손패로 바꿨다. 카드에는 원본 인쇄 이미지를 비율대로 표시하며, 현재 DB와 전투 상태에 따른 이름·레벨·소울·등급·AP/DP/HP를 별도 표시한다. 마우스 올리기와 길게 누르기 상세를 유지한다. 작은 화면의 글자는 최소 물리 높이를 적용하며 카드 영역은 실제 캔버스 크기에 반응한다.

## 원작 화면·인물 자료

출처와 파일별 해시는 `Docs/Research/FmRevivalSources.md`, `Tools/Research/FmRevival/official-ui-manifest.json`, `official-login-assets.json`, `unity-source-images.json`에 있다.

- `interface_lobby.gif`, `interface_gameroom.gif`, `interface_game.gif`는 2005년 공식 안내에 실린 게임 화면이다. 번호가 있는 전체 화면을 현재 배경으로 붙이지 않는다. 실제 동작하는 UI를 다시 만들고, 숫자·채팅·과거 방 이름이 없는 장식 가장자리만 런타임 UV로 샘플링한다.
- `login_img_01/02/04/06/08.gif`는 공식 **웹 로그인**에 사용한 원작 로고·인물 그림이다. 원작 클라이언트 로그인 화면을 복구한 파일로 소개하지 않는다. 현재 타이틀은 원래 웹 인물 조각을 각각 원본 비율로 배치한다.
- Unity의 `Resources/Art/Revival/*.png`는 해당 GIF 전체의 RGBA 무손실 디코딩본이다. 리터치·새 합성 원화가 아니며 모든 원본 픽셀을 보존한다. 인물 타일의 화면상 배치와 장식 UV만 UI가 계산한다.

현재 제공하는 결과는 남아 있는 낮은 해상도 자료를 이용한 첫 구현이다. 원작 클라이언트 전체 소스·원래 스킨 파일·모든 애니메이션을 확보하거나 1픽셀 단위로 복원했다는 의미가 아니다. 참조 화면으로 확인한 부분과 싱글플레이를 위한 새 연결을 구분한다.

## 원작 음악

기존 창작곡 `starlight-overture`의 자동 부착을 제거했다. 타이틀은 `login`, 대기실/대전실은 `lobby`, 덱 선택/도감은 `deck`, 전장은 `battle`을 `FmOriginalMusic`에 알린다. 화면을 다시 그릴 때 같은 곡을 재시작하지 않도록 브리지가 중복 장면을 합친다. 음악 켜기/끄기·음량은 `FC.originalMusic.muted`/`FC.originalMusic.volume`에 저장한다.

웹은 원 제작사 SOUND-I의 공개 플레이어에 연결한다. 곡 파일을 추출해 창작곡으로 재명명하거나 묶지 않는다. 네트워크·브라우저 정책에 따라 공식 플레이어의 첫 재생 입력이 필요할 수 있으며 실제 출력 여부는 공개 실행 검증으로 따로 기록한다. 네이티브에서는 공식 외부 플레이어가 없는 상태에서 예전 창작곡을 원작 BGM으로 대신 재생하지 않는다.

## 유지하는 규칙과 저장

Core와 `CardAsset`의 실제 수치·효과를 변경하지 않는다. 96종, 7속성, 현재 포함 5등급, 50장 덱, LP·색소울·총소울, 5칸 전열, 양측 준비 완료 후 자동 공방이다. 현재 단순 효과의 구체적 범위와 원작 근거가 미확인인 장비 상한·코인 해석 등은 `FantasyCardsRules.md`와 `FantasyMastersClassic.md`를 따른다.

저장은 기존 `fantasy-battle-classic-v3`/`fantasy-deck-classic-v3`와 공통 봉투 schema1을 사용한다. Game ID `starlight-oath`는 기존 외부 저장 호환 ID이며 현재 타이틀 이름이 아니다. 대기실·덱 선택은 상태 표시만 담당하고 전투 RNG를 소비하지 않는다.

## 다음 분할 개발

1. 이번 단계: 원작 자료를 확인한 진입 화면·대기실·대전실·전장, 실제 기존 싱글플레이와 연결.
2. 다음: 더 많은 원작 UI 자료에 맞춘 덱 편집/카드 목록 구조, 원작 옵션과 상태 표시를 실제 구현한 규칙으로 확대. 카드별 고유 효과는 원 필드와 판정 근거를 확보한 순서로 추가.
3. 이후: 컴퓨터 덱·전략·연습전 확대와 전체 싱글플레이 흐름 검수. 원작 회차·시기별 규칙 차이를 자료와 함께 정리.
4. 멀티플레이: 서버가 덱·규칙·난수·행동을 검증하는 별도 단계. 현재 로컬 방 화면을 온라인 매칭으로 소개하지 않는다.

실행/스크린샷/테스트 결과와 원작 참조를 구분한다. 이 문서의 구현 설명만으로 새 빌드·음악 출력·실물 모바일 성능이 통과했다고 판단하지 않으며 결과는 `Docs/Validation.md`의 해당 개정 근거를 따른다.
