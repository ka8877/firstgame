# 새벽의 길: 갈릴리 첫 구간

첫 구간의 질문은 “역사 속 장면을 바라보는 데 그칠 것인가, 눈앞의 한 사람에게 손을 건넬 것인가?”이다. 여행자는 예수님을 대체하지 않는다. 예수님을 중심에 둔 사건 주변에서 미리암과 군중의 필요에 반응한다.

## 콘텐츠와 분기

시작은 갈릴리 호숫가, 두 번째 결정은 가까운 석조 방이다. 걷기·카메라 조작·세 사물 조사·인물 대화와 읽기 시간을 합쳐 5–10분을 목표로 작성했다. 실제 사람의 첫 플레이 시간은 아직 측정하지 않았다.

| 첫 선택 | 두 번째 선택 | 결과 | 현재 세계 |
|---|---|---|---|
| 빵과 물을 나름 | 나눌 준비를 함 | 나눔의 목격자 / witness | 빵 소지품 소모, 공유 바구니 표시, 신뢰 3 |
| 말씀과 사정을 들음 | 나눌 준비를 함 | 이어진 발걸음 / reconcile | 사람들이 연결됨, 공유 바구니와 항아리 표시, 신뢰 3 |
| 어느 첫 선택이든 | 석조 방을 쉼터로 준비 | 문턱의 등불 / shelter | 쉼터 깔개 표시, 가지고 있던 빵 유지, 첫 선택의 신뢰 유지 |
| 나눔·쉼터 두 결과를 기억 | 기억으로 서로 연결하기 | 이어진 발걸음 / reconcile | 기억 적용 후에만 나타나는 세 번째 선택, 신뢰 +2 |

`witness`는 무리가 풀밭에 앉고 음식을 나누는 성경 사건으로 이어지는 문턱이다. 사건 전체를 재현하거나 창작 대사를 성경 인용문으로 제시하지 않는다. 출처는 마가복음 6:30–44, 요한복음 6:1–13. 여행자·미리암·석조 방·회귀와 모든 대사는 창작 연결 장면이다. `shelter`, `reconcile`는 가상 루트로 분리한다. 출처와 창작 범주는 `StoryChapter.sources`에 저장하고 결과 화면에서 표시한다.

## 소유권과 안정적인 ID

| 데이터 | 정본 소유자 | 저장 방식 |
|---|---|---|
| 대사, 선택, 조건, trust, first_choice, last_route | Ink | 공식 Story.state.ToJson()/LoadJson() |
| sceneId, pointId, 조사한 오브젝트, 월드 플래그 | C# WorldState | NarrativeSave/Checkpoint |
| bread_miriam 소지품, traveler/jesus/miriam 위치·방향 | C# WorldState | 깊은 복사 |
| 별도 게임 난수 | NarrativeSession | 32비트 xorshift 상태 |
| 발견한 세 경로, 세 단서, 누적 선택 이력 | MetaProgress | 저장에는 포함, 회귀 대상에서는 제외 |
| memory_witness/memory_shelter/memory_reconcile | MetaProgress에서 Ink로 주입하는 읽기용 투영 | 매 회귀 시 현재 메타에서 재계산 |
| 카메라, 오디오, Timeline, 자막 페이지 | Presentation | 월드 복원 전에 중단/재구성 |
| 제목/출처/안정 ID/콘텐츠 버전 | StoryChapter 제작 에셋 | 실행 중 변경하지 않음 |

장면 ID는 `galilee_dawn`, 시점은 `shore`, `room`, `ending`. 체크포인트는 `shore_before_choice`, `room_before_choice`. 조사 오브젝트는 `stopped_watch`, `shore_basket`, `room_lamp`. 소지품 추가는 ID 집합처럼 처리하므로 같은 빵을 두 번 얻지 않는다.

## 체크포인트 알고리즘

1. Unity 인물의 위치와 방향을 WorldState에 동기화한다.
2. MetaProgress를 Ink의 기억 조건에 적용하고 해당 선택 knot로 이동한다.
3. **Continue를 호출하기 전** Ink 상태, 월드 깊은 복사, RNG, 스키마·콘텐츠 버전을 캡처한다.
4. Continue로 대사와 선택을 생성한다. 선택 결과는 Ink 태그가 전달하고, Unity 월드 플래그를 멱등하게 갱신한다.
5. 회귀하면 진행 중 Timeline, 오디오, 코루틴을 먼저 중단하고 스냅샷을 검증한다.
6. 새 Ink 인스턴스에 저장 상태를 적재하고 현재 MetaProgress를 주입한다. 이전 선택 배열을 재사용하지 않고 checkpoint knot에서 다시 Continue한다.
7. 과거보다 미래에 있는 체크포인트를 삭제하고 월드 위치·소지품·플래그·RNG를 적용한다. 이전 분기에서 만든 바구니·깔개·항아리는 복원된 플래그에 따라 숨겨진다.

현재 대기 애니메이션은 진행 변수를 바꾸지 않는 시각적 루프다. 미래에 애니메이션 이벤트/비동기 로딩으로 게임 효과를 추가하면 취소 토큰이나 세션 세대 번호를 함께 도입해야 한다. 현재 구현에는 비동기 효과 작업이 없다.

## 저장과 이동

`NarrativeSave` schema 2, `contentVersion=galilee-0.1.0`이며 schema 1은 RNG 기본값을 제공해 메모리에서 마이그레이션한다. 미지원 버전·잘못된 Ink·위치 NaN/Infinity·중복 소지품·알 수 없는 체크포인트·세계와 Ink의 불일치·잘못된 경로를 거부한다. 실패 시 원래 파일을 자동 저장으로 덮지 않는다.

새 게임은 기존 저장이 있을 경우 별도 슬롯을 생성한다. 가져오기도 별도 슬롯으로 먼저 검증하여 기존 여정을 보존한다. 공통 저장 계층이 Windows 파일과 웹 저장을 분리한다. 설정의 JSON 내보내기/가져오기를 이용해 웹 여정을 PC로 이동할 수 있다. 실제 브라우저 클립보드 권한과 새로고침 후 영속성은 런타임 검증 항목이다.

## 화면과 조작

- WASD/방향키 또는 게임패드 왼쪽 스틱: 걷기.
- 마우스 오른쪽 드래그 또는 오른쪽 스틱: 카메라. Cinemachine Follow/RotationComposer와 Deoccluder 사용.
- E: 가까운 인물과 대화, 사물 조사, 다음 대사. 선택은 클릭/기본 uGUI 탐색으로 확정.
- M: 기억·경로·선택 이력·회귀. Esc: 설정.
- 자막 크기 90–130%, 전체 음량 0–100%를 PlayerPrefs에 별도로 저장.
- 6초 Timeline은 Galilee 조망 카메라를 움직인다. 되감기는 Timeline 재생 위치로 구현하지 않는다.

현재 캐릭터·환경 모델, 단순 바구니/깔개/항아리, 절차적 물결 소리와 선택 확인음은 임시다. 최종 자연스러운 연기·걷기·음성·피부·천·머리카락은 별도 아트 작업이다.
