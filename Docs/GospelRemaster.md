# 성경 여정: 대화와 움직임 개정

2026-10-26 · `gospel-remaster-2026-10-26`

이번 실행 구간은 베들레헴 탄생의 세 본문과 열두 살 예수님의 성전 방문(누가복음 2장)이다. 26장 목록의 후속 장은 준비 중으로 유지한다. 복음서의 기록을 학습하는 게임이며, 기록 밖 공간 배치와 조작을 역사적 사실로 제시하지 않는다.

- NPC 초상화 네 명(열두 살 예수님, 마리아, 요셉, 선생)과 총16개의 읽기/대화 턴을 연결한다. 생성 원본 atlas를 변형 없이 사용하며, UI UV로 한 인물을 선택한다. 인물의 얼굴은 창작 재현이다. 생성·파일 해시는 `Tools/Art/GospelRemaster/manifest.json`.
- 성경 직접 인용은 기존 검증된 개역한글 본문에서 추출한다. 마리아의 질문과 예수님의 대답은 누가복음 2:48–49다. 성경에 기록되지 않은 질문·대답을 창작하여 예수님의 말씀으로 표시하지 않는다. 요약/설명은 별도 표시하고 관련 본문을 대화 아래에서 계속 읽을 수 있다.
- 대화 중간 저장·복귀를 지원한다. schema1/`gospel-0.1.0`을 유지하며, 이전 저장에 없는 `dialoguePage`는0으로 해석해 열린 본문만 첫 대화에서 다시 읽는다. 이미 마친 본문과 인물 위치는 유지한다.
- Shift/모바일 토글 달리기, Space/화면 버튼 점프, 가속·회전·카메라 완화를 제공한다. 낮은 렌더 프레임에서도 이동 시간이 잘리지 않도록 실제 프레임 시간을 작은 충돌 이동 단계로 나누어 적용한다. 메뉴를 열면 달리기 토글 표시도 해제 상태로 맞춘다. 점프는 실제 중력·충돌과 준비/공중/착지 관절 애니메이션을 사용한다. 65개 뼈와 기존 형상을 유지하고 스킨드 렌더러를 소년38→8, 성인40→10으로 결합했다. 실제 성능은 실행 검증과 구분한다.
- 뜰 남서쪽의 금색 원은 선택적인 자유 연습 구역이다. F/클릭/화면 버튼은 짧은 팔 뻗기 동작을 실행한다. 현재 공격 판정·피해·NPC 전투·스토리 분기는 없으며, 성경 사건을 전투로 바꾸지 않는다. 향후 전투 입력을 확장할 수 있는 독립 액션 제어기다.
- 올리브 수관은 구형 덩어리에서 개별 곡면 잎 mesh로 교체하고 기존 석재 PBR·주인공 전용 보조 조명을 유지한다. 정지한 NPC가 공중 동작에 머물지 않도록 Animator의 바닥 상태 기본값도 수정한다.

조작: WASD/방향키 이동, Shift 달리기, Space 점프, 마우스 우클릭 시점, 휠 거리, E 대화, F 자유 연습 동작, Esc 설정. 모바일은 이동 패드·시점 드래그·달리기 토글·점프·대화 버튼을 사용한다.

원전 및 개역한글 출처: [GospelChronology.md](GospelChronology.md). 이전 서사 음성은 새 본문과 일치하지 않아 이번 대화에 자동 연결하지 않는다. 현재 검증 결과는 새 빌드 실행 이후 `RemasterValidation.md`에 기록한다.
