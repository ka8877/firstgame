# 판타지마스터즈 Arcana UI

`fm-arcana-2026-10-27`의 Presentation 변경이다. 실제 실행 검증 결과는 릴리스 담당이 `Docs/ArcanaValidation.md`와 `Artifacts/Validation/Arcana`에 별도로 기록한다. 이 문서는 화면 구현과 검사 위치를 설명하며 이전 판의 스크린샷을 이번 판의 실행 근거로 대신하지 않는다.

## 실제 세로 카드

`FmArcanaCards.cs`는 손패·큰 카드 도감·덱 편집·상세·필드·중앙 결투·공개된 카드 이동에 같은 카드 제작 함수를 사용한다. 화면의 카드 클릭/드래그 슬롯은 터치에 충분한 폭을 유지하지만, **보이는 카드 표면은 별도 자식의 5:7 세로 비율**로 부모 안에 맞춘다. `FmArcanaCardSurface.RenderedAspect`가 실제 표면의 종횡비다. 전체 슬롯이나 원화 창의 비율로 검사하지 않는다.

일반 카드에는 둥근 외곽 프레임, 등급색 포일, 별도의 속성색 소울 비용 보석, 이름, 일러스트 창, 비용, AP/DP/HP 영역이 있다. 도감의 큰 카드와 상세에는 타입/기술 요약을 추가한다. 비용 보석은 지형의 LP 또는 카드의 총소울 비용이며, 별도 비용 줄은 레벨·색소울·총소울을 구분한다. AP/DP/HP 수식은 원본 데이터의 기본값과 코인 수식을 그대로 표시하고, 전장의 현재 능력치는 실제 `UnitState`로 계산한다. 작은 카드의 긴 설명은 상세 화면으로 연결한다. 전체 기술 설명은 상세 오른쪽 스크롤에 보존한다.

원작 인쇄 전체를 작은 카드의 사각 패널에 압축하지 않는다. 원화 창은 기존 원작 텍스처에서 일러스트 부분 `Rect(.13,.36,.805,.56)`을 선택하고 `IllustrationCrop`으로 창에 맞춰 비율을 유지한 채 잘라낸다. 원본 픽셀과 GUID를 변경하지 않는다. 상세의 **원본 카드** 버튼에는 전체 인쇄 이미지를 원본 비율로 표시한다. 상세에서 돌아와도 기존 카드/검색/덱 선택을 유지한다.

등급은 실제 `CardDefinition.rarity`의 `CardRarity`를 읽는다. 프레임/등급 약호와 속성 보석을 분리했다. 이번 프레임은 Free 회청색, Common 황동, Uncommon 녹색, Rare 파랑, Special 보라, Upgrade 청록, Unique 금색, Event 민트, Legend 분홍보라 등 새 리마스터 팔레트다. 원작 인쇄 프레임은 속성·시기·버전에 따라 다르므로 이 새 팔레트를 원작의 고정 등급 배색으로 설명하지 않는다. 원본 비교 근거는 `Tools/Research/FmArcana/grade-print-reference.json`에 있다.

좁은 필드는 카드 원화·등급 프레임을 세로로 유지하고, 읽을 수 있는 이름/등급 약호/현재 AP·DP·HP를 별도 캡션으로 표시한다. 일반 화면은 이름·등급을 위, 현재 수치를 아래에 두고 프레임과 간격을 둔다. 모바일의 짧은 전열은 이름 아래에서 세로 원화를 왼쪽, 현재 수치 세 줄을 오른쪽에 둔다. 미니 카드 내부에는 빈 숫자/등급 셀을 그리지 않는다. 적의 미공개 예약 마법과 미공개 이동 카드는 중립 뒷면을 사용하며 등급·속성·이름을 노출하지 않는다. 카드 드래그 복사본도 `AspectRatioFitter`와 마스크를 유지한다. 전투 재생의 중간 스냅샷과 실제 코인 결과를 사용하고, UI가 RNG나 전투 상태를 소유하지 않는다.

## 타이틀·로비·기본 덱

타이틀과 로비는 기존 성채 파노라마 위에 새 오리지널 애니메이션풍 성인 인물 듀오를 투명 PNG로 겹친다. 리소스는 `Art/FmArcana/hero-duo`이며 원본·프롬프트·출처 표시는 `Tools/Art/FmArcana`에 있다. 이미지를 늘이지 않고 3:2 원본 비율을 유지한다. 짙은 남색과 보랏빛 패널, 금색 주요 동작, 둥근 모서리와 짧은 호버/누름 반응으로 화면을 통일한다. Pretendard 글꼴은 기존 포함 리소스를 유지한다.

기본 덱은 `DemoCatalog.StarterDecks`를 직접 읽는다. 이번 데이터는 600종·18개 기본 덱이며 단일 속성 7개와 듀얼 11개다. 전체/단일/듀얼 필터, 7속성 순환 필터, 네 덱씩 페이지 이동을 제공한다. 전체는 5페이지다. 단일 속성을 먼저 정렬하되 기존 선택 ID와 저장 호환을 유지한다. 덱 타일은 실제 지형으로 속성을 계산하고 실제 카드 종류별 장수를 표시한다. 기본 덱 선택은 기존 선택·저장 API를 사용한다.

로비 대전실은 실제 로컬 AI 연습전 세 개다. 프로필의 아바타·이름·전적과 완료 표시는 기존 로컬 기록을 읽는다. 가상 온라인 접속자·재화·서버 전적은 만들지 않는다. 음악은 실제 타이틀/로비/덱/전투 경로의 기존 역할 호출을 유지한다. 프로필/설정/카드 상세는 진입한 화면의 음악 역할을 유지하며 같은 화면 재생성은 음악을 다시 시작하지 않는다.

## 조작과 실행 검사 위치

마우스 호버 확대/상승과 누름 축소는 보간한다. 설명 툴팁은 약 0.23초 머문 뒤 열고, 모바일 길게 누르기는 기존 약 0.48초를 유지한다. 가로 손패 스크롤·세로 드래그·취소·포인터 ID·합법 칸 검사·준비 중 잠금은 기존 흐름을 유지한다. 작은 수치 글꼴의 12물리픽셀 하한을 유지하며 AP/DP/HP 순서는 전투 레일과 작은 도감 상단에도 표시한다.

첫 실제 네이티브 검사에서 작은 화면을 거쳐 큰 캔버스로 바꾼 뒤 보석·등급·수치가 비던 문제를 확인했다. 생성 당시의 `canvas.scaleFactor`로 계산한 최소 글꼴이 큰 화면에도 남는 것이 원인이었다. `UiCanvasTextSize`는 원래 지정한 글꼴 크기를 보존하고 현재 캔버스·한 줄 영역의 크기가 바뀔 때 다시 계산한다. 작은 손패/도감에서는 AP·DP를 윗줄, HP를 아랫줄 전체 폭에 배치해 긴 코인 수식을 생략하지 않는다. 작은 비용 줄은 지형의 생산량을 중복하지 않으며 유닛 속성은 빛/물/불/숲/금/대/암으로 줄여 쓴다. 전체 속성명·레벨·비용은 상세와 도움말에 있다. 실제 수정 후 화면·글리프 경계 통과 여부는 최신 릴리스 검증에 기록한다.
