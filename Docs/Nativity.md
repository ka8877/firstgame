# 이야기에 집중하는 탄생 서막과 성경책

현재 소스는 `fm-nativity-2026-11-02` / `gospel-nativity-2026-11-02`, Web 프로필은 `nativity`다. 실제 실행·공개 상태는 [이번 검증 기록](NativityValidation.md)을 따른다. 이전 [Restage](RestageValidation.md)는 보존한 성공판이며 새 구현의 실행 근거를 대신하지 않는다.

예수님의 길은 기존11개 탄생 사건을51개의 짧은 이야기 화면으로 펼친다. 마리아에게 전해진 소식, 엘리사벳의 방문, 요셉의 꿈, 베들레헴의 탄생, 목자들, 이름을 정함, 성전의 시므온·안나, 나사렛의 성장으로 이어진다. 마태복음2장의 박사 방문·애굽 피신·귀향은 다른 복음서가 전하는 기록으로 구분한다. 호적 명령의 연대나 두 복음서의 사건 간격을 새로 확정하지 않는다. 복음서가 기록하지 않은 어린 시절을 사실로 만들어 넣지 않는다. 직접 인용·본문 요약·극화 대사를 각 화면에서 구분하며 실제 근거 장절을 표시한다. [이야기·저장 계약](NativityStory.md)을 따른다.

기존23사건·19개역한글 본문과 저장 ID를 유지한다. 짧은 이야기의 위치는 선택적인 `storyDetailPage`로 보존하고 예전 저장의 대화 위치도 유지한다. 본문은 해당 사건을 마쳤을 때 한 번 기록한다. **오프닝에서는 성경 획득 화면과 종소리를 없애고** 다음 이야기 위에 `성경에 말씀이 추가되었습니다.`라는 작은 문구만2.8초 표시한다. 알림은 입력을 가로채지 않고 성경을 자동으로 펼치거나 페이지를 이동시키지 않는다. 다음 이야기로 넘어가기 전에 획득·진행을 저장한다. 대사 창에만 짧은 나타남 효과를 적용하고 장면 원화는 계속 불투명하게 유지해, 대사를 넘길 때 탐험 필드가 원화에 비치지 않게 한다.

성경은 장식이 많은 보상 도감 대신 가죽 표지·차례·절제된 종이 질감과 양면 제본으로 표현한다. 펼친 면의 중심은 복음서 이름·장절과 실제 본문이다. 원문과 절 번호를 보존하고 스크롤 영역을 넓혔다. 차례는 발견한 본문의 장절만 보여 주며 미발견 제목·본문·참조를 생성하지 않는다. 표지·차례에서 여정으로 돌아와도 현재 대화와 저장 위치는 바뀌지 않는다.

핵심 한국어 AI 음성은 정확한 현재 대사·화자·안정 키와 일치하는 녹음만 재생한다. 도입과 주요 인물의 대사를 대상으로 하며 모든 대사를 녹음한 것은 아니다. 녹음이 재생되는 동안 음악을 낮추고, 다음 대사·성경·가방·상태·메뉴·새 여정으로 이동하면 이전 녹음과 대기 중인 재생을 취소한다. 전체 음량과 별도 대사 음성 설정을 따른다. 실제 제작·문장 목록·검증 범위는 [음악과 음성](NativityAudio.md)을 참고한다. 기존20줄 Ink 음성은 이전판의 원본으로 보존한다.

탄생 음악은 플루트·현악기·첼로·하프의 조용한 새 오리지널 편곡이다. 오프닝 동안 버튼·대화 넘김·페이지·말씀 획득 효과음을 억제한다. 역사적 당시 음악의 복원이나 성우 연기·사람의 청취 검수를 수행한 것으로 소개하지 않는다. 새 장면 그림과 성경 종이는 `Tools/Art/Nativity`에 원본 PNG·복사본·SHA·프롬프트를 보존하며 해석적 삽화임을 밝힌다. 기존 원본/GUID를 덮어쓰지 않는다.

기존 다층 숲·32프레임 인물·자유 XZ 이동을 유지하고, 탐험 대시가 끝난 뒤 입력을 놓았을 때의 미끄러짐을 줄였다. Ori의 작은 UI·명암·유기적 환경을 참고하되 상용 게임과 동일한 품질·소스·자산을 복구했다고 소개하지 않는다. 카드게임은 실제 장착 원본 확인·개별 소각과 공격 전 HP0 처리의 누락을 보완한다. [카드 규칙 근거와 범위](FmNativityRules.md)를 따른다. 원본 카드 수·재화·덱·저장은 보존하며 원작 전체 클라이언트를 완성했다고 주장하지 않는다.
