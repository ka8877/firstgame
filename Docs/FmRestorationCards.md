# 판마 상위 등급·싱글 시나리오 개정

현재 개정은 `fm-restoration-2026-10-27`이다. 기존 **600종의 원본 DB 전체 필드·PNG/WebP 픽셀·텍스처 메타데이터와18개 기본 덱**을 보존하고, 실제 기술을 구현한 원작5종과 상위 등급 연습 덱2개를 추가했다. 플레이 카드는 **605종**, 기본 덱은 **20개(단일 속성7·듀얼13)**다. 듀얼13개에는 대지·빛 조합을 새 카드로 달리 구성한 두 프리셋이 포함되므로 서로 다른 속성 조합은12개다. 원 클라이언트나 원작 전체 소스를 회수한 것은 아니다.

위5종은 원작의 동일 카드 한도1장을 지킨다. 기존 킹핀사이클롭의 한도2장과 무료 장착 효과도 유지한다. 현재 플레이 가능한 상위 등급 카드는 유니크4·레전드2·시크릿1종이다. 전체605종의 종류는 지형29·유닛453·마법26·아이템97종이며 프리212·커먼201·언커먼149·레어3·스페셜11·업그레이드3·유니크4·이벤트19·레전드2·시크릿1종이다.

시크릿 카드 원문에는 영웅 카운터 삭제도 있다. 현재 클래식 체험 규칙에는 영웅 카운터나 영웅 활성화가 없어 합법적인 상태의 카운터는 항상0개다. 따라서 비어 있는 카운터 집합의 삭제는 효과가 없으며, 이를 사용할 수 있는 영웅 기능으로 소개하지 않는다. HP 변경과 조건부 무소울 보상은 실제로 처리한다. 이미 앞서 해결된 낮은 레벨 마법은 필드에 남아 있는 마법으로 세지 않는다. HP 나눗셈은 기존 수치 마법과 같은 일시 능력치 변경이며, 기존 물리 피해를 지우는 회복으로 바꾸지 않았다.

소스 카드의 연산이나 비용을 간소화하여 숫자를 채우지 않는다. 최초 후보 마르카토·길단보급장교는 원문 소울 코드83(`BONUS`)가 있어 이번 지원 대상에서 제외했다. 코드82(`NCS`)와도 구분한다. 후보 원본은 제작 이력에 보존했으며 런타임 카드·도감·덱에 섞지 않았다.

## 원본 상위 등급 도감

`OriginalCardArchive.All`은 플레이 카탈로그와 별도인 **감상 전용30종**이다. 유니크7·레전드7·시크릿7·에픽7·이카젠2종을 원본 인쇄 전체와 전체 원문으로 볼 수 있다. 예를 들어 전설의기사·천상의군주·요정여왕·오르브웨크·라리슈어와 첫 에픽7속성을 포함한다. 고유 상태·소환·섀도우 오라 등을 아직 구현하지 않은 카드를 수치만 남긴 전투 카드로 등록하지 않는다. 도감은 감상 전용과 미구현 사유를 표시하고 덱 추가 기능을 제공하지 않는다.

그림은 `Art/FmArchives`에 별도 보관한다. 공개 원본 WebP를 같은 크기의 PNG로 디코딩했으며, 모든 RGBA 픽셀을 대조한다. 원화 재제작·허가 확보·원작의 새 고해상도 원본으로 소개하지 않는다. 원작 파일·출처·전체 DB 필드·해시는 `Tools/Data/Restoration/archive-records.json`과 `archive-media.json`에 있다.

## 장비 코인·확률 보정

새 용의보주의 인쇄본을 확인하면서 기존 장비의 `CoinOption`과 `ProbOption`이 수치 장비처럼 처리되고 있던 문제도 수정했다. 공개 DB의 `liveappsetting/enumtable`을 직접 조회하여 전체97장 중 코인 수 보정19장(신규 용의보주 포함), 확률 보정37장의 실제 코드를 읽는다. 예를 들어23은 전체 `C+1`,13은 `AC+1`,33은 `DC+1`,43은 `HC+1`이고, 확률21은 `+5%`,22는 `+10%`다. `OriginalEquipmentModifiers`는 원본의97개 레코드에서 생성하며 원본600종의 필드나 기본 수치를 다시 쓰지 않는다.

공격·방어·HP의 코인 개수를 따로 보정하고 원래 `+/-/×/=` 연산과 배수를 유지한다. 보정으로 코인이 새로 생기는 기존 무코인 수치는 `+C`로 처리한다. 실제 공통 코인열을 굴린 뒤 각 보정된 개수만큼 읽는다. 기존 마법의 추가 코인도 실제 개별 수치 판정에 반영한다. 이전 구현은 추가 동전을 굴리고도 개별 산식에서 원래 개수까지만 읽었다.

최대5코인과 공통열의 앞 n개를 읽는 방식은 [현재 체험 규칙](FantasyCardsRules.md)의 기존 선택을 유지하며 원작 전 시기의 정확한 연산 방식으로 확정하지 않는다. 코인 개수는0–5, 확률은0–100%로 제한한다. 기본50%는 기존 `Range(2)` RNG 경로를 그대로 사용하고 실제 장비로 바뀐 확률만 정수 백분율 `Range(100)`으로 판정한다. UI·효과음은 RNG를 소비하지 않는다.

## 상위 등급 덱과 시나리오

`premium-grove`는 숲·금속의 강한치명/야수회피, `premium-relic`은 대지·빛의 킹핀사이클롭·랜드트랩퍼·용의보주·차원의충격파를 사용하는50장 연습 프리셋이다. 실제 원작 카드로 새로 구성한 프리셋이며 원작에서 판매한 동일 상품 덱을 복구한 것이 아니다. 기존18개 덱의 ID·구성은 그대로다.

`FmScenarioCatalog`는 소울의 기초 → 파도의 시험 → 강철의 관문 → 유산의 수호자로 이어지는4전의 새 싱글 학습 경로다. 실제 덱과 동일 규칙을 사용하는 CPU전이며, 원작 시나리오 전체를 복원했다고 표시하지 않는다. 승리 목표는 상대 덱 소진이다. 실제 승리로 다음 장을 열고 완료한 장은 다시 할 수 있다. 멀티플레이는 구분된 준비 화면이며 실제 접속자나 방을 꾸미지 않는다.

기존 연습전의0·1·2번을 바꾸지 않고 고유 ID의 시나리오 상대4개를 덧붙였다. 저장된 전투의 상대 인덱스·덱·아바타가 함께 일치해야 시나리오 승리로 인식하므로 연습전 승리를 시나리오 완료로 세지 않는다. 카드 콘텐츠 버전 `fm-classic-0.1.0`과 저장 schema3를 유지한다. `nextGenericSoulBonus`는 이전 저장에서0으로 읽는 선택 필드이며 다음 소울 코스트에서 한 번 소비하고 범위를 검사한다.
