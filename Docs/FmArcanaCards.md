# 판타지마스터즈 카드·기본 덱 확장

현재 개정은 `fm-arcana-2026-10-27`이다. 원작 공개 DB의 완전한 관찰 레코드와 원본 카드 그림을 이용해 **250종에서600종**으로 늘렸다. 원 클라이언트나 전체 게임 소스를 회수한 것은 아니다. 기존250종의 모든 필드·원본 WebP·PNG 픽셀·텍스처 GUID·CardAsset GUID를 보존하며, `fm-classic-0.1.0`/저장 schema3와 기존 다섯 기본 덱 ID를 유지한다.

| 종류 | 이전 | 추가 | 현재 |
|---|---:|---:|---:|
| 지형 |28|1|29|
| 유닛 |180|270|450|
| 마법 |15|10|25|
| 장비 |27|69|96|
| 합계 |250|350|600|

유닛은 레벨1/2/3/4/5/6/7/8에 각각80/87/82/74/61/53/12/1종이 있다. 빛·물·불·숲·금속·대지·암흑을 모두 포함한다. 새270유닛은 원본의 N랭크, 개별 AP/DP/HP와 코인 연산·장비/마법/야수 능력·소울 비용·유지비·장수 제한을 그대로 생성한다. 단순 수치 장비와 일반 지형은 지원하는 규칙만 선정했다. 지원하지 않는 기술을 지우거나 규칙 설명을 생략한 채 카드 수를 채우지 않는다.

## 기본 덱18개

기존 `forest`, `knights`, `tides`, `stars`, `fidelity`의 ID·구성·선택 호환을 유지하고13개를 추가했다. 합계는 **7단일 속성 덱과11개의 서로 다른 이중 속성 조합**이다. 추가 덱은 원작 카드로 새로 구성한 연습용 프리셋이며 원작에서 판매한 동일 이름의 덱을 복구했다는 의미가 아니다.

|---|---|

|`mono-water`|물 단일 · 푸른 심해|

|`mono-forest`|숲 단일 · 야수의 연대|

새 프리셋은 각각 **지형16/유닛24/마법6/장비4장의50장 덱**이다. 단일 덱은 실제 장수 제한4장인 서로 다른 지형4종을4장씩 사용한다. 이중 덱은 두 속성에 지형8장씩을 배분한다. 모든 지형은 LP1을 내고 색 소울1과 무속성 소울1을 생산한다. 유닛은 레벨1–2를14장 이상 넣고 낮은 유지비를 우선했으며, 유닛의 실제 능력 조건에 맞는 마법·장비를 선정했다. 프리셋별 카드 ID·장수·레벨 곡선·유지비 분포는 [starter-decks.json](../Tools/Data/Arcana/starter-decks.json)에 기록했다.

## 원문을 대조한 새 마법10종

스네이크스펠, 파이어월, 함정, 파이어실드, 적장목베기, 승리의함성, 프로즌실드, 황소힘겨루기, 도깨비불, 개미지옥을 추가했다. DB의 전체 규칙과 인쇄 원본을 직접 대조했고 기존 Core의 일시적 수치 연산으로 구현했다. 고정 전열 번호·아군/적군·야수 조건·공격/수비 전용·지속 시간을 보존한다. 예를 들어 파이어월의 ‘유닛3’은 세 번째 고정 전열이며, 함정은 적 전체 HP-1에 야수의 추가 HP-2를 합해 총 HP-3으로 처리한다. 마법 예약 칸은 효과의 원문 대상 칸과 독립적이다.

[spell-print-review.json](../Tools/Research/FmArcana/spell-print-review.json)은 직접 확인한10장의 경로·SHA-256·원문·연산을 보관한다. 수치 변경은 전투의 임시 HP/AP/DP 변경이며 보통 RPG의 최대 HP에 제한되는 회복으로 바꾸지 않았다.

## 원본 등급과 그림

현재 보유 등급은 Free212, Common201, Uncommon149, Rare3, Special11, Upgrade3, Unique1, Event19, Legend1종이다. 원본 DB의12등급 정의는 유지하지만, 미지원 규칙을 제거해 Icajen/Secret/Epic을 채우지 않았다. 등급과 N/C/B/A/S랭크는 별개이며 현재 지원 유닛은 모두 N랭크다. 동일 카드 제한1/2/4장은 원본 필드를 따른다.

9등급의 인쇄 예시를 직접 살펴본 결과, 예전 인쇄 테두리는 등급 하나만으로 정해지지 않고 속성과 인쇄 버전의 영향을 받는다. 새 일관된 등급 프레임 색은 리마스터 UI의 표시 규칙이며 원작의 보편적 색 규칙으로 소개하지 않는다. [grade-print-reference.json](../Tools/Research/FmArcana/grade-print-reference.json)에 예시와 관찰을 남겼다. 인쇄 전체는 상세 화면에서 보존하고 일반 카드는 원화 창과 새 수치·규칙 영역을 사용한다.

350장의 원본 WebP를 선택적으로 가져와 같은 크기의 PNG로 무손실 변환했다. 대부분285×405이며 일부284×404이고, 두 컨테이너의 디코딩 RGBA 픽셀을 모두 대조한다. 원본을 고해상도 재제작했다고 표시하지 않는다. 런타임 텍스처 압축은 빌드 설정의 별도 문제로 다루며 원본 파일의 픽셀·GUID를 바꾸지 않는다.

## 출처와 재현·검증

공개 카드 페이지는 `https://fmlunatic.com/card/<ID>`, 원본 미디어는 해당 DB의 `storage.googleapis.com/fmdb-bcb70.appspot.com/cardlist/` 경로다. 카테고리1/2/4의 기존 관찰과 새 카테고리3 관찰을 사용했다. 카테고리2/3은 각각 최대2000개를 조회한 제한된 관찰이며 전체 DB 백업으로 부르지 않는다. 모든 선택 카드의 전체 필드는 해시가 기록된 관찰과 일치해야 한다.

- `Tools/Data/Arcana/apply-expansion.py`: 보존 기준250종 검증, 지원하는350종 선정·원본 획득·카탈로그 생성.
- `Tools/Data/Arcana/generate-starter-decks.py`: 고정 ID의13개 프리셋과 카드/곡선 감사 자료 생성.
- `Tools/Data/ClassicCards/verify-remaster.py`: 이전96/161/178/250종 호환·전체 소스 필드·마법 검토·600장 원본 픽셀/GUID·카탈로그 재현 검증.
- Core 테스트:600종 수치 유효성, 새 마법10종의 실제 대상·전열·능력 필터,18개 덱의 제한/소울/장착 조건, 새13덱의 시드별 실제 전투 진행을 검사한다.

소스·픽셀 검증은 통과했고, 카드 관련 Core 테스트57개도 모두 통과했다(최종 실행18초). 여기에는 새13덱을 세 시드씩 실제 진행한39전, 기존 다섯 덱의 전투·저장 회귀, 새 마법10종의 대상 검사가 포함된다. 실행 기록은 `Artifacts/Validation/Arcana/CoreCards/arcana-card-core-final.trx`다. 실제 Unity 임포트/표시/고품질 압축·브라우저 조작·배포 결과는 [ArcanaValidation.md](ArcanaValidation.md)의 이번 개정 실행 기록으로 구분한다. 여기의 데이터 검증만으로 모든 카드 그림의 런타임 가독성이나 실제 플레이 품질을 통과했다고 주장하지 않는다.
