# 두 게임의 현대적 디자인 개정

현재 개정은 `fm-modern-2026-10-26`과 `gospel-modern-2026-10-26`이다. 이번 사용자 요청은 원작 카드 규칙을 유지하면서 UI와 그래픽은 현대적으로 바꾸고, 예수님 게임의 인물·의상·머리·카메라·상태창을 개선하는 것이다.

카드 타이틀은 새 창작 판타지 원화 위에 읽을 수 있는 어두운 그라데이션과 간결한 제목·시작 버튼을 배치한다. 잉크색·청록·샴페인 색의 둥근 패널과 얇은 구분선을 사용한다. 기존 원작 카드 161종의 그림·코스트·등급·규칙·덱·저장은 유지한다. 한글은 Pretendard Regular/SemiBold이며 숫자는 작은 화면에서 Regular와 실제 수식 길이에 맞춘 열 너비를 사용한다.

예수님의 길은 실제 스킨드 모델과 65개 뼈·7개 동작을 유지한다. 소년 예수님은 어깨 길이 머리, 부드러운 얼굴 비례, 크림색 리넨과 파란 겉옷을 사용한다. 성인 인물은 별도 성인 모델이며 마리아는 별도의 베일·긴 옷 실루엣을 가진다. 이는 허가된 기본 모델을 수정한 학습용 묘사이며 인물 외모의 역사적 확인이 아니다. 성전은 온화한 중립색 낮빛, 석재 모서리·문틀·목재 격자 세부를 보강했고 실제 이동 구역과 충돌 배치를 유지한다.

UI는 작은 목표 패널, 인물 상태, 흰색 대화 카드와 구별된 성경 본문으로 구성한다. 휠·화면 +/−·설정 슬라이더는 같은 1.8–8m 카메라 거리를 조절한다. 상태창은 실제 나이·목표·장·읽은 기록을 표시한다. 예전 본문·Core·저장 형식은 그대로이며 이후 장을 구현됐다고 표시하지 않는다.

음악은 외부 플레이어 대신 네 개의 내장 창작 연주곡으로 전환했다. 정확한 기존 안내 음성의 문장은 재현·녹음하지 못했으며, 그 출처를 광고와 트랙 도입 중 하나로 단정하지 않는다. 일반 플레이의 외부 삽입 경로는 제거했다. 실제 로컬 재생·PCM 관찰과 사람의 청취를 구분한다.

원본·라이선스·해시는 `Tools/Art/ModernRemaster`, `Tools/Art/Gospel3D`, `Docs/ModernTypography.md`, `Tools/Audio`와 각 제작 문서를 따른다. Blender 미리보기, Unity 실행, 실제 브라우저 원본 화면과 공개 URL 검증은 별도이며 최신 결과는 `Docs/ModernValidation.md`를 따른다. 실제 휴대폰·Safari·게임용 GPU 성능이나 상용 작품 수준의 품질을 검증한 것으로 표시하지 않는다.

참고한 현대 RPG의 일반 UI 패턴은 [원신 공식 소개/갤러리](https://www.playstation.com/en-us/games/genshin-impact/)와 [FFXIV 공식 HUD 가이드](https://na.finalfantasyxiv.com/uiguide/know/know-hud/hud-layout.html)의 화면 가장자리 HUD·정보 위계·투명도·별도 상태 메뉴다. 해당 게임의 코드·리소스를 가져오거나 화면을 1:1 재현한 범위는 아니다.
