# 성전 뜰의 우물과 휴대 등잔

개정: `gospel-toon-2026-10-27`.

이전의 낮고 넓은 수반은 Poly Haven의 불 피우는 돌 고리를 얕게 변형한
소품이었다. 새 뜰에서는 이 수반 대신 용도와 구조를 알아볼 수 있는 별도
우물 모델을 사용한다. 이전 수반 모델·출처·GUID는 제작 이력으로 보존한다.

새 우물은 엇갈려 쌓은 세 단의 석회암 벽돌, 별도 돌 테두리, 그 아래로
내려간 어두운 안쪽 벽과 수면, 목재 기둥과 상인방, 손잡이 있는 수평 권양축,
14번 감긴 밧줄, 양동이와 손잡이로 구성된다. 벽돌 이음과 양동이 안쪽은
실제 입체다. 수면을 바깥 바닥에 크게 덮는 판으로 표현하지 않는다.
일반 카메라에서도 돌 이음과 나무 결이 읽히도록 모서리와 재질을 조절했다.

우물의 최고 높이는 약 3.06 m, 돌 테두리 지름은 약 2.38 m이며 손잡이까지의
전체 가로 폭은 2.70 m다. 실제 배치는 `(0, .055, 0)`, 회전은 18도다.
테두리의 16개 충돌체와 두 목재 기둥 충돌체가 플레이어 진입을 막는다.
기존의 3.8 m 수반보다 바닥 점유가 작으며 주요 NPC와 말씀 이동 경로는
변경하지 않았다. 사용자가 좋게 평가한 기존 나무와 관목은 그대로 둔다.

인벤토리의 등불 동작에는 별도로 만든 작고 오목한 진흙 등잔을 연결한다.
약 20 cm 길이의 등잔에는 심지 홈, 기름을 담는 공간, 손가락 고리가 있다.
`GospelAuthoredProps.AddTravelLamp(Transform, Vector3)`는 충돌체나 진행 상태를
소유하지 않는 모델만 만든다. 장착 여부·실제 조명·저장은 인벤토리가 소유한다.

우물은 26,960개 삼각형·재질별 여섯 메시, 등잔은 2,032개 삼각형·두 메시다.
런타임은 FBX 루트의 축 변환을 보존한다. 우물의 손잡이 때문에 생기는
비대칭 바운드로 우물 중심을 밀지 않도록 원래 수평 원점을 유지한다.

재현 절차:

```sh
python3 Tools/Art/GospelWell/make-cedar.py
blender -b -t 4 --python-exit-code 1 --python Tools/Art/GospelWell/build-well.py -- --root .
blender -b -t 4 --python-exit-code 1 --python Tools/Art/GospelWell/verify-well.py -- --root .
```

`--render`를 덧붙이면 `/tmp/firstgame-gospel-well`에 실제 최종 FBX를 다시
가져온 정면·상단 미리보기를 출력한다. `manifest.json`은 정확한 파일 해시,
최종 삼각형 수, 유한 좌표·UV·바운드의 재가져오기 검사를 기록한다.
별도 `export-verification.json`은 닫힌 메시 조각의 면 방향과 양의 부피를
검사하여 실제 뒷면 제거에서 돌과 양동이 벽이 사라지지 않는지 확인한다.
이 검사는 Unity 게임 화면·카메라 충돌·물리 기기 성능 검증과 구분한다.
현재 실행과 공개 배포 검증은 새 Restoration 검증 기록을 따른다.

새 메시와 512 px 목재 결 텍스처는 프로젝트에서 직접 제작했다.
석회암에는 기존 ambientCG Plaster001의 CC0 표면 미리보기 이미지를 공유한다.
전체 원본 고해상도 팩을 복구했다고 소개하지 않는다. 기존 석회암 노멀은
DirectX 형식으로 기존 Unity 초록 채널 반전을 유지하며, 새 목재 노멀은
OpenGL 형식으로 반전하지 않는다. 출처는
[소품 제작 안내](../Tools/Art/GospelWell/SOURCE-NOTICE.txt)와
[기존 성전 재질 출처](../Tools/Art/GospelTemple/manifest.json)에 있다.

이 우물·등잔·성전 뜰 배치는 학습을 위한 미술적 구성이다. 특정 유적의 우물
구조나 당시 권양 장치의 고고학적 실측 복원이라고 주장하지 않는다.
성경 본문·진행 순서·저장 버전은 변경하지 않는다.
