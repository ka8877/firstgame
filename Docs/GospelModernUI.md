# 예수님의 길 · 현대 UI와 줌

이번 사용자 피드백에 따라 이전의 큰 금색 테두리와 반복되는 어두운 상자를 줄이고, 따뜻한 아이보리 대화창·잉크색 패널·얇은 분리선·Pretendard 본문/제목 계층으로 재구성했다. 이 문서는 구현 계약이다. 실제 화면 승인이나 Unity/브라우저 통과는 새 실행 결과를 별도로 기록한다.

- `DawnUi.ModernStyle`을 현재 Gospel 진입점에서만 사용한다. 보존된 이전 게임의 스타일은 바꾸지 않는다.
- 인물과 현재 목표를 왼쪽 위 작은 패널로 모으고, 오른쪽에 상태·기록·저장·설정을 배치한다. 이동 중 성경 본문은 아래 패널에 유지한다.
- `상태` 또는 `I`는 실제 주인공의 나이(열두 살), 현재 목표, 관련 성경 구절, 실제 읽은 말씀 개수를 보여준다. 구현하지 않은 체력·전투 수치를 만들지 않는다.
- 대화의 화자/직접 인용·학습 요약 구분, 아래의 정확한 본문과 출처는 유지한다. 저장 스키마와 구절 문자열은 바꾸지 않는다.
- 1280×720 설계 공간의 모든 현재 앱 텍스트는 최소 23pt다. 제목/버튼은 `Fonts/Display`, 본문과 성경은 `Fonts/Korean`을 사용하며 새 제목 폰트가 준비되기 전에는 기존 폰트로 동작한다.
- 화면은 180ms 동안 부드럽게 나타나고, 버튼은 짧은 색 전환과 작은 텍스트 인셋으로 호버/키보드 포커스를 알린다. 입력을 기다리는 임의 지연을 넣지 않는다.

마우스 휠은 `1.8–8.0m` 범위에서 목표 거리를 바꾸고 140ms 감쇠로 따라간다. 기본은 `4.6m`다. 기존 카메라 충돌 처리는 유지한다. 메뉴/대화 중에는 휠이 카메라를 움직이지 않으며, 탐험 중에도 실제 UI 위에서는 휠/우클릭 회전을 소비하지 않는다. 모바일 카메라 드래그 면은 예외이며 오른쪽 드래그로 회전할 수 있다. 눈에 보이는 `+`/`-` 버튼과 설정의 거리 슬라이더도 같은 API를 쓴다. 설정은 `GOSPEL.cameraDistance` 환경 설정이며 이야기 저장 형식과 분리한다.
