# Canopy: field-first interface

`gospel-canopy-2026-11-02` keeps the23 story events/19 passages, discovery-only physical Bible, source text and save IDs. The active field interface now uses a74px identity/goal strip instead of118/88px stacked plaques and removes two redundant progress bars. The actual discovered-passage/story counts remain visible. No health, mana or RPG level is invented.

The field is framed by small matte rounded panels, a circular two-axis pad and subdued touch actions. Existing movement-pad and jump/dash/run/dialogue event wiring remains intact. The status portrait still opens the real age-specific equipment/record panel, and book, journal, bag, pause and scenic mode remain available. Destination distance and NPC interaction availability still follow the actual XZ route.

All bordered panels reuse the existing DawnUi rounded geometry/trim, while decorative panel images keep raycasts disabled. Buttons explicitly enable their own target and use the existing Pretendard SemiBold asset; body copy remains Pretendard Regular. Main menu headings prioritize Korean over small English subtitles. Short unscaled modal fades do not disable input or delay progress.

Title/story scenes use gradual legibility veils rather than a hard dark half-screen rectangle. Dialogue still distinguishes direct scripture, dramatization and narration. The two-leaf Bible, undiscovered-page hiding, body scrolling and reward count are unchanged. Source PNGs are not modified.

The source changes require new Native/Web PC/touch captures and actual book/status/menu/movement inputs; no earlier Reprise aesthetic approval or physical-device/FPS claim is reused. Ori reference still images support composition, depth, value grouping and a small HUD, not a claim of identical commercial rendering or motion.
