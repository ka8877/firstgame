# 판마 Restage 화면과 상품 포장

현재 화면 개정은 `fm-restage-2026-11-02`, Web 프로필은 `restage`다. 이 문서는 구현 계약이며 실제 새 실행/공개 배포 여부는 `Artifacts/Validation/Restage`의 실행 근거를 따른다. 이전 Reprise 통과는 새 화면 검증이 아니다.

## 타이틀·상점·대기실

새 타이틀은 원본1672×941 무텍스트 판타지 원화와 왼쪽 전용 메뉴 영역을 사용한다. 과거 공식 웹 배경을 크게 잘라 인물 얼굴과 메뉴를 겹치던 화면을 대신한다. 기존 원작 카드 원본2장은 타이틀 오른쪽에서 전체 인쇄/종횡비를 유지하며 실제 상세 화면으로 연결된다. 새 원화의 원본·출처 구분·SHA는 `Tools/Art/Restage/manifest.json`·`SOURCE-NOTICE.txt`에 있다. 원본 픽셀은 재편집하지 않았고 importer는 NPOT 비율 유지·최대2048·고품질 압축·밉맵과 trilinear를 사용한다.

제목/버튼은 기존 Pretendard SemiBold TMP `Display`, 설명과 수치는 Pretendard Regular TMP `Korean`을 실제 역할에 맞춰 사용한다. 새 외부 폰트나 가짜 글꼴 이름을 추가하지 않는다. 어두운 청록·금색과 선명한 얇은 테두리, 큰 화면 제목·작은 영문 masthead·분리된 보조 문구로 계층을 정리한다. 애니메이션은 표현만 바꾸고 Core나 보상을 소유하지 않는다.

싱글 대기실은 실제 상대 덱의 원본 카드 미리보기와 단계/완료/입장을 보여준다. 우측은 실제 프로필 아바타·이름, SP 잔액·GP 준비 안내, 소유 카드 수를 나눈다. 가짜 XP·온라인 접속자·결제를 만들지 않는다. 기존 무료 덱 선택·보유 덱·임무·상점·자유 연습과 프로필 접근을 보존한다.

## 상품마다 구별되는 새 포장

원작의 실제 후기 상점/봉인 팩/상품별 뒷면을 새로 확인했다고 주장하지 않는다. [자료 조사](Research/RestageSources.md)대로 기존 `late-official.jpg`는 공식 웹사이트 배경이며 클라이언트 타이틀 증거와 구분한다. 새 포장과 개봉용 뒷면은 원작 카드·팩 결과를 감싸는 리마스터 제작물이다. **전투의 숨은 상대 카드 뒷면은 기존 원본을 그대로 사용한다.**

현재19개 상품은 실제 `offer.id`에 따라 구별된다. 클래식은 일곱 별의 청색 문양, 프리미엄은 금빛 보석, 무료 A/B/C는 각각 교차 검/펼친 책/새싹 문양이다. 7속성 부스터는 각 속성 기호·색·명칭을 사용하고, 7고정 기본 덱은 같은 속성의 별도 책등과 STARTER DECK50장 표시로 구별한다. 금속 테두리·접힌 포장 가장자리·지문처럼 정해진 선무늬는 벡터로 그려 해상도에 맞춘다. UI가 새 상품을 만들거나 원본 확률/재화를 임의 변경하지 않는다.

상품 미리보기·상점·구매 내역·봉인 팩·개봉 뒷면이 같은 `offer.id`를 사용한다. 포장의 모양은 카드 결과나 난수에서 정하지 않는다. 카드 결과는 기존과 같이 구매 순간 봉인되고 저장되며 재접속/외형 재생성으로 다시 뽑지 않는다. SP 차감·구매/개봉의 원자적 저장·무료 하루 한 종류·실제 확률/보장 표기·GP0은 기존 Core를 따른다.

개봉은 상품별 뒷면5장이 순서대로 뒤집혀 **실제로 봉인된 결과5개**를 보여준다. 같은 카드가 두 번 나와도 각각의 뽑기 위치를 표시한다. 원본 인쇄 카드 전체와 실제 보유 수를 보여주며, 고정50장 기본 덱 상품은5장씩10페이지로 모두 열람한다. `바로 보기`는 표현 시간만 줄인다. 결과를 다시 보거나 저장을 다시 열어도 카드를 재지급하지 않는다.

## 내 전열과 상대 전열

위쪽 상대 AI는 붉은 가장자리와 `상대 AI 전열`, 아래쪽 자신은 청록 가장자리와 `내 전열`로 구분한다. 색 외에도 텍스트와 실제 공개 카드/덱/소각 수가 항상 있다. 카드 그림을 가리지 않도록 각 전열 위에 실제 화면 기준 최소14px 제목 영역을 예약하고 나머지에서 전체 원본 카드를 같은 비율로 맞춘다. 코인/명중 집중 표시 중에도 헤더를 마지막 레이어로 유지한다.

전열 중심과 중앙 대결 카드 크기도 같은 실제 행 영역을 기준으로 계산한다. 준비/공방/저장/재배치/상대 숨은 정보, 기존 코인 창과 원본 카드 자체를 새 UI의 장식으로 대체하지 않는다. 전투 수치의 정확한 이벤트 시점 갱신은 `FmLiveCardValues`와 현재 전투의 실제 전후 프레임을 사용한다. 이 코드와 Core 수정의 계약은 별도 규칙 담당 문서를 따른다.

새 Core가 허용하는 미사용 지형은 기존 지형 클릭→선택 카드 소각으로 실제 소각할 수 있다. 이미 소울을 썼거나 옛 저장에서 사용 여부가 불명확한 지형은 Core의 구체적 이유로 잠근다. 소각 시 남은 생산 소울도 제거되며 LP를 반환한다고 표시하지 않는다.

## 실제 검증 경로

새 `FantasyCards.SmokeTests.RestageSmokeTests` partial은 타이틀 원화 실제 로드, PC/터치의 상품명·가격 글자,19개의 실제 상품별 구별되는 포장, 구매→봉인 결과 보존→전체 재시작→같은 포장/결과→개봉5위치→보유55장/200SP→재열람 중복 미지급을 확인한다. 동전/장비/피해 수치와 실제 전열 헤더는 `RestageBattleSmokeTests.cs`에서 확인한다.

Native의 결정론적 전투 fixture·UI 콜백과 실제 브라우저 포인터/터치·물리 기기·사람의 청취는 구분한다. 현재 새 실행이 완료되기 전 통과라고 표시하지 않는다.
