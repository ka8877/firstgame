# 예수님의 길 — 자연스러운 관절 인물

개정은 `gospel-natural-2026-10-27`이다. 현재 성전 구간의 주인공은 누가복음2장의 열두 살 예수님이며, 성인 예수님과 마리아는 별도 인물 자산으로 유지한다. 모델은 예술적 표현이며 실제 역사적 얼굴을 복원했다고 주장하지 않는다.

## 기존 외형의 문제와 교체

이전 공개판의 실제 확대 화면과 인물 정면/얼굴 렌더를 먼저 대조했다. 과장된 슈퍼히어로 원형의 입술·뺨·각진 턱, 큰 눈, 깊은 눈 주변 홈과 튜브형 머리카락은 조명을 바꾸는 것만으로 해결되지 않았다.

이번에는 MakeHuman의 명시적 CC0 인체 토폴로지와 연령/성별 매크로 데이터를 사용해 얼굴과 목의 실제 입체 구조를 교체한다. 눈꺼풀·콧방울·중립적인 닫힌 입술·귀와 두개골을 갖춘 표면이며, 원래 UV를 유지해 호환되는 공식 피부 아틀라스를 적용한다. 손·발의 기존 Quaternius UV와 새 얼굴의 MakeHuman UV는 별도 재질로 분리한다. 눈은 같은 인체 매크로를 따라가는 실제 눈 프록시와 동공/홍채 아틀라스를 사용한다. 원본의 붉은 홍채는 아틀라스 배치를 유지하는 이미지 생성 편집으로 차분한 갈색으로 바꿨고 원본을 보존했다.

기존 딱딱한 지그재그 튜브 머리는 제거했다. 공식 CC0 `long01`의 제작된 머리카락 표면·가닥 아틀라스·인체 프록시를 사용하며, 어깨 길이에서 잘라 윗부분의 원래 흐름을 보존한다. 투명 가닥 아래에는 두상에 맞춘 불투명 두피가 있어 정수리가 비어 보이지 않는다. 머리는 양면 알파 클리핑을 사용하며 Unity 재질에서 실제 확인해야 한다.

목은 새 해부학적 표면을 옷 안쪽까지 이어 기존 피부의 잘린 톱니 경계와 빈 목구멍을 없앤다. 의상의 기존 닫힌 메시·직물 UV·스킨 가중치는 유지하고 목둘레·어깨 연결 부위를 국소적으로 부드럽게 다듬는다. 커다란 떠 있는 장식 판을 새 목둘레로 사용하지 않는다.

## 골격·동작과 저장 계약

`GospelRig`의65개 뼈와 Generic 변환 경로를 유지한다. `Idle`, `Walk`, `Run`, `JumpStart`, `JumpAir`, `JumpLand`, `Practice`의 기존7클립을 그대로 내보낸다. 위치·충돌은 기존 CharacterController가 소유하며 애니메이션 루트 이동을 새로 켜지 않는다. 성경 본문·장 진행·저장 ID/schema/콘텐츠 버전은 이 아트 개정에서 바꾸지 않는다.

주인공 모델의 실제 렌더러는10개이며 새 얼굴·눈·피부·머리의 재질 이름과 텍스처는 `Assets/Resources/Art/Gospel3D/material-spec.json`에서 연결한다. `.fbx`의 기존 `.meta` GUID를 보존한다.

## 제작·근거와 검증 범위

재현: `blender -b -t 4 --python-exit-code 1 --python Tools/Art/GospelNatural/build-natural-actors.py -- --root . --no-render`.

실제 내보낸 FBX 검사: `blender -b -t 4 --python-exit-code 1 --python Tools/Art/GospelNatural/verify-exported-actors.py -- --root .`. 이 검사는 FBX를 다시 읽고65본·공통 변환 경로·7클립, 각 클립의 시작/중간/끝 변형 좌표, 정수리 바깥쪽 법선과 실제 파일 해시를 기록한다. `ExportedPreviews`는 이 FBX를 가져와 그린 자산 검토 이미지이며 Unity 게임 캡처가 아니다. 이전 실패한 얼굴/머리 초안은 최종 외형의 검증으로 사용하지 않는다. 최종 어깨 망토·수염·머리쓰개 접촉 수정 뒤에는 `--selected-fit-views`로 바뀐 세 부위의 현재 FBX 원본만 다시 캡처한다. 이전 전체 포즈 이미지는 별도 이력 보고서에 이전 파일 해시와 함께 보존한다.

공식 원본·CC0 약관·선택 파일 CRC/SHA·변형 출처는 `Tools/Art/GospelNatural/SOURCE-NOTICE.txt`, `source-files.json`, `Candidates/source-manifest.json`에 있다. 최신 실제 게임의 URP 재질·얼굴 확대·뒷면·이동·달리기·점프와 저장 복귀 검증은 릴리스 기록을 따른다. 얼굴 표정/립싱크·실물 모바일 성능·사용자 미적 승인·AAA 품질은 이 자산 검사의 통과 의미에 포함하지 않는다.
