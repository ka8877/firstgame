# 별빛의 서약 — Rules v0.2 체험판

이 문서는 **판타지마스터즈 1의 확인 자료**와 **이 프로젝트의 설계값**을 구분한다. 판마 1의 복제나 수치 재현을 주장하지 않는다. 카드 이름, 그림, UI, 스토리는 오리지널이다.

## 확인한 원작 자료

2026-10-20 조사. 다음 URL을 실제 HTTP로 열어 본문을 읽었다.

1. [Fantasy Masters — Gameplay / Coins / Constructing Deck](https://en.wikipedia.org/wiki/Fantasy_Masters), 2002년작의 2차 정리. 2016년 후속작은 소개 문단에서 별도로 구분된다. 문서 자체에 출처 보강 경고가 있으므로 아래 내용은 2차 자료에서 확인한 범위다.
   - Land, Unit, Item, Spell의 4종 분류.
   - 후열 지형이 soul 자원을 만들고, 전열 유닛·마법이 전투에 참여하는 준비/전투 구조.
   - 유닛 전투의 코인으로 AP/DP/HP가 변하는 구조.
   - 이 정리는 덱 50장, 지형 한도 10장, 최대 5코인, 7속성을 설명한다. 본 프로젝트 수치로 가져오지 않았다.
   - 원작 마법은 뒤집어 놓은 뒤 전투 때 공개하고 낮은 레벨부터, 동률이면 공격측부터 처리한다고 기술한다. 본 프로젝트의 즉시 시전과는 다르다.
2. [2007-02-17 원작 공식 홈페이지 보존본](https://web.archive.org/web/20070217213433/http://www.fantasymasters.co.kr/). 2016년 판마2 이전의 공식 페이지임을 확인했다. 카드 마켓/덱 스토어/교환 등 당시 원작 메뉴가 남아 있다. 세부 가이드는 Flash와 과거 ASP 경로에 의존하여 이번 조사에서 규칙 본문을 추가 검증하지 못했다.

원작 생명/덱 고갈 판정, 공격·방어 편성 상세, 효과 우선순위의 지역·버전 차이는 1차 가이드로 교차 검증하지 못했다. 이를 확정된 원작 규칙으로 취급하지 않는다. 판마2의 리뷰나 수치를 구현 근거로 사용하지 않았다.

### 이번 체험판의 추가 참고

2026-10-23 원문 HTTP 재조회에서 위 Fantasy Masters 자료의 지형 soul·전열 유닛/장비·공격/방어·코인 구조를 다시 확인했다. 이번 구현도 지형 전개와 자원 선택, 전열 유지, 장비, 상대의 가로막기와 코인 결과를 중심으로 확장했다. 준비 단계 즉시 마법·생명 18·24장 덱·두 속성은 이 프로젝트의 체험판 설계값이다.

Shadowverse의 리더·클래스와 캐릭터 중심 카드 경험을 추가 참고했다. 확인한 자료의 리더 방어력 20과 진화 시스템을 그대로 구현한 것은 아니다. **이번 네 리더의 턴당 1회 능동 기술은 우리 설계**이며 원작에 동일한 공통 시스템이 있다고 설명하지 않는다. 원문 재조회 증거는 `Artifacts/Validation/ExpandedDemo/{Fantasy_Masters,Shadowverse}-reference.txt/json`에 있다. 캐릭터·카드 이름·그림·음악은 별도의 창작 콘텐츠다.

전투 코어의 `RuleSet`에서 덱/손패/전장/지형/자원/생명/턴 한도, 시작 보장, 반격 여부, 기본 코인 수, `coinOrder`(공격측 먼저/방어측 먼저), `damageOrder`(동시 피해/공격 우선 피해)를 바꿀 수 있다. 공격 우선 피해에서는 치명상을 받은 수비 유닛의 반격 피해를 취소한다. 양측 코인 결과 기록은 피해 전에 완료한다. 현재 튜토리얼 UI의 덱 편집 조건은 24장에 맞춰져 있으므로 다른 RuleSet을 제품화할 때 UI도 변경해야 한다.

기본 해결 순서는 **공격 선언 → 방어 선택 → 공격 코인 → 방어 코인 → 피해 동시 적용 → 칸 순서대로 사망 제거 → 승리 확인**이다. 준비 단계의 마법/장비는 비용 지불 → 효과 적용 → 사망 제거 → 승리 확인. 판정은 모두 코어가 수행하며 UI는 `BattleEvent`를 재생하기만 한다.

리더 기술은 **자신의 준비 단계에 턴당 한 번**이다. 조건을 만족하지 않으면 자원·카드·기록·RNG를 바꾸지 않는다. 효과가 없는 회복이나 넘치는 손패를 위한 기술은 사용할 수 없다. 사용 턴과 총 횟수를 저장하며, 사건 기록과 불일치하면 불러오기를 거절한다. 별도의 무작위 리더 효과는 없다.

체험전은 `garden`(리리아/숲), `lake`(세린/물결), `observatory`(노아/별)의 세 결투다. 같은 카드 규칙과 생명 18을 사용한다. 2·3장의 AI는 현재 확정 공격으로 처치할 적 유닛을 우선 공격하며, 코인의 미래 결과를 읽거나 AI 전용 자원을 추가하지 않는다. 자동 대전 검사는 종료·저장·결정론을 검증하는 수단이며 인간 상대의 난이도나 균형을 확정한 결과는 아니다.

| 39 | `tide_crown` 월광 왕관 | 장비·조류 3 | 방어 +2 |

피해 마법과 리더 화살에는 방어가 적용된다. 드로우 마법은 기존 손패 한도·버림·탈진 규칙을 따른다. 자원 마법은 기존 자원 상한을 따른다. 소환 시 기본 방어/추가 코인도 `UnitState`에 기록되어 장비·저장·실제 코인 판정에 반영된다.

## 결정론과 저장

- Xorshift32 상태는 `BattleState.randomState`에 저장. 최초 덱 셔플·손패 교체 후 재셔플·코인만 난수를 사용한다. 0 seed는 1로 정규화한다. 정수 범위 선택은 rejection sampling을 쓴다.
- 같은 상태·RuleSet·콘텐츠 버전·행동이면 같은 사건 순서와 난수 상태로 진행한다.
- AI는 비용/종류/인스턴스 ID 정렬, 공격력/칸 정렬, 방어 체력/칸 정렬로 결정을 내린다. 생성형 API와 별도 난수 호출이 없다.
- `BattleState.Copy()`는 RuleSet/플레이어/카드/유닛/장비/로그를 복제한다. 실시간 상태는 ScriptableObject를 변경하지 않는다.
- 저장에는 덱/손패/지형/버림/유닛/장비/피해/자원/단계/선언/코인 상태/사건 기록과 리더 ID·덱 ID·체험전·손패 교체 여부·기술 사용 턴/횟수를 포함한다. 손패 선택 중과 방어 대응 도중도 복원 가능하다.
- 내부 전투 스키마 **2**, 콘텐츠 **`starlight-0.2.0`**이다. 외부 portable 봉투 스키마는 1을 유지한다. 이전 v0.1 전투를 임의 변환하지 않고 원본을 보존하며 새 결투 안내를 표시한다. 카드 총수·중복 ID·선택한 기본 덱의 정확한 구성·리더·체험전 상대·교체 기록·기술 기록·슬롯·자원·현재 공격 대상을 검증한다.
- 콘텐츠 값을 변경할 때는 `CardCatalog.Version`을 올려 이전 저장을 실수로 다른 규칙에 불러오지 않게 한다. 마이그레이션은 별도 후속 작업이다.

## 검증

확장 코어는 4개 기본 덱 × 상대 3종 × seed 3개, 총 36개의 자동 대전을 실제 종료까지 실행한다. 모든 행동에서 상태 JSON 복원본과 원본의 필드·RNG·사건 순서가 일치하고 카드 수가 보존되는지 검사한다. 별도로 16개 리더/덱 조합, 4종 기술의 실제 효과·비용·턴 제한, 손패 교체의 재등장 방지·단 1회·잘못된 입력 무변경, 3종 새 마법/기본 유닛 능력, 손상 저장 거부를 검사한다. Unity 전용 4종 JsonUtility 테스트는 실제 에디터에서 별도로 실행해야 한다. 실제 실행 여부와 결과는 `Docs/Validation.md`가 기준이다.
