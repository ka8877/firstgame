# 수집과 보상, 자유롭게 걷는 말씀의 여정

`fm-quest-2026-10-30` / `gospel-journey-2026-10-30`은 두 독립 Unity 프로젝트의 새 소스 개정이다. 실제 배포 여부와 새 실행 근거는 [검증 기록](QuestValidation.md)을 따른다.

카드는 원작의 SP 게임머니·GP 게임캐시·무료 부스터·6장 셔플 자료를 확인하고 첫 기본 덱 선택→수집전→보상→상점→보유 덱으로 이어지는 싱글 진행을 구현한다. 7개 단일 속성 중 한 덱50장과600SP를 받는다. 실제 수집전/시나리오 결과와 완료 과제로 SP를 얻고,19개 상품에서 팩·다른 기본 덱을 구한다. 구매 결과는 독립 RNG로 봉인해 저장하고, 개봉과 보상은 중복 지급하지 않는다. 레어 이상/스페셜 이상 보장과 상품별 실제 확률을 상점에서 확인한다. 원작 서버의 전체 가격·추첨표를 복구한 것은 아니며 현재 수치는 싱글판 재구성이다.

GP는0이며 결제는 구현하지 않는다. 멀티는 후속 제공 알림뿐이다. 기존27개 덱과 저장은 자유 연습에 보존하고, 자유 연습의 결과로 SP를 지급하지 않는다. 소유 덱은 실제 카드 수량과50장 규칙을 검사한다. 원본 그림·카드 비율·변동 수치·양측 코인 창과 지형은 유지하고, 셔플 연출은 실제6장이 덱으로 돌아가 다시 배분되는 방식으로 바꾼다. [경제 계약](FmQuestEconomy.md)·[화면 계약](FmQuestUI.md)에 세부 범위가 있다.

예수님의 길은 공식 FINAL FANTASY RESONANCE의 픽셀 인물/입체 필드와 메뉴 구성을 참고한다. 새로운 소년·성인12프레임과 네 NPC, 큰 메뉴 원화는 오리지널 제작물이다. 원본 PNG는 수정하지 않고 측정한 UV·몸 중심·발 기준으로 사용한다. 실제3D 지형과 충돌 안에서 WASD/터치로 앞뒤·좌우·대각선 이동하며, 두 축 모두 NPC 가까이에 도착해야 대화가 열린다. 새 상태창은 실제 나이·말씀·여정·장비를 표시하며 미구현 전투 능력치를 실제인 것처럼 채우지 않는다.

기존 탄생→열두 살 성전→성인 요단강23개 목표·19개 본문과 숨겨진 성경책은 유지한다. `GospelPilgrimageSave.Prepare`는 이전 저장을 복사하고 실제로 발견한 말씀만 계승한다. 옆보기 좌표를 새 필드로 재사용하지 않으며 원래 슬롯을 보존한 새 슬롯에 진행한다. 현재 공간의 저장만 X/Y/Z·방향을 그대로 복원한다. 전 생애·전투가 완성된 것으로 소개하지 않는다.

참고 작품의 확인은 [공식 자료 조사](Research/QuestReferences.md), 인물은 [원화·프레임](GospelPilgrimageCharacter.md), 공간·이동은 [월드 계약](GospelPilgrimageWorld.md)에 기록한다. 실제 Windows/물리 휴대폰/사람의 청취·미적 승인은 해당 근거가 없다면 주장하지 않는다.
