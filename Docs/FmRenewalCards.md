# 판마 원본 전체 목록과 출전 카드 확장

이번 소스 개정은 `fm-renewal-2026-10-29`다. 공개 FM Lunatic DB를 문서 이름 순서와 커서로 끝까지 조회했다. 500개씩 31페이지와 빈 마지막 페이지를 통해 **15,350개 원본 문서·고유 ID**를 확보했다. 제한 1,000개의 일부 등급 조회를 전체 목록으로 취급하지 않는다. 전체 필드·조회 조건·응답 SHA256·조회 시각은 `Tools/Data/Renewal/complete-observations.json`에 남긴다.

이 수는 현재 공개 커뮤니티 DB의 전체 조회 결과다. 원작의 종료 직전 클라이언트 전체나 상용 개발 소스 복구를 뜻하지 않는다. 원본 레코드의 가장 늦은 `ReleaseDate`는 2016-12-15이며, 같은 날의 카드에도 이후 수정 공지가 적혀 있다. 발매일과 최종 밸런스 수정일은 다르다. 2017년 공식 사이트에서 연결한 2016년 공식 매뉴얼을 함께 검토했고, 두 자료가 충돌하는 기술은 출처와 구현 범위를 별도로 남겼다.

## 전투에 실제 사용하는 카드

기존 **605종의 전체 필드·ID·그림·메타데이터를 보존**하고, 지원하는 원문 기술이 모두 갖춰진 **1,966종을 추가해 2,571종**으로 확장했다. 같은 이름의 재판·랭크는 원래 이름을 바꾸지 않고 각기 다른 원본 ID로 구분한다. 아직 구현하지 않은 상태·오라·특수 소울을 설명에서 제거한 뒤 일반 유닛으로 넣지 않는다.

| 종류 | 출전 수 |
|---|---:|
| 지형 | 29 |
| 유닛 | 2,232 |
| 마법 | 26 |
| 아이템 | 284 |

출전 등급은 프리393·커먼1,339·언커먼585·레어21·스페셜27·업그레이드5·유니크23·이벤트159·레전드4·시크릿15종이다. 이카젠·에픽의 복잡한 고유 기능은 아직 출전 지원 목록에 포함되지 않는다.

전체 원본 도감은 **15,350종을 함께 검색**한다. 출전 지원 여부를 실제 `CardCatalog`와 연결하고, 미지원12,779종은 원문과 확보된 인쇄 그림을 보여주되 덱에 추가하지 않는다. 이미지가 확보되지 않은 항목까지 원본 그림을 복구했다고 표시하지 않는다. DB에 등급 코드6666으로 들어 있는23종은 ‘미분류’로 표시한다. 이를 에픽이나 일반 카드로 바꾸지 않는다. 원본 전체에는 인첸트823종도 포함되며, 현재 전투 엔진은 인첸트 발동 단계 전체를 구현한 상태가 아니다.

전체 원본의 스페셜905·유니크207·레전드68·시크릿582·에픽115·이카젠24종과 실제 출전 수는 서로 다르다. 이 차이를 도감·설명·검증에서 숨기지 않는다.

## 전투 규칙과 코인 표시

27개 일반 공격 기술군과16개 추가 유니크의 원문 효과를 구현했다. 방어무시·약화·석화·돌진·공포·재생·장거리·연속·흡혈·혼란 등은 공격하는 순간의 실제 상태를 사용한다. 살아남은 방어 유닛이 반격할 때도 그 유닛의 공격 기술이 발동한다. 추가 공격 피해는 AP 수치와 별도다. 예를 들어 AP3·DP2인 돌진 공격은 AP를5로 바꾸는 것이 아니라 AP3에 추가 피해2를 더한다.

매번 동전이 공개될 때 `BattleEvent`에 실제 이전/이후 AP·DP·남은HP와 같은 시점의 전열 스냅샷을 기록한다. 화면은 이 값을 카드 위에 표시하며 동전을 다시 굴리지 않는다. 50% 기본 확률·최대5개 코인은 후기 공식 전투 설명에서 확인했다. 서로 다른 능력치의 식에 동일 코인열의 앞 n개를 적용하는 기존 선택은 별도 독립 난수라는 근거 없이 임의로 변경하지 않았다.

유니크 추가 구현에는 아이스브레스, 모랄라이징, 이블피어싱, 관통무시, 쉐이킹, 주문제압, 대지의왕, 행운훔치기, 영광의기사, 코인플레임, 에코카피, 워킹우드, 실드오오라, 크로스카운트, 포효공격, 스톤드로잉이 있다. 개별 원본 ID·직접 인용·검증 기준은 `premium-admissions.json`에 기록한다. 공식 매뉴얼과 DB가 서로 다른 그린그로우·블러드퓨리 등은 신규 지원에서 제외했으며, 기존 랜드루인 동작은 이전 저장과 소스 계약을 보존하면서 불일치를 문서화했다.

신규 시크릿 아이템은 속성별 더블체인7종과 이드카피7종이다. 더블체인은 실제 장착 후 미장착 아군에게 동일 아이템을 한 번 생성한다. 이드카피는2레벨 이하 장착 유닛을 장비 없이 실제 빈 전열에 복사한다. 공간이 없거나 조건이 맞지 않으면 생성하지 않는다. 이를 일반 스탯 아이템으로 축약하지 않는다.

생성 카드는 원본50장 규칙을 해제하는 방식으로 저장하지 않는다. 기존 양측 원본100개의 ID·덱 구성·동일 카드 한도는 계속 검증하고, 추가 인스턴스는 원본 기술/아이템·생성 사유·소유자·안정 ID를 기록해 일대일 대조한다. 출처가 빠지거나 지원하지 않는 기술로 생성된 저장은 거부한다. schema3의 선택 필드이므로 이전 저장에는 빈 목록과0이 적용된다. 모랄라이징의 영구 AP는 저장하며 턴 종료 시 임시 능력치와 함께 지워지지 않는다.

기존20개 덱은 유지하고, 속성마다 신규 기술 유닛과 두 종류의 시크릿 장비를 쓰는7개의50장 프리셋을 추가했다. 총27개다. 이는 이 프로젝트에서 구성한 연습 덱이며 당시 판매 상품의 덱 구성을 회수한 것으로 표시하지 않는다.

## 원본 그림과 실행 검증

기존605종의 원본 PNG/WebP·원래 종횡비·GUID를 유지한다. 신규 대량 카드 이미지는 시작 로딩에 전부 넣지 않고 `StreamingAssets/Cards/fm_ID.jpg`에서 화면에 표시할 때 읽는다. 원본 WebP는 내려받은 그대로 작업 참고 보관소에 보존하고, 원본 바이트·디코딩 RGBA·크기·전체 프레임·JPEG 전달본 해시를 기록한다. 전달본은 원본 크기의 JPEG88이며 손실 압축임을 명시한다. 가짜 고해상도 복원이나 새 원화로 소개하지 않는다. 웹의 단일100MB 파일 제한과 공개 사이트 크기 제한을 함께 확인한다.

**2026-10-29 04:08 UTC 최종 그림 검증은15,350/15,350장, 누락0장으로 통과했다.** 설치된 JPEG 전달본은749,704,026바이트이며 가장 큰 파일은69,968바이트다. 출전2,571종의 그림도 모두 준비되었다. 기존605종의 PNG/WebP·GUID와 전체 카드 정의를 보존했고 신규 출전1,966종은 스트리밍 그림을 사용한다. `media-manifest.json`의 `completeTraversal`은true이며, `missing-media.json`의 두 누락 목록은 모두 비어 있다.

`python Tools/Data/Renewal/verify-media.py`는 전체 원본15,350개의 파일·크기·SHA256·종횡비·GUID와 실제 JPEG88 양자화/4:2:0 샘플링을 검사했다. 결과는 `Tools/Data/Renewal/media-verification.json`에 있고, 현재 `media-inventory-verification.json`도 이 실제 엄격 검증 결과를 가리킨다. 원본605종 보존·신규 정의의 원문 필드·생성 코드 재현 검사는 `Tools/Data/ClassicCards/remaster-verification.json`에서 별도로 통과했다. 그림 확보와 실제 Unity·Web 입력·오디오 검증·공개 배포는 별개 단계다.

내려받은 정확한 WebP15,350장과 URL·해시 목록은 별도 원본 참고 ZIP에 보존했고 ZIP 내부 모든 파일을 다시 읽어 바이트 해시를 검증했다. 경로·크기·SHA256은 `original-full-reference-artifact.json`에 기록한다. 이전3,510장 원본 ZIP도 보존했다. 초기 HTTP503과 부분 확보 기록은 삭제하지 않았으며, 당시 부분 검증 보고서의 원본 바이트는 `History/media-inventory-3510-before-recovery.json`, 이력과 해시는 `media-report-history.json`에 남겼다. 이 초기 실패를 현재 누락으로 표시하지 않는다.

재개 가능한 `fetch-media.py`는 최신 첫 화면과 출전 상위 등급을 먼저 요청한다. 기본 TLS 검증·기존 프록시/CA를 유지하며, `requests`가 있으면 작업자별 연결 풀을 쓰고 없으면 표준 라이브러리로 동작한다. 이번 완료 실행은6개 작업자·요청 간0.25초·20개 단위 체크포인트·503/429 재시도와 차단기를 사용했다. `materialize-cached-media.py`는 성공 캐시만 일반 파일과 안정 GUID로 설치한다. 최종 검증 명령은 도감 전용 카드를 포함해 하나라도 이미지가 없으면 실패하며, `--inventory`는 진행 확인용으로만 사용한다.

새 규칙 검증은 `RenewalCardsTests`와 `RenewalPremiumTests`, 원본 보존·전체 필드·저장·기존 프리셋 검사는 기존 테스트를 유지한 확장으로 수행한다. 최종 실행·공개 URL 상태는 `Docs/RenewalValidation.md` 및 `Artifacts/Validation/Renewal`의 실제 결과를 따른다.
