# 타이틀·지형·인물 디테일 개정

개정은 `fm-detail-2026-10-27`과 `gospel-natural-2026-10-27`이다. 이번 요청은 두 게임을 모두 개선한다. 이전 판마 fidelity 작업의 예수님 게임 보존 규칙은 이번 변경에 적용하지 않는다. 실제 새 빌드·공개 상태와 검증 범위는 [DetailValidation](DetailValidation.md)에 별도로 기록한다.

## 판타지마스터즈

2005년 공식 안내의 backfield 항목과 2017년 실제 플레이 영상은 전열과 손패 사이에 지형 카드 그림을 놓는 별도 영역을 보여준다. 색 점이나 소울 숫자만 보여주던 화면을 실제 양측 지형 카드·자원 상태를 읽는 후열 표시로 개선한다. 지형의 사용 판정, 카드 보존, 준비 완료와 공방 재생은 기존 Core가 소유한다.

새 타이틀 배경은 이번 리마스터용으로 제작한 판타지 풍경이다. 원작 그림의 고해상도 복구로 소개하지 않는다. 원작 카드 그림·이름·수치·등급·랭크는 보존하며, 추가 카드는 전체 원본 데이터·인쇄 원화·능력 지원 여부까지 대조한다. 새 그림의 출처는 `Tools/Art/FmDetail`, 추가 카드의 출처는 `Tools/Data/Detail`과 `Tools/Research/FmDetail`에서 확인한다.

로비의 프로필은 현재 기기에 저장한 이름·아바타와 실제 기록한 연습전 결과를 보여준다. 서버 계정, 가상의 접속자, 원작 온라인 통화·랭킹을 생성하지 않는다. 기존 전투·덱의 schema와 저장 슬롯은 유지한다. 새 로컬 통계는 기록을 시작한 뒤의 완료 결과이며 과거의 미기록 전적을 추정하지 않는다.

## 예수님의 길

이번 캐릭터 개선의 기준은 외모의 미화보다 사람다운 해부 구조다. 과장된 입·턱, 두상과 몸의 비율, 지나치게 굵은 머리 조각을 다시 검토하고 실제 눈꺼풀·코·입술·귓바퀴를 가진 자연스러운 얼굴로 제작한다. 현재 누가복음2장의 열두 살 예수님과 별도의 성인·마리아 모델을 구분한다. 모델은 역사적 얼굴을 복원한 결과가 아닌 예술적 해석이다.

기존65개 뼈와 Idle/Walk/Run/JumpStart/JumpAir/JumpLand/Practice 동작, 물리 이동·충돌·줌·성경 대화·저장을 유지한다. 실제 내보낸 FBX의 얼굴·후두부·의상과 걷기·달리기 자세를 검토하고 Unity에서 재질·스키닝·발 접지·카메라를 확인한다. Blender 검토 렌더와 인게임 원본 화면을 구분한다.

성전은 기존 이동·대화 장소를 유지하면서 기둥·아치·석재 경계와 수목·빛·표면의 반복을 정돈한다. 실제3D 모델과 공간을 사용하며 그림 배경이나 단순 도형 인물로 대체하지 않는다. 성경 본문·사건과 배경 미술의 해석을 구분한다. 자연스러움과 미적 만족도, 실물 기기 성능은 검사 개수만으로 보장하지 않는다.

## 검증과 보존

이전 원본·GUID·편집 자료·배포 산출물은 보존한다. 새 실행 자료는 `Artifacts/Validation/Detail`에 쌓고 이전 통과를 새 외형과 UI의 결과로 재사용하지 않는다. Unity·브라우저는 단일 실행 소유자가 순서대로 실행한다. 원작 음악의 공개 출처와 안내 음성을 제외한 발췌·전투곡 녹음의 구분도 유지한다.
