# 원작 전장과 성경 이야기 개정

현재 개정은 `fm-chronicle-2026-10-29` / `gospel-chronicle-2026-10-29`다. 실제 실행·공개 URL 반영 여부는 [이번 검증](ChronicleValidation.md)을 따른다. 이전 Polish의 실행 결과와 ZIP은 제작 이력으로 보존한다.

판마는 새 카드 수를 늘리는 대신 실제 후기 전투 화면을 기준으로 배치와 조작을 바로잡는다. 위·아래 전열, 원본 인쇄 카드 자체의 숫자 위치, 다섯 슬롯의 사각형 코인 판정창과 실제 확률·앞뒷면·공방체 변화를 연결한다. 자료의 게시 날짜와 실제 촬영 날짜를 구분하며, 첨부 화면이 종료 직전 마지막 판이라고 단정하지 않는다. 카드2,646종·기본덱27개·원본도감15,350개와 기존 저장·실제 Core 판정은 유지한다. 화면 변경의 상세는 [전장 구현](FmChronicleUI.md)을 따른다.

예수님의 길은 탄생의 그림 서막, 열두 살의 유월절·성전 방문, 성인이 되어 요단강에서 세례를 받으시는 기록을 하나의 순서 있는 RPG 첫 구간으로 잇는다. 실제로 걸어서 목적지에 도착하고 NPC를 만나 대화를 마쳐야 다음 목표가 열린다. 성경책은 목록 대신 펼친 책의 두 면으로 나타나며, 발견하지 않은 말씀의 제목·출처·본문·그림은 표시하지 않는다. 현재 이야기는23개 목표와19개 말씀 묶음이며 예수님의 전 생애가 구현된 것은 아니다.

성인 예수님의 새 전신 원화와 연속된 팔·다리 메시, 소년의 기존 원화를 이용한 관절 수정을 적용한다. 소년의 그림을 새로 생성한 것으로 소개하지 않는다. 성인기에는 새 요단강 풍경과 세례 요한이 등장한다. 원본 PNG·알파는 편집하지 않고 측정한 UV와 메시로 사용한다. 자세한 이야기는 [성경 RPG](GospelChronicle.md), 인물은 [관절 제작](GospelChronicleCharacter.md), 본문은 [공식 출처](GospelChronicleSources.md)를 따른다.

이번 클라우드 배포 대상은 **Web**이다. 원본과 이전 ZIP을 모두 보존하는 저장 공간 안에서 새 웹 플레이어 두 개와 전체 Unity 소스·검증 자료를 보관한다. 이전 Polish Windows ZIP을 이번 개정의 실행본으로 표시하지 않는다. 일반 개발 PC에서는 같은 Unity 소스에서 Windows 빌드도 만들 수 있다.
