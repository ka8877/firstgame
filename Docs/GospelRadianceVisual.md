# 예수님의 길 · 빛의 숲 시각 개편

현재 개정은 `gospel-radiance-2026-10-29`다. Ori and the Will of the Wisps의 다층 실루엣, 차가운 안개와 따뜻한 중심광, 작은 발광 요소, 독립된 전경·중경·원경을 표현 방향으로 참고한다. 상용 게임의 코드나 자산을 복구한 결과 또는 같은 완성도라는 뜻은 아니다.

새 원경과 소년 아틀라스는 `Art/GospelRadiance`의 새 원화다. 생성 원본, 최종 무수정 이미지, 메타데이터와 해시는 `Tools/Art/GospelRadiance/manifest.json`을 따른다. 이전 Luminous 원본과 GUID는 보존한다. 풍경은 성경 공부를 위한 상징적 미술 공간이며 실제 성지의 측량 복원으로 소개하지 않는다.

## 실제 월드 구성

- 새 원경 그림은 실제 원경 계수0.91의 별도 층이다. 걷는 바닥·충돌·나무·수관·바위·풀·전경·인물은 독립 오브젝트다.
- 먼 안개0.77, 낮은 안개0.20, 수관 빛줄기0.28의 별도 층에 서로 다른 저속 이동을 적용한다. 원경 그림을 카메라 앞에 고정하여 전체 월드를 대신하지 않는다.
- 원래 Lost Crypt의 실제 노멀맵, Accurate Sprite Light2D, 물리 바닥과 전경 투명화는 유지한다. 팔레트는 인디고·청록·청색 원경과 밝은 걷기 경계, 성전의 금색 중심광으로 통일한다.
- 실제 첫 렌더에서 확인한 단색 검은 토양은 네 줄의 색을 읽는 별도60행 Ground2D 패스로 바꾼다. 기존 Mesh2D-Unlit-Default가 무시하던 정점 색을 실제로 렌더하며, 새 원본 earth-bank의 토양·매립 뿌리·석재 색을 직접 샘플링하며 2.8유닛 깊이·7.2유닛 가로 반복 UV와 부분 매립 바위를 조합한다. 별도의 줄기 잘라낸 장식은 제거하여 떠 있는 그루터기를 만들지 않는다. 공유 원본 텍스처나 물리 표면은 변경하지 않는다. 아래쪽은 어두운 남색으로 유지한다.
- Bloom은 임계0.94, 강도0.46, 산란0.68이다. 실제 HDR 색을 가진 작은 청록/금색 입자가 발광한다. 포스트프로세싱은 실제 URP 카메라에서 실행되어야 하며, 소스 값만으로 렌더 통과를 주장하지 않는다.

## 인물

`UsesRadiancePainting`은 새1254×1254 RGBA 아틀라스를 읽었는지, `UsesRadianceVista`는 새 원경이 실제 로드되었는지를 나타낸다. 아틀라스는 원본 픽셀을 편집하지 않고 읽기 전용으로 측정한16개 주요 창과 네 개의 겹치는 정강이·샌들 창으로 구성한다. 각20개 창이 원본 범위 안에 있는지 검사했다.

소년의 얼굴·몸통·무릎·발목은 실제 구분된 관절이며 측정 이동 속도와 땅의 기울기를 따른다. 발 접촉과 스윙을 기준으로 걷고, 머리와 발의 폭·옷자락을 조정한다. 새 뒷머리 원화는 얇은 꼬리로 늘리지 않고 얼굴 뒤의 온전한 실루엣으로 쓴다. 가방과 등잔, 천의 변형은 기존 실제 장착/진행을 따른다.

Sprite와 deforming MeshRenderer에는 Unity URP17의 실제2D 조명 계약에 약한 방향성 가장자리 색과 회화 중간톤 하한을 더한 새 셰이더를 사용한다. 원래 노멀 패스·Sprite flipping·실제 동적 조명은 보존한다. NPC도 같은 색 처리와 약한 호흡을 사용한다. 발밑의 부드러운 접촉 그림자는 실제 지형 높이에 남고 점프 시 넓어지며 옅어진다.

## 검증 범위

새 네이티브/웹 실행에서 정지, 양방향 걷기·달리기, 점프/착지, 근접 줌과 넓은 줌, 대화/가방/도감, 독립 풍경보기 화면의 실제 원본을 확인한다. 기존15개 말씀·그림 오프닝·저장 호환은 시각 개편 때문에 바꾸지 않는다. 그림 생성/읽기 전용 창 범위 검사와 실제 Unity/Web 렌더 결과, 사람의 미적 평가는 서로 구분한다.
