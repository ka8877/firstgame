# 판타지마스터즈 전투 화면·조작 보강

개정 `fm-polish-2026-10-29`. 기존 원본 카드 전체 인쇄·종횡비·카드 안 AP/DP/HP·실제 코인 증감은 유지하며, 상대 정보와 전투 기록을 묶고 카드 조작과 실제 사건의 움직임을 다듬는다. 원본 카드 이미지나 Core의 판정·난수를 변경하지 않는다.

## 상대 정보와 연습 메모

전투 오른쪽 **상대 정보**를 누르면 **대전 데스크**가 열린다.

- **상대 정보:** 현재 AI 연습 상대, 실제 덱 이름, 난도, 공개된 덱·손패·소각장·전열·지형 개수를 표시한다. 상대의 손패 내용이나 뽑기 순서를 공개하지 않는다. 원작 카드 한 장은 덱의 대표 카드이며 실제 온라인 플레이어의 아바타가 아니다.
- **전투 기록:** 현재 결투의 실제 사건 중 최근 80개를 턴·행동 주체와 함께 대화형 기록으로 보여준다. 코인 사건에는 실제 이전/이후 AP·DP·HP와 변화량이 포함된다. 스크롤로 이전 기록을 읽는다.
- **연습 메모:** 자신에게 남기는 최대 120자 메모다. 다른 사람에게 전송되거나 가상의 AI 채팅 답변을 생성하지 않는다. 최근 24개를 현재 앱 세션에서 보관하며 새 결투·새로고침 시 비워진다. 입력 뒤 **기록** 또는 Enter를 누른다.

**전장으로** 또는 Esc로 돌아간다. 판정 재생 중에는 상태 변경과 이 화면의 진입을 잠근다.

## 카드 조작

| 입력 | 전투에서의 동작 |
|---|---|
| 손패 한 번 누르기 | 카드를 선택하고 실제 사용 가능한 대상·비용 안내 표시 |
| 공개 전열·지형 한 번 누르기 | 그 카드를 선택하고 테두리·원본 상세 안내 표시 |
| 같은 카드 두 번 빠르게 누르기 | 원본 인쇄와 능력 설명을 가진 상세 화면 |
| 모바일에서 0.48초 길게 누르기 | 같은 상세 화면, 움직임이 12px를 넘으면 누르기 취소 |
| 선택한 손패의 합법 대상 누르기 | 기존대로 즉시 카드 사용. 선택 또는 상세 동작으로 가로채지 않음 |
| 손패 위로 끌기 | 실제 합법 전열·지형·소각장에 놓기. 모바일 가로 밀기는 손패 스크롤 |
| 상세의 크게 보기 | 동적 수치가 없는 전체 원본 확대 |
| Esc | 입력창 편집 종료 → 상세/대전 데스크에서 복귀, 전장에서는 선택 해제 → 메뉴 |

두 번 누르기는 화면 재생성에 영향받지 않게 앱이 카드 인스턴스와 0.38초 간격을 추적한다. 드래그·실제 행동·상세 진입 때 추적을 초기화한다. **원작의 모든 더블클릭 조작을 복원한 것이 아니다.** 확보한 공식 FAQ737에는 섀도우 발동을 더블클릭/Ctrl+클릭으로 설명한다. 이번 상세 조작은 리마스터 편의 기능이며 미지원 섀도우 기술을 발동하는 버튼을 꾸미지 않는다.

## 실제 전투 사건의 움직임

2017년 플레이 원본에서 확인한 중앙 대결·상단 코인 판정·카드 위 피해 표시를 유지한다. 각 대결 쌍은 처음 등장할 때 실제 전열에서 중앙으로 이동한다. 다음 코인마다 입장을 반복하지 않는다. 코인은 회전 후 확정된 면을 잠시 유지하며 카드 안 증감과 상단 전투 안내를 함께 읽을 수 있다.

공격·반격은 뒤로 당김, 돌진, 명중 순간 정지, 복귀로 나뉜다. 곡선과 대상 원은 실제 사건의 출발·도착 카드를 연결하고, 명중 시점에 피해 숫자와 해당 위치의 효과음이 나온다. 방어 결과는 방패 효과를 사용한다. 파괴된 카드는 실제 소각장 위치로 기울어 이동하며 사라진다. 덱/소각장 좌표는 모바일의 실제 캔버스 높이에 맞춘다. 배속·끝까지는 연출 시간만 바꾼다.

## 원작 근거와 실행 확인

후기 화면 근거는 [Renewal 조사](Research/FmRenewalSources.md)의 2017 플레이 영상과 공식 홈페이지 자료다. 구형 `tutorial2_1.html`의 채팅·상세 정보 안내는 기능 배치 참고이며 후기 최종 화면 증거로 섞지 않는다. 공개 채팅의 외형을 개인 연습 기록으로 바꾼 것은 현재 싱글플레이 범위에 맞춘 신규 UI다.

소스 검토와 공백 검사를 진행했으며, 실제 새 Unity·PC/모바일 브라우저 화면·공개 배포 결과는 릴리스 담당의 `Polish` 실행 기록을 따른다. 앞선 Renewal 통과나 그 스크린샷을 이번 변경의 통과로 대신하지 않는다.

### 실행 담당용 안정된 진입점

- 공개 관찰값: `IsBattleDeskOpen`, `BattleDeskTab`(0 상대 / 1 기록 / 2 메모).
- 전장 상대 정보의 정규화 좌표(좌상단 기준): 데스크톱 `(0.898, 0.52546)`, 작은 화면 `(0.898, 0.023 + 176 / 실제 캔버스 높이)`.
- 데스크 탭: `(0.192, 0.235)`, `(0.500, 0.235)`, `(0.808, 0.235)`. 메모 입력 `(0.415, 0.75)`, 기록 `(0.8675, 0.75)`, 전장으로 `(0.845, 0.945)`.
- 기존 손패·전열·Ready 위치를 유지한다. 단, 전장 지형 상세는 한 번 클릭 대신 두 번 누르기/길게 누르기로 검증한다. 클릭 간 실제 렌더 프레임을 주고 두 번째 누르기는 0.38초 안에 보낸다.
- 실제 입력 확인: 손패 선택→상세→Esc 복귀→Esc 선택 해제, 전열/지형 상세, 합법 드래그, 상대 정보·스크롤 기록·개인 메모, 코인 실제 변화량·명중·소각장 이동, 저장과 복귀. PC와 실제 작은 캔버스 원본에서 각각 확인한다.
