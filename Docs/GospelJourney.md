# 말씀을 따라 예수님의 길

2026-10-26 사용자가 개발 방향을 바꾸어 요청한 복음서 학습 어드벤처의 첫 구현이다. 예수님이 주인공이며 탄생에서 부활·승천까지의 기록을 순서대로 살펴보는 구조를 만든다. 이전 시간 여행자·갈릴리의 가상 선택·회귀 서사는 현재 실행 경로에서 분리한다.

## 이번 첫 구간

- 베들레헴 탄생: 누가복음 2:6–7, 10–11, 19–20을 세 번의 말씀 읽기로 시작한다. 아기 예수님을 걷게 하지 않고 구유를 바라보는 도입 장면으로 표현한다.
- 성전의 소년: 열두 살 예수님으로 실제 3D 성전 뜰을 걷는다. 성전 문 → 선생들 → 부모 → 나사렛으로 돌아가는 문을 따라 누가복음 2:41–43, 46–47, 48–50, 51–52를 읽는다.
- 읽은 구절을 기록에서 다시 열고, 위치·현재 말씀·진행을 저장한 뒤 이어갈 수 있다.
- 장 목록은 전체 일생의 26개 구간을 보여 주며, 아직 구현하지 않은 구간은 `준비 중`으로 표시한다. 현재 플레이 가능한 것은 탄생과 성전 방문이다.

성경 본문과 장면을 연결하는 요약은 별도 필드로 다룬다. 원문의 대사를 새로 만들어 성경 인용처럼 보여주지 않는다. 정확한 인용·출처·연대 배열의 한계는 [GospelChronology.md](GospelChronology.md)에 기록한다. 본문 표기는 `성경전서 개역한글판 · 대한성서공회`다.

## 인물과 공간

`GospelTempleWorld`는 성전 뜰·기둥 회랑·계단·분수·올리브 정원·도시 원경을 실제 메시와 충돌체로 만든다. 공간은 학습을 위한 재현이며 헤롯 성전의 고고학적 실측 복원으로 소개하지 않는다. 이동하는 2D 회화 배경은 사용하지 않는다.

주인공은 `Art/Gospel3D/YoungJesus.fbx`의 관절과 스키닝을 가진 3D 인물이다. 원본과 제작·라이선스 기록은 [Gospel3DArt.md](Gospel3DArt.md)를 따른다. 에셋이나 애니메이션이 빠지면 명시적 오류를 내며 기본 도형 인물로 바꾸지 않는다. `YouthLocomotion.controller`의 `Speed` 블렌드가 Idle/Walk/Run을 연결한다. 실제 이동은 CharacterController가 소유하고 측정한 이동 속도를 애니메이션에 전달한다.

빛·높이·그림자·카메라 투영은 실제 3D 장면이다. 성전의 광물성 표면과 포장에는 ambientCG의 CC0 `Plaster001`/`Tiles143` 알베도·노멀 맵을 사용한다. 공식 API가 공개한 2048픽셀 표면 미리보기 원본을 보존하고 Unity에서는 최대1024·mipmap·DirectX 노멀의 녹색 채널 변환을 적용한다. 원래 ZIP 다운로드 CDN은403이므로 이를 원본 전체 PBR 패키지 복구로 표현하지 않는다. 출처·바이트 해시는 `Tools/Art/GospelTemple/manifest.json`에 있다. 월드 투영 UV로 큰 벽이나 기둥에서 무늬가 늘어나지 않게 하고, 거친 낮은 광택의 재질과 작은 요철·포장 줄눈·풍화를 표현한다. 기둥·석재·단지 등 같은 재질의 정적 메시를 합쳐 불필요한 렌더 호출을 줄이고, 올리브 잎과 표식의 작은 움직임만 독립적으로 갱신한다. NPC는 현재 같은 기본 인물 자산을 바탕으로 크기·의상색을 구분하는 첫 모델이며, 인물별 고유 얼굴·연기 완성을 뜻하지 않는다.

## 조작

WASD/방향키로 카메라 기준 이동, Shift로 달리기, 우클릭 드래그로 카메라 회전, 마우스 휠로 거리 조절, E로 가까운 표식의 말씀을 읽는다. 이동은 가속·감속·부드러운 방향 전환과 중력·충돌을 적용한다. 카메라는 벽을 관통하지 않도록 구체 충돌 검사와 따라가기 완충을 사용한다. 모바일은 왼쪽 이동 패드와 오른쪽 시점 드래그·읽기 버튼을 사용한다.

본문은 긴 문장이 잘리지 않도록 세로로 스크롤할 수 있다. 탐색 중에도 현재 읽는 성경 위치와 첫 구절을 고정 표시한다. `성경 기록`에서 읽은 본문 전체를 다시 볼 수 있다. 배경 음악은 첫 입력 뒤 시작하며 설정에서 켜기·끄기·음량을 바꾼다. 이전 가상 서사의 합성 음성은 새 성경 본문에 자동 재사용하지 않는다.

## 저장과 확장

`GospelJourney`는 Unity와 분리된 진행 상태이고 내부 저장은 schema1 / `gospel-0.1.0`, 게임 ID는 `gospel-journey`다. 기본 슬롯은 `gospel-journey-v1`, 새 여정은 기존 슬롯이 있으면 별도 슬롯을 사용한다. `GOSPEL.activeSlot`이 현재 이어하기 슬롯을 고른다. 이전 관찰자 서사의 슬롯과 `POD.activeSlot`은 수정하지 않는다. 공통 `PersistentSaves`가 버전·무결성·원본 보존을 처리한다.

향후 전투에 대비해 인물 이동 상태와 상호작용 소켓을 분리했지만, 이번 구간에 가상 전투나 성경과 다른 결말을 넣지는 않는다. 다음은 세례·광야·공생애 첫 장면을 추가하고 성인 인물·환경을 확장하는 단계다. 네이티브·웹 실행, 사람의 미적 평가, 실제 모바일 성능 검증은 서로 다른 범위로 기록한다.
