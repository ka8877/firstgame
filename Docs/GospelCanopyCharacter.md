# Canopy 인물과 보행

이번 인물은 한 장의 완전한 몸 그림을 방향과 실제 이동 거리에 맞춰 재생한다. 소년1.64m·성인1.94m, XZ 자유 이동, 실제 충돌과 중력, 장착된 등잔의 가장 긴 축0.22m는 유지한다. 몸·팔·다리를 분리한 종이 관절로 바꾸지 않는다. Ori 참고 화면은 환경의 빛·색·깊이를 검토한 이미지이며, 그 정지 화면에서 보행 애니메이션의 구현을 확인했다고 주장하지 않는다.

기존 원본 `Art/GospelPilgrimage/Actors/jesus-child`, `jesus-adult`, `npcs`와 PNG·알파·GUID·레이아웃은 보존한다. 이전 소년 옆모습의 두 보행 그림은 선행 팔과 다리의 실루엣이 매우 비슷하다. 같은 그림을 더 빨리 재생하거나 별도 관절을 흔들어도 반대쪽 발을 디디는 원화가 생기지는 않는다. 기존 세 셀을 사용하는 경우 접촉 자세의 유지 시간을 늘리고 중립 자세를 짧은 통과 단계로 쓴다. 새 원화가 없는 상황에서 정교한 여섯 동작 보행으로 표시하지 않는다.

새 원본은 `Art/GospelCanopy/Actors/jesus-child`와 `jesus-adult`다. 각 시트는 정면·뒷면·왼쪽·오른쪽 순서의 네 줄, 줄마다 여덟 개의 전신 그림이다. 순서는 대기, 왼발 접촉, 왼발 하강, 왼발 통과, 오른발 접촉, 오른발 하강, 오른발 통과, 공중이다. 두 접촉 자세에서는 선행 발과 반대편 팔이 실제로 바뀌어야 한다. 여섯 보행 그림은 `1,2,3,4,5,6`으로 재생하고 대기 그림을 보행 중간에 반복 삽입하지 않는다. 달리기는 같은 보행 원화를 더 긴 보폭으로 사용하며 별도 달리기 원화가 있다고 소개하지 않는다.

`*-layout.json`은 원본 전체 픽셀 크기와 `referenceHeight`, 각 프레임의 bottom-left 픽셀 사각형·발 pivot을 기록한다. 원본 PNG를 다시 인코딩하거나 잘라 저장하지 않고 런타임 UV만 지정한다. 새 필드는 다음과 같다.

```json
{
  "framesPerDirection": 8,
  "idleFrame": 0,
  "airFrame": 7,
  "strideLength": 1.8,
  "walkSequence": [1, 2, 3, 4, 5, 6],
  "smoothFiltering": true
}
```

`walkDurations`는 선택 필드이며 지정할 경우 각 단계의 양수 비율을 담고 합이1이어야 한다. 생략하면 동일한 시간 비율이다. `smoothFiltering`은 새 회화 원화의 bilinear 표시를 허용하며 기존 픽셀 원본은 Point를 유지한다. 프레임의 선택적 `hasLampAnchor`, `lampAnchorX`, `lampAnchorY`는 발 pivot 기준 손 위치를 서 있는 인물 높이의 비율로 기록한다. 등잔 메시·재질·광원은 기존 제작 원본을 계속 사용한다.

채택한 새 원본은 여전히 머리가 큰 스타일화 인물이다. 접촉 프레임의 선행 팔·발이 해부학적으로 완전히 반전한다고 주장하지 않는다. 소년의 하강 자세는 서 있는 자세보다 약9% 낮게 그려져 있으므로 하강은 한 주기의10%, 접촉23%, 통과17%씩 유지한다. 원본을 늘려 몸 높이를 강제로 맞추지 않는다. 새 PNG는 모두1536×1024이며 실제 알파 범위0–254를 보존한다. 소년의 주요 전신 성분32개와 작은 성분2개, 성인의 전신 성분32개를 읽기 전용으로 측정했다. 서 있는 원화 높이 중앙값은 소년235.5px·성인232px이다. 정확한 원본·레이아웃 해시와 측정 기록은 `Tools/Art/GospelCanopy/actors-manifest.json`, 생성 출처와 별도 보존 원본은 `Tools/Art/Restage/manifest.json`에 기록한다.

모터가 소유한 실제 속도·접지·방향을 Actor의 `LateUpdate`에서 읽어 실행 순서에 따른 한 프레임의 반응 지연을 없앤다. 대각선 경계에는 작은 방향 여유를 두며 시작·정지 속도 기준을 다르게 사용해 접지 보정으로 방향이나 보행이 다시 시작되지 않게 한다. 측정 이동 속도가 정지 기준 아래로 내려간 뒤 0.075초의 대기 시간을 두고 다음 프레임에 대기 자세로 정착한다. 점프·낙하·짧은 대시는 전용 공중 그림을 유지하고, 대시 속도로 다리를 과도하게 회전시키지 않는다. 실제 위치와 발 기준은 인물 그림이 변경하지 않는다.

기존 `Build`, `BuildNpc`, `SetMotion`, `SetAdult`, `SetLamp`, `SetGroundSampler` 계약을 보존한다. `FramesPerDirectionCount`, `WalkPoseCount`, `UsesExpandedAnimation`은 현재 사용 중인 원화와 보행 구성을 구분하는 읽기 전용 속성이다. NPC 네 원본은 기존 정적인 만남으로 유지한다. 새 원본과 측정 데이터가 준비되지 않은 나이는 기존 원본을 사용하고, 존재하는 새 원본의 치수·셀·발 pivot·보행 설정이 잘못되면 오류를 보고한다.

이 문서와 소스 검토는 Unity/Web 실행 통과나 사용자 미적 승인이 아니다. 현재 원본의 네 방향, 반대 발 접촉, 느린 이동·걷기·달리기·정지·점프·대시, 소년/성인 전환, 실제 장착·0.22m 등잔과 지면 가림을 새 실행에서 확인해야 한다.
