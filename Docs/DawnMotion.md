# 새벽의 길 움직임과 조작감

개정: `fluid-dawn-2026-10-24`. 기존 일곱 PNG의 원본 바이트, 캐릭터 디자인과 배경은 유지한다. 사용자가 요청한 걷기·정지·방향 전환과 키보드/모바일 조작 반응을 개선한다. 최종 실행 결과는 [Validation.md](Validation.md)를 따른다.

## 이동

`DawnMovement`가 화면 방향 입력을 적분하고 실제 `CharacterController`가 충돌을 해결한다. 3D 모델의 회전 완료를 기다리던 속도 제한을 제거했다. 기준 속도는 2.15, 전후 깊이 보정은 1.65다. 짧은 가속과 빠른 제동, 반대 입력에 대한 즉각적인 재가속을 사용한다. 입력의 대각선 크기는 1로 제한하며 작은 패드 입력은 그에 비례한 느린 걷기를 제공한다. 회전은 표현이며 이동을 차단하지 않는다. 배경의 실제 바닥과 맞도록 뒤쪽 이동 한계를 좁혀 벽·화분 위로 떠 보이던 이동도 제한한다.

모바일 패드는 반경의 12% 이내를 중립으로 처리하고 92%에서 최대 입력에 도달한다. 중심 부근 손떨림을 걸러도 thumb는 손가락을 즉시 따라간다. 독립 pointer 소유권, 취소·비활성화·포커스 상실 초기화를 유지한다. 창을 벗어나면 이동을 끊고 중립 입력을 확인한 뒤 재개한다. 대화·메뉴·회귀·저장 복원에서도 속도가 남지 않는다.

## 그림 애니메이션

`DawnLivingImage`와 `DawnLivingSprite.shader`는 발을 바닥에 두고 상체 호흡·무게 이동·망토의 작은 움직임을 연속적으로 표현한다. 인물 전체의 상하 이동과 좌우 음수 스케일 반전을 제거했다. 원본 네 자세씩의 걷기 루프와 앞/뒤 정지 그림은 약95ms의 premultiplied-alpha 전환으로 이어진다. 두 UI 그림을 겹쳐 알파가 빠지는 방식이 아니다. `traveler-motion.bytes`에 저장한 양방향 수치 대응장을 이용해 발·망토 위치를 중간 자세로 맞춘 뒤 색을 연결하여 단순 crossfade의 이중 발 잔상을 줄인다. `Tools/Art/Painted/build-motion-fields.py`가 PNG와 UV를 읽어 OpenCV DIS로 수치 데이터만 생성하며 원화 파일은 수정하지 않는다.

여행자와 보행 atlas의 투명 경계를 읽어 머리 중심을 몸의 기준 축으로 측정한다. 망토 폭이 달라져도 인물 중심이 좌우로 튀지 않도록 같은 축과 높이에 맞춘다. 측정 결과만 `layout.json`에 기록하며 원본 PNG를 재가공하지 않는다. 실제 이동 거리로 보행 위상을 진행하므로 벽에 막히거나 정지하면 제자리 걷기를 계속하지 않는다.

이는 기존 2.5D 원화를 연결하는 개선이며 신규 다방향 원화·모션 캡처·완전한 골격 애니메이션을 추가한 것은 아니다. 짧은 자세 전환과 천의 보조 움직임은 실제 렌더 캡처로 별도 확인한다.

## 확인 범위

정지 거리, 반대 입력, 30/60/144Hz 이동 거리 일치, 대각선/아날로그 속도, 패드 소유권/취소를 자동 검사한다. 기존 실제 Unity 씬 검사에서 앞 이동 후 좌우 반전, 발 기준점, 새 그림 렌더러, 대화·선택·회귀·저장을 함께 검사한다. 브라우저는 원본 입력으로 네 방향 이동·정지, 두 선택·결말·저장/재로드·음악/음성을 확인한다. PC 원본 브라우저 영상은 움직임 확인 자료이며 물리 기기 성능 측정이 아니다.
