# 실제 인물과 성경을 함께 읽는 대화

`gospel-authored-2026-10-27`은 기존 탄생 도입과 누가복음2장 성전의 소년 구간을 유지하면서 실제 인물에게 접근해 대화하는 흐름을 보강한다. 이후 생애 장 전체를 새로 플레이할 수 있게 만든 개정은 아니다.

성전 길잡이, 율법 선생, 성전의 선생, 마리아, 요셉의 실제3D 인물에 `GospelNpcAnchor` 식별자를 붙인다. 가까이 가면 HUD에 이름과 대화 가능 상태가 나오고 E/화면 대화 버튼으로 말을 건다. PC에서는 가까운 인물을 마우스로 눌러도 대화한다. NPC는 대화 상대를 향해 천천히 몸을 돌리며, 인물 위치나 퀘스트 상태를 움직여 맞추지 않는다.

각 인물은 두 개의 반복 가능한 주제를 제공한다. 선택한 주제의 대화 아래에는 해당하는 정확한 개역한글 본문 전체와 출처를 스크롤 영역으로 표시한다. 상단의 해설은 `학습 안내 · 본문 요약`, 기록된 구절은 `성경 직접 인용`으로 구분한다. NPC의 새 해설을 실제 역사적 발언이나 새 성경 구절로 소개하지 않는다.

현재 여정에 해당하는 인물은 `여정 이어가기`를 제공한다. 길잡이→선생들→부모→나사렛 귀환의 기존 순서를 지키며 실제 본문 대화를 한 턴씩 마쳐야 다음 목표와 읽은 말씀 기록이 진행된다. 현재 목표와 관계없는 NPC에게 물어보거나 반복 주제를 읽는 것으로 본문 순서를 건너뛰지 않는다. 성경 인용과 기존 스키마1/`gospel-0.1.0` 저장·슬롯·대화 턴 호환을 유지한다. 반복 주제는 언제든 다시 열 수 있으며 주제 선택 화면 자체를 메인 진행으로 저장하지 않는다.

핵심 Core는 `GospelNpcCatalog`와 `TryBeginStory`, 실제 접근/입력/주제 UI는 `GospelNpcDialog` 부분 클래스다. `GospelNpcTests`는 잘못된 NPC·탄생 건너뛰기 거부, 모든 순차 목표의 정상 NPC 경로와 대화 저장 복원, 표시된 본문과 직접 인용 일치를 확인한다. 실제 Unity·Web에서 접근/E/클릭/터치, 대화/본문 가독성, 본문 진행과 저장 복귀는 `ArcanaValidation`의 새 실행 근거를 따른다.
