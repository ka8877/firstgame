# 판마 음악·효과음 추가 다듬기

현재 화면 개정은 `fm-polish-2026-10-29`다. 확인된 원작 공개 곡과 이전 반복 경계 편집의 바이트를 유지한다. 새 음원을 원작 OST라고 소개하지 않는다. 기존 출처·발췌 길이·반복 편집은 [Renewal 오디오 기록](FmRenewalAudio.md)에 보존한다.

마우스 오버·선택·클릭의 소리를 전투 타격보다 낮게 조정했다. 마우스 오버는 이전 0.62에서 0.30, 클릭은 0.86에서 0.70의 상대 이득을 사용한다. 선택·뽑기·착지·능력치 확정도 큐별로 구분하며 사용자의 전체 효과음 슬라이더를 곱한다. 이미 재생 중인 소리의 음량을 조절해도 이 상대 균형은 유지된다. 기존 16개 음성 풀·중요도 보호·순번 기반 음높이 변화는 유지한다.

새 `FmBattleAudio.PlayAt(cue, pan)`은 공격 출발점과 피해 표적의 위치를 좁은 스테레오 범위 ±0.28에 연결한다. 연출 소리만 이동하며 전투 난수나 카드 상태를 소유하지 않는다. 헤드폰의 한쪽으로 소리를 완전히 밀어내지 않는다.

웹에서 다른 탭으로 이동하면 배경 음악을 일시 중지한다. 같은 장면으로 돌아오면 정지한 위치에서 페이드로 이어지고, 숨겨진 동안 실제 장면 역할이 바뀌었으면 마지막으로 선택한 곡만 처음부터 재생한다. 사용자의 음소거 설정을 바꾸거나 첫 사용자 입력을 건너뛰지 않는다. 늦게 끝난 재생 요청도 숨겨진 탭에서 소리를 내지 못한다. 네이티브는 운영체제의 `OnApplicationPause`에 같은 위치 보존 정책을 적용한다. 이 동작을 모든 Windows 포커스 변경과 동일하다고 주장하지 않는다.

`node --test Tools/Validation/test-fm-local-music.cjs`는 23/23 통과했다. 새 네 검사는 탭 이동·동일 곡 이어듣기, 숨겨진 동안 역할 변경, 지연 재생 요청과 음소거, WebAudio 없는 경로와 자동재생 권한을 다룬다. 이것은 제어기 회귀 검사이며 새 빌드의 실제 출력·사람의 청취를 대신하지 않는다. 새 Unity/Web 실행은 `PolishValidation.md`의 현재 기록을 따른다.
