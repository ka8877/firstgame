# 판타지마스터즈 원작 정보와 화면 동선 보강

이번 작업은 판타지마스터즈만 대상으로 한다. 자료의 시대가 다른 원작 화면과 DB 분류를 한 해의 클라이언트 전체라고 합치지 않는다. 원작 규칙·도감 필드의 근거는 [공식 규칙 조사](Research/FantasyMastersRulesSources.md), [카드 DB 조사](Research/FantasyMastersDatabaseSources.md), [공식 화면 자료](Research/FmRevivalSources.md)와 새 공식 인터페이스 읽기 기록 `Tools/Research/FmFidelity/official-interface-guide.json`이다.

## 등급과 랭크

기존 도감은 12등급 필터를 정의했지만, 유닛 카드의 축소 화면에는 등급 배지가 없었고 N/C/B/A/S 랭크를 따로 표시하지 않았다. 등급과 랭크를 별도 값으로 읽고 원본 카드 수치나 등급을 임의로 바꾸지 않는다.

- 손패·도감 카드의 그림 하단에 실제 등급 코드와 유닛 랭크 배지를 붙인다. 카드 이름·소울·AP/DP/HP의 기존 실제 줄 높이와 전체 코인 식을 유지한다. 등급 색만으로 정보를 전달하지 않고 코드·전체 명칭을 상세와 도움말에 함께 표시한다.
- 12등급 안내는 실제 CardCatalog를 집계해 이름·코드·수록 종수를 보여 준다. 각 항목을 누르면 해당 등급으로 필터한 도감으로 이동한다. 수록하지 않은 등급은 0종이라고 명시한다. 등급을 전투력 순서로 소개하지 않는다.
- 유닛 N/C/B/A/S 랭크 필터와 정렬, 능력(만능/장비/마법/야수) 필터를 추가한다. 복합 능력 유닛은 해당 능력 검색에 포함한다. 비유닛에 유닛 랭크를 붙이지 않는다.
- 상세 및 hover 설명에 유닛 능력, 아이템 장착 조건, 마법 공격/방어 사용 시점을 표시한다. 소울·레벨·등급·랭크를 한 수치로 합치지 않는다.
- 이름·효과 검색은 등급 이름과 실제 원작 sourceId도 찾는다. 검색 결과·등급별 종수·페이지 수·덱 안 수량은 카탈로그에서 계산한다.

## 목록 편집과 원작 화면 정체성

덱 편집의 첫 진입은 목록 보기다. 넓은 화면은 한 페이지 6행, 높이 600px 미만은 4행으로 실제 줄 높이를 확보한다. 각 행은 작은 원화·카드명·등급/랭크·레벨/색소울·총소울/유지비·AP/DP/HP 전체 코인식·편성 수량과 +/-를 제공한다. 공식 수치식을 잘라내거나 12px 아래로 줄이지 않는다. 큰 카드 갤러리로 전환할 수 있고, 페이지 크기와 전체 페이지 수는 보기 방식과 실제 카탈로그에 따라 계산한다.

타이틀은 보존된 원작 웹 로그인 인물 4타일을 원래 비율과 픽셀 그대로 사용한다. 짙은 녹색과 청동 몰딩, 원작 로비의 보라색 소울 구체와 방 목록/우측 rail 구성을 새 UI 도형으로 그린다. 원작의 설명 숫자가 찍힌 스크린샷을 배경으로 쓰거나 로그인 웹 그림을 특정 연도 클라이언트 타이틀이라고 소개하지 않는다. 원작 웹 그림의 회색 점무늬 배경과 낮은 해상도도 원본에 포함되어 있으며 HD 복원으로 표시하지 않는다.

## 덱과 로비 동선

덱 분석은 소울 곡선 / 속성·유지비 / 등급·랭크 3탭이다. 속성별 총 카드와 지형 수, 편성한 유닛 전체의 유지비 합계, 덱 안 등급별 장수와 유닛 랭크별 장수를 보여 준다. 유지비 합계는 현재 전장의 유지비가 아니라 덱 전체의 합계라고 tooltip에서 구분한다.

로비 정보 구역은 실제 수록 카드·등급 수를 표시하고 게임 방법·등급/랭크·편집 덱 분석으로 연결한다. 대전실에는 실제 지원하는 50장/6손패/5전열과 공격 준비→방어 준비→배틀→소울코스트를 표시한다. 기본 덱은 2×2 네 개씩 페이지로 탐색하므로 다섯 번째 강화 체험 덱도 겹치지 않는다. 종류 합계와 속성 요약은 실제 덱에서 계산한다. 없는 온라인 접속자·채팅·상점 경제를 만들지 않는다.

## 소각장과 양측 상태

공식 2005 안내의 양측 손패·덱·LP·소각장 열람을 근거로 전투 메뉴에 `소각장 / 상태`를 추가한다. 실제 BattleDisplayState의 양측 손패 수·남은 덱·LP·discard 수를 읽고 소각장 카드를 최근 순으로 네 장씩 열람한다. 원본 카드와 상세 화면으로 이어지며 상대 손패의 내용은 노출하지 않는다. 내 소각장 버튼은 root의 BindDiscardDrop과 연결되어 손패 드래그 소각을 받으며, 클릭은 소각장 열람이다. 업그레이드 소각의 총소울+1은 실제 Core 판정에 따른다.

전투 재생 중 자원 rail과 손패는 엔진 최종 상태가 아니라 전투 agent의 BattleDisplayState를 읽는다. 판정·버튼 적법성은 실제 engine을 사용한다. locked 중 길게 눌러 상세 화면으로 전환하지 못하게 하며 Core/RNG/저장 상태를 UI가 변경하지 않는다. 실제 손패에만 root의 BindHandDrag를 연결한다.

## 브라우저 입력 좌표 계약

좌표는 실제 게임 캔버스의 정규화 좌표다. UI의 Y는 아래에서 위로, Playwright의 Y는 `1-Y`로 바꾼다.

|---|---|---|
| 도감 1차 속성/종류/소울/등급 필터 | .035 + 열*.236 ~ +.222 | .666–.748 |
| 도감 랭크 필터 | .035–.254 | .598–.654 |
| 도감 능력 필터 | .272–.491 | .598–.654 |
| 도감 등급/랭크 안내 | .509–.728 | .598–.654 |
| 도감 목록/큰 카드 보기 전환 | .746–.965 | .598–.654 |
| 도감 네 카드 그림 위 경계 | .035 + 열*.237 ~ +.222 | 위 .586 / 아래 .207(도감), .245(편집) |
| 랭크/능력 선택 3열×2행 | .055+열*.302 ~ +.286 | .52-행*.19 ~ +.16 |
