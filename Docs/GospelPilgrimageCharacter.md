# 자유 이동 필드의 방향별 픽셀 인물

현재 개정은 `gospel-journey-2026-10-30`이다. 실제 FINAL FANTASY RESONANCE의 필드는 픽셀 인물과 입체 배경을 조합한다. 홍보용 큰 인물 일러스트와 실제 필드 스프라이트를 구분하고, 새 예수님·NPC는 별도 오리지널 PNG를 사용한다. 원작의 코드나 인물 파일을 회수했다고 소개하지 않는다.

## 원본과 방향

`GospelPilgrimageActor`는 소년과 성인의 별도 원본, 실제 정면·뒷면·왼쪽·오른쪽을 사용한다. 진행 방향의 주축에 따라 방향을 고르며 대각선 경계에는 작은 각도 여유를 둔다. 현재 방향이 그 사분면의 유효한 두 방향에 포함될 때만 경계를 유지하므로 첫 대각선 이동에 반대 정면 그림이 남지 않는다. 좌우 이미지를 뒤집어 뒷모습으로 가장하지 않는다. 각 방향은 중립·보행A·보행B의 세 셀이다. 실제 이동 속도와 거리에 따라 `중립→A→중립→B`를 재생하고 정지·공중에서는 중립 자세로 돌아간다. 생성 원화가 완벽히 번갈아 디디는 해부학적 발 동작까지 제공한다고 주장하지 않는다. 달리기는 같은 원화의 보폭·주기를 빠르게 사용하며 별도 달리기 원화가 있다고 주장하지 않는다. 걷기/달리기 판정은 현재 모터의 두 속도 설정 사이를 기준으로 하므로 보통 걷기를 달리기로 잘못 분류하지 않는다.

제작 결과의 알파 영역과 발 기준을 읽기 전용으로 측정한 `*-layout.json`이 필요하다. 원본 PNG·알파·GUID를 수정하지 않고 `Sprite.Create`의 UV 영역·pivot·pixels-per-unit만 적용한다. 잘못된 크기·셀 수·영역은 오류로 처리하며 이전의 종이 관절 인물이나 도형 인물로 조용히 대체하지 않는다. 실제 성인1086×1448·소년1086×1448은 등간격 그리드가 아니므로, 알파32 초과의 가장 큰12개 연결 성분을 네 줄·각 줄 세 인물로 정렬했다. NPC1774×887은 가장 큰4개 성분을 왼쪽부터 마리아·요셉·선생·요한으로 사용한다. 원본의 아주 작은 별도 성분은 인물 UV 밖에 남으며 PNG에서 삭제하지 않는다.

각 성분의4픽셀 여백과 상단1/3의 알파 중앙 X를 측정해, 보행에서 넓어지는 손·발 바운딩 박스의 중심 때문에 몸통이 옆으로 튀지 않게 한다. 각 실제 발 지지선의 아래쪽 알파 끝을 pivot Y로 삼아 투명 셀 여백이 접지를 움직이지 않게 한다. `referenceHeight`는 같은 시트의 인물 높이 중앙값(성인332.5px·소년326px·NPC750.5px)이며 소년1.64·성인1.94 월드 단위에 대응한다. [원본·SHA·측정 기록](../Tools/Art/GospelPilgrimage/manifest.json)과 [측정 도구](../Tools/Art/GospelPilgrimage/measure-actor-atlases.py)는 복사·읽기 전용 측정만 수행한다. 상태창 일러스트1536×1024는 픽셀 인물과 별개다. 원본은 왼쪽/오른쪽 두 인물이며 실제 표시에서는 소년 UV 폭을.455로 좁혀 옆 성인 의상의 작은 침범을 제외하고, 성인은 오른쪽.5영역을 사용한다. 원본 PNG는 수정하지 않는다.

## 입체 공간과 조작

인물은 카메라를 향한 한 장의 스프라이트로 보이며, 몸통·팔·다리를 따로 잘라 흔드는 구조가 아니다. 실제 위치·중력·충돌은 모터가 소유한다. Actor는 부모 위치·회전을 변경하지 않고 현재 속도·접지·방향을 읽는다. 3D용 전용 URP 셰이더는 원본 알파를 컷아웃하고 실제 깊이를 기록하므로 기둥·난간·나무·다른 인물 앞뒤에서 실제 입체 가림이 적용된다. 픽셀은 Point 필터로 표시하고 장면 안개를 적용한다. 새 셰이더는 Resources에서 직접 참조하여 빌드 시 런타임 이름 검색에만 의존하지 않는다.

접지 그림자는 월드 높이 또는 실제 아래쪽 충돌 결과에 놓인다. 점프 중에는 지면에 남고 고도에 따라 넓이·투명도가 변한다. 등잔은 보존한 제작 메시와 따뜻한3D 광원이며 실제 장착 상태로 켜고 끈다. 손의 위치만 빌보드 좌표를 따르고 등잔 자체는 실제 월드 위쪽을 유지한다. FBX의 기존 축 변환·스케일을 보존해 크기를 맞춘다. 스프라이트 텍스처·셰이더·등잔 원본 메시를 인물 파괴 시 함께 지우지 않는다.

NPC는 같은 픽셀 스타일의 개별 인물(Mary/Joseph/Teacher/John)을 사용한다. NPC에 별도의 보행 애니메이션이 있다고 표시하지 않으며 정적인 실제 만남으로 제공한다. 대화·발견·성경 본문·순서는 기존 Core의 상태를 따른다.

실제 Web 원본에서 등잔이 몸통을 가리는 크기 오류를 확인했다. 보존한 제작 원본은 폭0.122×깊이0.20223×높이0.049m인 납작한 등잔이다. 높이를0.23m로 맞추던 처리가 전체를 약4.69배 키웠으므로, 이제 가장 긴 축을0.22m로 제한한다. 기존 원본·축 변환·재질은 유지하고 광원 높이도 최종 모델 높이+0.02m(약0.073m)에 맞춘다. 이 수정의 실제 렌더링은 새 실행 원본으로 확인해야 한다.

## 통합 계약과 실제 검증

`Build(parent,camera,adult)`와 `BuildNpc(parent,camera,npcId,height)`는 Actor를 반환한다. `SetMotion(velocity,grounded,yaw)`, `SetAdult`, `SetLamp`, `SetGroundSampler(World.HeightAt)`로 실제 상태를 전달한다. `CurrentState`, `CurrentFacing`, `CurrentFrame`, `PortraitSprite`, `OriginalAtlasResource`, `AnimationFrameCount`, `UsesMeasuredLayout`은 읽기 전용 검사·메뉴용이다. 이 문서의 설계 설명은 실행 통과가 아니다. 현재 Unity/브라우저 검사에서 새 원본 인물의 네 방향·걷기/달리기/정지·장착·소년/성인 전환·가림과 실제 자유 이동을 별도로 확인해야 한다.
