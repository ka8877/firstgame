# 판타지마스터즈: 전열 조작과 필드 소각

`fm-reprise-2026-11-02`의 전투 규칙 보완이다. 이전 카드 2,646종, 원본 15,350종, 27개 자유 연습 덱, 실제 소유 카드·SP와 기존 schema 3 저장을 보존한다. 규칙 자체의 누락과 화면 연출의 부족을 나누어 확인했으며, 아래 두 준비 조작을 실제 Core에 추가했다.

후기 공식 [FAQ 734 전투 안내](https://web.archive.org/web/20160911090258id_/http://www.fantasymasters.co.kr/HelpDesk/FAQ_view.asp?category=106&Nowpage=1&faqNo=734)는 다음과 같이 설명한다.

> 자신이 사용할 수 있는 필드는 모두 5칸의 슬롯으로 이루어져 있으며, 공격이나 방어할 때 필드에 놓인 카드의 위치를, 마우스드래그로 변경하여 배치할 수 있습니다.

실제 확보한 원문 `Tools/Research/FmRenewal/faq734-text.txt`의 해당 문장을 이번에 다시 읽었다. 이 자료의 보존 시각은 2016년이며 마지막 서버 패치 시각을 증명하지는 않는다. 기존 구현은 처음 카드를 놓을 칸을 고를 수 있었으나, 놓인 유닛과 예고 마법을 다시 옮기는 기능이 없었다. 이제 양측 각자의 준비 단계에서 아군 유닛·예고 마법을 빈 칸으로 옮기거나 다른 아군 전열 카드와 교환한다. 이 배치는 실제 다음 전투의 공격·방어 순서에 반영된다.

[2005년 공식 오프라인 매뉴얼](https://web.archive.org/web/20051101013311id_/http://www.fantasymasters.co.kr:80/Guide/Manual/tutorial6.asp)의 준비 완료 설명에는 다음 문장이 있다.

> 준비완료 전에 어느 시점이라도 카드를 소각 (무덤에 버리는일)을 할수 있습니다. (소울을 사용한 지형은 소각불가)

기확보 본문과 응답 해시·문장 근거는 `Tools/Research/FmFidelity/hand-discard-official-evidence.json`에 남아 있다. 손패에만 제공하던 소각을 유닛·장착 아이템·예고 마법으로 확장했다. 유닛을 소각하면 해당 유닛과 장착 아이템의 실제 인스턴스가 소각장으로 이동하고, 기존 카드의 파괴 기술도 같은 처리 경로를 사용한다. 아이템만 소각하면 그 장착 능력치를 잃으며, 체력 아이템을 잃어 유닛이 파괴되는 경우도 처리한다. 예고 마법을 소각하면 효과를 발동하지 않는다. 소환 비용은 돌려받지 않는다.

지형별 소울 사용 여부는 현재 저장에 개별 기록되지 않는다. 따라서 사용한 지형까지 임의로 버릴 수 있도록 만들지 않았으며 **지형 소각은 이번에도 지원하지 않는다.** 이 범위를 전체 필드 소각 복원으로 소개하지 않는다.

## Core와 화면 연결

`CanMoveFieldCard` / `MoveFieldCard`는 소유 플레이어·인스턴스 ID·목적 전열 칸을 받는다. `CanDiscardField` / `DiscardField`는 소유 플레이어·인스턴스 ID를 받는다. 시작 손패 확정 전·다른 플레이어의 준비·전투 종료 뒤에는 수행할 수 없다. 이동·교환 자체는 LP·소울·코인 RNG를 소비하지 않는다. 재배치와 소각은 새 카드 사용으로 세지 않으므로, 아직 카드를 사용하지 않았다면 기존 손패 셔플 조건은 유지된다. 마지막 조합의 세부 정책까지 위 원문에서 확인됐다고 주장하지 않는다.

새 `reposition` 이벤트의 `sourceLane`은 이전 칸, `targetLane`은 새 칸이다. 실제 완료 상태를 깊은 복사한 재생 프레임과 함께 전달한다. 예고 마법은 이동·소각 로그에서도 이름을 공개하지 않는다. `discard-field`도 실제 카드 ID·칸과 소각 직후 스냅샷을 전달한다. UI가 전투 결과나 코인을 다시 굴리지 않는다. 기존 이벤트·ID·저장 필드를 바꾸지 않아 예전 schema 3 저장을 그대로 읽는다.

## 원작과 이미 일치하는 기본 처리와 남은 범위

양측 준비 → 낮은 레벨의 마법 우선 공개 → 전열 순 공격 → 생존 반격 → 소울 회복·유닛 유지비 → 공수 교대는 기존 Core에서 확인했다. 카드별 공통 코인열의 실제 결과·AP/DP/HP 변화, 방어 유닛의 연속 방어, 유닛 레벨에 따른 직접 덱 소각을 유지한다. 별도 리더 HP를 기본 덱 전투의 승리 수치로 바꾸거나, 효과음을 위해 판정을 다시 계산하지 않는다.

후기 원작 전체 카드 기술, 개별 지형의 사용 추적, 모든 방 옵션, 원작 서버의 결제·멀티플레이를 복구한 것은 아니다. 코인열의 앞 n개 해석, 장비 2장 상한, 60턴 제한 등 이전에 별도 구현 선택으로 기록한 항목도 그대로이며, 이를 새로 원작 확정 규칙이라고 표현하지 않는다. [기본 규칙과 확인 수준](FantasyCardsRules.md), [후기 공식 자료](Research/FmRenewalSources.md)를 함께 따른다.

새 의미 검사는 `Tools/Validation/Tests/RepriseFieldActionsTests.cs`다. 실제 공격 순서 변화, 유닛/마법 교환과 대상 칸 보존, 깊은 재생 복사, 잘못된 소유·단계·칸의 무변경 거부, 실제 카드 수 보존, 아이템을 잃은 유닛의 파괴, 파괴 기술, 저장 왕복·RNG/자원 보존을 검사한다. 실행·화면·공개 배포의 실제 결과는 이번 Reprise 검증 기록을 따르며 소스 추가 자체를 통과로 간주하지 않는다.
