# 예수님의 길 — 탄생의 기억과 말씀 도감

현재 개정은 `gospel-renewal-2026-10-29`다. 새 여정은 게임 공간으로 바로 들어가지 않고 새 탄생/성전 여행 일러스트와 여섯 장의 도입을 보여 준다. 베들레헴의 탄생, 이름, 아기 때의 성전 방문, 나사렛의 성장, 현재 열두 살의 예수님을 소개한다. 도입은 건너뛸 수 있고 메뉴에서 다시 볼 수 있다. 도입을 보거나 건너뛰는 일은 말씀을 획득하지 않는다.

조작하는 인물은 누가복음 2:41–52의 **열두 살 예수님**이다. 다른 사람에서 예수님으로 변하는 이야기가 아니다. 성장 과정 중 기록되지 않은 사건을 역사적 사실처럼 채우지 않는다. 기억의 길에서 예수님과 마리아·요셉·선생이 나누는 대화는 본문에 근거한 **학습용 극화**이며, 도입에서 이 성격을 안내한다. 대화 아래 정확한 성경 직접 인용을 별도로 표시한다. 기존 성전 본편의 마리아·예수님의 직접 인용 대사는 그대로 보존한다.

## 실제 첫 장의 흐름

1. 새 타이틀 → 여섯 장의 도입 → 열두 살의 여정 시작.
2. 세 탄생 만남에서 기존 세 말씀을 획득한다. 새 여정은 해당 NPC 가까이 걸어가 대화를 시작해야 한다.
3. 기억의 길 여덟 만남에서 호적 여행, 밤의 목자들, 목자들의 방문, 예수라는 이름, 아기 때 성전 방문, 시므온, 안나, 나사렛의 성장을 읽는다. 각 만남은 서로 번갈아 말하는 여덟 대화 턴이며, 마지막 턴을 마쳐야 말씀 한 장을 획득한다.
4. 성전 문 → 선생들 → 부모와의 만남 → 나사렛으로 돌아가기의 기존 네 목표를 진행한다. 새 여정은 앞의 여덟 만남을 끝내야 이 단계에 들어갈 수 있다.
5. 말씀 도감 **15장**을 완성한다. 이후 공생애 전체가 플레이 가능하다고 표시하지 않는다.

여덟 만남에는 본문에 관한 질문 두 가지씩, 총 열여섯 가지의 선택 대화가 있다. 질문을 열고 답을 읽어도 원래 대화 위치가 바뀌거나 말씀이 중복 획득되지 않는다. 말씀 도감은 획득/잠금 상태, 제목, 출처, 정확한 본문과 페이지 이동을 제공한다. 잠긴 말씀의 본문은 획득한 것처럼 표시하지 않는다.

## 분량과 조작

새 기억의 길은 64개 대화 턴, 공백 포함 6,564자다. 여섯 도입 본문은 673자이며, 새 구절과 기존 탄생/성전 본편, 선택 질문, 걷기를 더한 첫 장이다. 정상적으로 읽고 탐색하는 **약 10–15분을 목표로 설계한 분량**이며, 아직 사람의 실제 플레이 시간을 측정한 결과가 아니다. 빠르게 넘기는 플레이를 막는 강제 대기나 시간을 채우기 위한 진행 제한은 없다.

A/D 이동, Shift 달리기, Space 점프, E 가까운 만남, 휠 확대/축소, I 인물, B 가방, M 도감, Esc 메뉴를 사용한다. 모바일은 가로 화면의 좌우 누르기·달리기 토글·점프·대화 버튼을 사용한다. 현재 배우의 보행/달리기는 각각 2.2/4.2 월드 단위/초이며, 이동 경로는 기존 숲과 성전 뜰을 따라 여러 만남을 잇는다.

가방의 여섯 물품은 새로 제작한 그림, 이름, 설명과 용도를 보여 준다. 토기 등잔은 실제 손의 조명과 저장에 연결되고, 말씀 수첩은 실제 도감을 연다. 물주머니처럼 소모 기능이 없는 소품은 효과가 있다고 꾸미지 않는다.

## 본문 출처와 저장 호환

추가 본문은 대한성서공회 [개역한글 누가복음 2장](https://www.bskorea.or.kr/bible/korbibReadpage.php?version=HAN&book=luk&chap=2)에서 2026-10-29에 직접 조회했다. `Tools/Data/GospelRenewal`에 응답 원본, URL/SHA256, 추출한 절, 대화 원문과 재현 도구가 있다. 원문 사이트의 숨은 교차 참조 팝업과 `ㄱ)` 등 주석 표시는 성경 인용에 섞지 않고 출처 기록에 따로 보존한다. 원래 일곱 본문의 ID·단어·순서는 바꾸지 않았다.

저장 schema 1 / `gospel-0.1.0`과 기존 슬롯을 유지한다. 새 선택 필드에 도입 위치·확장 여정 여부·현재 대화 턴·획득한 여덟 말씀을 보관한다. 이전 필드가 없는 저장은 원래 일곱 말씀 여정 그대로 이어지고, 이미 끝난 저장을 새 구간 미완료로 바꾸지 않는다. 확장 여정은 순서가 다른 ID·중복 획득·범위 밖 대화·건너뛴 성전 진입을 거부하며 현재 유효한 진행을 바꾸지 않는다.

새 Core 검사는 도입 재개/건너뛰기, 64턴 각각의 JSON 저장 복원, 마지막 턴에서만 획득, 중복 획득 방지, 새 15장 완료, 옛 7장 완료 저장 호환, 손상된 기록의 원상 보존, 직접 확인한 본문 22–24절의 단어와 주석 분리를 다룬다. 실행 결과와 실제 Unity/Web 화면은 `Artifacts/Validation/Renewal`에서 따로 기록한다. 과거 Luminous 통과를 새 구현의 통과로 재사용하지 않는다.
