# 후기 판마1 전투 표시 재구성

현재 소스 개정은 `fm-chronicle-2026-10-29`다. 이번 변경은 카드 수나 규칙을 늘리는 작업이 아니라, 원본 카드·코인·전장 배치를 원작 자료에 더 가깝게 표시하는 작업이다. Core·저장 구조·난수는 바꾸지 않는다. 이전 [Polish 조작과 대전 데스크](FmPolishUI.md)는 유지하며 이 문서가 전투 카드와 코인 화면 설명을 대체한다.

## 원작 근거의 범위

- 직접 확인한 기본 영상은 [2017-07-02 실제 플레이 글](https://m.blog.naver.com/orderandchaos030/221042522552)의 `Tools/Research/FmFidelity/VideoFrames/Gameplay2017` 원본 프레임이다. 글 작성자는 당시 리플레이가 실행되지 않아 실제 플레이를 녹화했다고 설명한다. 재확인 응답은 `Tools/Research/FmChronicle/known-2017-blog-recheck.json`에 기록된다.
- 117.00·118.50·119.00·120.50·121.50초 원본에서 어두운 파란 전장, 위쪽 상대/아래쪽 내 전열, 원본 인쇄 카드, 사각형 5칸 코인 창, 실제 `Coin:90%`, 카드 오른쪽 아래 수치, 붉은 피해와 불꽃을 확인했다. 같은 아래쪽 줄에 놓인 카드 둘을 서로 다른 편이라고 단정하지 않는다.
- 사용자의 새 400×300 인라인 이미지는 추가 배치 참고다. 별도 원본 파일 경로나 촬영 날짜가 제공되지 않아 파일을 확보했다거나 그 이미지만으로 마지막 클라이언트 버전을 확인했다고 기록하지 않는다.
- 더 늦은 [2017-12-29 실제 접속·싱글 플레이](https://m.blog.naver.com/orderandchaos030/221173940991)의 640×480 원본 `Live2017December/0056.0s.png`에서 **두 결과 창**, 위쪽 상대/아래쪽 내 전열, 금색 앞면과 원작 인물 역면, 슬롯별 능력 아이콘을 직접 확인했다. 같은 영상 90·120초는 준비 중 손패와 지형을 확인하는 근거다.
- [2018-10-12 마지막 PvP 재게시](https://m.blog.naver.com/orderandchaos030/221375920763)의 `LastPvp2018Post/0165.0s.png`는 5칸 코인 창과 붉은 역면, 숫자 자리를, 180초는 Battle End의 하단 지형 띠를 보여준다. **2018년 게시일을 촬영일로 간주하지 않는다.** 파일들은 `Tools/Research/FmChronicle/VideoFrames`에 있다. 완성된 마지막 클라이언트 소스나 원본 GUI 텍스처 전체를 복구했다는 의미는 아니다.

## 원래 숫자 자리에서 갱신되는 카드

손패의 이름·일러스트·비용·등급·기술 설명·기본 인쇄 수치를 덮던 새 머리글/꼬리글을 제거했다. 전열과 중앙 대결 카드에서도 넓은 AP/DP/HP 판과 카드 중앙 코인 띠를 제거했다. 전체 원본의 종횡비와 인쇄 프레임을 유지한다.

실제 전투 유닛은 **원본 오른쪽 하단 AP/DP/HP 숫자 자리만** 갱신한다. 285×405 원본의 비어 있는 세로 띠 `x246–249`를 해당 숫자 영역 안에서 늘려 이전 글자를 가리고 현재 수치를 넣는다. 구판의 밝은 종이색과 후기의 검은 숫자칸에 각각 같은 원본 질감이 사용된다. RawImage UV 표시이며 이미지 파일을 수정하지 않는다. 기술 설명과 원래 숫자칸 테두리는 보존된다.

직접 확인한 원본은 `3042520487 리틀엔젤`, `9020423826 실프`, `3010820340 아크데몬`, `16113028641 그레이트월`, `16051128346 테오`, `16121528664 각성한지테사`다. 커먼부터 유니크·레전드·시크릿까지 확인했으며 모두 285×405의 같은 숫자 열을 사용한다. 원본 전체 판형에 대한 자동 보증으로 확대하지 않는다.

| 숫자 | 원본 픽셀 영역(좌상단 기준) | UI Y 범위(아래쪽 원점) |
|---|---|---|
| AP | x246–275, y313–334 | .1753–.2272 |
| DP | x246–275, y340–359 | .1136–.1605 |
| HP | x246–275, y365–386 | .0469–.0988 |

현재 숫자는 읽기 전용 Core 값과 실제 `before/after` 전환값을 사용한다. 증가·감소 중에는 숫자 색도 변하며, 작은 인쇄칸에 긴 증감 설명을 끼워 넣지 않는다. 상세/원본 확대 화면에는 동적 숫자 덮개 없이 원본 인쇄를 그대로 보여준다. 축소 카드의 긴 원문은 두 번 누르기/길게 누르기 상세에서 읽는다.

## 양측 코인·결과 창

상대와 내 유닛은 위/아래 실제 전열을 유지한다. 집중 표시하는 대결 카드 양옆에 두 사각형 결과 창을 배치한다. 상대 창은 위쪽 오른편, 내 창은 아래쪽 왼편이다. 창이 카드의 원래 숫자칸을 가리지 않도록 한다. 카드나 화면 전체를 스크린샷으로 붙이는 방식은 쓰지 않는다.

각 창에는 다음 실제 값이 들어간다.

- 금속 테두리의 **5개 사각 슬롯**. 던지지 않은 슬롯은 비어 있고, 기록된 슬롯에만 동전이 나온다. 앞면은 금색 FANTASY/MASTERS 각인, 뒷면은 동그란 금속 테두리 안의 해당 유닛 원작 그림으로 명확히 다르다. 원작 GUI 파일을 추출한 것이 아니라 기존 원작 카드 그림을 재사용한 재구성 스킨이다. 이번에 판정 중인 동전만 회전한다.
- 각 해결된 슬롯 아래에는 그 코인이 관여하는 실제 AP/DP/HP의 작은 아이콘이 나온다. 카드·장비·기술이 지정한 코인 개수를 읽으며, 뒷면이라 수치가 그대로여도 해당 능력 아이콘은 남는다.
- `Coin : N%`. Core의 `OriginalEquipmentModifiers.ChancePercent`를 읽으며 50%로 고정하지 않는다.
- AP·DP·HP 아이콘, 현재 수치, 실제 이전→이후 및 부호 있는 변화량. 덱/장비/효과가 판정한 결과를 그대로 읽는다.

이번 코인의 예정 개수는 Core가 이미 만든 재생 사건의 `coinIndex`에서 가져온다. UI에서 난수를 굴리거나 판정식을 다시 계산하지 않는다. 코인 1번 사건이 다시 나타나면 그 유닛의 표시열을 새로 시작한다. 배속/끝까지는 표현 시간을 바꾸며 저장된 결과에 영향을 주지 않는다.

## 전장과 기존 조작

전투 전체 배경을 어두운 파란 장으로 바꾸고, 전열·손패·지형·오른쪽 정보 창은 얇은 사각 금속 테두리로 맞췄다. 파란 배경과 금속·동전·능력 아이콘은 해상도에 맞춰 새로 그리는 UI이며 회수한 원작 GUI 파일이라고 부르지 않는다. 기존 웹 인물 타이틀 그림을 전투 뒤에 겹쳐 쓰지 않는다.

원본 인쇄 카드의 선택·드래그·합법 대상·두 번 누르기·길게 누르기·Esc 복귀는 유지한다. **상대 정보**, 실제 전투 기록과 개인 연습 메모, 저장·이어하기·소리 설정도 그대로다. 실제 공격/반격 사건의 준비·이동·명중, 붉은 피해와 소각장 이동을 유지하며, 추가했던 곡선 대상 연결선과 능력 확정의 큰 마법진은 활성 전투에서 제거했다.

준비 중에는 하단에 손패, 집중 공방 중에는 같은 위치에 내 지형 원본들을 보여준다. 다음 준비에 손패가 돌아오며 이는 표시만 바꾸는 동작이다. 상대 지형은 오른쪽 위 작은 실제 원본 목록에, 최근 실제 사건은 왼쪽 위에 겹쳐 표시한다. 모바일에서는 사건 한 줄, 큰 화면에서는 두 줄로 제한하고 나머지는 전투 기록에서 읽는다. 다른 사용자의 채팅·SP·가상 타이머를 생성하지 않는다.

## 실행 담당용 확인 항목

이번 변경의 Unity·PC/모바일 브라우저·공개 배포 결과는 새 `Artifacts/Validation/Chronicle` 근거로 확인한다. 이전 Polish/Renewal 통과 화면을 새 통과로 대신하지 않는다. 현재 문서는 소스 계약이며 실제 시각 검토 결과는 실행 기록을 따른다.

- 기존 준비 중 손패·전열·지형·Ready/메뉴 입력 좌표를 유지한다.
- `Card live AP/DP/HP <instanceId>`는 이제 **숫자만** 표시한다. 좁은 실제 인쇄칸 안에 있는지 확인한다. 더 이상 옛 손패 머리글/꼬리글이나 넓은 카드 수치판을 요구하지 않는다.
- `ChronicleVisibleCoinPanels`는 평상시 0, 두 유닛 집중 대결에서 2다. 창 이름은 `Chronicle coin result <owner> <instanceId>`이며 `Coin slot <owner> 1..5`가 있다.
- 실제 동전은 `Resolved coin <owner> <index> heads/tails`, 확률은 `Actual coin chance <owner>`, 증감은 `Coin result change <owner> AP/DP/HP`로 관찰할 수 있다.
- 앞·뒤 면, 기본 50%와 실제 보정 확률, 0→양수/음수 변화, 피해 후 HP, 여러 코인, 방어·파괴, 저장/복귀를 실제 사건과 비교한다. 모바일은 고정된 실제 캔버스에서 전체 원본을 보고 수치창의 글자·슬롯 겹침을 확인한다.
