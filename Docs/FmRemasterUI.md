# 판타지마스터즈 UI 리마스터

화면 개정은 `fm-remaster-2026-10-26`이다. 원작의 캐릭터·카드 원화, 일곱 속성, 50장 덱, 여섯 손패, 우측 정보 패널과 5열×2전열을 유지하면서 화면의 선명도와 조작을 개선한다. 규칙·내부 schema3·공통 봉투 schema1·기존 안정 ID와 저장 슬롯은 바꾸지 않는다. 이전 화면 계약은 [FmRevival](FmRevival.md), 원작 카드 출처는 [ClassicCardArt](ClassicCardArt.md)를 따른다.

## 화면과 원화

- 기존 스크린샷의 좁은 장식 띠를 확대하던 테두리를 직접 그리는 황동 몰딩·명암·음각 곡선·리벳으로 바꾼다. Canvas 좌표에서 그리므로 고해상도 화면에서도 장식선이 선명하다.
- 일곱 속성은 태양·물방울·불꽃·잎·검·결정·초승달의 선형 문장으로 표시하고 속성명도 함께 쓴다. 색만으로 소울을 구분하지 않는다.
- 타이틀에는 원작 웹 인물의 네 타일을 원래 비율로 유지한다. 체크무늬가 구워진 옛 GIF 로고 조각은 큰 배너로 확대하지 않는다. 투명한 독립 로고가 없으면 `Fantasy Masters`라는 원래 이름을 선명한 텍스트로 표시한다.
- 카드 이름, 소울 비용, AP·DP·HP/각 코인은 원화 바깥에 표시한다. 카드 일러스트 창은 종횡비를 유지하며 전체 창을 표시한다. 상세 화면은 인쇄 카드 전체를 보여 주고 현재 DB 수치와 효과를 별도 텍스트로 표시한다.
- 원본 PNG와 캐릭터 타일의 픽셀 수는 변하지 않는다. UI 개선을 원작 원화의 HD 복원으로 표현하지 않는다.
- 이전 창작 카드 atlas10장·아바타4장·타이틀/전장 배경2장은 `Assets/Art/Archive/LegacyResources`에 원본과 `.meta`를 함께 보존한다. 총50,698,103바이트의 PNG를 자동 포함되는 `Resources`에서 옮겨 활성 패키지에서 제외한다. 이동 전후 PNG/메타 해시와 GUID가 같으며, 이전 `LegacyCardData`의 참조는 유지한다. 원작161종·뒷면·Revival 인물은 활성 Resources에 남긴다.

## 조작과 정보

도감/덱 편집은 실제 카드 이름·효과 텍스트 검색, 속성/종류/총소울/등급 필터, 원본/소울/레벨/이름 순 정렬과 내 덱 카드만 보기를 제공한다. 검색 버튼 또는 입력 완료로 적용한다. 네 카드씩 표시하며 전체 수·검색 결과·페이지는 `CardCatalog`에서 계산한다. 기존96종과 추가 카드가 같은 경로로 탐색되며 마지막 부분 페이지와 결과 없음도 처리한다. 덱의 종류별 합계와 카드별 현재 수량/편성 한도를 표시하고 덱50장/카드 한도를 넘는 추가는 막는다.

전장의 우측 패널은 턴/공격·방어 준비 상태, LP, 총소울, 일곱 색소울, 지형 수, 양쪽 남은 덱을 분리한다. `손패 셔플`·`준비 완료`에는 한국어 동작명을 사용한다. 손패 아래에는 카드 선택 후 전열 배치와 길게 누르기 안내를 표시한다. 카드 hover는 실제 비용/코인/효과에 맞춰 높이를 계산하며 모바일 길게 누르기는 상세 화면을 연다. 효과 설명은 세로 스크롤로 전부 확인한다.

음악 설정은 `FmOriginalMusic.Muted/Volume`의 현재 값을 읽고 `SetMuted/SetVolume`만 호출한다. 따라서 웹 하단 플레이어와 게임 설정이 같은 값을 표시한다. 공식 외부 플레이어의 네트워크·출력 검증은 별도 음악 검증이다.

## 확인 범위

이번 UI 소스 작업은 Unity 라이브러리를 참조한 C# 컴파일과 `git diff --check`로 확인한다. 실제 Unity/WebGL 캡처, 터치 조작, 검색 입력과 원곡 재생 결과는 루트 담당이 [Validation](Validation.md)에 기록한다. 이 문서는 실행 또는 사용자 미적 승인을 대신하지 않는다. 특히 1280×720 및 가로 모바일에서 긴 카드 이름/코인/소울 값이 잘리지 않는지와 검색 입력 후 페이지 이동을 실제 빌드에서 확인해야 한다.
