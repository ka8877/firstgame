# 탄생의 첫 장: 짧은 장면과 조용한 말씀 기록

`gospel-nativity-2026-11-02`는 탄생 도입을 11개 사건 안의 **51개 짧은 이야기 화면**으로 확장한다. 기존 23개 사건 ID, 19개 발견 본문 ID·정확한 개역한글 원문, 이전 저장의 `dialoguePage` 범위는 유지한다. 구약·신약 전체나 공생애 전체를 구현한 분량이라고 소개하지 않는다.

첫 사건에서는 누가복음 1장의 나사렛·수태고지·마리아의 응답·엘리사벳 방문, 마태복음 1장의 요셉의 고민·꿈·예수라는 이름과 마리아를 맞아들이는 행동을 먼저 전한다. 이어 누가복음 2장의 호적·베들레헴·구유·목자·천사의 소식과 표적·찬송·방문·마리아의 기억을 따라간다. 이름과 할례의 팔 일, 이후의 정결 예식과 성전 봉헌을 같은 날의 사건으로 합치지 않는다. 시므온의 찬송은 기존에 보존한 2:29–32의 문장을 나누어 들려 주며, 안나의 감사와 나사렛의 성장으로 이어진다.

마지막 도입 사건은 `또 다른 복음서의 시선`이라는 시간 표지 아래 마태복음 2장의 박사들의 집 방문·애굽 피신·헤롯의 폭력과 애도·나사렛 귀향을 돌아본다. 목자들과 박사들을 같은 밤 구유에 모으거나 예물이 세 종류이므로 방문객도 세 명이었다고 단정하지 않는다. 누가복음 2:39의 배열과 마태복음의 피신을 근거 없는 날짜로 맞추지 않는다. 구유·사관은 본문에 있으나, 정확한 생일·계절, 동굴/마구간 형태, 여관 주인의 거절 대화 등 기록되지 않은 세부를 사실로 덧붙이지 않는다. 새 원화는 사건을 이해하기 위한 상징적 장면이며 건축·인물 외모의 실증 복원은 아니다.

이는 복음서가 전하는 사건을 따라가는 서사다. 종교적 기록을 별도 사료로 독립 입증된 근대 역사 사실과 혼동하지 않는다. 헤롯과 구레뇨의 연대 문제를 임의로 해결하거나 정확한 탄생 연도를 제시하지 않는다. 직접 인용은 기존에 보존한 정확한 개역한글 본문에서만 추출한다. 새 누가복음 1장·마태복음 1–2장·누가복음 2:12–14 등의 부분은 출처가 표시된 현대어 요약이다. 극화 대화는 직접 인용과 구분하며, 기록되지 않은 예수님의 발언을 만들지 않는다. 열두 살 성전의 시간 표지도 누가복음 2:46의 `사흘 후`를 사용하며 세 날 모두를 수색에 썼다고 추가하지 않는다.

## 저장과 사건 경계

선택적인 schema-one 정수 `chronicle.storyDetailPage`를 더한다. 이전 JSON에 이 필드가 없으면 0이며, 같은 사건과 같은 기존 `dialoguePage`의 첫 세부 화면에서 이어진다. 기존 사건의 순서나 식별자, 기존 대화 인덱스가 다른 사건으로 바뀌지 않는다. 새 세부 화면의 저장은 화면 문장·출처·장면·음성 키까지 같은 위치로 복원한다. 음수·범위 밖 인덱스나 이동/완료 상태의 열린 세부 화면은 저장 검증에서 거부한다. 이전 원본 파일의 보존과 필드 공간 이동은 기존 App 저장 포크 정책을 따른다.

`StoryBeatIndex`/`StoryBeatCount`는 현재 사건 안의 실제 화면 위치와 개수다. `StoryVoiceKey`는 안정 사건 ID와 그 실제 인덱스를 잇는 `questId:index`이며, `CurrentStoryReference`는 그 화면의 실제 출처다. 구형 `DialogueIndex`/`DialogueCount`/`CurrentDialogue`와 `GetBeats`는 기존 저장·어댑터용 범위를 유지한다. 실제 현재 게임은 `AdvanceStory`로 세부 화면을 진행한다. 마지막 세부 화면을 마쳤을 때에만 기존 사건의 본문을 한 번 발견한다. 책 열기·표지·차례·음성 재생은 이 경계를 호출하지 않는다.

## 오프닝의 알림과 음성

도입에서 발견한 본문은 저장한 뒤 바로 다음 이야기 화면으로 이어진다. 별도 보상 책 화면이나 읽기 확인을 요구하지 않으며, `성경에 말씀이 추가되었습니다.`라는 작은 알림만 남긴다. 도입의 발견 차임과 대사 이동 효과음을 억제한다. 필드의 기존 발견 책 표현은 별도 경로로 보존한다.

선정한 핵심 음성은 총 28개 화면이다. 현재 `Tools/Voice/Nativity/dialogue-lines.json`은 기본22개와 추가6개를 합친 문안이며, 추가 문안은 `essential-additions.json`에도 별도로 기록한다. 최초22개 문안 파일은 `Artifacts/Validation/Nativity/AudioVoice/Source/Tools/Voice/Nativity/dialogue-lines.json`, 이미 생성한 음원·통과한 ASR 근거는 `Artifacts/Validation/Nativity/AudioVoice/Base22`에 보존한다. 그22개의 문구·화자·키와 음원 바이트는 변경하지 않고 추가6개의 생성·검증은 별도의 계보로 묶는다. 대사와 음성의 키·정확한 문장이 일치할 때만 재생하며, 장면을 넘기거나 책을 열거나 불러오기를 하면 이전 음성을 중단한다. 일반 한국어 AI 내레이터를 사용하며 실존 인물의 목소리를 복제하지 않는다. 실제 생성·출력·ASR·청취 범위는 오디오 담당의 새 생성 근거와 런타임 검증을 따른다. 소스만 작성한 이 문서를 실행 통과나 사람의 청취 승인으로 대신하지 않는다.

## 실제 검증 계약

새 Core 테스트는 51개 출처·인용 경계, 기존 JSON의 선택 필드 누락, 세부 화면 저장/복원, 마지막 사건 경계에서만 획득, 잘못된 세부 인덱스의 원본 보존, 수태고지→요셉→호적의 순서를 확인한다. 기존 전체 23사건/19본문·원본 책 개인정보 숨김 검사는 유지한다.

새 `GospelNativityStorySmokeTests`는 실제 App/Native UI에서 첫 세부 화면의 이중 클릭 방지와 전체 재시작, 책을 연 뒤 폐기된 같은 장면의 콜백을 호출해도 숨은 이야기를 진행하지 않는 경계, 비어 있는 성경의 표지/차례, 작은 알림 후 다음 이야기, 본문 19회의 실제 책 원문, 발견한 차례 링크, 물리 XZ 이동과 NPC 대화, 잘못된 깊이에서 상호작용 거부, 방향별 보행/달리기, 실제 소년·성인 등잔 크기, 대화/위치 저장·복원, 이전 필드 저장의 새 슬롯 포크와 원본 바이트를 확인한다. 실제 실행·브라우저 입력·배포는 유일 실행 담당이 새 `Artifacts/Validation/Nativity` 근거로 수행한다.
