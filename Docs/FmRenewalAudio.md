# 판마 리마스터 음악 전환과 카드 효과음

현재 개정은 `fm-renewal-2026-10-29`다. 원작 제작자가 공개한 로그인·로비·덱 편집 발췌와 전투 녹음의 원본·출처를 보존한다. 이번 변경은 실제 재생 전환과 카드 행동별 효과음을 다듬는다. 전체 원작 클라이언트의 마지막 버전 음악을 회수했다고 표시하지 않는다.

## 장면 음악

기존에는 나가는 곡을 0.18초에 줄이고 들어오는 곡을 0.42초에 올려 전환 중 음량이 깊게 꺼졌다. Windows의 `FmLocalMusicHost`와 Web의 로컬 음악 제어기를 모두 **0.55초의 동일한 길이, 등전력 곡선**으로 맞췄다. 두 곡이 정상적으로 겹치는 동안 각 이득의 제곱 합이 일정하도록 한다. 첫 곡 또는 음소거 해제도 부드럽게 들어온다.

새 곡이 준비될 때까지 기존 곡을 유지하며, 실제 로그인/로비/덱/전투 역할이 바뀌면 선택한 곡을 0초부터 시작한다. 같은 화면의 다시 그리기, 설정 열기, 음량 조절은 다시 시작하지 않는다. 음소거는 현재 위치를 보존하고 재생 중 소리를 멈춘다. 빠른 화면 왕복에서 이전 재생 요청과 타이머가 새 요청을 중단하지 않도록 기존 취소 토큰과 역할 번호를 유지했다.

Web은 같은 출처에 포함한 네 개의 로컬 파일과 기존 HTMLAudio→WebAudio Gain 경로를 사용한다. 외부 음악 플레이어·광고·음성 소스를 추가하지 않았다. 브라우저의 첫 실제 사용자 입력 조건은 그대로 적용된다. SOUND-I의 짧은 공개 발췌는 전체 원곡과 다르며, 전환 개선이 잘린 원곡의 복구를 뜻하지 않는다.

## 같은 곡의 반복 경계

장면 전환과 별도로 기존 전투 녹음을 디코딩해 반복 끝과 시작을 검사했다. RMS 0.005 미만인 처음 0.80초와 마지막 0.94초가 만나 **매 반복마다 약 1.74초의 매우 작은 소리 구간**이 생겼다. 로그인 발췌에도 처음 0.34초의 낮은 음량 구간이 있었다. 로비·덱은 같은 기준의 앞뒤 공백이 없어 파일을 바꾸지 않았다.

전투는 정규화한 원본의 0.85–59.35초를 사용하고 0.35초의 등전력 순환 겹침을 적용해 **58.15초** 루프로 만들었다. 로그인은 기존에 조합한 무음성 발췌의 0.35–18.52952381초를 사용하고 0.30초 겹침으로 **17.87952381초** 루프로 만들었다. 겹침에서 소비한 첫 부분 다음 샘플부터 파일을 시작하므로 끝에서 첫 부분을 두 번 재생하지 않는다. 이것은 기록된 편집이며 원작 파일 그대로 또는 빠진 원곡 복구로 표시하지 않는다. 원 제작자 MP3와 이전 런타임 Ogg/MP3는 보존한다.

새 Ogg와 MP3를 모두 다시 디코딩하여 실제 반복 경계 전후 1초를 10ms 단위로 검사했다. 두 형식 모두 RMS 0.005 미만 구간이 0개이고 클리핑도 0이었다. Ogg의 경계 최저 RMS는 로그인 0.00774, 전투 0.00752다. 네이티브와 Web Ogg는 같은 바이트이며 Web MP3는 같은 편집 PCM의 별도 인코딩이다. 로비·덱 파일 6개의 해시가 모두 유지되었다. 재현 도구와 원본/출력 해시·측정값은 `Tools/Audio/Renewal/polish-loops.py`와 `loop-polish-manifest.json`에 있다. 별도 런타임 플레이어나 비동기 루프 제어를 추가하지 않았다. 실제 브라우저 반복 출력 확인은 릴리스 검증과 구분한다.

## 카드 소리

새 PCM 효과음은 9개다. 기존 클릭·카드 뽑기·셔플 3개를 보다 낮고 짧은 타격과 종이 마찰로 교체하고, **코인 앞면/뒷면·능력치 상승/하락·카드 착지·상위 카드 공개** 6개를 더했다. 기존 25종과 합쳐 런타임은 31개 의미별 큐를 로드한다. 기존 원본 효과음 파일은 보존하며 새 파일을 우선 읽는다.

- 코인은 Core가 확정한 앞면/뒷면을 각각 다른 금속 울림으로 낸다. 화면에서 동전을 다시 굴리거나 게임 난수를 소비하지 않는다.
- 능력치 확정은 실제 합계 변화가 있을 때 상승/하락 소리를 한 번 낸다. 동전 소리를 중복해서 덧붙이지 않는다.
- 종이·코인·공격·피해의 반복 소리에 순번 기반 ±2.5% 음높이 차이를 주어 동일 파형의 기계적인 반복을 줄인다.
- 효과음 풀을 16개로 늘리고 전투/결과 소리를 우선한다. 가벼운 마우스 오버나 클릭이 진행 중인 타격·동전·승리 소리를 빼앗지 못한다.
- 효과음 음소거/음량은 BGM과 별도이며 이미 재생 중인 소리에도 적용한다. 자동 저장과 단순 화면 재생성으로 새 효과음을 재생하지 않는다.

`Tools/Audio/Renewal/render-sfx.py`는 고정 시드 합성으로 44.1kHz/stereo/PCM16 WAV 9개(949,428바이트)를 만든다. 모든 파일의 유한값·시작/끝 0·DC 절댓값 0.001 미만·비무음 RMS·클리핑 0을 실제 PCM으로 검사했다. 출처·해시·측정값은 `sfx-manifest.json`이다. 제3자 녹음이나 원작에서 추출한 소리로 소개하지 않는다.

## 검증 범위

새 음악 JavaScript는 `node --check` 구문 검사를 통과했다. WAV 검사는 파일 분석이며 실제 Unity/Web 출력·장면 전환·음소거는 Release 실행 기록에서 별도로 검증한다. 사람의 청취 평가나 물리 모바일 성능을 이 문서로 주장하지 않는다. 읽기 전용 `FmSfxHost.History`에는 실제 요청 큐·소스 음량·음높이·팬·클립 길이가 있고, Web 음악의 기존 진단 API와 출력 관찰 경로를 유지한다.
