# 참고 자료

현재 제공된 것은 `Docs/Brief.md`에 보존한 개발 요청이다. 이전 웹 시제품, ZIP, 승인한 카드 일러스트나 예수님 컨셉 원화는 작업 공간에서 발견되지 않았다. 따라서 승인된 원화가 이미 들어온 것으로 취급하지 않는다.

추후 제공된 자료는 원본을 이 폴더에 보존하고, 출처·저작권·사용 범위·승인 상태를 `Docs/AssetRegister.md`에 기록한 뒤 제작 참고로 사용한다. 웹 시제품은 화면과 분위기 참고이며 두 독립 Unity 프로젝트의 게임 실행 경로가 아니다.

새로 만든 임시 3D 소스/실제 Blender 렌더는 `Tools/Art`에 있다. 이는 이전 시제품이나 사용자 승인 원화가 아니다.
