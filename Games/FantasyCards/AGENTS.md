## 현재 사용자 원본 카드·효과음·상위 등급 개정

현재 개정은 `fm-restoration-2026-10-27`, 릴리스 프로필 `restoration`이다. 아래 Arcana의 재조립 카드 프레임 지침보다 최신 사용자 요청이 우선한다. 손패·도감·상세·전장·드래그에 원본 인쇄 카드 전체와 실제 원본 종횡비를 기본으로 사용한다. 원본 PNG 픽셀·GUID·ID를 보존하며 실제 변동 AP/DP/HP와 현재 DB 설명은 카드 밖에서 읽는다. 출전605종·20개 기본 덱(단일7·듀얼13)과 별도 감상 전용 원본30종의 수와 지원 기술을 섞지 않는다.

원작 대기실의 실제 자료를 참고한 방 목록·우측 프로필·구체·하단 이동을 구현하며 ROOM의 AI3상대, 실제4과제 SCENARIO, 준비 중인 MULTI를 구분한다. 시나리오 저장 식별과 실제 승리로만 해금하고 가짜 온라인 이용자·채팅·매칭을 만들지 않는다. BGM과 UI·카드·전투 효과음은 별도 음량/음소거로 다루며 UI와 오디오는 RNG를 소비하지 않는다. 카드 규칙/저장 `fm-classic-0.1.0`·schema3와 기존 슬롯은 유지한다.

현재 계약은 `../../Docs/FmRestorationUI.md`·`FmRestorationCards.md`·`FmRestorationAudio.md`, 현재 실행 근거는 `../../Docs/RestorationValidation.md`와 `Artifacts/Validation/Restoration`이다. ## 소유권과 구현

- `Assets/Game/Core`: Unity에 독립된 규칙/실행 상태. 161종(기존96종의 ID·수치·원본 보존), 7속성, 현재 포함5등급, 50장4덱, 6손패, 5전열, LP·색소울·총소울, 양측 준비와 자동 공방이다. RNG는 Core만 소비한다.
- `Assets/Game/Presentation`: `FantasyCardsRevival`이 타이틀→로컬 대기실→대전실→덱→시작 손패를 구성한다. 실제 원작 웹 인물을 유지하고, 금속·황동 테두리/속성 기호를 해상도 독립 UI 도형으로 그리며, 예전 창작 아바타는 활성 흐름에 두지 않는다. 5열×2전열/우측소울·덱/6손패 구성을 사용한다. 버튼·상세·셔플·저장과 실제 Core 판정이 연결되어야 한다.
- `FmOriginalMusic`, `Plugins/WebGL`, WebGL template: 원 제작사 공식 공개 플레이어 연결. 창작곡을 원작 BGM으로 대체하지 않는다. 원곡 소스와 실제 출력 검증은 구분한다.
- `Assets/Resources/Art/Revival`: 공식2005 안내와 웹로그인 GIF의 전체 무손실 PNG 디코딩본. 원본과 출처·픽셀·해시를 `Tools/Research/FmRevival`에 보존한다. 번호·옛채팅이 포함된 스샷 전체를 배경 UI로 쓰지 않는다. 원작 웹 인물 타일은 실제 UI에서 배치한다. 낮은 해상도의 스크린샷 가장자리나 체크무늬 로고 배너를 확대해 새 프레임으로 쓰지 않는다.
- `Assets/Resources/Art/ClassicCards`: 원작161종/뒷면(기존96종 보존). `Docs/ClassicCardArt.md`의 출처와 픽셀 검증을 유지한다. 원래 인쇄 수치와 현재 DB/진행 중 수치를 구분해 표시한다. 도감의 검색·필터·정렬·페이지·덱 수량은 실제 CardCatalog에 연결하며 카드 수를 고정하지 않는다. 전체 원본은 상세 화면에서 종횡비를 유지해 표시한다.
- `Assets/Game/Data`: 전체 `CardDefinition`을 보존하는 제작용 CardAsset/RuleSetAsset. 실행 상태를 ScriptableObject에 기록하지 않는다.
- `Assets/Game/Tests`: 규칙·저장 결정론. 새 화면의 실제 동작은 해당 개정 smoke/browser 결과로 검사한다. 이전 아바타 화면의 통과 결과를 새 화면 결과로 대신하지 않는다.
- `Assets/Editor`, 씬, 공통 저장/빌드와 메타는 루트 담당과 협의한다. 같은 씬/프리팹을 동시에 편집하지 않는다.

Unity6000.3.26f1, C#/URP/uGUI+TMP/Input System. manifest/lock이 패키지 버전의 기준이다. 기존 checkout을 사용하고 별도 worktree를 임의로 만들지 않는다. 에셋과.meta를 함께 관리하며 캐시·빌드·인증 정보를 커밋하지 않는다.

## 저장과 한계

내부 schema3, 공통 봉투 schema1, Game ID `starlight-oath`, `fantasy-battle-classic-v3`/`fantasy-deck-classic-v3`를 유지한다. 이름은 외부 저장 호환 ID다. 기존 `leaderId`도 저장 호환을 위해 보존하며 새 화면에서 원작 리더 능력으로 소개하지 않는다. 손상·미지원 저장의 원본을 보존한다. 가져오기 후 이전 engine이 새 저장을 덮어쓰지 않도록 한다.

현재 방 목록은 실제 로컬 AI 연습전 진입점이다. 온라인 접속자·채팅·매칭을 꾸미지 않는다. 남아 있는 공개 스크린샷과 웹 인물을 사용한 첫 구현을 원작 클라이언트 전체 소스 복원이나 픽셀 단위 완전 복제로 소개하지 않는다. 원작 시기별 UI/규칙 근거, 이번 실행/음악 출력/기기 성능과 사용자의 미적 평가를 구분한다. 최신 검증은 `../../Docs/Validation.md`에 기록한다.
