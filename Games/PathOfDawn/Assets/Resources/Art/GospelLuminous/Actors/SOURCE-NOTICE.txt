Luminous actor artwork and rendering

jesus-parts.png and npcs.png are original image-generation outputs created for
this project. They are not extracted Ori, Lost Crypt or other commercial-game
character art. Original pixels, alpha channels and file hashes are recorded in
Tools/Art/GospelLuminous/Actors/manifest.json. Runtime sprite rectangles only
select those pixels; there is no source-pixel postprocessing.

LuminousCloth2D.shader adapts the material/pass contract of Unity URP 17's
Mesh2D-Lit-Default.shader for this project's deforming cloth meshes. It uses
Unity's package shader includes. Changes: two-sided alpha rendering without
depth writes, explicit material tint, and mesh-normal rendering independent of
SpriteRenderer-only per-draw properties (including correct mirrored tangent
handedness). The original Unity shader/package copyright remains:
