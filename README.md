# FirstGame · 두 게임 체험판

두 독립 Unity 프로젝트의 개발 저장소입니다.

**[설치 없이 두 게임 플레이하기](https://ka8877.github.io/firstgame/)** · PC 및 모바일 가로 화면. 업데이트 후에도 같은 주소를 사용합니다.

현재 소스는 **판타지마스터즈 클래식 규칙 체험판과 일러스트 2.5D 서사 체험판**입니다. 카드 개정은 `fm-classic-2026-10-26`이며, 원작 공개 DB의 카드와 보존된 공식 가이드를 바탕으로 한 비공식 체험판입니다. 새벽의 길의 최신 시각 개정은 `painted-dawn-2026-10-24`입니다. 아래 표는 구현 범위이며, 새 빌드의 검증·공개 URL 반영 여부는 [검증 기록](Docs/Validation.md)을 확인하세요. 이전 공개판의 통과 결과를 새 버전의 검증으로 간주하지 않습니다. 모바일 브라우저 에뮬레이션과 실제 휴대폰 검수도 구분합니다.

| 게임 | 프로젝트 | 현재 범위 |
|---|---|---|
| **판타지마스터즈 · 클래식 규칙 체험판** | `Games/FantasyCards` | 원작 카드 96종·7속성·5등급, 아바타 4명, 50장 기본 덱 4종, 체험 결투 3전, 6장 손패·전체 셔플, 양측 준비·자동 공방, 도감 필터·덱 편집·저장 |
| **새벽의 길** | `Games/PathOfDawn` | 회화풍 호숫가·석조 방, 전신 만화 인물·보행 atlas의 2.5D 탐색·대화, 초반 한국어 AI 음성 20줄, 선택 두 번·결과 세 가지·기억과 회귀 |

Unity **6000.3.26f1 LTS (de8167e7440c)**를 사용합니다. 두 폴더를 각각 Unity Hub에서 여세요. 첫 import가 끝나면 `FirstGame > Prepare First Slice`로 씬·URP·한국어 글꼴·제작 데이터·프리팹을 준비하고 `Assets/Scenes/Boot.unity`에서 Play합니다. 현재 실행 검증 여부와 제한은 반드시 [검증 기록](Docs/Validation.md)을 확인하세요.

카드는 공개 DB에서 확인한 원작 이름·수치·이미지 96종을 사용합니다. 암흑·불·물·숲·금속·대지·빛 7속성과 프리·커먼·언커먼·레어·스페셜 5등급이 들어 있으며, 상세 화면에서 원본 카드 전체를 볼 수 있습니다. 지형 14종·유닛 56종·마법 14종·아이템 12종을 속성·종류·소울 비용·등급으로 찾고, 카드별 편성 한도를 지켜 50장 덱을 구성합니다. 리리아·카엘·세린·노아는 선택 가능한 아바타이며 이번 규칙에서는 고유 기술을 사용하지 않습니다.

전투는 LP로 지형을 전개하고 소울로 카드를 사용한 뒤, 공격측과 방어측이 모두 **준비 완료**하면 전열 순서대로 진행됩니다. 지형은 최대 10장, 유닛과 예약 마법은 전열 5칸을 공유합니다. AP·DP·HP와 코인 결과가 전투에 적용되며, 직접 공격은 공격 유닛 레벨만큼 상대 덱을 파괴합니다. 매턴 손패를 6장까지 보충하고 각 준비 단계의 카드 사용 전에 전체 손패를 한 번 다시 섞을 수 있습니다. 마우스 설명·터치 상세·카드 비용 곡선·저장과 이어하기를 제공합니다. 원작의 모든 카드와 예외를 복구한 공식 서비스는 아니며, 자료와 구현 범위는 위 클래식 문서에 기록합니다.

새벽의 길은 얼굴과 배경의 완성도를 높이기 위해 따뜻한 일러스트 2.5D로 구성합니다. 꽃과 올리브나무·호수·석조 집이 있는 호숫가와 빛이 드는 석조 방을 새로 그리고, 전신 만화 인물과 앞뒤 걷기 그림을 실제 이동에 연결합니다. 대화할 때는 인물을 크게 보여 주며, 기존 이동·상호작용·한국어 원문·선택·저장·회귀를 유지합니다. 초반 도입 9줄과 호숫가 11줄에는 일반 한국어 MeloTTS 음성을 넣습니다. 한 명의 일반 음성이며 실존 배우의 음성 복제나 인물별 연기를 제공하는 구성은 아닙니다.

두 게임에는 서로 다른 오리지널 오케스트라 BGM이 포함됩니다. Web에서는 로딩 뒤 게임 화면을 한 번 클릭하거나 탭하면 오디오가 활성화됩니다. 카드는 **음악**에서 켜기/끄기·음량을, 서사는 **설정**에서 음악·대화 음성을 조절하고 현재 음성 대사를 다시 들을 수 있습니다. 실행 중 외부 음악·음성 생성 API를 호출하지 않습니다. 자세한 조작은 [첫 플레이 안내](Docs/PlaytestGuide.md#배경-음악과-음량)를 참고하세요.

PC 마우스/키보드와 모바일 가로 화면의 터치 입력을 유지합니다. 표정·손짓·걷기 자세의 연결과 립싱크, 전투 효과·음향의 최종 완성도와 실제 휴대폰 성능은 남은 검수·제작 범위입니다. 실제 측정 전에는 목표 플레이 시간·60fps·상용 게임 수준의 비주얼을 달성한 것으로 간주하지 않습니다. 카드 새 버전은 별도 저장 슬롯을 사용해 이전 전투·편집 덱 파일을 보존합니다. Git LFS를 설치하고 클론해야 모델·그림·글꼴·음원을 받을 수 있습니다.

새벽의 길의 현재 움직임 개선(`fluid-dawn-2026-10-24`)은 [DawnMotion](Docs/DawnMotion.md)에 설명한다. 방향 전환 지연·제동·터치 패드와 자세 보간을 개선했으며 최신 검증/배포 결과는 [Validation](Docs/Validation.md)를 따른다.
