# Fresh Native selection

Root runs this only after the final selected attempt has actually passed and the current frozen source remains unchanged:

```bash
python3 Tools/Validation/SharpIllustration/select-native.py FantasyCards CardNative02 --confirm-fresh-only-copy
```

Use the actual final game/attempt, not this example as a claim of a result. The explicit `sharp-illustration` environment is required. Root may invoke it through the current owned generic wrapper so the selector source and execution are captured.

The selector authenticates the exact frozen Card11/Gospel18 XML test set, binding/inputs/current full per-game source fingerprint, driver/selector/registry/three contract snapshots, actual acquired cycle and event windows, accepted contained guard/optional preparation/Native execution and complete descendant cleanup. It binds the original producer's five Native payloads, original runner and Gospel voice fixture without rewriting any embedded paths. Generated TMP font-cache before/after metadata stays byte-preserved rather than being mistaken for immutable current font assets.

Only absent destinations are accepted: `OUT/Native/<game>`, `OUT/Screenshots/<game>` and `OUT/NativeSelections/<game>-<attempt>`. Existing parent directories for the other game are allowed. All five Native payload files and every file/directory of the actual original capture tree are copied, with complete SHA/size/path readback and a second authentication of the unchanged current source and original attempt. Every required changed-area Native PNG suffix must already exist. No prior path is overwritten, moved, deleted or cleaned up.

The new selection directory contains `before.json` and, on success, `selection.json`. A copy failure instead adds `failure.json`, preserving every original and partial destination. There is no automatic retry or rollback. The successful selection ledger is provenance only: Root must separately directly view the actual originals and write its Native review. No source, art, image, product or publication approval is fabricated.

This helper was authored and independently statically reviewed only; its author did not import/run it, inspect current attempt results, execute tests, hash products, or perform Git/network actions.
