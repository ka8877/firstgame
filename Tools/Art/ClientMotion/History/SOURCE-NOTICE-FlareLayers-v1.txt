No weapon/shield layers or Flare gameplay are selected. Whole unchanged source
atlases also contain unused action/death drawings; only their stance and run
rectangles are referenced by the Unity character metadata.

Changes: original PNG bytes are copied unchanged. Original packed rectangles
and anchor offsets are translated to Unity's coordinate system, preserving all
five layers on one synchronized authored pose. Alpha is read only to measure
visible bounds and the common per-pose sole offset; no PNG is cropped, edited,
recoloured, resampled or composited. A shader colours cloth at runtime, retaining
original sampled shading. Skin and head pixels retain their original palette.
Character identities, clothing colours, metre scale and foot-contact metadata
are project presentation choices. The child uses the same clean short-haired
avatar at the existing child height; it is not claimed to be a separate authored
child anatomy model. This requires direct small-scale visual review.

Original directions: SW,W,NW,N,NE,E,SE,S, confirmed by hero_layers.txt and the
original engine direction convention. Unity's fixed yaw0 camera maps those to
world yaws 225,270,315,0,45,90,135,180 degrees respectively. The source contains
four stance poses and eight run poses per direction. Walking and running use
the authored locomotion cycle at a distance-matched rate; no separate walk take
is claimed. Flare provides no jump take: actual physical jumps retain selected
locomotion drawings while the unchanged motor owns flight and landing.

Tools/Art/ClientMotion/install_flare_layers.py performs no image write except
exact source byte copies, verifies original files against the saved upstream
tree and records all derived metadata. Only the release owner executes it.
