# Actual cloth outer seam, source handoff 2026-11-18

V8 preserves V7 and retains class/API `GospelCharacterGarmentsV2.Apply`, existing output assets and renderer identity. It replaces the outer ellipse query with measured points on the actual retained Linen/FittedLinen triangles. WarmSkin is explicitly ineligible as an outer seam source; its measurements and optional intermediate cover-lift role remain.

For each angle, radial direction `(sin(angle),0,cos(angle))` and normal `(cos(angle),0,-sin(angle))` define the actual vertical plane through the measured neck center. Each eligible source triangle is cut with that plane. Its actual cut segment is analytically clipped to the unchanged measured Y band and a safe radial interval. Existing physical dimensions define that interval: `innerRadius + Clearance` through `shoulderHalf - Thickness`; final anchors must also satisfy `r > innerRadius + Thickness` and `r < shoulderHalf`. No radius stepping, wider shoulder threshold or arbitrary Y search is used.

The candidate is the exact 3D closest point on the remaining actual segment to the measured inner anchor. Coplanar triangles are clipped by the same four Y/r half-planes with source barycentric coordinates retained, then the complete remaining polygon is searched using its fan triangles, including polygon interiors. Near-plane vertices are never snapped onto the radial plane. The original triangle's vertex normals are blended from the final original barycentric coordinates and normalized. Selected cloth triangle/submesh, original vertex IDs, barycentric coordinates, actual point/normal, radial distance, anchor distance, plane residual and method are reported for each angle.

There is no skin or invented-surface outer fallback. No valid source point causes `FIRSTGAME_CLOTH_OUTER_SEAM_DIAGNOSTIC` and an explicit failure, with up to 512 actual cuts and rejection reasons. Intermediate rows remain fabric lofts between the measured inner and outer seams, lifted only by an actual source surface above the chord. Existing thickness, full four-bone weights, native bindposes, closed-index manifold, nonzero triangle area, UV/tangent and source mesh/hash preservation checks remain. The report flags main-ring samples and measures their next-neighbor outer distance and its maximum, including loop closure, to expose possible source-layer jumps. The placket's extra angles do not divide those main-ring edges. These measurements are not a visual or continuity approval.

Only source was read/authored. No actual runtime, compiler, test, PNG or log was read or executed. Root must compile/generate and inspect complete actors and animation attachment. Actual-source endpoints alone do not establish a smooth or nonintersecting collar during movement.
