# Bounded actual-cut branch search, source handoff 2026-11-18

V12 preserves V11 and changes only overlap-path search/diagnostics. API/output root, 5 mm physical chord, end height, actual source triangle/barycentric anchors, Y/r/anatomical-sphere clipping, full native palette/inverse skin/read-back/0.5 mm gate, closed thickness/sidecar and all Native proposals remain unchanged. No actual asset or other model recipe was read or changed by this author.

Instead of committing to a single greedy walk, an iterative depth-first stack explores other actual adjacent branches when a path ends, closes a local cycle or fails the goal. Parent states and their actual cut segments are immutable; each child copies its path list, visited edges and visited nodes. A full path never revisits a node/edge, and no join exceeds the unchanged weld distance. Down/forward remain ordering preferences, not a ban on initially ascending folds. Reverse stack insertion retains that priority. A partial successful endpoint is returned without contaminating the full source-edge state used for another branch.

Success candidates lie on the actual source segment. Analytical events include the physical width-sphere crossings and contact-height crossing; derived interval midpoints and full endpoints cover the remaining valid segments. Thus a state already outside the width sphere can continue down to a valid end without requiring another sphere crossing. Every returned point is rechecked for actual chord >=5 mm, unchanged path length/weld budget and end Y <= contact Y. Nothing replaces the design width with a smaller value or an invented lower point.

Queued plus explored branches are bounded to 4096. Budget exhaustion is reported separately from a completed search finding no valid simple path. Failure diagnostics include states/depth/join rejections and the contact-connected cut component's exact endpoints, bounds, maximum possible chord and maximum chord at/below contact height. A tiny contact component can therefore be distinguished from an incomplete search; it may call for another measured artist seam choice, not a silently weakened requirement.

Only source was authored/read. No runtime/compiler/test, actual asset or evidence was read/executed. Root must perform the actual preparation, complete actor and pose inspection before approval. The graph search is over the represented actual cut graph and does not prove absence of every possible path on the entire 2D garment surface.
