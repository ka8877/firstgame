# Downward source-cloth overlap path, 2026-11-18 source handoff

V11 preserves V10 source and all prior assets. Class/API, new `GarmentsV1/v2` output, full Body-native palette/frame/bindposes, Auto/Unlimited, inverse-skin reconstruction, native weight read-back, 0.5 mm neutral gate, thickness, UV/tangent, closed topology and sidecar are unchanged. The Native proposal and all Card/test/contract/harness files are unchanged by this author.

V10 wrongly required 5 mm radial growth. Root supplied a back-shirt failure showing a near-vertical actual cloth surface where physical downward overlap exists while radial growth does not. V11 removes only that radial-extension overlap recipe. It cuts actual same-source/component Linen triangles with the radial plane, clips actual segments to the existing Y/r bands and anatomical sphere, then builds an endpoint-connected cut graph using the existing weld budget. Contact is split into the graph. Coplanar contact triangles include an actual in-triangle downward connector and source-surface spokes/edges; original triangle barycentric coordinates remain attached to every segment. Endpoints split shared source edges so an interior contact or a clipped UV junction can connect without fabricating closure.

The initial direction favors lower cloth. Subsequent choices favor directional continuation and do not revisit edges. This is a bounded preferred walk, not an exhaustive search proving that every other branch is absent. The graph is walked until the actual endpoint is at least 5 mm from contact and no higher than contact. The width sphere includes only the existing plane-resolution margin to avoid a float-rounded endpoint below 5 mm. A partial-segment stop that fails the final direction/width condition fails that walk instead of jumping to the original segment endpoint. Anatomical sphere clipping applies to complete segments, not only their nearest point. The resulting actual surface arc can be longer than its 5 mm chord; this is an actual connected polyline, not a claimed shortest geodesic. Arc, chord, maximum measured weld join gap and every source-triangle/barycentric segment are reported.

The arc is cached once per angle. Both overlap midpoint and outer endpoint are sampled by cumulative arc length on that same path; they are not separately reselected by radius or nearest-point search. Each sample uses its own actual source triangle and full native weights. No missing path is converted into an invented lower Y or an off-cloth extension; it produces a bounded `FIRSTGAME_CLOTH_OVERLAP_PATH_DIAGNOSTIC` and fails.

Only source was read/authored. No actual runtime, compiler, assets or evidence was read or executed. Root must compile/generate, inspect complete actors and measure actual neutral/idle/walk attachment before approval. Source anchoring and a connected rest-pose path do not establish animation quality by themselves.
