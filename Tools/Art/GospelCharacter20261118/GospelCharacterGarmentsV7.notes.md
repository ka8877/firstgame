It retains the original neck-bone and measured slice-center planes in the same order. If neither qualifies, it tries additional finite planes in ascending order from the actual neck-bone Y up to the measured neck-slice maximum.

Each additional candidate is either an exact drawn WarmSkin neck-slice vertex height or the midpoint `lo + (hi - lo) * .5f` of adjacent measured heights/boundaries. The neck-bone lower boundary is explicit provenance, not a fabricated source vertex. Equal float candidates are deduplicated; an interval without a representable interior midpoint is counted. Original mesh vertex IDs are retained and grouped for every lower/upper source height. The complete unique candidate set is bounded to 256: after the original planes fail, an oversized additional search fails explicitly without sampling or truncating the search set. Existing successful original planes are not blocked by that cap. Failure JSON may bound its diagnostic candidate list separately and reports that truncation explicitly.
