Gospel Pilgrimage original artwork — 2026-10-30

These Jesus age variants, NPCs and illustrated portraits were generated as
original development artwork for this project. They are not extracted FINAL
FANTASY RESONANCE sprites, portraits, code or game data. Official reference
images remain research material under Tools/Research/Quest and are not used
as these game characters.

All adopted PNG files are exact byte copies of their retained generated source
files. No resizing, repainting, alpha cleanup, quantization, re-encoding or
raster editing has been performed. manifest.json records original and adopted
paths, SHA256, dimensions and measured layout hashes. Earlier proportion studies
remain in generated_images and are explicitly not adopted.

The actor uses alpha-component measurements, runtime sprite UV rectangles,
feet pivots and one common pixels-per-unit scale per source sheet. Point
filtering retains the pixel source. Tiny stray components outside the principal
body region are not selected by runtime UV; the PNG and its alpha remain intact.
Walk-a/b are authored poses, not a claim of recovered original FF animation.
The illustrated status portraits remain separate from in-field pixel artwork.

Runtime shader and actor code are authored for this project. The equipped lamp
mesh and soft contact-shadow source are preserved earlier project assets, whose
source notices remain under GospelWell and GospelLuminous respectively.
