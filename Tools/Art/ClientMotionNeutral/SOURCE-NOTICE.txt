Project adaptations: child/adult/Mary/Joseph/teacher proportions and clothing
palettes; original facial/garment refinements; relaxed open-handed upright idle;
project-authored planted-foot walk and a separate longer-stride run. These
motions and educational depictions are adaptations, not original Flare combat
clips, historical likenesses, or an endorsement by the artist or Flare team.
Added project geometry includes small facial features attached to the actual
head skin. Beard boundaries split the actual head topology along a horizontal
line below the mouth and assign lower-jaw materials without adding a beard
object; teacher hair is gray. Mary retains the licensed source long hair.
The child has shortened limbs, narrower shoulders and a softer unbearded face.
Rejected preview-only primitive hair, beard and veil additions are not selected
by the current baker; their earlier render proofs remain preserved.

Tools/Art/ClientMotionNeutral/bake_neutral_actors.py directly renders transparent
whole-body PNG grids in Blender. Each actor has 8 directions and 20 poses per
direction: idle4, walk8, run8. The actual 20 poses in all 8 directions determine
one padded projection scale and one common physical foot anchor per identity,
including during locomotion. There is no per-frame sole resnapping. Installation
rejects any candidate whose actual visible alpha enters a cell's 4-pixel border.

Tools/Art/ClientMotionNeutral/install_neutral_actors.py requires explicit
--candidate-root and --root and is executed only by the release owner after
visual review. It validates all five direct renders, their index/grid/reports,
source LFS identities and the exact HD license proof before writing. PNGs are
copied byte-for-byte; PIL only reads alpha to measure metadata. It does not
crop, recolour, resample, composite or write image pixels. Portraits select
head/shoulder UV rectangles from the same original whole-body rendered PNG.
