Hello guys

This package includes sprites of various Base Human Males and around 400 items for those Base Human Males, which can be layered one on another to make characters. Check out the previews for more detail (animated gifs!) and the background on this thread: https://opengameart.org/forumtopic/need-help-clearance-with-my-submission

TLDR: These were created by me from scratch as a mod for an old isometric RPG named "Siege of Avalon" and released for that game. They're based on the original items from that game, and some items share the same design (but were made from scratch!). Some items that could cause trademark issues were not included.

There are 8 animations and 8 directions (N, NE, E, SE, S, SW, W, NW) with 488 sprites/frames (PNG) per item / base body. The size of the sprites is 148x130.

- Idle
- Attack (Melee, one handed)
- Ranged Attack (Bow)
- Casting Spells
- Walk
- Run
- Pain
- Death

The bases which can use the same items also have or include:
- Normal Human Males, various skin colors, hair types with beards and tattoos
- Orcs
- Skeletons (some of them are "layered" with items)
- Elf base

The items are mostly medieval generic stuff (weapons, armor, robes, clothes) but there are also some barbarian / orc themed items.

Sadly, I was forced to render everything with hard alpha around the edges eventhough I used antialiasing, because the ancient game engine they were made for uses the bmp format, which doesn't support transparency. Also, the image size and the amount of frames were limited.

Maybe someone can use this for a project, which I'd love to see.

For the moment I don't intend to expand on these assets, but if you need anything new you can always ask me.

I am licensing these with CC-BY 4.0.

I accept donations.

Cheers,

Skyzor
