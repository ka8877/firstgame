게임데이터 - 지속상태 전체 목록
지속 상태는 에피소드 9에서부터 적용된 개념입니다.
상태지속 마법은 조건이 되는 대상에 "상태"를 부여하며 해당 상태는 지정된 턴동안 매턴 
효과가 나타납니다. 상태는 카드 이미지의 좌하단에 표시됩니다.
▶ 지속 마법의 상태 부여 후 "효과 적용 시점"
- 1턴 효과
전투턴에 마법이 발동하여 상태가 부여되는 즉시 적용됩니다.
- 2턴 효과
전투턴이 종료된 후 다음 턴의 맨 처음인 소울코스트 직전에 적용됩니다.
- 3턴 이후 효과
2턴 효과와 마찬가지로 매 턴마다의 맨 처음인 소울코스트 직전 적용됩니다.
- 마지막 적용 이후 상태의 사라짐
상태가 적용되는 즉시 아이콘이 표기되며 상태 아이콘은 상태 효과가 적용되고 있음을 의미합니
다.
다음턴에 해당 상태가 적용되지 않는다면 즉, 다음턴에는 상태가 사라진다면 상태 아이콘이 깜빡
거립니다.
▶ 상태 적용에 대한 규칙
1. 상태 적용 규칙
1) 상태가 부여된 유니트 카드가 덱이나 핸드로 가면 발동은 진행되지 않습니다. (상태는 오직 
프론트 필드에서만 적용됩니다.)
2) 동일한 상태가 중복 적용될 경우 기존 상태 적용이 사라지고 새롭게 적용된 상태로 
교체됩니다.
3) 상태는 최대 3개까지만 중복 가능하며 4번째 상태가 적용시 가장 먼저 적용되었던 
상태가 사라집니다.
2. 상태 적용 처리
1) 모든 상태는 소울 코스트 시에 발동합니다.
2) 상태의 적용은 공격자의 필드부터 처리되고, 방어자의 필드에 이어서 처리됩니다.
3) 소울코스트 시 부여된 상태는 필드 맨뒤의 필드값부터 차례대로 부여된 상태의 
효과를 적용합니다.
ex) 필드 유닛에 1번부터 3번 유닛까지 순서대로 광폭화, 크리티컬데스, 데스 상태가 부여되어 
있다면 필드 3번 유닛부터 순서대로 데스 상태, 크리티컬데스 상태, 광폭화 상태 순서로 효과를 
적용
4) 상태가 같은 필드 내에서 누적으로 적용되는 경우 뒤부터 처리가 진행됩니다.
ex) 필드 유닛에 1번부터 3번 유닛까지 순서대로 훈련상태가 부여되면 1번 유닛이 +1+1+1, 2번 
유닛이 +2+2+2, 3번 유닛이 +3+3+3으로 상태가 누적되어 처리됩니다.
5) 예외
(1) 해당 상태 적용이 진행되는 과정에서 '속박상태'가 발동하여 상대편 필드로 
넘어간 경우 '속박상태'보다 먼저 또는 나중에 적용된 상태의 처리가 달라지게 됩니다.
※ 해당 내용에 대한 자세한 설명을 원하시면 속박상태로 검색하시면 좀더 정확한 
설명을 확인 하실 수 있습니다.
(2) 결계상태는 소울코스트가 아닌 인첸트페이즈 때 발동합니다. (유지턴이 0턴 남은 경우에도 
효과 발동)

: 상태 해제시, 아군 필드 빈공간에 응축상태가 1턴간 부여된 코
론 1을 소환한다.
와일드니스 상태
: 상태 발동시, 자신을 제외한 아군 필드유닛 수만큼 AP/HP가 
감소하고, 아군 필드유닛이 자신뿐일 경우 AP/DP를 1 증가시킨다.
코러스 상태
: 상태 발동시, 아군 필드에 자신을 제외한 동일한 카드(같은 카드
번호) 유닛 수에 따라 효과 발동한다.
1 : AP+1.
2 : AP/HP+1, 기술제거 방어기술 추가 
부여
3 이상 : AP/HP+3, 환상폭발 방어기술 추가 부여
소울의주인 상태
: 상태 해제시, 자신 유소울(NCS), 속성을 아군 백필드 지형 최
대생성 유소울의 속성으로 영구히 변경한다.
렐릭파워 상태
: 상태 해제시, 아군 소각장 1 레벨 유닛 중 맨 위에 위치한 유
닛 1을 아군 필드 맨 뒤로 이동시킨다.
얼라이라이즈 상태
: 상태 해제시, 아군 소각장 1레벨 유닛 중 맨 위 유닛 2을 
아군 필드 맨뒤로 이동.
에너미라이즈 상태

아군 필드 맨뒤로 이동.
차원성장 상태
: 상태 해제시, 상태 보유 유닛의 AP,HP 1 증가 후 유닛의 일러스
트를 교체.

소울로 영구히 교체.
