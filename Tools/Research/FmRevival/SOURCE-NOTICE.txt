Fantasy Masters original interface reference material

The three interface GIFs were served by the original Fantasy Masters publisher's
online manual and retrieved from the Internet Archive. Capture URLs, redirects,
file sizes and SHA-256 values are recorded in official-ui-manifest.json.
The publisher's manual includes numbered explanation markers over the actual
game screenshots. The full screenshots are preserved without repainting.

The Unity PNG files are lossless RGBA decodes of those GIFs, not recovered
original client UI texture atlases. unity-source-images.json verifies identical
decoded pixels. Runtime UV sampling may use unannotated decorative regions.

The login_img_*.gif files are original publisher WEBSITE login-window pieces,
not proof of the original game client's launch-screen composition.

Artwork, logos and game names remain associated with their original creators.
No general redistribution license or original program source was established.
Use here follows the user's explicit original-game reconstruction request.

The SOUND-I music source is its public SoundCloud portfolio. Only metadata and
official embed URLs are recorded. No original music stream was downloaded or
copied into the player. All-rights-reserved and disabled-download metadata are
retained. External embeds require Internet and user interaction.
