# 2011 개편의 실제 원작 로그인 — 새 확인

`naver2011-client-renewal-image.jpg`를 2026-11-11 새로 내려받아 정적 이미지로 직접 확인했다. **실제 Fantasy Masters 원작 클라이언트 로그인**이다. 공식 홈페이지 그림이나 Fantasy Masters II가 아니다. 이 자료는 같은 폴더의 2010 Ver4.95 캡처보다 늦은 UI 개편 이후의 모습이다.

- 공개 원본: `http://imgnews.naver.net/image/5053/2011/08/03/20110803161338_3c81e997.jpg`
- 응답: HTTP200, 90,667B, JPEG 530×398.
- SHA256: `dabf97d8c495e4b216aa0117e5d24f4499ed8e332dc8e887bb72e8c926a43cd8`.
- 원문 응답 메타데이터: `naver2011-client-renewal-image.json`.
- 화면 우하단 버전: **Ver.5.73**.
- 발견 경로: `naver-client-login-search.html`의 공개 이미지 검색 메타데이터. 제목은 「NTCG 왕의 귀환, 판타지마스터즈 새단장 완료」, 게시일은 **2011-08-03**, 매체는 ThisIsGame, 연결된 당시 URL은 `http://www.thisisgame.com/board/view.php?id=727264&category=101`이다. 이 Naver 응답 자체의 SHA/시각도 동명 JSON에 남겼다.
- 당시 URL의 새 GET은404였고, 추정한 현대 기사 URL `/webzine/news/nboard/4/?n=28490`은403이었다. 각각 `thisisgame2011-client-renewal.*`, `thisisgame2011-modern-alias.*`에 실패 응답을 보존했다. 기사 원문을 새로 읽었다고 하지 않으며403을 우회하지 않았다.

독립적인 같은 날 제오닉스 보도자료 `daily-2011-client-renewal.html`([원문](https://www.dailyesports.com/view.php?ud=201108031601180048304_26))는 홈페이지 일러스트 변경과 별도로 게임 클라이언트의 색·일러스트·버튼·구성을 바꿨다고 설명한다.

### 추가로 복구한 당시 기사와 웹/클라이언트 동시 비교

이후 [GG게임의 같은2011-08-03 기사](https://www.ggemguide.com/news/143073/) 「NTCG 왕의 귀환 판타지마스터즈 새단장 완료」 원문을 HTTP200으로 직접 새로 읽고 보존했다. `ggem2011-native-login-source.html`54,600B, SHA256 `6c3939ac38cca2548baff0fc9aa3607a31e903707fda82a7f1f2d43b8bbb38f0`이다. 현재 사이트의 다른2026 기사 이미지들은 본문 그림과 구분한다.

당시 본문 그림 `https://www.ggemguide.com/news_screen2/b201108030207406001312351167.jpg`는 `ggem2011-native-login-image.jpg`로 보존했다. HTTP200, JPEG560×621, 103,850B, SHA256 `fc06c4b644936c6570afda9b8e7b6ecce50708c8fad0e3fa0c1d00dbad2e9b7a`, 서버 Last-Modified `Wed, 03 Aug 2011 05:59:27 GMT`다. **그림을 직접 확인했으며 위쪽 y0–195는 공식 웹 사이트, 아래쪽 y197–620은 실제 원작 클라이언트 Ver5.73 로그인**이다. 같은 보도자료가 웹과 네이티브 화면을 서로 다른 그림으로 보여 주므로 둘을 혼동할 여지가 줄었다. 아래쪽 네이티브 영역은 위 Naver 이미지와 같은 보라색 여성/불꽃 거인/검붉은 게임접속 창이다. 2014–2018년 동일 그림 유지 여부는 이 기사로 입증되지 않는다.

## 직접 확인한 모양

검고 어두운 붉은 금속 테두리, 왼쪽의 보랏빛 검은 머리 여성, 오른쪽의 거대한 불꽃 거인 얼굴, 아래쪽의 푸른 보라색 흐르는 옷자락이다. 위쪽 가운데 작은 금색 Fantasy Masters 글자와 붉은 용 모양 받침이 있다. 오른쪽 위에는 녹색/흰색 전체이용가 표시가 있다. 이 배색·금속 창은 기존2017/2018 후기 클라이언트의 검붉은 테두리와 더 가까우나, **2014–2018에도 이 로그인 원화가 그대로였다는 것은 아직 확인하지 못했다.**

530×398 원본에서 대략적인 좌표는 다음과 같다(픽셀 판독 오차가 있는 관찰값).

| 요소 | 영역 |
|---|---|
| 전체 화면 | 530×398, 거의4:3 |
| 원본 로고와 용 받침 | x178–355, y0–40 |
| 로그인 창 바깥틀 | x171–360, y81–192 |
| 게임접속 제목 | 중앙 x~264, y~94 |
| 입력칸 | x235–341, y110/129/148 부근의3행 |
| 하단 버튼 | y174 부근, `ID만들기`/`접속하기`/`종료하기` |

원본800×600 좌표로 환산하면 창은 약 `(258,122,285,168)`이다. ID·비밀번호·인증번호는 작은 밝은 회색 글씨, 입력칸은 검정, 버튼은 진한 붉은색/회색 금속 입체 버튼이다. 창 너비가 화면의 약36%이고 화면 중앙보다 위에 있다. 현대식 큰 카드·청색 발광·장문의 로그인 설명은 없다. 원본 포인터 모양 손 커서가 x370/y247 부근에 찍혀 있으므로 원화 자체에 포함된 그림으로 오해하지 않는다.

제품에 사용하려면 실제 입력·버튼과 오프라인 플레이 흐름을 구현해야 한다. 원본 전체 스크린샷의 죽은 버튼을 동작하는 UI처럼 제시하면 안 된다. 새로운 제품 자산을 만들거나 기존 자산을 바꾼 것은 이번 조사에 포함되지 않는다.

## 별도로 찾은 원화·후기 화면

[2015-11-23 회고](https://blog.naver.com/dlfdjr110a/220548105750)의 원문은 `blog2015-client-source.html`에 보존했고, 본문은 옛 플레이 경험을 설명하므로 이미지 게시일을 당시 클라이언트 캡처일로 간주하지 않는다.

- `blog2015-client-25.jpg`는529×379의 **깨끗한2010 로그인 원화**다. 2010 캡처와 같은 기사/금발 여성/백발 남성/로고가 있고, 입력 창·등급 표시·손 커서는 없다. SHA256 `ff8463e2d5d021020cc2c8526de6f6967c51814b344f32c4bb8ffce05fda1064`. 2011 불꽃 거인 원화와는 다르다.
- `blog2015-client-27.jpg`는519×394 실제 퀘스트 대기실이다. 왼쪽 붉은 머리 여성/커튼, 오른쪽7명 NPC의 얼굴과 노란 느낌표가 붙은 대륙 지도, 위쪽 작은 파란 메뉴/유틸리티 아이콘, 왼쪽 아래 `랜덤매칭`/`싱글플레이`/`방만들기`3행 버튼, 오른쪽 아래 시스템 로그가 보인다. SHA256 `323ef9feee7833d1a9620be751ca8d47dba7bb5d38383b70b296b02e86261824`.
- `blog2015-client-26.jpg`는 노르니르 카드 그림이며 전체 로그인 UI가 아니다. `blog2015-client-28.jpg`는 더 오래된 판마 홍보 포스터이며 네이티브 UI가 아니다.

[tinuu의 글](https://blog.naver.com/tinuu/220429652345)은 검색에2016-05-23으로 표시되며, 원본 이미지 업로드 경로는2015-07-24다. 원문은 `blog2016-tinuu-source.html`에 보존했다. 파일명·본문만으로 캡처 날짜를 새로 단정하지 않는다.

- `blog2015-tinuu-0232.jpg`550×412(SHA256 `7de8b86d8c01b259f2581b4447a0acd16b62695443819b302a457cb134972c93`)는 후기 대기실 위의 **내정보** 창이다. 원본 화면 안에800×600 크기 표시가 보인다. 창은 x286–531/y33–221, 왼쪽 큰 불꽃 거인 초상은 x300–373/y62–189, 오른쪽 닉네임·승패·등급·SP·XP·NEXT XP·히어로 속성·15자 한마디, 아래쪽 작은 저장/취소 버튼이다. 대기실 외곽은 검붉은색이고 이 팝업의 테두리는 푸른 금속색이다.
- `blog2015-tinuu-0244.jpg`550×413(SHA256 `c0a3aa84f73dc1992637601556bd1f446049c484790cc020a9be0545fc8ad71a`)는 두 독립5칸 코인 창·오른쪽 양 플레이어 초상과 작은 상태표·파란 불꽃 배경이 있는 실제 전투 화면이다.

`blog2017-eeuu-source.html`의2017-07-30 「이 게임을 아시나요?」는 회고 글이다. 직접 확인한 `blog2017-eeuu-3.jpg`는 **훨씬 오래된 갈색/금색 덱 편집 UI**다. 따라서2017년 게시일을 후기 클라이언트 캡처 날짜로 사용하지 않는다. 이 자료는2017-12-29 실제 접속 후기와 성격이 다르다.

## 새로 확인한2010 웹 상점

같은 폴더 `blog2010-web-card-purchase.jpg`(740×587, SHA256 `d0f2c19cbc3dd79621beec23d4be640a54add4bef2da9c1b484cac1ac402e2d4`)와 `blog2010-web-booster.jpg`(769×776, SHA256 `b1a29659bb4c890e3b34850169e29805058d4ebd5cff1c714345184888b0e323`)도 직접 봤다. [2010-02-25 리뷰](https://blog.naver.com/2001tngh/30081240806)의 웹 상점이며 후기에 대한 증거로 승격하지 않는다.

카드 구매는 흰색/연회색3열 격자에 카드 그림이 왼쪽, 작은 이름·희귀도·GP/SP·보유/구매 조건·구매/보기 버튼이 오른쪽이다. IE 구매 팝업은 카드·가격·잔액·인증번호·수량·확인/취소를 표시한다. 부스터 화면은 위쪽의 팩 그림·가격·카드/랭크 구성표와 아래쪽 검색 행·3열 카드 격자로 구성된다. 검은 전투 화면과 같은 색의 상점은 아니다. 후기 네이티브 상점 전체는 여전히 미확인이다.
