### 800×600 로그인 좌표와 모양

- 원본 그림은 왼쪽의 금발 여성·상단 왼쪽 검은 기사·오른쪽의 백발 갑옷 남성으로 구성된다. 큰 녹색/금색/검은색 Fantasy Masters 로고는 대략 x240–573, y96–177이다. 위아래는 검게 어두워지고 우상단에는 녹색 `전체이용가` 타원이 있다.
- 중앙 게임접속 창 바깥은 대략 `(267,236,265,189)`, 내부 남색 판은 `(287,250,224,160)`이다. 검은 무늬 금속 바깥틀과 아주 얇은 회색·청색 안쪽 테두리가 겹친다.
- 제목은 y269 부근, 작은 밝은 회색 고딕/세리프 혼합 느낌이다. 폰트 파일 자체는 식별하지 못했다.
- 행은 y303/331/360 부근의 아이디/비밀번호/인증번호이며, 검은 입력칸은 대략 x349–506이다.
- 하단에는 x294/367/440, y383 부근의 `ID 만들기`/`접속하기`/`종료하기` 작은 청록 회색 입체 버튼이 있다. 큰 현대식 카드·발광 장식·부연 설명 패널은 없다.

### 800×600 서버 선택 좌표와 모양

- 전체 창은 대략 `(230,111,340,340)`, 내부 남색 판은 `(250,123,300,316)`이다.
- 목록은 `(273,169,254,190)`의 검은 영역이며 작은 회색 글씨로 `Standard Server(초중급)`, `Master Server(고급) -권장-`가 보인다.
- 하단 버튼은 대략 `(329,407,65,23)`, `(408,407,65,23)`다.

제품에서는 이러한 구획을 실제 동작하는 입력·버튼으로 재현해야 한다. 죽은 입력칸·버튼이 박힌 스크린샷 한 장으로 대체했다는 사실을 감추면 안 된다. 원화나 UI 조각의 별도 원본 확보가 가장 좋다.

## 시기와 화면 종류를 바꾸지 말 것

- `inven-season2-20090204.html`은 [2009-02-04 제오닉스 보도자료](https://www.inven.co.kr/webzine/news/?news=19610)다. 시즌2에서 로그인·로딩·게임 BG를 새로 바꿨다고 명시한다. 기사 안 네 원본 JPG는 현재 오래된 IP 호스트를 가리킨다. 시도한 두 HTTP 원본은503, 한 Wayback 경로와 추정 CDN 경로는404였다. 실패는 보존했으며 복구 성공으로 세지 않는다.

## 후기 클라이언트와 상점의 남은 공백

현재 실제 후기 클라이언트의 가장 강한 원본은 `Tools/Research/FmChronicle/VideoFrames/Live2017December/0001.0s.png`(2017-12-29 접속 후기의 대기실), 같은 폴더 `0056.0s.png`(전투), `BlogImages/LastPvp2018Post-0.jpg`(2018-10-12 회고에 실린 내정보/퀘스트 지도)다. 마지막 자료의 게시일은 확인되지만 캡처 당일은 확인되지 않는다.

2010 리뷰는 카드를 사려면 게임을 종료해야 한다고 불편을 설명한다. 공식 후기 매뉴얼에도 CardMarket/DeckStore/PointMarket/SkinShop/Booster의 웹 경로가 남아 있다. **2014–2018 네이티브 상점의 실제 화면은 이번 조사에서도 아직 확인하지 못했다.** 2010 웹 상점이나 현재 복원 상점을 종료 직전 네이티브 상점으로 표시하면 안 된다.

공식 `faq966.html`의201404171658/1659 이미지는 FM사이트맵 상점 연결 그림이며, `faq741.html`의 `manual_img_01.gif`–`07.gif`는 기본덱 웹 상점 연결 그림이다. 화면 전체인지 직접 확인하기 전에는 상점 스크린샷으로 세지 않는다.
