# 현재 카드 제품의 등급 안내 원본 수집 초안

아직 실행하지 않았습니다. template의 `requiredBuildSummary`는 null이며, 실패한 CardWeb01 또는 그 뒤늦은 Unity 산출물로 실행할 수 없습니다. 실제 새 CardWeb02의 전체 common build·복원·자식 종료·durable proof가 성공한 경우에만 실행 담당이 새 계획 파일에 정확한 summary full reference를 넣습니다. 이전 template이나 증거 원문은 재작성하지 않습니다.

이 도구는 PC1280×720과 touch844×390에서 실제 canvas 사각형에 맞춘 일반 마우스/터치 입력으로 타이틀→도감→등급 안내→도감 복귀 원본을 수집합니다. read-only DOM 준비/geometry/input capabilities 확인과 실제 PNG만 사용하며 게임 상태·저장·RNG·자세 주입은 없습니다. 새 출력은 고유 persistent Autonomy 경로여야 하고, source와 complete runtime은 전후 SHA/size로 대조합니다. Native04 Root0d·새 genuine build caller·proof·원본 build metadata의 결합도 필수입니다.

결과는 `originals-captured-visual-review-pending`이며 화면 내용은 직접 원본을 읽기 전까지 승인하지 않습니다. 8개 viewport 원본이 생겨도 full C1 PC162/touch163 입력, PCM4, reload2, 현재 규칙·저장, CI, paired recovery, Root, public 및985MB 전체 파일 검증을 대신하지 않습니다. `publishReady`, `baselineReady`, `fullC1Acceptance`, `RootVisualApproval`, `audioOrPerformancePass`는 모두 false입니다.

실행할 경우 전체 900초 이하/lease-60 예산과 실제 idle 확인은 단일 실행 담당의 바깥 제어에서 지켜야 합니다. 같은 시간에 Unity·다른 browser를 실행하지 않습니다. 새 browser와 loopback server는 정상/예외 경로에서 닫습니다. 기존 공개 서버·배포 설정은 변경하지 않습니다.
